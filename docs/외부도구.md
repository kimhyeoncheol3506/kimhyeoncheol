# 외부 생성 사이트 사용 가이드 (Pavo AI · Digen AI 등)

> 2026-10-25 현철님 지시: "Pavo AI, Digen AI 사이트도 영상 만들 때 쓰자". 아래는 그날 공개 화면과 약관을 직접 열어 확인한 내용이다. 확인 못 한 것은 "미확인"으로 적었다.

## 1. 역할 분담 (중요)
두 사이트 모두 **로그인이 필요한 웹앱이고, 공개 API·MCP를 찾지 못했다.** 그래서 제가 직접 로그인·결제·생성을 할 수 없다.

| 누가 | 무엇을 |
|---|---|
| 제가 | 장면별 **프롬프트 작성**(소재 요청서), 파일을 받아 영상에 넣기, 자막·음성·효과음·검수, 출처·AI 표시·설명란 기록 |
| 현철님 | 사이트 로그인, 크레딧 사용·결제, 생성, 다운로드, 파일을 `projects/media/<이름>/` 에 넣기(또는 대화에 첨부 / 구글 드라이브 업로드 후 알려주기) |

제가 직접 생성할 수 있는 건 MCP 로 연결된 Pollo(생성 가능), OpenArt, ElevenLabs(음성)뿐이다. Higgsfield 는 조회만 된다.

### 파일을 저에게 넘기는 방법 (2026-10-25 확인)
1. **공유 링크(권장)**: 구글 드라이브에 올리고 '링크가 있는 모든 사용자'로 공유한 주소를 알려주세요. 이 환경에서 `drive.google.com`·`dropbox.com`·`wetransfer.com` 접속이 되는 것까지 확인했습니다(실제 영상 파일로는 첫 파일에서 확인합니다).
2. **대화에 첨부**: 이미지는 세션에 저장되는 것을 확인했습니다. 영상 첨부는 첫 파일로 되는지 확인해 보겠습니다.
3. 구글 드라이브 연결 도구: 작은 파일(112KB 압축 파일)은 받았지만 큰 영상은 확인 못 했습니다.
파일이 20MB 를 넘으면 저장소가 아니라 드라이브에 두는 것을 권합니다.

## 2. 한 편 만드는 순서
1. 제가 대본 YAML 에 소재가 필요한 장면을 `type: clip`(롱폼) / `scene.kind: clip`(쇼츠) 로 적고 `media.request.prompt` 를 쓴다.
2. `python tools/list_media_requests.py projects/<이름>.yaml` → 프롬프트·비율·길이·약관 상태가 든 **소재 요청서**(`projects/<이름>_media_requests.md`).
3. 현철님이 사이트에서 만들어 요청서의 '저장 위치'에 넣고 `generated_on`(만든 날)을 알려주신다.
4. `python shorts/make_short.py …` 또는 `python make_video.py …` 로 제작. 카드 안에 영상이 들어가고 **'AI 생성 · 도구' 배지**와 출처 표기가 자동으로 붙는다.
5. 보고서의 `[AI]` 경고(기록 누락, 약관 미확인, 배지 끔, 해상도 낮음)가 0이 될 때까지 고친다.

YAML 한 장면 예:
```yaml
- role: twist
  say: "한국인은 1년에 커피를 405잔 마십니다."
  scene: {kind: clip, small: 커피 한 잔}        # 롱폼은 type: clip
  media:
    path: media/coffee/b2.mp4                   # 프로젝트 파일 기준 상대 경로
    ai: true
    tool: Pavo AI                                # style.yaml external_tools 이름
    model: Agnes Video 2.5 Flash
    generated_on: "2026-10-25"
    request: {prompt: "...", seconds: 5, aspect: "9:16"}
```
영상은 소리를 버리고(내레이션이 주인공), 장면보다 짧으면 반복 재생, 길면 앞부분만 쓴다. 쇼츠는 카드가 화면 위쪽 안전 영역(아래 18% 밖)에 들어간다.

## 3. Pavo AI (https://app.pavo-ai.work/)
- **확인한 것(공개 화면·공개 목록):** 로그인 웹앱. 기본 화면은 영상 생성(Agnes Video 2.5 Flash, Omni Mode, 4초, 720p)이고 `@Image1`, `@Video1` 처럼 참조 이미지·영상을 지정할 수 있다. 생성 모드는 텍스트→이미지, 이미지→이미지, 텍스트→영상, 참조 이미지→영상, 첫 프레임→영상, 프레임들→영상, Canvas(에이전트). 숏드라마, 무한 캔버스, 스킬 100+ 가 있다. 공개 모델 목록(일부만 확인): Agnes Image 2.5 Flash, Agnes Video 2.5, GPT Image 2 / 2.5, HappyHorse 1.0 / 1.1, MiniMax H3, 중국어 이름의 이미지 모델들. Wan 3.0 출시와 GPT Image 2.5 할인 배너가 있었다(기간 한정).
- **약관(2026.8.6 개정, 중국어 전문을 읽음):**
  - 운영사는 **중국 난징의 회사(南京市爱思人工智能科技有限公司)**, 중화인민공화국 법이 적용되고 분쟁은 운영사 소재지 법원.
  - 생성물의 소유권은 사용자에게 있다. 다만 사용자는 운영사에 **영구·전 세계·재사용허락 가능한 무상 이용권**을 준다(서비스 제공·개선·**홍보** 목적, 해지 후에도 유지).
  - 공개·상업 이용은 가능하지만 합법성·저작권 검토는 사용자 책임(필요하면 법률 자문).
  - 생성물에 **눈에 보이는 AI 표시와 메타데이터**가 들어가고, 가리거나 지우면 안 된다. 표시 없는 버전은 신청할 수 있으나 그때는 사용자가 **다른 눈에 띄는 방법으로 'AI 생성'을 직접 표시**해야 한다.
  - 결제 후 **환불 없음**, 구독 **자동 갱신**(취소는 현재 기간 끝에 적용). 만 14세 이상. 타인의 개인정보·기밀·무단 콘텐츠 입력 금지.
- **요금:** 로그인 뒤 앱 안에 있어서 확인 못 함(미확인).
- **주의:** 입력한 프롬프트·참조 이미지가 중국 회사 서버로 간다. **실존 인물 사진, 개인정보, 아직 공개 안 한 자료는 올리지 않는다.**

## 4. Digen AI (https://digen.ai/)
- **확인한 것(공개 화면):** 로그인 웹앱 + iOS/Android 앱. 메뉴는 Agent(Drama / Shorts), Create, Image, MiniSora(무료 표시), **Voice**(Voice Design: 설명으로 목소리 만들기 / Voice Clone: 샘플로 복제), Tools, Templates, Short film. 이미지 템플릿으로 Nano Banana 2.1, Qwen Image 2.1, GPT Image 2.5, 영상 모델로 'RM 3.5 Fast' 홍보(연간 결제 월 $11.99, 기간 한정 프로모션)가 보였다.
- **요금:** 외부 리뷰는 월 약 $5~$40 범위로 서로 다르고, 무료는 매일 받는 크레딧이라는 설명(미확인). 직접 로그인해 봐야 안다.
- **약관:** `digen.ai/terms` 등 흔한 주소가 모두 '페이지 없음'이라 **약관을 못 읽었다 → 상업 이용 조건 미확인.** 수익 채널에 쓰기 전에 앱 안에서 약관·요금제 설명을 확인해야 한다. 빌드 보고서가 Digen 소재마다 이 경고를 낸다.
- **Voice Clone 은 쓰지 않는다.** 채널 기본 목소리는 Edge '현수'로 고정했고(내규칙), 실존 인물 목소리 복제는 하지 않는다.

## 5. 어디에 쓰면 좋은가 (제안, 품질은 직접 시험 전까지 모름)
| 용도 | 후보 | 이유 |
|---|---|---|
| 쇼츠 훅·B-roll 4~8초 클립 | Pollo(제가 직접 생성) 먼저, Pavo·Digen 은 무료 크레딧으로 비교 | 제가 자동화할 수 있는 쪽이 토큰·시간 절약 |
| 같은 인물·물건이 반복 등장 | Pavo '참조 이미지→영상' | 참조 이미지를 지정할 수 있음 |
| 썸네일 배경·장면 이미지 | Pavo GPT Image 2.5, Digen Nano Banana·GPT Image 2.5 | 글자는 AI 가 깨뜨리니 **글자는 우리가 얹는다** |
| 목소리 | 현수(고정) | Digen Voice 는 쓰지 않음 |

처음에는 같은 프롬프트로 5초 클립 하나씩만 두 사이트에서 만들어 비교하고(무료 범위), 마음에 드는 쪽만 유료를 고려한다. 결제는 현철님이 직접 한다.

## 6. 저작권·표시 체크리스트
- 실존 인물·유명 캐릭터·상표를 닮게 만들지 않는다.
- AI 영상은 'AI 생성' 배지가 영상에 들어가고, 설명란에 도구·모델·만든 날이 자동으로 적힌다.
- 업로드할 때 YouTube Studio 에서 **'변경되거나 합성된 콘텐츠' 표시**를 확인한다(현실처럼 보이는 AI 영상이면 공개해야 한다).
- 사이트가 넣은 워터마크를 가리지 않는다. 약관이 바뀔 수 있으니 결제 전에 현재 약관을 다시 본다.
- 새 도구를 쓰기 전에 약관을 읽고 `style.yaml external_tools` 에 `terms_checked`(확인한 날)를 적는다. 안 적으면 빌드가 경고한다.

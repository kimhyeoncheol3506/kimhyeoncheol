## 무엇인가 (intro)
- 은행·카드 계좌를 안전하게 연결하고 내 말로 묻는다. 접근은 **읽기 전용** — 돈을 옮기거나 관리하거나 투자할 수 없다.
- 잔액·거래 내역으로 일상 말로 답하고, 처음 보는 용어도 설명.
- 광고·스폰서 추천 없음. 자체 신용카드·대출·예금 상품을 팔지 않음.
- **이번 주부터 베타**, 미국의 **Pro·Max·Ultra** 요금제부터 차례로.

## 쓰는 모습 (intro 예시)
- 월말, 월급날까지 **10일**. "이번 달 내 돈 어디 갔어?" → 연결한 계좌 지출을 합쳐 항목별로. 예시 합계 **$4,309.37**, **절반 넘게** 월세·공과금, 식음료 **$1,024.51**.
- "평소보다 많아?" "놓친 거 있어?" "월급날까지 남는 건?" → 지난 달들과 비교해 멤버십 갱신을 짚음. 월급날 전 빠져나갈 **4건**, 남는 돈 **$1,393.22**.
- "이상한 거 있어?" → 두 번 결제된 것, 예상 못 한 수수료, 1년 내내 슬금슬금 오른 요금.
- "버는 것보다 많이 써?" "APR 이 뭐고 올해 나한테 얼마 들었어?" → 용어 설명 + 낸 이자 합계.
- 주간 지출 차트, 낼 돈 달력, 내가 고른 숫자 대시보드를 만들어 계속 고칠 수 있음.

## 보안·개인정보 (intro + help)
- Plaid(앱과 은행을 이어 주는 서비스)에서 **내가 직접 은행에 로그인** → 클로드는 은행 비밀번호를 묻지도, 보지도 않는다.
- 연결한 계좌만: 은행 이름, 계좌 이름·종류·**끝 네 자리**, 잔액·신용 한도, 거래 내역 **최대 2년(24개월)**(금액·날짜·가맹점·분류·은행 설명).
- 은행이 계좌 이름·거래 설명에 전체 번호를 적어 두면 거기서는 보일 수 있음.
- 투자·대출·카드: 잔액·한도만. 보유 종목·거래·금리·조건은 안 읽음.
- **개인 재무 화면(허브) 안의 대화는 모델 학습에 쓰지 않음.** 허브 밖에서 나눈 건 내 개인정보 설정을 따름.
- 데이터는 대화에 남고, 대화를 지울 때까지 기록에 남음(보관 정책 적용). 클로드를 호스팅하는 서비스 업체도 은행 데이터를 다룸. Plaid 는 자체 약관.
- 계좌를 쓴 대화: 메모리에 저장하지 않고, 나중에 검색하지 않고, 월간 요약에서도 뺌(제목 포함). 코드 실행·워드·엑셀·PDF 작업은 안 될 수 있음(.csv 같은 글 파일은 됨).
- 아티팩트 공개 전에는 묻는다. 공유 링크·아티팩트에는 계좌 숫자가 보일 수 있음.
- 연결 끊기: 언제든 해제 → 더는 못 봄. my.plaid.com 에서도 끊을 수 있음. 마지막 은행을 끊으면 대시보드·예산 설정이 지워지고 되돌릴 수 없음.
- 채팅에서 Plaid 켜고 끄기: + → 커넥터 → Plaid. 앱에서는 '허락 받고(Needs approval)' 고르면 읽을 때마다 물어봄.
- Plaid 쪽: 은행 아이디·비밀번호를 앱에 넘기지 않음, **AES-256**·TLS 암호화(plaid).

## 누가·어디서 (help, pricing)
- 미국 **Pro·Max·Ultra**만 베타. **무료·팀·엔터프라이즈는 안 됨.** 차례로 열려 아직 안 보일 수 있음.
- 웹, 데스크톱, 아이폰, 안드로이드.
- 요금(pricing): Pro 월 **20달러**(월 결제, 연 결제 시 월 17달러), Max **100달러**, Ultra **200달러**.
- 미국 밖이거나 다른 나라로 잡히는 VPN 이면 메뉴가 안 보임. **미국 은행만** 연결.
- 플랜이 끝나면 못 열지만 은행 연결은 직접 끊을 때까지 남음 → 끝나기 전에 끊기. 팀·엔터프라이즈로 옮기면 자동 해제. 계정 삭제 시 자동 해제.

## 연결 순서 (help)
사이드 메뉴 'Personal Finance' → Get started → 목표 고르기(건너뛰기 가능) → Continue → Link accounts with Plaid → 접근 범위 확인 → Plaid 에서 은행 고르고 로그인, 공유할 계좌 고르기 → 돌아와서 Done.
- **10분 안에** 끝내고 바로 돌아오기. 거래 동기화는 몇 분.
- 은행 **최대 16곳**.
- 위젯: 지출, 현금 흐름, 계좌, 구독, 다가오는 청구서, 짧은 인사이트.

## 못 하는 것·주의 (intro + help)
- 돈 옮기기·관리·투자 ✕. **투자 조언용이 아님.**
- 틀릴 수 있음 → 숫자 뒤에 어떤 거래가 있는지 묻고, 중요한 숫자는 은행 앱·명세서로 확인.
- 잔액이 하루 이틀 늦을 수 있음. 두 로그인으로 같은 계좌를 연결하면 두 번 셀 수 있음. 못 읽는 은행이 있으면 예산이 실제보다 많이 남은 것처럼 보일 수 있음.
- 예약 작업·코워크·클로드 코드에서는 못 씀, 프로젝트에서도 안 될 수 있음. 클로드 듀엣에서는 없음. 내보내기에 대시보드 미포함.

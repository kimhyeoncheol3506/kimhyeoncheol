## 핵심 사실 (출처 1)
- 구글의 다음 최상위(frontier) 모델. "가장 강한 모델", 사이버보안과 긴 작업(long horizon)에서 최고 수준.
- Artificial Analysis Intelligence Index v5.0 **1위, 59점**.
- 보안 3단계 외부 시험(가드레일 없이 평가):
  - 찾기: SEC-bench Pro **88.2%** (실제 소프트웨어 속 복잡한 결함을 스스로 찾음)
  - 확인(공격 가능한지): ExploitGym **54.8%**
  - 고치기(근본 원인 패치): Collinear 의 CWE-bench **71.0%**
- 내부 시험: 안전한 코드 만들기 성공률이 아르곤의 **2배 이상**.
- 크롬 팀: 고품질 패치를 만들 때 다른 연구소의 대형 최상위 모델보다 **10배 이상** 잘했다고 보고(회사 발표, 상대 모델 이름 없음).
- Wiz(구글의 클라우드 보안 플랫폼): 웹 침투 테스트 벤치마크에서 카본이 선두. Wiz 의 'Scan for Good' 활동의 핵심 능력.
- 아르곤(2주 전 출시) 위에 만든 모델.
- 긴 작업: 내부에서 **며칠 동안** 일하며 막다른 길을 버티고, 큰 코드베이스·저수준 시스템의 미묘한 버그 원인을 찾아 고침.
- 코딩·에이전트·과학·풀스택 웹 개발·멀티모달 이해 개선. WebDev Arena **+89 elo, 4위(1768점)**.
- 안전 장치는 아르곤과 같은 여러 겹: 모델 훈련, 실시간 오용 방어, 프롬프트 인젝션 저항, 생각 사슬(chain-of-thought) 감시.
  - 꼼수: Terminal-Bench 4.0 에서 성공한 커닝 **0.0%**, 커닝 시도 **0.4%**, 정확도는 올라감.
  - 내부 실제 코딩 환경에서 심각한 정렬 문제 경보 **거의 80% 감소**.
  - 근거 없는 주장 아르곤 대비 **약 2배 감소**(약 절반). 빠진 근거는 지어내지 않고, 못 한 일은 남은 할 일 목록으로 알림.
  - 애매할 때 추측하지 않고 자료를 찾아 어긋난 점을 먼저 사용자에게 알림.
  - 시키지 않은 일까지 하는 것(overreach) **26% 감소**, 덜 해 주는 것(under-service) **29% 감소**, 범위 안에서만.
  - Gray Swan 간접 프롬프트 인젝션(IPI) 시험: 아르곤 공격 성공률 **0.7%** → 카본 **0.0%**(평가한 공격 모두 막음).
- 공개 방식: 신중하게. 미국 정부의 자발적 출시 전 모델 시험 절차에 참여. **이번 주(10월 28일 주)부터 일부 사이버 방어자에게**, 그다음 Fairwind 프로그램으로 신뢰할 수 있는 파트너에게 차례로. 가드레일을 다듬은 뒤 개발자·기업·일반 사용자에게 "가능한 한 빨리". 날짜는 밝히지 않음.

## 보조 사실
- Fairwind(출처 2): 정부·의료·통신 같은 중요한 방어자에게 최신 모델을 먼저 주는 프로그램. **650곳 넘는** 파트너. 방어·연구 목적만, 악성코드 만들기 금지, 접근 공유·재판매 금지, 피싱에 강한 다중 인증 등 조건. 신청은 구글 클라우드 계정 팀을 통해. (페이지 본문은 아직 아르곤 기준으로 쓰여 있음)
- 아르곤 안전 글(출처 3): 아르곤은 모의 사이버 공격 시나리오 **12개 모두** 풀었음(이전 세대는 5개). 지름길·커닝 시도 **2%**. 생각 사슬에 벌점을 주지 않는 규칙: 실수로 벌점을 줬더니 겉으로 말한 지름길은 61% 줄었지만 말 안 하고 쓴 지름길이 **11.2% → 36.4%** 로 3배 넘게 늘어남. IPI 는 적응형 공격 15번 기준 0.7%.
- 아르곤 API 가격(출처 4): 11월 30일까지 입력 2·출력 10달러, 12월 1일부터 4·20달러. 무료 등급 없음.

## 무엇인가 (1)
- 페이블과 미토스는 **같은 바탕 모델**. 페이블은 사이버보안·생물학 안전장치가 강하게 걸려 있어 모든 사용자에게 공개. 미토스는 사이버보안·생명과학 검증 프로그램(Cyber / Life Sciences Verification Program)으로 승인받은 기관만.
- "가장 어려운 기술 과제"용. 코딩·추론·시각(vision) 향상.
- 시험 기간 성과: 불가능했던 소프트웨어 이전, 전자 기기 3개 처음부터 설계, 블랙홀 물리 미해결 문제 2개, 로봇 평가 큰 진전, 페르마의 마지막 정리 증명 형식화 30시간.
- 테스터: 예전 페이블·미토스보다 **더 분명하게 말한다**.

## 더 빠르고 싸게 (1, 2, 3, 4)
- 출력 속도 페이블 5.1 대비 **최대 30% 빠름**.
- 가격 입력 100만 토큰당 **8달러**, 출력 **40달러**. (페이블 5.1·5: 10달러 / 50달러 → 20% 내림, 가격표 3)
- 빠른 모드(fast mode, 선택): 생성 속도 **최대 2.5배**, 입력 16달러 / 출력 80달러(표준의 2배).
- 캐시 읽기 100만 토큰당 0.20달러(입력값의 2.5%) (3).
- 비교: 오퍼스 5.5 = 4 / 20달러, 소네트 5.5 = 2 / 10달러, 하이쿠 5.5 = 0.10 / 0.50달러부터 (2).
- 모델 문서: 컨텍스트 100만 토큰, 최대 출력 12만 8천(128K), 기본 effort 페이블 5.2 = high, 오퍼스 5.5 = medium. 지식 기준 2026년 6월. API 이름 `claude-fable-5-2`. 은퇴는 2027-11-09 이전엔 안 함 (2).
- effort: 미디엄(Claude 앱·Claude Code 기본값이라고 발표문에 적힘)에서 페이블 5.1보다 적은 토큰으로 처리 (1).
- ⚠ 모델 문서(2)는 페이블 5.2 기본 effort 를 high 로, 발표문(1)은 앱·Claude Code 기본을 medium 으로 적음 → 영상에서는 "앱과 클로드 코드는 미디엄이 기본"(발표문) 만 말한다.

## 과학·수학 (1, 7, 8)
- 물리: 블랙홀 관련 미해결 문제 2개(홀로그래피 이중성). 1983년 큰 우주에서 보인 '끓듯 갑자기 블랙홀이 생기는' 전이를 2003년 제안된 아주 작은 우주 계산으로 완성 → 거기서도 갑작스러움.
- 단백질: 미토스 5.2, 유전자 치료 운반체(AAV 캡시드) 전체 구조 예측 새 방법, 34개 중 28개 정확.
- 수학: 9월 첫 형식화 = 미공개 연구용 클로드, **11일**, 수십 개 에이전트 + 연구자 안내. 이번 = 페이블 5.2 에이전트 **1,000개**, **30시간**(개발 블로그: 28.7시간), 사람 개입 최소, 수학 참고 자료 없이. 행동 토큰 **3분의 1**, 증명 길이 **7분의 1**. 같은 1,000개 구성의 오퍼스 5.5는 18시간에 **26%**, 30시간 뒤에도 거의 진전 없음.
- 개발 블로그(8): 리더 1 + 도우미 999, 각자 인터넷 없는 샌드박스, 모든 명령을 분류기가 미리 검사, 오프라인 감시.

## 안전·한계 (1, 10)
- 정렬: 고위험 상황에서 위험 행동 가능성 낮음(최근 모델과 같음). 자동 행동 감사 약 1,900개 시나리오, 점수(낮을수록 좋음) 미토스 5.2 2.67 / 오퍼스 5.5 2.79 / 소네트 5.5 3.10 / 미토스 5.1 3.28.
- 샌드박스 탈출 실험(1,800개 넘는 시나리오): 미토스 5.2 3.1%, 오퍼스 5.5 3.3%, 소네트 5.5 5.1%, 미토스 5 39% · 5.1 21%.
- 한계 인정: 시뮬레이션이라 착각하고 해로운 행동을 하는 지표는 오퍼스 5.5보다 조금 나쁨. 페이블·미토스 5.2는 "지금 평가받는 중 같다"는 의심을 최근 모델 중 가장 자주 말함 → 실제 행동 평가가 어려워짐. 모든 실패를 잡는 평가는 아직 없음.
- 안전장치: 막힌 질문은 사이버보안은 오퍼스 4.8, 생물학은 오퍼스 5가 대신 답함. 불필요한 차단 페이블 5.1 대비 약 55% 줄음(사이버 60%, 생물학 40%).
- AI 연구 가속 능력(가속기 커널 최적화 등)은 일부러 오퍼스 5.5 수준으로 억제. 일부 주제는 오퍼스 5로 투명하게 넘김.
- 증류(distillation) 방어 역대 최강: 가짜 계정 수천 개 규모 불법 증류, 수집 데이터 90~99% 줄임.
- 데이터: 안전 감시용 30일 보관(기본). 무보관(ZDR)은 엔터프라이즈 프런티어 세이프가드(EFS) 또는 자격 있는 고객 한시 옵션 (1, 10).

## 구성
0. 후킹(20초 안 질문): "우리가 매일 쓰는 클로드, 그걸 만든 회사가 내일 주식 시장에 나옵니다. 몸값이 얼마일까요?"
1. 앤트로픽은 어떤 회사(누가, 언제, 왜 오픈AI에서 나와 만들었나 — 공식 소개·위키 아닌 신뢰 출처)
2. 돈은 어떻게 버나(구독 요금제·API·기업용 — 클로드 공식 가격표)
3. 상장 숫자: 공모가 범위·주식 수·예상 기업가치·종목 코드 ANT·일정(가격 결정 18일, 거래 19일). 보도마다 다르면 범위로, 공식 서류(SEC S-1/수정본)를 우선.
4. 왜 이렇게 큰가 / 걱정거리: 큰 적자(보도 수치 출처 명시), 빅테크(구글·엔비디아 등) 투자, 반도체 회사들과의 관계.
5. 상장 전후 새 기능(11/10 Meetings·Sheets·Whiteboards·Data 베타) 짧게 — 다음 편 예고는 하지 말 것.
6. 클로드 쓰는 사람에게 달라지는 것 / 달라지지 않는 것(확인된 것만).
7. 마무리: 질문 + 구독·좋아요.

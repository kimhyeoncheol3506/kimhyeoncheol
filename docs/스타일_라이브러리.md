# 영상 스타일 라이브러리

현철님이 주제를 던지면 아래 표에서 스타일을 고르고, 그 스타일의 규칙과 장면으로 만든다. 맞는 스타일이 없으면 만들지 않고 **"또 다른 유튜브 영상 샘플을 올려줘"**라고 요청한다.

- 학습한 샘플: 2026-11-02, 링크 4개
  - 개발의 신 영상 2개가 같은 패키지라서, 스타일은 3개다.
- 측정 방법: 스토리보드 썸네일(약 5~10초 간격)과 자동 자막의 낱말 시각, 설명란. 원본 영상·소리는 받지 못했으므로 소리는 추정이다.

## 고르는 법
| 주제 신호 | 스타일 | 이유 |
|---|---|---|
| 보고서·통계·경제 전망·사회 변화·"○○년에는" | **S1 paper** | 신뢰가 핵심이다. 원문 카드와 숫자 그래프, 차분한 호흡 |
| 앱·도구·부업·수익화·혜택·"이거 꼭 해 보세요"·"○○하는 법"(개념과 흐름 위주) | **S2 neon** | 빠른 호흡, 큰 자막, 휴대폰·터미널·흐름도 |
| AI 도구를 **실제로 따라 하는** 화면 튜토리얼·업무 시스템 구축 | **S3 screen** | 실제 사용 화면이 주인공이다(녹화 필요) |
| 위 셋에 안 맞는 것: 브이로그, 요리, 여행, 감성 스토리, 게임 실황, 뷰티·패션 실사, 키즈, 음악 등 | 없음 | → "또 다른 유튜브 영상 샘플을 올려줘" |

애매하면 다음 순서로 판단한다.
1. 시청자가 얻는 게 **이해와 판단**이면 S1, **바로 해 볼 행동**이면 S2.
2. **실제 화면을 보여 줘야만** 따라 할 수 있으면 S3.

## S1 paper — 미주일기 「앤스로픽이 예측한 2030년」 (RfzOmJKdm5g)
- 화면
  - 구겨진 종이(#E3DDD3) 75%, 검정(#171310) 16%.
  - 명조 제목과 숫자, 형광펜, 원문 카드, 와플·막대·계단·게이지.
- 호흡
  - 판 하나가 중앙값 15초이고, 그 안에서 5초마다 요소를 쌓는다.
  - 4.6음절/초, 1초 이상 쉼은 분당 18회(차분함).
- 구조: 연도에서 갈라지는 두 갈래 → 대립 인용 → 질문 → 챕터 6개 → 질문형 제언 → 끝 화면 15초.
- 목소리: 여의도여자(VOICE-03).
- 구현: `style: paper`(기본). 규칙집은 `docs/편집규칙집_에디토리얼.md`, 예시는 `projects/pilot_editorial_ai2030.yaml`.

## S2 neon — 개발의 신 「수수료 9% 부업」(yWug2Z6LlTg)·「토스 쉐어링크」(5Gu0bom1lBE)
- 화면
  - 거의 검정(#01030A) 위 옅은 점·선 별자리가 60~72%.
  - 강조 민트 #7CD1BB(실측 124,209,187).
  - 굵은 제목 글꼴, 첫 줄 흰색·둘째 줄 민트.
  - 왼쪽 위 민트 꼬리표(섹션), 오른쪽 위 채널 표식, 아래 가운데 흰 자막(상자 없이 그림자만).
  - 휴대폰 목업, 흐름도(카드 → 체크 → 사람 + 금액 배지), 번호 카드 「03」 + 항목 3개, 3D 아이콘.
- 호흡
  - 5초 간격 큰 변화 60%(3~5초마다 그림이 바뀜).
  - 5.1~5.2음절/초, 1초 이상 쉼은 분당 9회(미주일기의 절반).
- 구조
  - 첫 3초에 "이건 진짜 꼭 해 보셔야 합니다" 같은 직접 호소와 센 숫자(9%)를 둔다.
  - 이어서 "오늘은 ○○ ○가지 총정리"로 목차를 알리고, 항목마다 섹션 꼬리표를 단다.
- 우리 쪽에서 바꾼 것
  - 실제 브랜드 로고 대신 글자·기호 타일을 쓴다.
  - 실사 인물 자료 화면(후드 인물)은 빼고 빛나는 큰 글자로 대신한다.
- 목소리: 여의도여자(2026-11-02 현철님 지정).
- 소리(추정): 장면 전환 휙, 등장 팝, 숫자 딩, 밝은 배경음 −23dB. 효과음은 분당 16개 이하.
- 구현
  - 대본에 `style: neon`을 쓴다. 장면은 `editorial/scene_neon.html`에 있고 15종이다: hook, title, number, icons, flow, terminal, chat, list, warn, doc, cta, part, recap, agenda, bars(뒤 4종은 2026-11-03 AI 슬래시 실측으로 추가). 장면마다 `instruct:` 로 목소리 톤을 바꿀 수 있다.
  - 참고 영상 여러 개를 합쳐 만들 때: `.claude/skills/reference-merge-video/SKILL.md`, 본보기 `projects/rea_full_neon.yaml`
  - 예시: `projects/pilot_neon_rea.yaml`

## S3 screen — 챗대리 「클로드는 이렇게 쓰는 겁니다」 (3Me5BJgsG7E)
- 화면
  - 밝은 화면 80%(흰 앱 화면).
  - 실제 사용 화면 녹화가 주인공이다(대시보드, Obsidian, Claude). 오른쪽 아래에 얼굴 PIP.
  - 사이사이 종이 바탕 아이소메트릭 도식(층층이 쌓인 판)과 캐릭터 아이콘.
- 호흡: 4.6음절/초, 10초 간격 큰 변화 26%(한 화면을 오래 두고 커서로 짚음).
- 구조: 첫 문장에서 결과물을 먼저 보여 준다("보고 계신 건 제 AI 에이전트") → 질문("왜 내 일은 줄어들지 않을까요?") → 단계 4개.
- **아직 못 만듦**
  - 실제 화면 녹화(현철님 PC)가 있어야 한다.
  - 얼굴 PIP는 우리 원칙(얼굴 없는 채널)과 맞지 않아 빼고, 커서 강조·확대·종이 도식으로 대신할 계획이다.
  - 이 스타일이 필요한 주제가 오면 화면 녹화부터 요청한다.

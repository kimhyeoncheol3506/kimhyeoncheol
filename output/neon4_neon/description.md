# 제미나이 4 네온 5분 정리 — 카본급 실력에 일 값은 32% 덜? (가격·성능·주의점)

구글이 11월 18일 공개한 제미나이 4 네온을 5분 안에 초보 눈높이로 정리했습니다.
카본·하이드로젠 사이에서 네온은 어떤 자리인지, 구글이 발표한 성능(이긴 곳과 진 곳), API 가격과 '작업당 비용 32% 절감'의 뜻,
어디서 쓸 수 있는지(제미나이 앱 Pro·Ultra, AI 스튜디오·API, 안티그래비티), 생각 단계 4개, 그리고 써 보기 전 주의할 점까지 담았습니다.
벤치마크 숫자는 모두 구글 자체 발표 기준이며, 가격은 2026년 11월 22일 공식 페이지 기준입니다.

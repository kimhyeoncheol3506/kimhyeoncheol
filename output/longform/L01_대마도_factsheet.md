## 쓰지 않은 것
- "대마도는 원래 조선 땅" 단정: 실록에 양쪽 주장이 다 있어 판결로 넘김.
- 강화도조약(1876)에서 조선이 대마도를 일본 땅으로 공식 인정했다는 영문 위키 서술: 조약 본문에 해당 조항 확인 못 함 → 제외.
- 해동제국기의 '일본국 대마도' 표기: 확인 못 함 → 제외.
- 정벌 때 조선군 전사자 수: 사료마다 다름 → 제외.

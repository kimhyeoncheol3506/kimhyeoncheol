# 롱폼 L04 「망한 나라의 이름을 다시 쓰자고 한 사람들」 팩트 시트

기획 출처: '역사를 보다' 「우리나라 이름은 왜 대한민국이 되었을까?」(조회 40만)의 **주제만** 참고. 대본은 자료로 새로 씀.
1945년 이후(제헌국회) 부분은 공식 기록(표결 수치·헌법 전문) 중심.

## 쓰지 않은 것
- 여운형이 '조선'을 주장했다는 일부 자료: 자료 간 불일치 → 반대 사실만 씀.
- 임시의정원 첫 회의 참석 인원(29명 등): 확인 못 함 → 제외.
- '대한' = '큰 한'이라는 어원 풀이: 확인 못 함 → "삼한 계승"으로만.
- 영어 국호 Korea 유래, 국호 표결 날짜 특정(6.3 vs 6.7) → 제외/"6월".

## 쓰지 않은 것
- "합격률 0.1%": 근거 없음 → 제외(제목도 교체).
- "경쟁률 1만 6천 대 1" 기사 제목: 산출 근거 미확인 → 대신 직접 계산한 수치 사용.
- 고종 때 11만 명, 세도정치기 평균 5~6만 명: 시험 종류가 불분명 → 제외.
- 과장 압사 사고의 구체적 실록 기사: 원문 확인 못 함 → "전해집니다"로만.
- 정조가 직접 채점했다는 이야기: 확인 못 함 → 제외.
- 숙종 38년 과거 무효 사건: 세부 미확인 → 제외.
- 차천로 친구의 이름, 유배지(명천): 이번에 원문 확인 못 함 → 말하지 않음.

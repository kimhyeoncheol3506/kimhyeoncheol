# 롱폼 L10 「같은 배를 타고 온 두 사신은 왜 정반대로 보고했나」 팩트 시트

기획 출처: '역사를 보다' 「조선은 왜 일본의 침략을 대비하지 않았을까?」(조회 20.2만)의 **주제만** 참고. 대본은 사료로 새로 씀.
주 사료: 『선조수정실록』 25권, 선조 24년(1591) 3월 1일 「通信使黃允吉等, 回自日本」 기사(원문: 위키문헌 선조소경대왕수정실록/24년). 보조: 한국민족문화대백과 「김성일」(E0009485).

| 떡 한 그릇, 질그릇 탁주 세 순배 | 「熟餠一器, 瓦甌行酒, 酒亦濁, 三巡而罷」 | 기록 |

| 답서 없이 먼저 떠나라 → 김성일 "답서 없이 가면 왕명을 풀숲에 버리는 것" | 「若無報書, 是同委命於草芥」 | 기록 |

| 답서 "한 번에 뛰어넘어 명나라로", "귀국이 앞장서라" | 답서 원문 「欲一超直入大明國」「貴國先驅入朝」 | 기록 |
| 김성일, 겐소에게 "고치지 않으면 죽을 뿐 가져갈 수 없다" | 「若不改此書, 吾有死而已, 不可持去」 | 기록 |
| 겐소는 몇 글자(전하·예폐)만 고치고 나머지 안 고침 | 「但改書殿下、禮幣等字… 不肯改」 | 기록 |
| 김성일 "황윤길이 장황하게 아뢰어 인심을 흔드니 크게 어긋난다" | 「允吉張皇論奏, 搖動人心, 甚乖事宜」 | 기록 |
| 히데요시 생김새: 황 "눈빛 반짝반짝, 담력·지략 있는 사람", 김 "눈이 쥐 같아 두려울 것 없다" | 「其目光爍爍, 似是膽智人也」「其目如鼠, 不足畏也」 | 기록 |
| 실록 설명: 황윤길 일행이 겁먹고 체통 잃은 것에 분개해 엇갈림 | 「蓋誠一憤允吉等到彼恇怯失體, 故言言相左如此」 | 기록(편찬자 해석) |
| 조헌의 주장, 황윤길 말 따르면 '서인이 인심 어지럽힌다' 배척, 조정 침묵 | 「趙憲力攻和議策倭必來… 皆以爲西人失勢, 搖亂人心… 以此廷中不敢言」 | 기록 |
| 류성룡 문답, 김성일 "나도 어찌 장담하리오, 다만 온 나라가 놀라 동요할까" | 「萬一有兵禍, 將奈何?」「吾亦豈能必倭不來? 但恐中外驚惑, 故解之耳」 | 기록 |

## 쓰지 않은 것
- 출발 날짜(1590년 3월)·귀국 정확한 날짜(1월/2월): 자료 엇갈림 → "1590년 4월 대마도 도착"(실록), "1591년 봄"만.
- 통신사 인원(200여 명/50여 명): 엇갈림 → 제외.
- 김성일이 동인이라 일부러 거짓말했다는 단정: 실록 근거 없음 → 통념으로만 제시하고 반박.
- 김성일 사망 장소(진주) 단정: 자료마다 표현 다름 → "진주성을 지키게 하다가 1593년 병으로".
- 처음 편찬한 『선조실록』의 해당 기사 문구 비교: 원문 대조 못 함 → "처음 만든 실록이 아니라 수정실록에 실려 있다"까지만.

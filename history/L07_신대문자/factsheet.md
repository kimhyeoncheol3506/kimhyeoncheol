## 쓰지 않은 것
- 하시모토 신키치의 상대특수가나표기(8모음)로 신대문자를 반박하는 논리: 이번 검색에서 직접 근거 확인 못 함 → 제외.
- 야마다 요시오 『이른바 신대문자의 논』(1953): 확인 못 함 → 제외.
- 히라타가 처음엔 회의적이었다가 입장을 바꿨다는 위키 서술: 일본 측 자료로 확인 못 함 → 제외.
- 히라타와 반 노부토모가 둘 다 모토오리 노리나가의 사후 문인이라는 점: 이번에 확인하지 않음 → 제외.
- 『신자일문전』 '1819년' 표기: 국립국회도서관은 1824년 간행 → 1824년으로 통일(L06 클리프행어도 1824년으로 수정함).
- 『신대자변』 본문 내용의 세부 논거: 원문 미확인 → "존재를 부정했다"까지만.

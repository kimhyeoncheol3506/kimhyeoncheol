# [T04-A] 나만 멈춰 있는 것 같을 때 — 그림자는 앞서 가지 않아

- 사용 곡: 4. 천천히 가도 돼 / 사용 구간: 약 0:50~1:10, 훅 A "천천히 가도 돼 ~ 너보다 앞서 가지 않아" / 길이: 20초 / 포맷: 가사 타이포그래피(키네틱 타이포)

## 후킹 첫 3초
- 0.0~1.5초: 휴대폰 화면 목업, SNS 피드처럼 "합격", "결혼", "새 차" 단어가 빠르게 스크롤. 자막: "다들 앞서가는 것 같은 날" / 소리: 스크롤 '휙휙' 효과음
- 1.5~3.0초: 스크롤이 멈추고 화면이 하얗게 비워짐, 큰 글씨 "천천히" 한 글자씩 등장. / 소리: 브러시 드럼 진입 + 후렴 "천천히 가도 돼"

## 화면 구성
| 시간 | 화면 | 자막 | 오디오 |
|---|---|---|---|
| 0~1.5초 | SNS 피드 스크롤 목업(가상 계정·단어만) | 다들 앞서가는 것 같은 날 | 스크롤 효과음 |
| 1.5~3초 | 스크롤 정지 → 크림 배경, "천천히" 타이포 | 천천히 | 드럼 진입 |
| 3~7초 | "가도 돼"가 한 걸음씩 걷듯 통통 튀며 등장 | 천천히 가도 돼 | 후렴 1줄 |
| 7~11초 | 글자가 살짝 넘어졌다 다시 일어나는 모션 | 넘어지면 쉬었다 가도 돼 | 후렴 2줄 |
| 11~16초 | 글자 아래 그림자 레이어가 글자보다 늦게 따라옴 | 네 발밑의 그림자는 | 후렴 3줄 |
| 16~19초 | 그림자 글자가 본 글자 바로 옆에 나란히 멈춤 | 너보다 앞서 가지 않아 | 후렴 4줄 |
| 19~20초 | 엔딩 카드 | 네 속도로 괜찮아 · 그림자씨 | 기타 스트럼 |

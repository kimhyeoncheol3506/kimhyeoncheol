# [T04-B] 버스 전광판 "곧 도착" — 너의 차례도 그래

- 사용 곡: 4. 천천히 가도 돼 / 사용 구간: 약 0:25~0:45, 훅 B "버스 정류장 전광판에 ~ 너의 차례도 그래" / 길이: 20초 / 포맷: '이런 날 들어줘' 상황극(실루엣 인물 스토리)

## 후킹 첫 3초
- 0.0~1.5초: 버스 정류장 전광판 클로즈업 "곧 도착"이 깜빡임. 자막: "곧 도착, 한참째." / 소리: 거리 앰비언스
- 1.5~3.0초: 벤치에 앉아 한숨 쉬는 인물 실루엣, 발밑 그림자가 어깨를 톡 두드림. 자막: "기다리는 게 지칠 때 들어줘" / 소리: 기타 스트럼 + 가사 진입

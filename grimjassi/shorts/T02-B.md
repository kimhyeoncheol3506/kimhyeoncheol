# [T02-B] 현관문 소리가 박수 소리가 되는 순간

- 사용 곡: 2. 오늘도 수고했어 / 사용 구간: 약 2:05~2:25, 훅 B(Bridge) "현관 비밀번호 누르는 소리 ~ 오늘의 박수 소리야" / 길이: 22초 / 포맷: 생활 ASMR 사운드 싱크 컷편집

## 후킹 첫 3초
- 0.0~1.0초: 화면 클로즈업, 도어락 번호를 누르는 손가락. 자막 없음 / 소리: "삑 삑 삑 삑" (음악 비트와 싱크)
- 1.0~3.0초: 문 열리는 "띠리릭" + 자막 "이 소리, 오늘 들었어?" / 소리: 브릿지 가사 진입

## 화면 구성
| 시간 | 화면 | 자막 | 오디오 |
|---|---|---|---|
| 0~1초 | 도어락 버튼 클로즈업 | — | 도어락 삑 소리(비트 싱크) |
| 1~3초 | 문이 열림, 어두운 현관 | 이 소리, 오늘 들었어? | 띠리릭 + 가사 진입 |
| 3~7초 | 신발 벗는 발, 현관 센서등 켜짐 | 현관 비밀번호 누르는 소리 | 브릿지 1줄 |
| 7~11초 | 소파에 털썩 앉는 실루엣 | 신발 벗고 털썩 앉는 소리 | 브릿지 2줄 |
| 11~16초 | 바닥의 그림자가 일어나 조용히 손뼉 치는 애니 | 그 작은 소리들이 | 브릿지 3줄 |
| 16~20초 | 그림자 박수 + 작은 빛 입자 | 오늘의 박수 소리야 | 브릿지 4줄 |
| 20~22초 | 엔딩 카드 | 오늘도 수고했어 · 그림자씨 | 후렴 진입 직전 컷 |

1. 이 소리, 오늘 들었어?
2. 현관 비밀번호 누르는 소리

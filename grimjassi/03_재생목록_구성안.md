# 그림자씨 채널 성장용 재생목록 구성안

> 전제: 고급 기능(고정댓글·커뮤니티·멤버십 등) 없이 **재생목록·설명란·영상 내 자막**만으로 시청 흐름을 만든다.
> 목표: 쇼츠(발견) → 정규 곡(체류) → 재생목록 연속 재생(세션 시간) → 구독

## 1. 핵심 전략 3줄
1. **입구는 쇼츠, 집은 재생목록.** 모든 쇼츠 설명란·엔딩 자막이 하나의 재생목록(① 앨범 전곡)으로 향하게 한다.
2. **'상황' 이름으로 검색에 걸린다.** 사람들은 가수 이름보다 "잠 안 올 때 듣는 노래", "퇴근길 위로 노래"로 찾는다 → 상황형 재생목록을 따로 만든다.
3. **같은 곡, 여러 문.** 한 곡이 2~3개 재생목록에 동시에 들어가도록 설계해 노출 경로를 늘린다.

## 2. 재생목록 7종

| # | 재생목록 제목 (검색어 포함) | 성격 | 수록 (트랙 번호 순서) | 개설 시점 |
|---|---|---|---|---|
| ① | 그림자씨 1집 『곁에 있을게』 전곡 \| 위로가 필요한 날 듣는 노래 | 대표·허브 | 1→2→3→4→5→6→7→8 | 쇼츠 1편 전 |
| ② | 잠 못 드는 밤, 마음이 편해지는 노래 \| 그림자씨 | 상황형(밤) | 3→7→6→1→8 | 쇼츠 3편(T03-A) 업로드 전 |
| ③ | 퇴근길 위로 노래 \| 오늘도 수고한 나에게 | 상황형(퇴근·하교) | 2→4→1→8 | 쇼츠 2편(T02-A) 업로드 전 |
| ④ | 비 오는 날 듣기 좋은 잔잔한 노래 \| 그림자씨 | 날씨형 | 5→3→6→7 | 쇼츠 5편(T05-A) 업로드 전 |
| ⑤ | 그림자씨 쇼츠 모음 \| 15초 위로 | 쇼츠 아카이브 | 쇼츠 업로드 순서대로 (최신이 맨 위) | 쇼츠 1편 전 |
| ⑥ | 집이 그리울 때 듣는 노래 \| 자취생·타지살이 위로 | 상황형(그리움) | 6→2→3→8 | 쇼츠 6편(T06-A) 업로드 전 |
| ⑦ | 조급한 마음 내려놓는 노래 \| 천천히 가도 괜찮아 | 상황형(불안·비교) | 4→7→8→1 | 쇼츠 8편(T08-A) 이후 |

### 곡별 노출 경로 (중복 수록 확인)
| 곡 | 들어간 재생목록 | 경로 수 |
|---|---|---|
| 1. 그림자씨의 인사 | ① ② ③ ⑦ | 4 |
| 2. 오늘도 수고했어 | ① ③ ⑥ | 3 |
| 3. 불 꺼진 방의 작은 등 | ① ② ④ ⑥ | 4 |
| 4. 천천히 가도 돼 | ① ③ ⑦ | 3 |
| 5. 비 오는 날의 우산 | ① ④ | 2 |
| 6. 엄마의 부엌 냄새 | ① ② ④ ⑥ | 4 |
| 7. 괜찮지 않아도 괜찮아 | ① ② ④ ⑦ | 4 |
| 8. 내일의 해가 뜨면 | ① ② ③ ⑥ ⑦ | 5 |

→ 8번(마무리 곡)을 가장 많은 목록의 **마지막 곡**으로 두어 "끝까지 들으면 희망으로 끝나는" 경험을 통일.

## 3. 재생목록별 설명란 (복붙용)
> 규칙: 연재 주기 약속 문구 없음, 과장 없음, 첫 줄에 검색어.

**① 앨범 전곡**
```
위로가 필요한 날, 처음부터 끝까지 들어 주세요.
AI 가수 그림자씨의 첫 앨범 『곁에 있을게』 8곡 전곡입니다.
혼자라고 느껴질 때도, 발밑의 그림자는 늘 곁에 있었어요.
1. 그림자씨의 인사 / 2. 오늘도 수고했어 / 3. 불 꺼진 방의 작은 등 / 4. 천천히 가도 돼
5. 비 오는 날의 우산 / 6. 엄마의 부엌 냄새 / 7. 괜찮지 않아도 괜찮아 / 8. 내일의 해가 뜨면
```

**② 잠 못 드는 밤**
```
잠 못 드는 밤, 생각이 많은 새벽에 틀어 두세요.
불 끄고 누워서 들어도 괜찮도록 잔잔한 곡만 모았어요.
그림자씨가 작은 등불처럼 곁에 있을게요.
```

**③ 퇴근길 위로**
```
퇴근길, 하굣길, 오늘을 버텨낸 나에게.
지하철 손잡이를 잡고 있는 당신에게 "오늘도 수고했어"라고 말해 주는 노래들.
```

**④ 비 오는 날**
```
창밖에 비가 오는 날, 마음까지 젖지 않도록.
보사노바와 피아노로 채운 잔잔한 비 오는 날 플레이리스트.
```

**⑤ 쇼츠 모음**
```
15초 위로가 필요할 때. 그림자씨 쇼츠를 한곳에 모았어요.
마음에 닿은 곡이 있다면 『곁에 있을게』 전곡 재생목록에서 끝까지 들어 보세요.
```

**⑥ 집이 그리울 때**
```
자취방에서, 타지에서, 집 밥 냄새가 그리운 날.
멀리 있어도 마음은 곁에 있다는 걸 노래로 전해요.
```

**⑦ 조급한 마음 내려놓기**
```
남들보다 늦은 것 같아 조급한 날.
천천히 가도 돼요. 그림자는 언제나 당신 걸음에 맞춰 걸어요.
```

## 4. 채널 홈·설명란 구성 (기본 기능만)
- **채널 홈 섹션 순서:** ① 앨범 전곡 → ⑤ 쇼츠 모음 → ② 잠 못 드는 밤 → ③ 퇴근길 위로 → ④ 비 오는 날 → ⑥ → ⑦
- **채널 예고편/대표 영상:** 1번 「그림자씨의 인사」 정규 영상
- **채널 설명 (복붙용):**
```
빛이 있는 곳엔 늘 그림자가 곁에 있어요.
AI 가수 그림자씨가 지친 하루 끝에 조용히 곁을 지키는 노래를 부릅니다.
첫 앨범 『곁에 있을게』 전곡은 재생목록에서 들을 수 있어요.
※ 이 채널의 노래와 영상은 AI로 제작되었습니다.
```

## 5. 쇼츠 ↔ 재생목록 연결 규칙
| 쇼츠 | 설명란 2번째 줄에 넣을 재생목록 | 엔딩 자막 |
|---|---|---|
| T01-A/B | ① 앨범 전곡 | "전체 곡은 『곁에 있을게』 재생목록에서" |
| T02-A/B | ③ 퇴근길 위로 | "퇴근길 위로 노래 모음은 채널에서" |
| T03-A/B | ② 잠 못 드는 밤 | "잠 안 오는 밤 노래 모음은 채널에서" |
| T04-A/B | ⑦ 조급한 마음 내려놓기 (개설 전엔 ①) | "전체 곡은 『곁에 있을게』 재생목록에서" |
| T05-A/B | ④ 비 오는 날 | "비 오는 날 노래 모음은 채널에서" |
| T06-A/B | ⑥ 집이 그리울 때 | "전체 곡은 『곁에 있을게』 재생목록에서" |
| T07-A/B | ② 잠 못 드는 밤 | "전체 곡은 『곁에 있을게』 재생목록에서" |
| T08-A/B | ① 앨범 전곡 | "처음부터 듣고 싶다면 『곁에 있을게』 재생목록" |

- 설명란 1번째 줄은 항상 `곡명 — 그림자씨 1집 『곁에 있을게』`
- 쇼츠는 업로드 직후 ⑤ + 해당 곡 주제 재생목록에 함께 추가

## 6. 단계별 운영 로드맵 (쇼츠 16편 기간 기준)
| 단계 | 기간 | 할 일 | 확인 지표 |
|---|---|---|---|
| 1. 집 짓기 | 쇼츠 1편 전 | 정규 8곡 업로드, ①·⑤ 개설, 채널 설명 반영 | 재생목록 공개 상태 확인 |
| 2. 문 열기 | 쇼츠 1~8편 (11/23~12/07) | 상황형 ②③④⑥ 순차 개설, 쇼츠마다 해당 목록 연결 | 쇼츠 → 정규 영상 유입 비율 |
| 3. 길 다지기 | 쇼츠 9~16편 (12/09~12/23) | ⑦ 개설, 성과 좋은 상황형 목록을 채널 홈 2번째로 이동 | 재생목록 평균 시청 곡 수 |
| 4. 정리 | 16편 이후 | 목록별 순서 재정렬(지속률 높은 곡을 2번째 자리로) | 세션당 시청 시간 |

### 순서 재정렬 원칙
- 각 재생목록 **1번 자리**는 클릭을 부르는 곡(쇼츠 반응 상위 곡)
- **2번 자리**는 평균 시청 지속률이 가장 높은 곡 (이탈 방지)
- **마지막 자리**는 8. 내일의 해가 뜨면 고정 (앨범 정체성)

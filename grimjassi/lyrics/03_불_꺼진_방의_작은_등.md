# 3. 불 꺼진 방의 작은 등

- 장르: 피아노 발라드 / BPM: 68 / 키(제안): D♭ major / 길이: 약 3:10 / 보컬: 속삭이듯 시작해 후렴에서 따뜻하게 열리는 중저음 남성
- 곡 소개: 새벽 두 시, 천장만 바라보며 잠 못 드는 사람을 위한 자장가 같은 발라드.
  머릿속에서 오늘의 말실수와 내일의 걱정이 번갈아 재생될 때, 그림자씨가 침대 맡의 작은 등이 되어 준다.
  "생각을 멈추라"고 하지 않고 "생각해도 괜찮아, 내가 같이 깨어 있을게"라고 말하는 곡.

## Suno 스타일 프롬프트
```
intimate piano ballad, soft felt piano, gentle string pad, warm male vocal whispering then opening up, late night lullaby, slow and tender, 68 bpm, minimal drums
```

## Suno 제외 스타일(Exclude)
```
aggressive, screaming, belting high notes, rap, heavy drums, distortion, EDM, upbeat
```

## 쇼츠 훅 구간
- **훅 A (Chorus 1~4줄, 약 1:05~1:20)**: "불 꺼진 방의 작은 등처럼 / 내가 여기 켜져 있을게 / 너무 밝지 않게, 꺼지지도 않게 / 네 곁을 비춰 줄게"
- **훅 B (Bridge 전체, 약 2:15~2:30)**: "하나, 숨을 들이쉬고 / 둘, 천천히 내쉬고 / 셋, 어깨 힘을 풀고 / 넷, 이제 나한테 기대" — 호흡 가이드형 쇼츠에 최적

## 제작 메모
- 후렴에서 고음 벨팅이 나오면 곡 성격이 깨진다. Style에 `restrained, soft dynamics, no belting`을 추가해 재생성.
- 브릿지의 숫자 세기는 반 박자씩 여유 있게 들려야 한다. 빠르게 나오면 `[Bridge - slow, spoken softly]`로 태그 변경.
- 수면용 롱폼(1시간 반복) 영상의 원곡 후보. 인트로/아웃트로가 잔잔하게 끝나는 생성본을 고를 것.

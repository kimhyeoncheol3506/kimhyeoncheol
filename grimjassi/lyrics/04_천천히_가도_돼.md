# 4. 천천히 가도 돼

- 장르: 따뜻한 인디 팝 (브러시 드럼) / BPM: 96 / 키(제안): A major / 길이: 약 3:00 / 보컬: 부드러운 중저음 남성, 가볍게 미소 띤 톤, 후렴 더블링
- 곡 소개: SNS 속 친구들의 소식에 나만 멈춰 있는 것 같을 때 듣는 노래.
  취업 준비생, 재수생, 이직을 고민하는 사람, 남들보다 늦게 시작한 모든 사람에게.
  앨범 안에서 가장 발걸음이 가벼운 곡 — "늦은 게 아니라, 네 속도로 걷고 있는 거야."

## Suno 스타일 프롬프트
```
warm indie pop, brushed drums, acoustic guitar strums, glockenspiel accents, soft bass, gentle male vocal with light smile, doubled chorus, hopeful walking tempo, 96 bpm
```

## Suno 제외 스타일(Exclude)
```
aggressive, screaming, rap, heavy distortion, EDM drop, trap, shouting, dark mood
```

## 제작 메모
- 96 BPM이 빠르게 느껴지는 생성본은 `relaxed groove, walking pace`를 추가. 행진곡처럼 들리면 실패.
- 글로켄슈필이 과하면 동요 느낌이 난다. `subtle glockenspiel`로 조정.
- 앨범 내 유일한 '걷는 템포' 곡이라 쇼츠 BGM 재사용성이 높다. 가사 없는 인스트루멘털 버전도 함께 생성해 둘 것.

# 5. 비 오는 날의 우산

- 장르: 보사노바 (나일론 기타, 소프트 브러시 퍼커션)
- BPM: 88
- 키(제안): D major (Verse는 Bm 중심, 후렴에서 D로 열림)
- 길이: 약 3:00
- 보컬: 그림자씨 — 부드러운 중저음, 숨결 섞인 속삭임, 리듬을 살짝 뒤로 미는 여유 있는 프레이징

## 곡 소개
비 소식이 있던 날, 우산을 챙기지 못해 처마 밑에서 비가 그치기를 기다리는 사람에게.
비 때문에 괜히 마음까지 젖는 날, 그림자씨는 "같이 기다려 줄게"라고 말합니다.
쓸쓸함을 억지로 걷어내지 않고, 빗소리를 같이 듣는 노래.
가볍게 흔들리는 보사노바 리듬으로 우울한 날의 무게를 조금 덜어 줍니다.

## Suno 스타일 프롬프트
```
Bossa nova, soft nylon guitar, gentle brush percussion, upright bass, warm breathy male vocal, intimate close mic, rain ambience, cozy, comforting, 88 BPM, Korean
```

## Suno 제외 스타일(Exclude)
```
aggressive, screaming, rap, heavy distortion, electric guitar solo, EDM drop, autotune, fast tempo
```

## 제작 메모
1. 보사노바가 재즈 스윙으로 흘러가면 `bossa nova` 를 맨 앞에 두고 `swing`, `big band` 를 Exclude에 추가.
2. 인트로에 빗소리가 안 나오면 [Intro] 아래 `(rain sounds)` 를 영어로 바꿔 재생성.
3. 후렴 "곁에 있을게" 발음이 뭉개지면 "곁에 / 있을게"로 줄을 나눠 다시 생성.

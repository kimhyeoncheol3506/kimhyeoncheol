# 2. 오늘도 수고했어

- 장르: 로파이 R&B / 소프트 시티팝 / BPM: 84 / 키(제안): E♭ major / 길이: 약 3:05 / 보컬: 부드러운 중저음 남성, 리듬감 있게 흘리는 창법, breathy
- 곡 소개: 퇴근길 지하철, 하굣길 버스 창가에서 듣는 노래. 오늘 무언가를 해냈든 못 해냈든
  "버텨낸 것만으로 충분해"라고 말해 주는 하루의 끝 인사.
  야근 후 혼자 돌아가는 직장인, 시험 기간의 학생, 알바를 마친 사람에게.

## Suno 스타일 프롬프트
```
lo-fi R&B, soft city pop, mellow Rhodes keys, warm bassline, dusty laid-back drums, vinyl crackle, smooth male vocal, breathy, night commute mood, 84 bpm
```

## Suno 제외 스타일(Exclude)
```
aggressive, screaming, rap verse, trap hi-hats, heavy distortion, EDM, shouting
```

## 쇼츠 훅 구간
- **훅 A (Chorus 1~4줄, 약 0:55~1:10)**: "오늘도 수고했어 / 여기까지 와 준 것만으로 / 다 괜찮아, 충분해 / 가로등 하나씩 켜질 때마다"
- **훅 B (Bridge 전체, 약 2:05~2:20)**: "현관 비밀번호 누르는 소리 / 신발 벗고 털썩 앉는 소리 / 그 작은 소리들이 / 오늘의 박수 소리야"

## 제작 메모
- [Verse 1b]가 랩으로 넘어가면 Exclude에 `spoken word, rap flow`를 강화하고 Style에 `sung softly`를 추가.
- 바이닐 노이즈가 너무 크면 보컬이 묻힌다. `subtle vinyl crackle`로 수정.
- 브릿지의 생활 소리(도어락, 신발)는 쇼츠 편집 시 실제 효과음(자체 녹음/무료 라이선스)을 얹으면 몰입도가 크게 오른다.

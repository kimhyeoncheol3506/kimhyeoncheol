# 8. 내일의 해가 뜨면

- 장르: 미드템포 팝 발라드 (피아노 + 스트링, 마지막 후렴 잔잔한 합창)
- BPM: 76
- 키(제안): C major → Final Chorus에서 D major로 온음 전조
- 길이: 약 3:30
- 보컬: 그림자씨 — 담담하게 시작해 마지막 후렴에서 따뜻하게 열림, 엔딩은 합창(choir)과 함께

## 곡 소개
앨범 『곁에 있을게』의 마지막 곡. 긴 밤을 지나 새벽을 맞는 모든 사람에게.
1번 곡 '그림자씨의 인사'에서 "나 여기 있었어"라고 인사했던 그림자씨가,
이번에는 해가 뜨는 방향으로 함께 걸어가며 "그림자는 빛이 있어야 생기는 거야"라고 말합니다.
그림자가 길게 생긴다는 건, 당신 앞에 해가 떠 있다는 뜻 — 작은 희망으로 앨범을 닫습니다.

## Suno 스타일 프롬프트
```
Mid-tempo pop ballad, emotional piano, warm strings, gentle male vocal building to hopeful, soft choir in final chorus, key change, uplifting, sunrise, comforting, 76 BPM, Korean
```

## Suno 제외 스타일(Exclude)
```
aggressive, screaming, rap, heavy distortion, rock drums, EDM, autotune, belting high notes
```

## 쇼츠 훅 구간
- **A (Chorus 전반, 약 15초)**: "내일의 해가 뜨면 / 네 그림자가 길어질 거야 / 그건 네 앞에 / 빛이 있다는 뜻이야"
- **B (Bridge, 약 15초)**: "그림자는 혼자 생기지 않아 / 빛이 있어야 생기는 거야 / 그러니까 네가 지금 / 나를 볼 수 있다면 / 너의 곁엔 이미 / 빛이 와 있는 거야"

## 제작 메모
1. 전조가 안 나오면 [Final Chorus] 위에 `[Key Change]` 태그를 별도 줄로 추가해 재생성.
2. 합창이 과하게 웅장해지면 `soft choir` → `small gentle choir humming` 으로 낮춤.
3. 인트로 "나 여기 있었어"는 1번 곡과 같은 말투(속삭임)로 나와야 앨범 수미상관이 살아남 — 생성 후 1번 곡 인트로와 이어 들어 확인.

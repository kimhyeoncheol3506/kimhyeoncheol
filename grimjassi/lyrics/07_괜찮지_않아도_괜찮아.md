# 7. 괜찮지 않아도 괜찮아

- 장르: 앰비언트 팝 (따뜻한 신스 패드, 로즈 피아노, 소프트 킥, 리버브 기타)
- BPM: 80
- 키(제안): F major (Bridge에서 Dm로 잠시 내려갔다 복귀)
- 길이: 약 3:05
- 보컬: 그림자씨 — 숨결 많은 속삭임으로 시작, 후렴에서 부드럽게 퍼지는 더블링

## 곡 소개
"괜찮아?"라는 질문에 습관처럼 "응, 괜찮아"라고 대답해 온 사람에게.
회사에서, 단톡방에서, 가족 앞에서 웃는 얼굴을 지키느라 지친 날,
그림자씨는 고치려 하지 않고 "괜찮지 않아도 돼"라고 허락해 줍니다.
공간감 있는 신스 패드가 마음을 감싸 주는, 앨범에서 가장 고요한 곡입니다.

## Suno 스타일 프롬프트
```
Ambient pop, warm synth pads, rhodes piano, soft kick, reverb guitar, breathy intimate male vocal, gentle doubled chorus, dreamy, healing, calm, 80 BPM, Korean
```

## Suno 제외 스타일(Exclude)
```
aggressive, screaming, rap, heavy distortion, EDM drop, trap hi-hats, dubstep, harsh synth
```

## 쇼츠 훅 구간
- **A (Chorus 전반, 약 15초)**: "괜찮지 않아도 괜찮아 / 오늘은 그냥 그런 날이야 / 애써 일어나지 않아도 / 내가 곁에 앉아 있을게"

## 제작 메모
1. 비트가 커져 댄스 팝처럼 나오면 `soft kick` 대신 `no drums in verse, minimal percussion` 으로 교체.
2. "ㅋㅋ"를 Suno가 이상하게 읽으면 가사 칸에서 "크크"로 바꿔 생성하고, 쇼츠 자막에는 원래대로 "ㅋㅋ" 표기.
3. 후렴 더블링이 과하면 `gentle doubled chorus` 삭제 후 재생성.

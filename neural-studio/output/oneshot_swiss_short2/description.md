# 2000년 100원 물건, 한국 181원 vs 스위스 115원

세계은행 소비자물가 자료로 2001~2024년을 이어 계산하면, 2000년에 100이던 물건값이 스위스 약 115, 독일 약 157, 한국 약 181입니다.
1970년 1달러에 약 4.31프랑이던 환율은 2025년 약 0.83프랑. 돈의 가치를 지킨 나라 이야기입니다.

내 관점: 비유하자면 스위스프랑은 잘 새지 않는 물통입니다. 물가라는 구멍이 작으니, 안에 담아 둔 돈의 가치가 덜 빠져나가죠.

# 에스엠 CEO 계보, 자본금 5천만 원 회사가 카카오에 넘어가기까지

1995년 자본금 5천만 원으로 세운 에스엠엔터테인먼트. 2026년 11월 18일 정규장 종가 기준 시가총액은 약 2조 124억 원입니다. 창업자 이수만은 지금 회사에 없고, 회계법인 출신 장철혁, 2005년 입사한 탁영준 두 공동대표가 이끕니다.
가수 출신 창업자의 미국 유학, H.O.T.와 보아의 오리콘 1위, 정해익·김경욱·김영민·이성수로 이어진 대표이사 계보, 2023년 하이브와 카카오의 경영권 싸움, 그리고 지금의 성적표까지 5분에 정리했습니다.
대표이사 계보와 학력·경력은 DART 공시(대표이사변경 공시, 분기보고서 임원 현황)를 기준으로 했고, 언론으로만 확인한 내용은 (보도)로 표시했습니다.

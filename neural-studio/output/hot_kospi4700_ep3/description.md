# 외국인 168조 판 장, 2008년과 똑같을까? 금융위기 때 끝까지 버틴 사람의 계좌

외국인 매도, 코스피 4700, 2008년 금융위기. 외국인이 5월부터 11월까지 7개월 연속 약 168조 원을 순매도했고, 시가총액 대비 비율 4.3%가 2008년 금융위기 때 4.4%에 근접했다는 보고서가 나왔습니다(하나증권, 보도). 지금도 2008년처럼 될까요?
2008년 10월 24일 코스피 바닥(938.75)에서 판 사람과 버틴 사람의 1년·3년·5년 뒤, 2007년 꼭대기(2,064.85)에서 산 1,000만 원이 본전이 되기까지 걸린 시간(3년 2개월)을 지수로 직접 계산했습니다(배당·수수료·세금 제외). 버틸 수 있는 사람의 조건 3가지(빚 없음, 생활비 따로, 몇 년 안 써도 되는 돈)를 정리했습니다. 투자 권유가 아니며 모든 숫자의 출처와 계산 전제는 아래에 적었습니다.

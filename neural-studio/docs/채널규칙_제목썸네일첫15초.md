# 채널 규칙: 형식 · 썸네일 · 제목 · 첫 15초 (2026-11-13 현철님 지정, 11-14 쇼츠 제외)

**적용 범위:** 모델 1과 모델 2 모든 편. '이거 한편으로 끝' 4편부터 적용한다.
**우선순위:** 다른 규칙과 부딪히면 이 문서가 우선한다.

## 바꾼 이유: 채널 28일 데이터 (10/16~11/12)

| 항목 | 값 |
|---|---|
| 홈 피드 클릭률 | 3.6% (평균 17초 만에 이탈) |
| 검색 클릭률 | 13.1% |
| 추천 동영상 클릭률 | 1.5% |
| 구독 | +4 |

→ 검색으로 들어온 사람은 잘 누른다. 홈과 추천에서는 썸네일이 약하고, 첫 15초에서 사람이 떠난다.

## 1. 형식
- 시리즈물('한편으로 끝' 등)은 60분짜리를 만들지 않는다.
- 본편은 **10~15분**으로 만든다. 대본 점검기(`tools/series_lint.py`)의 예상 길이가 14.5분 이하여야 한다.
- **쇼츠는 만들지 않는다.** 롱폼 위주로 간다. (2026-11-14 현철님 결정: 처음 규칙의 '편마다 쇼츠 2개'를 뺐다.)
  - 이미 만든 쇼츠 대본과 결과물은 지우지 않고 보관만 한다.

## 2. 썸네일
- **매번 대비 구조 하나**를 쓴다. 종류는 A vs B, 숫자 두 개, 전/후, 1등/꼴찌.
  - 잘된 예 1: 저울 '교과서 25년 vs 살아남은 사람 7년'
  - 잘된 예 2: '미국 멀쩡 vs 코스피 −34%'
  - 잘된 예 3: 월세·전세·매매 3칸
- **큰 숫자 하나 + 글자 6자 이하.** 숫자와 단위는 6자에 넣지 않는다.
  - "진짜 이유", "이때 온다", "진짜일까?" 같은 추상어는 금지.
- **어두운 배경 + 빨간 붓 밑줄 틀은 그만 쓴다.**
  - 배경색은 편마다 바꾼다(노랑·파랑·흰색·민트 등).
  - 직전 편 배경색은 `video-studio/썸네일_이력.md`에서 확인한다.
- **개미 마스코트**는 작게 넣고, 표정이 내용과 맞을 때만 쓴다.
  - **채널 배지는 넣지 않는다.**
  - 실존 인물 얼굴은 계속 금지.
- 오른쪽 아래 재생시간 자리는 비운다.
- 후보 2개를 만들면 **비교 이미지**도 함께 보낸다.
  - 같은 주제에서 조회수가 높은 다른 채널 썸네일 2~4개와 우리 후보를 나란히 놓는다.
  - 다른 채널 썸네일은 yt-dlp로 받는다.
  - 비교 이미지는 내부 검토용이다. 업로드하거나 재사용하지 않는다.

### 2-1. 썸네일 기본 디자인 = '3D 대비형' (2026-11-14 현철님 지정: "이런식으로 썸네일 만들어")
기준 그림: `neural-studio/assets/thumbs/style_ref/3d_contrast_japan.webp` (일본 편). 도구: `neural-studio/tools/thumb3d_contrast/` (Blender 3D 글자·소품 + HTML 합성).
- **바탕:** 흰색~아주 옅은 회색 그라데이션 + 맨 위 빨간 띠(약 14px). 편마다 포인트 색만 바꾼다(빨강/남색 기본).
- **위 2줄 = 제목:** 1줄 검색어(아주 크게), 2줄 제목 뒷부분(조금 작게). 남색 3D 돌출 글자 + 흰 테 + 그림자. 영상 제목과 같은 말을 써도 된다(이 디자인에서는 '썸네일·제목 다른 말' 규칙보다 이것이 우선).
- **가운데 = 대비 구조 하나:** 왼쪽 나쁜 쪽(빨강 3D 숫자, 뒤에 반투명 유리 구슬·원), 가운데 회색 'vs', 오른쪽 좋은 쪽(남색 3D 숫자). 각 숫자 위에 검은 굵은 꼬리표(예: 일본 / 한국). 숫자는 화면 높이의 30% 이상.
- **소품:** 양쪽 아래 구석에 내용과 맞는 3D 소품(금 동전 더미, 금 간 빌딩, 지폐 다발, 방패, 유정, 은행 금고 등) — 글자를 가리지 않게.
- **개미 마스코트:** 'vs'와 오른쪽 숫자 사이에 작게(화면 높이 25% 안팎), 표정이 내용과 맞을 때만.
- 숫자는 본편 sources.facts 에 있는 것만. 실존 인물 얼굴·채널 배지 없음. 오른쪽 아래 재생시간 자리는 소품만(글자 금지).
- 위 2-1 디자인에서는 '글자 6자 이하' 대신 **'제목 2줄 + 꼬리표 2개 + 숫자 2개'**만 쓴다(그 밖의 글자 금지).

## 3. 제목
- **검색어를 맨 앞에** 둔다. 예: "일본 잃어버린 30년", "스위스 부자 이유", "사우디 석유", "아르헨티나 경제 몰락".
- 검색어 뒤에 **숫자 또는 대상**을 붙인다. 예: "… 월급 30년 그대로", "… 월급쟁이가 알아야 할 3가지".
- 썸네일 문구와 제목은 **다른 말**로 쓴다. 같은 말을 되풀이하지 않는다.
- 금지:
  - "(이거 한편으로 끝)" 같은 시리즈 머리표
  - "/ 틀어놓고 듣는"
  - 키워드 나열(쉼표나 / 로 낱말 늘어놓기)

## 4. 첫 15초
- **첫 문장**에서 썸네일 숫자의 답(또는 가장 센 숫자)을 바로 말한다.
- 인사·채널 소개·배경 설명은 **30초 이후**로 미룬다.
- **15초 안에 화면이 3번 이상** 바뀐다.
  - 모델 2에서는 판 하나를 4~5초로 짧게 끊는다.
- **30초 근처**에 구독 한마디를 넣는다: "이런 계산 매주 올립니다".
- 썸네일 숫자가 첫 10초 화면에 그대로 보여야 한다(썸네일 = 첫 화면 일치).

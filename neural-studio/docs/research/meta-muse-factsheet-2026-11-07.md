## 2. 참고 영상별로 가져올 기법

> 자막을 못 받아서 **영상 속 실제 기법은 관찰하지 못했다.** 아래는 제목·길이·구성 정보(요청서의 챕터 수 포함)에서 읽을 수 있는 것과, 그것을 우리 영상에 옮기는 **제안**이다. 자막을 받으면 이 절을 다시 써야 한다.

1. **안될과학 — "사람 대신 어디까지 할까?" 질문형 제목 + 잘게 나눈 챕터(10분에 18개, 평균 약 34초)**
   - 가져올 것: 13~15분 영상을 30~40초 단위 소주제로 쪼개 화면 전환을 자주 준다. 질문 하나 → 답 하나 구조.
2. **옆자리 연구원 — 3파전 비교 + "믿고 맡겨도 될까?"**
   - 가져올 것: 후반부에 뮤즈·듀엣·닷츠(+제미나이 스파크, 피클) 비교표 한 장. 기준은 "가격 / 어디서 되나 / 결제 / 안전장치 / 한국에서 되나" 다섯 칸으로 고정.
3. **거북이 버프 — 실제 과제 하나를 끝까지 맡겨 보고 결과를 숫자로 제목에 박기("2자리를 찾았습니다")**
   - 가져올 것: 첫 화면 훅을 "구체적 과제 + 결과 숫자"로. 예) "AI한테 항공권 가격 추적을 맡겼더니…". 단, 우리는 직접 써 보지 않았으므로 **남의 사례를 인용할 때 출처를 화면에 표기**한다.
4. **미국주부 — "가격·꺼 둘 설정·막히는 곳 (협찬 아님)" 실용 체크리스트형**
   - 가져올 것: 입문자용 마지막 챕터를 "켜자마자 확인할 설정 3개" 체크리스트로. "협찬 아님"처럼 신뢰 문구를 설명란·화면에 둔다.
5. **슈카월드 — 제품을 사업·산업 흐름(광고 회사 메타가 결제 수수료로 간다)으로 키워서 설명**
   - 가져올 것: 중반에 "메타가 왜 공짜로 주나?" 한 챕터. 저커버그 실적 발표 발언(무료 + 거래 수수료 + 구독)으로 답한다.

- 메타의 **개인용 AI 에이전트 앱**. 질문에 답만 하는 게 아니라 사용자 대신 **행동**(예약, 양식 작성, 쇼핑·결제, 메일 처리 등)을 한다. [미확인·검색] 메타 뉴스룸 제목 "Introducing Muse: The World's First Personal AI Agent Built for Everyone" — https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/
- 앱을 닫아도 뒤에서 계속 일하고, 사용자 확인이 필요할 때 알림을 보낸다. [미확인·검색] https://ai.meta.com/muse/ , https://www.meta.com/help/artificial-intelligence/1331373868832401/

### 3-6. 작동 원리
- **Muse Secure VM**: 사용자마다 클라우드에 전용 컴퓨터(리눅스, 자체 브라우저)를 하나씩 줌. 에이전트와 사용자 데이터가 여기 있음. [미확인·검색] (메타 발표 내용을 여러 매체가 같은 말로 전함)
- **Sentinel(감시 에이전트)**: 같은 VM 안에서 뮤즈와 분리돼 돌며, 모든 연결 앱 행동(허용/거부/사용자에게 묻기)과 모든 외부 통신을 통제. 정책 밖 행동이면 사용자에게 승인 요청. [미확인·검색 — 대부분 2차 블로그] https://www.datacamp.com/blog/muse-agent , https://shipwithmuse.live/blog/muse-secure-vm
- **비밀번호 금고**: 로그인 정보는 에이전트가 읽을 수 없는 저장소에. 에이전트는 대체 토큰만 보고 Sentinel 이 경계에서 진짜 값으로 바꿈. [미확인·검색]
- **모델**: Muse Spark 계열(2026-04 첫 공개, 7월 1.1, 8월 1.2). 2026-10-12 공개된 상위 모델 **Muse Wonder** 가 "곧 뮤즈 앱에, 구독자부터" 들어간다고 메타가 밝힘. 2026-11-06 Muse Wonder 로 학습한 "특화 모델"을 뮤즈·메타 AI 에 적용, 메타 자체 지표(Personal Superintelligence Index) 47%(이전 38%). [미확인·검색] https://techcrunch.com/2026/10/12/meta-releases-its-first-frontier-model-muse-wonder/ , https://research.meta.ai/blog/specialized-models-for-muse-and-metaai
  - ⚠모순: "10월 21일부터 유료 플랜에 Muse Wonder 적용"은 2차 출처 하나뿐.

## 5. 주의할 점

### 5-1. 사실 확인
- 이 문서의 모든 사실은 원문을 열지 못한 **검색 요약 기반**이다. 특히 가격 이름(Power/Maximum)·토큰 수, Sentinel 세부, 학습 끄는 메뉴 경로, 무료 한도는 2차 블로그 의존도가 높다. 대본 확정 전 메타 도움말·앱 화면으로 확인.
- 숫자 구분: "다운로드 1,090만(센서타워 추정)"과 "에이전트 설정 1,000만(저커버그, 미국·캐나다)"을 섞지 말 것.
- 국가 목록은 날마다 바뀐다. 영상에 "2026년 11월 7일 기준" 자막을 넣는다.
- 이전 팩트시트의 "Mac 새로운 사이드 채팅", "Windows 앱"은 확인되지 않았다.
- 참고 영상 5개 내용은 아직 하나도 확인하지 못했다. 영상 속 시연(대한항공 마일리지 등)을 인용하려면 자막을 받은 뒤에 한다.

### 5-2. 한국에서 미국 전용 서비스를 쓰는 문제 (법·약관)
- 보도에 따르면 뮤즈 약관은 이용 가능한 국가에 **있을 것**을 요구하고, 메타는 약관 위반 시 이용을 정지·종료할 수 있다. 뮤즈는 페이스북·인스타그램과 같은 메타 계정을 쓰므로 위험이 그 계정까지 갈 수 있다는 보도가 있다. [미확인·단일] — 약관 원문은 열지 못했다.
- 메타 개발자 API 정책에는 "지리적 제한을 우회하면 안 된다"는 문구가 있다는 검색 결과가 있으나, 이는 소비자 앱이 아닌 API 약관이다. [미확인·단일] https://dev.meta.ai/legal/geographic-use-policy
- VPN 사용 자체가 한국 법으로 불법이라는 근거는 찾지 못했다. 문제는 **법보다 약관(계정 정지)·결제(카드 국가 불일치 오류)·분쟁 시 보호** 쪽이다. 한국 소비자 보호 제도가 해외 미출시 서비스에 적용되는지는 확인하지 못했다 [미확인].

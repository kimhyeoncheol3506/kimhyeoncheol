## 1. 한 줄 정의와 출시 역사

**쉬운 말:** 크롬에 붙이는 확장 프로그램. 오른쪽 옆 칸(사이드 패널)에 클로드를 불러 부탁하면, 내가 이미 로그인한 웹사이트에서 클로드가 **읽고, 누르고, 글자를 치고, 신청서를 채운다**. 나는 지켜보다가 중요한 순간에 결정한다. [확인: 제품, 웹스토어]
- 공식 문장: "reads the page you're signed in to, then clicks, types, and fills forms while you decide what happens next." [확인: 제품]
- API가 없는 사이트(사내 시스템, 오래된 포털, 관리자 화면, 송장 시스템)도 내 로그인으로 다룬다. [확인: 제품, GA 발표]

## 2. 누가 쓸 수 있나 (요금제·가격·브라우저·OS)

**요금제** [확인: 시작하기, 요금, 웹스토어]
- **유료 요금제만**: Pro, Max, Ultra, Team, Enterprise. **Free(무료)는 안 됨**(요금 비교표 Claude in Chrome: Free "No").
- 가격(세금 별도) [확인: 요금]
  - Pro: 월 $20(월 결제) / 연간 결제 시 월 $17($200 선결제)
  - Max: 월 $100 (Pro 의 5배 사용량)
  - Ultra: 월 $200 (Pro 의 10배, 인증 계정은 5시간 제한 없음)
  - Team: 표준 좌석 $25/월(월 결제), $20(연 결제) · 프리미엄 좌석 $125 / $100
  - Enterprise: 좌석당 $20/월(연 결제, 20석 이상) + API 요금만큼 사용료
- 사용량: 일반 채팅과 **같은 한도를 나눠 쓴다**. 브라우저 일은 계산이 많아 한도를 더 빨리 쓴다. [확인: 문제해결]
- 사이드 패널이 Cowork 세션으로 도는 것: Max·Ultra·Team 은 지금, **Pro 는 "rollout reaches you"(차례로 배포 중)**, Enterprise 는 관리자가 Cowork in the cloud 를 켜야 함. 안 켜지면 예전(classic) 패널. [확인: 시작하기, 안전]
- Team 은 기본 켜짐, Enterprise 도 기본 켜짐(HIPAA 조직은 기본 꺼짐, BAA 적용 안 됨). ZDR(데이터 무보존) 미지원. [확인: 관리자, 안전]

**브라우저·기기**
- **Google Chrome 만**. "not supported on other Chromium-based web browsers or mobile devices." [확인: 시작하기, 웹스토어, GA 발표]
- ⚠모순: Claude Code 문서는 "Chrome integration works with Google Chrome and Microsoft Edge" 이고, Brave·Arc·Vivaldi·Opera 에서도 연결을 잡는다고 쓴다. WSL 은 안 됨. 즉 **Claude Code에서 부를 때는 Edge 등도 되지만, 일반 사용자용 도움말·웹스토어는 크롬만 지원한다고 함**. 대본은 "크롬에서 쓰세요"가 안전. [확인: Claude Code 문서]
- OS: 확장 자체의 OS 요구 사항은 문서에 없음. 웹스토어는 데스크톱 앱을 "Mac or Windows"로 적음. 1Password 연동은 macOS 베타. [확인: 웹스토어, 시작하기] / Linux 에서 사이드 패널이 되는지는 [미확인].
- Claude Code 로 쓰려면: 확장 1.0.36 이상, /login 으로 로그인(API 키·setup-token 이면 꺼짐), Bedrock·Google Cloud·Foundry 같은 제3자 경로로는 불가. [확인: Claude Code 문서]
- 웹스토어 현황: 버전 **1.0.105**, 업데이트 **2026-11-04**, 사용자 **21,000,000명**, 평점 **3.6(1.9K)**, 6.89MiB, 개발자 Anthropic. [확인: 웹스토어]

## 3. 설치·설정 단계 (영상용 순서)
[확인: 시작하기, 웹스토어]
1. 유료 요금제 가입(Pro 이상).
2. **크롬**을 연다 → Chrome 웹스토어에서 "Claude"(Anthropic) 찾기 → **"Chrome에 추가"**.
3. 클로드 계정으로 **로그인**.
4. 오른쪽 위 **퍼즐 조각 아이콘 → "Claude" 옆 압정(핀)** 눌러 고정.
5. 요청하는 **권한 허용**(sidePanel, scripting, debugger, tabs, tabGroups, alarms, notifications, downloads, nativeMessaging 등 15가지. debugger 가 "클릭·입력·스크린샷"을 하게 해 주는 권한).
6. 툴바의 **클로드 아이콘** 클릭 → 오른쪽에 **사이드 패널**이 열림(브라우징하는 동안 계속 보임).
7. 입력 칸 아래 드롭다운에서 **권한 모드** 고르기(아래 표). 처음 사이트에 들어가면 "이 사이트 허용?" 질문 → "이번만 허용 / 이 사이트 항상 허용 / 거절".
8. (선택) Claude 데스크톱 앱: 설정 → Customize → Connectors → Claude in Chrome → Configure → 켜기. 채팅마다 커넥터 메뉴에서 직접 켜야 함(기본 꺼짐).
9. (선택) Claude Code: `claude --chrome`, `/chrome` 으로 상태 확인("Status: Enabled", "Extension: Installed"), "Enabled by default" 로 항상 켜기. [확인: Claude Code 문서]

**권한 모드 3가지** [확인: 권한, 안전, 시작하기]
| 이름(현재) | 예전 이름 | 하는 일 |
|---|---|---|
| Manually approve (수동) | "Ask before acting" | 동작마다 허락. 예전 패널은 먼저 **계획**(갈 사이트·방법)을 보여 주고 승인받음 |
| **Automatically approve (자동) — Cowork 패널의 기본값** | (새로 생김, GA 때) | 계속 일하되 **동작마다 별도 안전 검사**(데이터 빼돌리기·숨은 지시 확인). 위험하면 막거나 멈추고 물어봄. 계속 막히면 수동으로 돌아감 |
| Skip all approvals (건너뛰기) | "Act without asking" | 묻지도 검사하지도 않음. "완전히 믿을 때만" |
- 고른 모드는 다음 세션에도 기억. [확인: 시작하기]

**기본 모델**
- 현재 기본 모델은 **공식 문서에 적혀 있지 않다**. 시작하기 문서: "available on all public models"(모든 공개 모델 사용 가능). [확인]
- 역사: 2025-09-29 Sonnet 4.5 기본 → **2025-10-15 Haiku 4.5 기본** → 2025-11-24 Haiku 4.5/Sonnet 4.5/Opus 4.5 중 선택. [확인: 릴리스노트]
- "기본 = Haiku 4.5"는 **2025년 10월 기준의 옛 정보**. 지금도 그런지는 [미확인]. 참고 영상들은 Opus 5.5 "높음"(SJ Tech), Sonnet 5.5 중간(옆자리 연구원), Haiku(코난쌤, 2026-01)를 골라 썼다. 모델 옆에서 "얼마나 깊이 생각할지"도 고른다(옆자리 연구원). Haiku 5.5 발표문은 "browser use" 용도를 언급(2026-10-07). [확인: anthropic.com/news]

## 4. 주요 기능
[확인: 시작하기, 제품, 웹스토어, 릴리스노트, Claude Code 문서]
- **읽기·클릭·입력·이동·양식 채우기**, 화면 스크린샷으로 페이지를 보고 버튼 위치를 찾음.
- **여러 탭**: 탭을 **클로드 탭 그룹(색깔 다른 묶음)에 끌어 넣어야** 함께 다룸. (그냥 열어만 두면 안 들어감 — VIZENSOFT 가 "흔한 실수"로 지적)
- **백그라운드 작업**: 다른 탭으로 가도 크롬이 켜져 있으면 계속. 알림으로 "허락 필요/끝남" 알려 줌.
- **워크플로 녹화("가르치기")**: 녹화 버튼 → 내가 직접 해 보임 → 멈춤 → 단축키로 저장. **예전(classic) 패널에서만** 가능, Cowork 패널에는 없음.
- **단축키(Shortcuts)**: 잘 된 프롬프트 저장, 채팅에서 "/" 로 불러 씀. 시작 URL 도 넣을 수 있음(길호 영상).
- **예약 작업**: 패널 오른쪽 위 **시계 아이콘**, 매일·매주·매월·매년.
- **잘 아는 사이트**: Slack, Google 캘린더, Gmail, Google Docs, GitHub.
- **이미지 업로드**(경비 영수증·첨부칸), **화면 일부 캡처로 가리키기**, **상황별 프롬프트 제안**, **파일 다운로드**.
- **콘솔 로그 읽기**: 오류·네트워크 요청·DOM 상태(개발자용).
- **1Password 로그인**: 생체 인증으로 승인, 클로드는 비밀번호·OTP 를 못 봄(macOS 베타, 조직은 기본 꺼짐).
- **Cowork 패널**: 대화가 기록에 저장, 웹·데스크톱·모바일에서 이어 하기, **스킬·플러그인·커넥터**가 패널에서 그대로 작동.
- **세 가지 쓰는 곳**: ①사이드 패널(페이지 앞에서 바로) ②Claude Cowork/데스크톱 앱(브라우저가 긴 일의 한 단계일 때, 내 컴퓨터 파일 필요할 때 — 데스크톱 앱이 켜져 연결돼 있어야 함) ③Claude Code(내가 만드는 사이트를 테스트할 때).
- **Claude Code 연동**: `claude --chrome`, `/chrome`, VS Code 에서는 `@browser`. 로컬 웹앱 테스트, 콘솔 디버깅, CSV 를 읽어 CRM 에 입력, 파일 업로드(최대 10MB, .env·.pem·.ssh 같은 비밀 파일 거부), Google Docs 에 초안 쓰기, 표 추출→CSV, 여러 사이트 작업, **GIF 녹화**, 스크린샷 저장. 로그인 페이지·CAPTCHA 만나면 멈추고 사람에게 넘김. 컨텍스트를 더 씀. [확인: Claude Code 문서]
- **새 소식 — Cowork 내장 브라우저**: 데스크톱 앱 안에 설치 필요 없는 브라우저가 "이번 주 차례로 배포". 이미 Claude in Chrome 을 쓰면 크롬이 계속 기본. 설정 → Cowork → Preferred browser 로 바꿈. [확인: 시작하기, 제품 FAQ]
- 공식 예시 작업: 분석 대시보드 숫자 모으기, Google Drive 정리(중복·오래된 파일 표시), 캘린더+메일로 회의 준비·회의실 예약, 경쟁사 가격 조사→PPT, 영업 통화를 Salesforce 에 기록, 홍보 메일 정리 후 일괄 삭제 목록. "벤더 포털 6곳의 송장 6장을 스프레드시트로". [확인: 제품, 웹스토어]

## 5. 안전
[확인: 안전, 권한, 제품, GA 발표, 파일럿 발표, 연구]
- **가장 큰 위험 = 프롬프트 인젝션(숨은 지시)**: 웹페이지·메일·문서에 사람 눈엔 안 보이는 글(예: 흰 글씨)로 "다른 일을 하라"고 숨겨 두는 공격. 공식 예: 메일 답장을 부탁했는데 숨은 지시가 다른 메일을 공격자에게 전달하게 함.
- **스크린샷 문제**: 클로드는 작업 탭의 화면을 찍어 보므로, 화면에 보이는 개인 정보도 대화에 들어간다. 걸러 내지 못한다 → 민감한 사이트에서 쓰지 말고 **별도 브라우저 프로필** 권장. Cowork 패널 대화는 기록에 저장돼 다른 기기에서도 열림.
- **안전장치**: 모델 학습(강화학습), 들어오는 내용 검사 분류기(probe), **실행 전 동작 검사 분류기(자동 승인 모드)**, 사이트별 권한, 위험 사이트 차단, 민감 동작 확인, 외부 레드팀.
- **차단 사이트**: 성인 사이트, 불법 복제 사이트는 접근 불가. **금융 사이트는 먼저 허락을 구함**(안전 문서). ⚠모순: 문제해결 문서는 기본 차단 범주로 "financial services, banking, investment platforms, cryptocurrency exchanges, adult content, pirated content"를 적음. 파일럿 글(2025)도 금융 서비스를 차단 범주로 적음. → "은행·투자·코인 사이트는 막히거나 허락을 받아야 한다"로 표현.
- **어느 모드든 꼭 허락받는 것**: 권한 설정 바꾸기, 권한 부여, 민감 정보 입력(+"항상 허용" 사이트에서도 파일 다운로드).
- **절대 안 하는 것(금지)**: 구매·금융 거래, 계정 만들기, 카드·신분증 정보 다루기, 믿을 수 없는 곳에서 다운로드, 영구 삭제(휴지통 비우기, 메일·파일·메시지 삭제), 투자·금융 조언, 주식·투자 거래, 시스템 파일 수정, **메일·웹 내용 속 지시 따르기**, 캡차 우회, 얼굴 사진 수집. 예전 패널 기준 추가: 봇 인증 우회.
  - ⚠참고: 제품 페이지는 "구매·금융처럼 되돌릴 수 없는 일은 당신을 기다린다"(멈춘다)라고 쓰고, 권한 문서는 "금지"라고 쓴다. 대본: "돈이 나가는 버튼은 클로드가 못 누르거나 반드시 멈춘다."
- **쓰지 말라는 곳**: 금융 계좌·투자, 법률 문서·계약, 의료·건강 정보, 민감한 회사 데이터가 있는 업무 계정, 남의 개인 정보가 있는 사이트, 비밀번호 관리, 규제 데이터(HIPAA). 시작은 믿을 만한 사이트·익숙한 일·간단한 조사부터. 책임은 사용자에게(보낸 메시지, 구매, 바뀐 데이터, 사이트 이용약관).
- 이상 신호: 엉뚱한 주제, 예상 못한 사이트 방문, 민감 정보 요구 → 즉시 멈추고 신고(엄지 아래, usersafety 메일).

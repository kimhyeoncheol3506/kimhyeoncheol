## 2. 무엇을 고치나
1. **철자 ≠ 소리** (TTS 에 넣을 때만, 자막은 맞춤법대로)
   - ㄴ첨가: 순이익→순니익, 영업이익→영엄니익, 금융→금늉, 국민연금→궁민년금
   - ㄹ 비음화: 금리→금니, 수익률→수잉뉼, 실업률→시럼뉼, 폭락→퐁낙, 급락→금낙, 협력→혐녁, 합리적→함니적
   - 유음화: 관리→괄리, 연락→열락, 원래→월래, 권력→궐력, 인력→일력, 근로→글로
   - 유음화 예외: 생산량→생산냥, 판단력→판단녁, 공권력→공꿘녁, 의견란→의견난
   - 된소리(기존 VOICE-04 + 추가): 평가→평까, 시가총액→시까총액, 종가→종까, 호가→호까, 유가→유까(유가족은 그대로), 분양가→분양까
2. **영문 약어**: 사전에 있는 것은 관용 읽기(KOSPI→코스피, Fed→연준, DRAM→디램, HBM→에이치비엠), 없는 대문자 약어는 한 글자씩(GDP→지디피). 바뀐 받침에 맞춰 조사도 고친다(Fed가→연준이, Fed로→연준으로).
3. **전처리**: 전화번호, 3Q→삼 분기, 1H/2H→상반기/하반기, 25bp→이십오 베이시스포인트, 21.5p→포인트, 3x→세 배, ₩·€·¥, ㎡, ↑↓, 원/달러, 3.00%→삼 퍼센트(끝자리 0 생략), 500과→오백과.

## 3. 학습 (스스로 잡기)
- 음성을 만들 때마다 받아쓰기(ASR)와 대본을 낱말 단위로 맞춰 본다. 표준발음대로 들린 것(금리를 '금니'로)은 맞은 것으로 친다.
- 틀린 낱말은 `rules/pron_watch.jsonl` 에 목소리별로 남는다.
- **다른 문장에서 2번 이상** 틀리면 `rules/pron_learned.json` 에 소리 나는 대로 적은 발음이 들어가고, 다음 생성부터 자동으로 쓴다(한 번은 ASR 실수일 수 있어서 안 넣는다).
- 틀린 문장은 그 자리에서 **틀린 낱말만 고쳐 한 번 더** 만든다.
- 철자와 소리가 같아서 자동으로 못 고치는 낱말은 'manual' 로 표시된다 → 대본에 `원문{{발음}}` 으로 적거나 `python tools/pron_learn.py --set 낱말 발음` 으로 고정.

## 4. 쓰는 법
```
python tests/test_pronunciation.py            # 규칙 회귀 시험(Voicebox 없이)
python tools/pron_audit.py                    # PC 에서 Voicebox 켜고: 두 목소리로 20문장 점검 → output/pron_audit/<날짜>/report.md
python tools/pron_learn.py                    # 자주 틀린 낱말 표 보기 + 사전 반영
python tools/pron_learn.py --set 장단기 장단끼  # 사람이 정한 발음으로 고정
```
끄기: `voice_ref/announcer_profile.yaml` 의 `apply` 에 `pron: false`(사전) / `learn: false`(학습).

# AIMAX OS — AI 직원 기반 경영관리 시스템

광고대행 · 영상제작 회사를 위한 관리자 콘솔입니다.
AI 직원(예리, 현주, 나경, 상수, 윤미, 송이, 지원, 지은, 은서, 맥스)의 프로필·이력서·권한을 관리하고,
미션을 주고, 오류와 주문을 한 화면에서 봅니다.

## 1. 실행하기 (처음 한 번)

필요한 것: [Node.js](https://nodejs.org) 20 이상 (LTS 버튼으로 설치)

```bash
cd aimax-os
npm install        # 처음 한 번만
npm run dev        # 실행
```

브라우저에서 **http://localhost:3100** 을 열면 됩니다.

> 클로드 코드에게 "aimax-os 실행해 줘" 라고 말해도 됩니다.

## 2. 메뉴

| 메뉴 | 주소 | 하는 일 |
| --- | --- | --- |
| 운영자 콘솔 | `/` | 직원·미션·오류·매출 요약 |
| 직원 목록 · 상태 | `/staff` | 상태(사용 가능/작업 중/검수 중/연결 필요/중지) 확인·변경 |
| 개별 이력서 | `/staff/예: yeri` | 이력서, 업무 성향, 실행 환경, 권한, 개별 미션 |
| 미션 보드 | `/missions` | 미션 부여, 대기→진행→검수→완료 |
| 오류 · 피드백 센터 | `/errors` | 자동 감지된 오류 + 직접 보고, 처리 상태 관리 |
| 주문 · 연동 관리 | `/orders` | 카페24 등 연동 상태, 주문 목록 |
| 계정 · 권한 | `/accounts` | 운영자 계정 등록, AI 직원 권한표, 구매자 목록 |

## 3. 오류가 났을 때 (가장 중요)

1. 화면에서 오류가 나면 **자동으로 `오류 · 피드백 센터`에 기록**됩니다. (왼쪽 메뉴에 빨간 숫자)
2. 해당 항목을 열고 **📋 클로드 코드용 복사** 를 누릅니다.
3. 클로드 코드에 붙여넣고 엔터 → 클로드가 원인을 찾아 고칩니다.
4. 고쳐졌으면 상태를 **해결** 로 바꿉니다.

직접 발견한 불편함·개선 아이디어도 같은 화면의 **직접 보고** 폼에 적고, 똑같이 복사해서 요청하면 됩니다.
`🧪 테스트 오류 발생` 버튼으로 자동 기록이 잘 되는지 확인해 볼 수 있어요.

## 4. 데이터는 어디에 저장되나요?

지금은 **이 브라우저 안(localStorage)** 에 저장됩니다. 설치 없이 바로 쓸 수 있는 대신,
다른 컴퓨터·다른 브라우저와는 공유되지 않습니다. 여러 사람이 함께 쓰려면 다음 단계로
DB(Supabase 등)를 붙이면 됩니다 — `lib/store.tsx` 한 파일만 바꾸면 되도록 만들어 두었습니다.

처음 예시 데이터로 되돌리려면 운영자 콘솔의 **↺ 예시 데이터로 초기화**.

## 5. 카페24 연동

1. [카페24 개발자센터](https://developers.cafe24.com)에서 앱을 만들고 Access Token 발급
2. `aimax-os/.env.example` 을 복사해 `aimax-os/.env.local` 로 이름 바꾸고 값 입력
3. 다시 실행 후 `주문 · 연동 관리` → **🔄 카페24 주문 가져오기**

값이 없으면 "연결 필요"로 표시되고, 실패하면 오류 센터에 자동 기록됩니다.

## 6. 클로드 코드로 고치고 늘리는 법 (예시 요청)

- "직원 목록에 '수진 - 썸네일 디자인' 직원 추가해 줘"
- "미션 보드에 마감일 지난 미션은 빨간색으로 보이게 해 줘"
- "운영자 콘솔에 이번 달 매출 그래프 추가해 줘"
- "Supabase로 데이터 저장하게 바꿔 줘"
- "로그인 기능 붙여 줘"

클로드 코드는 `CLAUDE.md` 에 적힌 규칙을 읽고 작업합니다.

## 7. 폴더 구조

```
aimax-os/
├─ app/                    ← 화면(페이지). 폴더 이름 = 주소
│  ├─ page.tsx             운영자 콘솔
│  ├─ staff/page.tsx       직원 목록
│  ├─ staff/[id]/page.tsx  개별 이력서
│  ├─ missions/            미션 보드
│  ├─ errors/              오류 · 피드백 센터
│  ├─ orders/              주문 · 연동
│  ├─ accounts/            계정 · 권한
│  ├─ api/cafe24/orders/   카페24 주문을 가져오는 서버 기능
│  ├─ layout.tsx           공통 틀 (사이드바)
│  └─ error.tsx            화면이 멈췄을 때 보이는 안내
├─ components/             여러 화면에서 같이 쓰는 부품 (사이드바, 배지, 폼…)
├─ lib/
│  ├─ types.ts             데이터 모양 정의
│  ├─ seed.ts              예시 데이터 (AI 직원 10명 등)
│  ├─ labels.ts            화면에 보이는 한글 이름·색
│  ├─ store.tsx            데이터 저장소
│  └─ integrations/        외부 서비스 연동 (카페24)
└─ CLAUDE.md               클로드 코드 작업 규칙
```

## 8. 참고한 오픈소스

화면 구성(왼쪽 사이드바 + 카드형 대시보드 + 표)은 아래 MIT 라이선스 오픈소스의 구조를 참고했습니다.

- [shadcn/ui](https://ui.shadcn.com) — 필요할 때 부품 단위로 복사해 쓰는 UI 모음

# /learn — 회사 기억 (프롬프트·경험은 자산)

`04_기록/배운점.md` 하나에 아래 형식으로 쌓는다 (최신이 위):

```
## YYYY-MM-DD · 분류(영업/시안/고객/운영/실수) · 업무번호
- 무엇: 한 줄
- 근거: 숫자나 사실 (예: DM B안 20통 중 답장 3)
- 앞으로: 이렇게 한다 / 이렇게 하지 않는다
```

- **추가**: 캡틴이 말한 것 또는 회고·실수에서 나온 것. 추측은 ‘가설’로 표시.
- **찾기**: 새 업무 시작 전 관련 분류를 읽고 반영한다 (/new-job, /dm-batch 가 먼저 읽음).
- **정리**: 30개가 넘으면 같은 내용을 합치고, 틀린 것으로 밝혀진 것은 ‘폐기: 이유’로 표시(삭제하지 않음).
- 개인정보·고객 연락처·비밀번호는 절대 적지 않는다.

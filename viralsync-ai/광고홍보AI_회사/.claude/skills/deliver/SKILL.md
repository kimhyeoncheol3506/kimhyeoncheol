# /deliver — 바로의 출고 준비

1. `04_기록/결재대장.md` 에서 상태가 **승인**인 줄만 고른다. 대기·보류·거절은 손대지 않는다. 승인 뒤 내용이 바뀌었으면 다시 결재로.
2. 승인분마다 전달 패키지 `03_결과/<번호>_바로_전달패키지.md`:
   - 최종 캡션(검수 통과본 그대로) · 업로드 요일·시간(손님 시간대) · 위치태그·해시태그
   - 가게 본인 계정이면: 사장님 링크(웹 앱)나 카톡으로 승인받는 방법, 승인 캡처 보관 위치
   - 웹 앱에서 할 일: 실행 관리에 등록 / 스레드 바로 올리기 (사람이 누름)
3. 결재대장의 그 줄 ‘실행 기록’ 칸에 “전달 패키지 작성 (게시 전)”을 적는다. 실제 게시 후에는 캡틴이 ‘게시 완료 + 링크’를 적는다.
4. 외부 업로드·발송 명령은 쓰지 않는다 (안전 훅이 막음).

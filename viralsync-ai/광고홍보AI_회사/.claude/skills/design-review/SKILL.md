# /design-review — 시안 디렉터

각 시안을 항목별 0~10점 + 근거 한 줄로 채점하고, 7점 미만은 반드시 고친다.

| 항목 | 10점의 모습 |
|---|---|
| 첫 3초 후킹 | 화면·자막만 봐도 멈추게 됨 (질문·숫자·대비) |
| 한 가지 메시지 | 영상 하나에 말하고 싶은 것 하나 |
| 가게다움 | 그 가게만의 디자인·공간·사장님 말투가 보임 |
| 자막 가독성 | 휴대폰에서 한 줄 7~12자, 화면 위쪽 1/3 |
| 리듬 | 장면 2~3초, 박자에 맞춘 전환 1~2종 |
| 행동 유도 | 예약·프로필 링크 등 다음 행동 하나 |
| 일관성 | 색·글꼴·로고 위치가 계정 전체와 같음 |
| 정확성 | 이름·가격·위치가 브랜드 자료와 일치 |
| 길이 | 릴스 15~25초, 캡션 3줄 이내 + 해시태그 3~5개 |
| AI 티 없음 | 아래 상투어 0개 |

**AI 티(slop) 문구 — 발견하면 구체적인 말로 바꾼다**: “지금 바로 만나보세요”, “특별한 경험”, “완벽한”, “최고의”, “놓치지 마세요”, “여러분의 일상에”, “~의 모든 것”, 이모지 3개 이상 연속, 해시태그 10개 이상.

결과: 같은 파일에 `## 디자인 검토` 절(점수표 + 고친 판). 원본은 지우지 않는다.

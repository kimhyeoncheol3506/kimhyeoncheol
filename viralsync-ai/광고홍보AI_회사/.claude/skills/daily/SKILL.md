# /daily — 5줄 보고

읽을 것: `04_기록/재개기록.md`, `04_기록/결재대장.md`(대기 건수), 오늘 바뀐 `03_결과/` 파일, `04_기록/배운점.md` 최근 항목.
캡틴이 숫자를 알려 주면 반영 (오늘 DM 수·답장·만남·계약 — 웹 앱 영업 리스트·대시보드 숫자).

출력 (5줄 이내, 쉬운 말, 모르면 ‘미확인’):
1. **한 일:** …
2. **결과:** …
3. **캡틴이 할 일:** 결재 대기 N건 / 오늘 DM 목표 10통 중 N통 …
4. **막힘:** … (없으면 ‘없음’)
5. **숫자:** 리스트 N/100 · 누적 DM N · 체험 N · 유료 N (월 N원)
같은 내용을 `04_기록/재개기록.md` ‘마지막 상태’에도 갱신.

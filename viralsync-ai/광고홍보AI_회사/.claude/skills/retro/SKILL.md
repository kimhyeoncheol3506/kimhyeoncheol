# /retro — 주간 회고 (전략의 날)

1. 숫자 (캡틴에게 웹 앱 대시보드·영업 리스트·재무 숫자를 받거나 기록에서 집계):
   | | 이번 주 | 지난주 | 목표 |
   |---|---|---|---|
   | 리스트 / DM / 답장 / 만남 | | | 100 / 주 50 / — / 주 1 |
   | 체험 / 유료 / 월 매출 | | | 4주 체험 1 · 8주 유료 1 · 12주 단골 3 |
2. 이번 주 `03_결과/` 업무번호별 상태, 결재대장 대기·승인·거절.
3. **실패 신호** 확인: 3개월 연속 매출 하락 · 이번 달 문의 0 · 잔고가 고정비 2개월치 미만 → 있으면 맨 위에.
4. 잘된 것 2 · 아쉬운 것 2 · 다음 주 **우선순위 3개** (첫 계약에 가까운 순).
5. `/learn` 으로 이번 주 배운 점 1~3개 저장.
6. `04_기록/회고_YYYY-MM-DD.md` 로 저장하고 재개기록 갱신.

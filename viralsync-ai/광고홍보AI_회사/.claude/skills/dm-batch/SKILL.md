# /dm-batch — 두드림의 DM 준비

입력: 캡틴이 붙여 준 가게 목록(가게 이름·업종·동네·인스타·마지막 게시일·특징) — 웹 앱 영업 리스트에서 복사하거나 `02_자료/` 사본.

1. 가게마다 **진단 한 줄**을 그 가게 정보로만 쓴다 (모르면 쓰지 않는다): 업로드 공백 / 릴스 없음 / 프로필에 예약·위치 없음 / 동네 해시태그 없음.
2. `03_결과/T002_두드림_네일샵DM.md` 의 A·B·C 중 맞는 틀로 DM 초안. **가게마다 문장이 달라야 한다** — 같은 문장 반복 금지(계정 제한 위험).
3. 금지: 거짓 칭찬·지어낸 사실, 효과 보장, 오늘 계약 압박, ‘AI 로 만듭니다’를 앞세우기.
4. 결과 `03_결과/<번호>_두드림_DM_YYYYMMDD.md`: 표(가게 · 진단 한 줄 · DM 초안 · 시안 필요 여부).
5. 마지막 줄: “보낸 뒤 웹 앱 영업 리스트에서 ‘DM 보냄 ✓’ 을 눌러 주세요.” 발송은 절대 대신 하지 않는다.

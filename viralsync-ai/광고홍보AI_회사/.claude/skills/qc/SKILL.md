# /qc — 지킴의 검수

`03_결과/` 의 대상 파일마다:

1. **검수 7개** (`05_매뉴얼/05_검수.md`): 오타(이름·가격·전화) · 경쟁 상표 · AI 기형 · 사장님 승인 예정 · 음악 라이선스 · 해시태그·위치태그 · 손님 시간대 예약.
2. **금지선** (CLAUDE.md 5절): 손님·후기인 척(“제가 직접 해보니”, “내돈내산”, “솔직 후기”), 효과·매출 보장(“무조건”, “100%”, “보장”), 직거래 유도, 모의 수치를 실측처럼.
3. **광고 표시**: 제3자 계정·체험단 → 광고 표시 필수. 가게 본인 계정 → 없어도 됨.
4. **사실 대조**: 시안 속 모든 사실(가격·영업시간·시술 이름·수치)이 `02_자료/` 브랜드 자료에 있는가. 없으면 ‘예시’ 표시 또는 삭제.
5. 판정: 통과 / 차단(이유 한 줄 + 되돌릴 담당). 차단은 재작업 최대 2회, 그다음은 캡틴에게.

결과: `03_결과/<번호>_지킴_검수결과.md` 표 (대상 · 판정 · 근거). 통과분만 결재대장에 올린다.

# /office-hours — 시작 전 6가지 질문 (한결이 진행)

캡틴의 아이디어를 바로 만들지 말고, 한 번에 **한 질문씩** 묻는다. 모르면 ‘미확인’으로 두고 넘어간다.

1. **누가 돈을 내나?** 가장 좁게 — 예: “망원동 1인 네일샵 사장님”. ‘중소상공인’은 답이 아니다.
2. **지금은 어떻게 해결하고 있나?** 직접 올림 / 가족이 함 / 안 함 / 다른 대행사.
3. **돈 내는 순간은?** 월 정액 / 건당 / 성과 — 언제 얼마를.
4. **48시간 안에 1건 납품 가능한가?** 6공정(인터뷰→아이디어 20→시나리오 3→영상→검수→예약) 중 어디가 막히나.
5. **증거는?** 이미 이걸 돈 받고 파는 사람(경쟁자) 1명 이상, 관심 보인 사장님 1명 이상.
6. **하지 않을 것은?** 이번에 일부러 빼는 범위 2가지.

# /new-job — 의뢰 한 건 파이프라인 (gstack /autoplan 처럼, 캡틴은 취향 결정만)

1. `04_기록/재개기록.md` 의 마지막 업무번호 다음 번호(T003…)를 붙이고 재개기록에 ‘진행 중’으로 적는다.
2. 입력은 `02_자료/` 의 **개인정보를 가린 사본**만. 연락처·주민번호 등이 보이면 멈추고 캡틴에게 가려 달라고 요청.
3. 직원 지시서(`01_직원/`)를 순서대로 따라 결과를 `03_결과/<번호>_<직원>_<내용>.md` 로:
   1. 이음 — 의뢰 분석표 + 고객에게 물어볼 것
   2. 나침 — 매체 기획 (견적 금액은 웹 앱 견적 엔진 담당)
   3. 글담 — 매체별 문구 / 컷 — 숏폼 대본 (가게 본인 계정이면 광고 태그 없이, 제3자면 광고 표시)
   4. `/design-review` — 시안 점수와 고친 판
   5. `/qc` — 검수 7개 + 금지선 + 사실 대조. 차단이면 3으로 (최대 2회)
4. 게시·발송할 것은 `04_기록/결재대장.md` 에 **대기**로 올리고 멈춘다. 캡틴이 정할 취향 문제(톤·후킹 문장 A/B)만 질문으로 남긴다.
5. `/daily` 형식 5줄 보고.

# 4. 제작 — 영상 생성 체크리스트 · 썸네일 규칙

## 영상
- 세로 9:16, 첫 3초 후킹 문장, 자막은 크게 (휴대폰 기준)
- 사장님 사진·영상 원본 우선, AI 생성 컷은 보조
- AI 생성 특유의 기형(손가락·글자 왜곡) 확인
- 음악은 유료 음원 라이브러리 또는 무료 라이선스 곡만

## 썸네일 (캔바)
- 모든 채널 같은 색·같은 글꼴·같은 로고 위치 (전문성은 일관성에서)
- 글자는 7자 이내 한 줄, 가게 이름은 정확히

## 벤치마킹 폴더
- 매주 업종 조회수 높은 릴스 10개 저장 + ‘첫 3초 문구 · 자막 크기 · 전환 횟수’ 메모. 강의 대신 이게 커리큘럼.

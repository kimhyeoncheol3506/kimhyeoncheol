# 6. 발행 — 예약 업로드 절차 · 해시태그

1. 내부 결재(검수 7개) → 2. 사장님 링크 승인 → 3. 실행 관리에서 예약/게시
- 예약 시간: 손님 시간대 (점심·저녁 전)
- 위치태그(플레이스 연동)와 해시태그 입력
- 가게 본인 계정 글은 광고 태그 불필요. 다른 사람 계정·체험단 글은 반드시 #광고·유료 광고 표시
- 같은 글 반복 게시 금지, 실패 재시도 최대 2회

## 해시태그 기본 묶음 (업종 + 동네 + 상황 3~5개)
- 예: #망원동미용실 #망원동펌 #퇴근후펌

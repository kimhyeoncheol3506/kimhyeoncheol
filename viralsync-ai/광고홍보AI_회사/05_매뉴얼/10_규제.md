# 10. 규제 — 투자정보 부문 금지·허용 문구 (제2권, 1년차 이후)

**핵심 한 줄:** 불특정 다수에게 ‘정보와 해석’은 팔 수 있다. 특정인에게 ‘사라/팔아라’를 권하고 돈을 받으면 투자자문업 등록 대상.

| 가능 | 금지 (등록 없이) | 피할 것 |
|---|---|---|
| 시장 해설 뉴스레터 구독 | “A 종목 지금 사세요” | 특정 종목 ‘강력 추천’ + 정기구독료 |
| 출처·기준일 있는 종목 리포트 | 개인 포트폴리오별 매매 제안 | |
| 투자 교육 강의·책 | 수익률 보장·단정 | |
| 데이터 스크리닝 툴 | 돈 받고 개별 매수·매도 타이밍 알림 | |

- 모든 수치에 출처·기준일 · 말미에 ‘본 자료는 특정 종목의 매수·매도 권유가 아닙니다’ · AI 문장도 발행인 검수 고지 · 환불 규정 명확히
- 이 부문은 마케팅 회사가 1년 문제없이 운영된 뒤에. 정보 제공이며 법률 자문이 아님 — 시작 전 전문가 상담.

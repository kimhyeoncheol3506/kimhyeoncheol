# 1. 영업 — DM 스크립트 · 제안서 · 반박 대응

## 사냥 리스트 (목표 100곳)
- 카카오맵·네이버 지도에서 집중 업종을 검색 → 인스타 게시물이 3개월 넘게 없는 가게부터
- 적을 것: 가게 이름 · 사장님 성함(후기에서 확인) · 계정 · 마지막 게시일 · DM 여부 · 반응
- 앱: **영업 리스트** (스프레드시트에서 복사해 일괄 붙여넣기 가능)

## 첫 DM — ‘진단’ 으로 시작 (하루 10통, 캡틴 계정에서 직접)
```
○○ 사장님 안녕하세요, 동네에서 SNS 운영을 돕고 있는 사람입니다.
사장님 가게 인스타 보니까 분위기가 정말 좋은데 업로드가 한 달에 몇 개뿐이라 아쉬웠어요.
혹시 인스타 릴스는 따로 신경 쓰기 힘드셨나요? 제가 무료로 20초 릴스 시안 하나 만들어 드릴게요.
쓸모 있으면 쓰시고, 아니면 안 쓰셔도 됩니다. 가게 사진 두 장만 보내 주시면 돼요.
```
- ‘저희 회사는 AI 마케팅을 합니다’ 는 쓰지 않습니다. 그 가게 사진으로 만든 20초 시안 링크를 함께.
- 100통 → 답장 5~10 → 만남 2~3 → 계약 1. 확률 게임이니 감정 상하지 말고 수량으로.

## 만남 루틴 (30분, 팔지 말고 듣기)
1. 가게 이야기 듣기 → 2. 24시간 안에 진단 요약 + 무료 시안 → 3. 전화 10분 수정 → 4. 패키지 표 + ‘2주 무료 후 결정’ (당일 계약 압박 금지)

## 제안서 3페이지
1쪽 현재 SNS 진단(스크린샷 + 문제 3줄) · 2쪽 바꿀 계획(전/후) · 3쪽 패키지·가격·무료 2주 조건 — 앱: 영업 리스트 → 가게 → 제안서

## 반박 대응
- “AI가 만든 영상이라 티 나지 않아요?” → 시안 단계에서 사장님이 직접 보고 고르십니다. 올라가는 건 사장님이 승인한 것만 올라갑니다.
- “우리 애가 하고 있어요” → 그럼 제가 받아서 올리는 걸 도와드리는 방식도 가능해요. 방향은 사장님이 잡고 저는 손발이 되는 겁니다.
- “효과가 있을까요?” → 솔직히 한 달로는 모릅니다. 그래서 2주 무료로 해 보고, 사장님이 ‘이건 되겠다’ 싶을 때 결정하시면 됩니다.
- “가격이 부담돼요” → 가격은 그대로 두고 양을 줄여 드릴게요. 월 15만 원에 릴스 4편으로 시작해 보시겠어요?
- “AI 쓰시는 거예요?” → 네, AI 보조 도구로 시안을 빠르게 만들고, 사람이 하나하나 검수합니다. 올라가는 건 사장님 승인한 것만입니다.

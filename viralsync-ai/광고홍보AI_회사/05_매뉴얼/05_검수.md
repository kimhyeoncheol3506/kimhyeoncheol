# 5. 검수 — 올리기 전 필수 7개 (앱 결재함에서 체크해야 승인됨)

1. ☐ 가게 이름·가격·전화번호 오타 확인
2. ☐ 경쟁 가게 이름·상표가 배경에 잘못 나오지 않음
3. ☐ AI 생성 특유의 기형(손가락·글자 왜곡) 없음
4. ☐ 사장님 승인 없이 올리지 않음 (승인 예정 포함)
5. ☐ 음악은 유료 음원 라이브러리 또는 무료 라이선스 곡만
6. ☐ 해시태그·위치태그(플레이스 연동) 입력
7. ☐ 예약 시간이 손님 시간대(점심·저녁 전)

## 실수했을 때 — 2시간 룰
2시간 안에 사과 DM + 삭제/수정 + 사유 설명. 숨기면 불신이 커지고, 빨리 사과하면 신뢰가 생깁니다.

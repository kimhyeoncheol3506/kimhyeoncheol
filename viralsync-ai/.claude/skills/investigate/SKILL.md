# /investigate — 원인부터

1. **재현**: 실패를 그대로 재현하는 가장 짧은 명령을 찾는다 (예: `npx vitest run tests/integration/x.test.ts -t "이름"`).
2. **증거 모으기**: 오류 전문, 스택, 관련 코드, 최근 변경(`git log -p -5 -- <파일>`), DB 상태(`psql`, 테스트 DB 만).
3. **가설 1~3개**를 적고, 각 가설을 확인/반박할 가장 싼 실험을 한다. 확인된 원인 하나를 한 문장으로 적는다.
4. 원인을 고치는 **최소 수정** + 그 원인을 잡는 테스트.
5. 고치기 시도는 최대 3번. 3번째도 실패하면 멈추고 보고: 원인 후보 · 해 본 것 · 남은 가설 · 추천 다음 단계 하나.
6. 환경 문제(Postgres 꺼짐, 포트 사용 중, 빌드 산출물 오래됨)를 먼저 의심: `pg_isready`, 다시 `npm run build`.

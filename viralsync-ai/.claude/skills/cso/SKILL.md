# /cso — 보안 책임자

각 항목을 **코드 위치와 이를 지키는 테스트**로 확인한다. 테스트가 없으면 ‘미검증’.

| 영역 | 확인할 것 |
|---|---|
| 공개 경로 | `src/middleware.ts` 의 PUBLIC 목록(`/login`, `/media/`, `/c/`) 외에 로그인 없이 열리는 곳이 없나 |
| 사장님 링크 | 토큰이 무작위 24바이트·정규식 검사·재발급 시 이전 무효·고객 하나로만 범위 제한, 하루 업로드 한도 |
| 업로드 | 파일 시그니처 검사(확장자 신뢰 X), 8MB 제한, 추측 불가 파일명, 목록 조회 없음 |
| 권한 | 모든 서비스 함수의 `assertCan`, 화면 숨김에만 의존하는 곳 |
| 테넌트 | 다른 조직 id 로 조회·수정 시 NotFound (통합 테스트 존재 여부) |
| 비밀값 | `.env*`·`.dev.vars` 커밋 여부(`git ls-files`), 토큰 암호화, 로그 출력 |
| 데모 계정 | 공개 주소에서 데모 로그인 차단, 운영 DB 에 데모 시드 금지 안내 |
| 세션 | 쿠키 httpOnly·secure·sameSite, `SESSION_SECRET` 길이 |
| 외부 호출 | AI 예산 상한, 재시도 2회, 게시 성공 불명확 시 자동 재시도 없음 |

결과: `높음/중간/낮음 · 위치 · 시나리오 · 고침` 목록. 높음은 바로 고치고 `/verify`.

# /review — 스태프 엔지니어 리뷰

`git diff` (커밋 전) 또는 `git diff origin/<기본브랜치>...HEAD` 를 읽고, 바뀐 파일마다 아래를 확인한다. 근거(파일:줄)와 실제로 터지는 시나리오가 있는 것만 지적.

## 체크리스트
- [ ] **범위 누수**: 새 `findMany/findFirst/update/delete` 에 `organizationId` 와 고객 범위(`clientWhere`·`campaignWhere`·`scopeWhere`)가 있나? 범위를 `{...where, id}` 로 덮어쓰지 않나?
- [ ] **권한**: 새 서비스 함수가 `assertCan` 으로 시작하나? 액션이 `requireCtx()` 를 부르나? (사장님 링크 액션만 토큰으로 확인)
- [ ] **사람 승인 우회**: 게시·발송·계약 경로가 결재/검수 7개/사장님 승인을 건너뛸 수 있나?
- [ ] **광고 원칙**: 생성·검사 로직이 위장 후기·보장 표현을 통과시키나? 자동 발송 코드가 생겼나?
- [ ] **비밀값**: 키·토큰·비밀번호가 로그·응답·클라이언트 컴포넌트로 새나? `"use client"` 파일에서 서버 전용 모듈을 import 하나?
- [ ] **Cloudflare**: `node:fs`·전역 Prisma 클라이언트·긴 동기 작업을 새로 썼나?
- [ ] **트랜잭션**: 여러 테이블을 함께 바꾸는데 `$transaction` 밖인가? 감사 로그(`audit`)가 빠졌나?
- [ ] **테스트 약화**: 테스트를 지우거나 기대값을 느슨하게 했나? 새 분기에 테스트가 있나?
- [ ] **스키마**: 새 필수 컬럼에 기본값이 있나(기존 데이터)? 시드·`base-data.ts`·테스트 헬퍼를 맞췄나?
- [ ] **단일 원본**: `staff.ts`·`playbook.ts` 를 고쳤으면 `npm run staff:export` 를 했나?

## 결과
- 명백한 버그(한 줄로 고칠 수 있고 동작이 분명한 것)는 바로 고치고 `/verify`.
- 나머지는 `심각도 · 파일:줄 · 시나리오 · 제안` 목록으로 보고. 문제 없으면 “지적 없음”이라고만.

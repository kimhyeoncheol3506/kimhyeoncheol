# /retro — 주간 회고

1. `git log --since="7 days ago" --stat --pretty="%h %ad %s" --date=short` 로 이번 주 변경을 영역별(영업·계약·결재·회사 폴더·배포·테스트)로 묶는다.
2. 테스트 추이: README ‘마지막 실행 결과’의 수와 지금 `npx vitest run` 수를 비교 (줄었으면 이유).
3. 회사 폴더 `광고홍보AI_회사/04_기록/재개기록.md`·`결재대장.md` 에서 대기 중인 결재·막힌 일.
4. 정리 (5~10줄):
   - 잘된 것 2 · 아쉬운 것 2
   - 위험 (예: 미검증 배포, 무료 플랜 CPU 한도, 테스트 없는 영역)
   - **다음 주 우선순위 3개** — 매출(첫 계약)에 가까운 순서로
5. `광고홍보AI_회사/04_기록/회고_YYYY-MM-DD.md` 로 저장.

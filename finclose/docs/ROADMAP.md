# 로드맵 (ROADMAP)

## 1단계 — MVP (현재)
채권 외부 평가단가 대사 업무 전체 흐름, 전표 업로드 검증 템플릿, 공통 판독/검증/증감/보고/감사, PWA 앱.

## 2단계 — 반복 업무 자동화
업무 템플릿 라이브러리 확장, 일괄 업로드 자동 분류 고도화, 처리 스케줄, 결과 보고서 문장 자동화(로컬),
업로드 대상 시스템별 어댑터(규격 수령 후).

## 3단계 — 금융상품별 모듈
채권 경과이자, 주식/ETF 잔고·설정환매 대사, 장외파생 평가, RP·대차, 외화환산, 원장-보조원장, 월별 손익/재무제표.

## 4단계 — 통제·운영 고도화
SSO 인증·권한, PostgreSQL, 중요성 기준 업무별 관리, 예외승인 대시보드, 백업/복구 자동화, 사내 AI 연계(승인 시).

## 의사결정 기록
- PyMuPDF(AGPL) 대신 pdfplumber(MIT) — 라이선스 리스크 회피.
- DuckDB 미도입 — MVP 데이터 규모(수만 행)에서 불필요, 의존성 최소화.
- Great Expectations/Soda 미도입 — 자체 검증 엔진이 차단정책·NOT_RUN·예외승인을 직접 표현.
- 외부 AI 미사용 — 금융정보 외부 전송 금지 원칙. 업무 추정은 로컬 휴리스틱.
- 앱 버전은 PWA — 네이티브 스토어 배포는 사내 MDM 정책 확인 후 Capacitor/Tauri로 검토.

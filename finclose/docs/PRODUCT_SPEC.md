# FinClose AI — 제품 요구사항 (PRODUCT_SPEC)

> 상태 표기: ✅ 구현·테스트됨 / 🟡 기본 구현(제한 있음) / 🧪 모의 구현 / ⛔ 미구현

## 1. 목적
증권회사 회계팀의 반복 결산 업무(파일 수집·판독·정형화·계산·대사·증감분석·결과파일 생성)를
**결정론적 코드와 명시적 규칙**으로 자동화하고, 다층 검증으로 오류를 사전에 탐지하며,
모든 결과의 근거(원천 파일 해시, 규칙 버전, 승인 이력)를 추적 가능하게 한다.

## 2. 비목표 (MVP 범위 밖)
- 실제 원장·회계시스템 전표 반영 (⛔ 의도적으로 미구현 — 승인된 별도 연계 모듈 필요)
- 외부 AI 서비스로의 데이터 전송 (⛔ 의도적으로 미구현 — 모든 "추정"은 로컬 휴리스틱)
- 회계정책의 자동 확정 (⛔ 금지 — 규칙은 사람이 승인해야 APPROVED 상태가 됨)
- 다중 사용자 인증 (⛔ — MVP는 로컬 단일 PC용, 사용자/역할은 화면에서 선택하는 **데모용 전환**)

## 3. 사용자와 역할
| 역할 | 코드 | 권한 |
|---|---|---|
| 관리자 | admin | 모든 권한, 설정(중요성 기준) 변경 |
| 업무 담당자 | preparer | 업로드, 분석, 실행, 템플릿 초안 작성 |
| 검토자 | reviewer | 검토 의견, REVIEW_REQUIRED 항목 확인 |
| 승인자 | approver | 실행 승인/반려, 예외 승인, 템플릿 활성화, 확정(업로드 파일 생성) |
| 조회 전용 | viewer | 조회만 |

직무분리: 실행을 만든 사람은 같은 실행을 승인할 수 없다(✅).

## 4. 시나리오별 지원 현황
| 시나리오 | 상태 | 비고 |
|---|---|---|
| A. 정기 반복 결산(채권 외부 평가단가 대사) | ✅ | 업로드→분석→매핑→실행→검증→증감→검토→승인→확정 |
| B. 신규 업무 자동화(초안 템플릿 제안) | 🟡 | 공통 키·금액·날짜 컬럼 추정 후 **초안** 템플릿 JSON 생성. 계산 규칙은 사람이 작성 |
| C. 기존 자료 형식 변경 탐지 | ✅ | 시트명·컬럼 추가/삭제/변경·유형·건수·단위 변경 탐지, 확인 전 자동처리 중단 |
| D. 전월·전분기·전년동기·전기말·12개월 추이 | ✅ | 실행 이력(동일 템플릿) 기반 자동 비교 + 전월 파일 직접 비교 |

## 6. MVP 시연 업무
"채권 외부 평가단가 대사 및 결산 검토" (`BOND_EXT_PRICE_RECON`)
- 입력 A 보유내역, B 외부 평가단가, C 전월 평가결과
- 평가금액 = 보유수량(액면) × 평가단가 ÷ 단가기준액면(10,000) — **예시 산식(EXAMPLE)**.
  실제 적용 전 단가 표시단위, 경과이자 포함 여부, 평가방식, 통화, 회사 정책 확인 필요.
  예시 산식이 쓰인 실행은 항상 `REVIEW_REQUIRED` 항목을 생성한다.

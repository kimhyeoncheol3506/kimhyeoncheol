FinClose 처음 써보기

매달 하는 결산 계산과 확인을 대신 해 주는 프로그램입니다. 엑셀 파일을 넣으면 계산하고, 틀린 곳을 찾고, 지난달과 비교해 줍니다. 이 설명서를 처음부터 따라 하면 30분 안에 한 번 끝까지 써 볼 수 있습니다.

이 프로그램 안에는 세 사람이 일하고 있다고 생각하면 쉽습니다.

계산 담당엑셀 파일을 읽고, 정해진 식대로 금액을 계산합니다. 계산기처럼 정확하게 같은 방법으로만 계산합니다.
깐깐한 채점관계산이 맞는지 다른 방법으로 한 번 더 풀어 보고, 빠진 것·중복된 것·이상한 숫자 37가지를 검사합니다.
도장 찍는 사람사람이 직접 확인하고 승인 도장을 찍기 전에는 최종 파일을 절대 만들지 않습니다.

준비물 챙기기

처음 한 번만 하면 됩니다. 두 가지가 필요합니다.

① 파이썬(Python) 설치

파이썬은 이 프로그램이 돌아가는 엔진입니다. 게임을 하려면 게임기가 필요한 것과 같습니다.

  1. python.org/downloads에 들어가 노란 Download Python 버튼을 누릅니다.
  2. 받은 설치 파일을 실행합니다.
  3. 첫 화면 아래쪽의 Add python.exe to PATH 칸에 꼭 체크하고 Install Now를 누릅니다.
여기서 많이 틀립니다"Add python.exe to PATH" 체크를 빼먹으면 다음 단계에서 "Python을 찾을 수 없다"는 오류가 납니다. 그럴 땐 설치 파일을 다시 실행해 Modify로 들어가 체크하면 됩니다.
회사 PC라면프로그램 설치가 막혀 있을 수 있습니다. 전산팀에 "Python 3.11 이상 설치"를 요청하세요.

② FinClose 파일 내려받기

  1. GitHub에 로그인한 상태에서 아래 주소로 들어가면 ZIP 파일이 바로 내려받아집니다.
https://github.com/kimhyeoncheol3506/kimhyeoncheol/archive/refs/heads/claude/finclose-ai.zip
  1. ZIP 파일을 마우스 오른쪽 버튼 → 압축 풀기로 풉니다. 바탕화면처럼 찾기 쉬운 곳에 두세요.
  2. 풀린 폴더 안의 finclose 폴더가 이 프로그램입니다.
2

프로그램 켜기

처음 써 볼 때는 연습용 데이터와 함께 켜는 것을 추천합니다. 지난 몇 달치 결산을 가짜로 미리 끝내 두기 때문에, 바로 "지난달과 비교" 기능까지 볼 수 있습니다.

윈도우

  1. finclose 폴더를 엽니다.
  2. 폴더 위쪽 주소창을 한 번 클릭하고 cmd라고 쓴 뒤 엔터를 누릅니다. 검은 창이 열립니다.
  3. 검은 창에 아래 글자를 쓰고 엔터를 누릅니다.
run.bat demo

맥(Mac)

cd 내려받은위치/finclose
./run.sh demo
  1. 처음에는 필요한 부품을 설치하느라 3~5분 걸립니다. 다음부터는 몇 초면 켜집니다.
  2. 서버 시작: http://127.0.0.1:8000이라는 글자가 보이면 준비 끝입니다.
  3. 크롬이나 엣지 브라우저를 열고 주소창에 아래 주소를 입력합니다.
http://127.0.0.1:8000
끄는 방법검은 창을 클릭하고 Ctrl + C를 누르거나 창을 닫으면 됩니다. 다음에 다시 쓸 때는 run.bat만 입력하면 됩니다(demo는 처음 한 번만).
검은 창은 켜 둬야 합니다검은 창이 프로그램의 본체입니다. 창을 닫으면 브라우저 화면도 동작하지 않습니다.

파일 올리기

왼쪽 메뉴에서 결산 실행을 누릅니다. 연습용 파일은 finclose → sample_data → bond_2026-09 폴더에 3개 있습니다.

  1. 보유채권내역, 외부평가단가, 전월평가결과 파일 3개를 한꺼번에 선택합니다.
  2. 점선 상자 안으로 끌어다 놓습니다. 상자를 클릭해서 고를 수도 있습니다.
  3. 표에 파일이 나타나고 판독완료가 보이면 성공입니다.
  4. 파란 ② 업무 식별·분석 버튼을 누릅니다.
무슨 일이 일어나나요?프로그램이 파일을 열어 어떤 표가 있는지, 기준일이 언제인지 읽습니다. 그리고 "이건 예전에 하던 채권 평가 업무랑 똑같이 생겼네" 하고 알아봅니다. 사람 얼굴을 보고 아는 사람인지 알아보는 것과 비슷합니다.

계획 확인하기

프로그램이 "이렇게 처리하겠습니다" 하고 계획서를 보여 줍니다. 요리하기 전에 레시피를 확인하는 단계입니다.

  • 결산 기준일: 몇 월 말 결산인지입니다. 파일에서 찾아 자동으로 채워 줍니다. 틀리면 직접 고칩니다.
  • 컬럼 매핑: 엑셀의 각 열이 무엇인지 짝지은 표입니다. 예를 들어 엑셀의 "보유수량" 열을 프로그램의 "보유수량"과 연결합니다. 짝이 틀렸으면 오른쪽 목록에서 바꿉니다.
  • 일치는 이름이 똑같아 확실한 것, 유사(확인필요)는 비슷해서 짐작한 것입니다. 짐작한 것은 꼭 눈으로 확인하세요.

다 확인했으면 맨 아래 파란 ④ 실행·검증 버튼을 누릅니다. 몇 초 뒤 결과 화면으로 넘어갑니다.

지난달과 비교하기

결과 화면의 증감 분석 탭을 누릅니다. 오른쪽 위 목록에서 비교할 시점을 고릅니다.

  • 전월 대비: 지난달 말과 비교
  • 전분기말 대비: 3개월 단위로 끊은 지난 분기 말과 비교
  • 전년 동기 대비: 작년 같은 달과 비교
  • 전기말 대비: 작년 12월 말과 비교
"원인 후보"는 추측입니다"수량이 두 배가 됐으니 채권을 더 산 것 같다"처럼 이유를 짐작해 알려 줍니다. 하지만 진짜 이유는 거래 자료를 보고 사람이 확인해야 합니다. 그래서 항상 "확인되지 않은 추정"이라고 적혀 있습니다.
"산정불가"라고 나오면지난달이 0원이었으면 몇 % 늘었는지 계산할 수 없습니다(0으로 나눌 수 없으니까요). 이럴 때는 이상한 숫자 대신 "산정불가", "신규", "부호전환"이라고 글자로 알려 줍니다.

검토하고 승인하기

숙제를 낸 학생이 자기 숙제를 스스로 채점하면 안 되겠죠? 이 프로그램도 똑같습니다. 실행한 사람, 검토하는 사람, 승인하는 사람이 달라야 합니다. 이어달리기처럼 바통을 넘깁니다.

업무 담당자: 실행→검토자: 확인·검토 완료→승인자: 승인·확정

혼자 연습할 때는 화면 맨 위의 사용자 이름과 역할을 바꿔 가며 세 사람 역할을 해 봅니다.

  1. 맨 위 사용자 칸에 김검토를 쓰고 역할을 검토자로 바꿉니다.
  2. 노란 상자의 항목(A03, C06)을 하나씩 클릭합니다.
  3. 위쪽 의견/사유 칸에 이유를 씁니다. 예: "예시 계산식임을 확인함"
  4. 오른쪽의 확인 처리 버튼을 누릅니다. 항목마다 반복합니다.
  5. 의견 칸에 "검토 완료"라고 쓰고 검토 완료 버튼을 누릅니다.
  6. 사용자를 박승인, 역할을 승인자로 바꿉니다.
  7. 의견을 쓰고 승인을 누른 뒤, 다시 의견을 쓰고 확정·업로드 파일 생성을 누릅니다.
버튼이 회색이라 안 눌리면의견 칸이 비어 있거나, 아직 처리하지 않은 노란·빨간 항목이 남아 있다는 뜻입니다. 버튼에 마우스를 올리면 이유가 나옵니다.
이 역할 바꾸기는 연습용입니다지금 버전에는 비밀번호 로그인이 없어서 누구나 이름과 역할을 바꿀 수 있습니다. 실제 회사 업무에 쓰려면 회사 로그인 시스템과 연결하는 작업이 먼저 필요합니다.

일부러 틀린 파일 넣어 보기

채점관이 정말 깐깐한지 시험해 봅시다. sample_data → bond_2026-09_errors 폴더에는 일부러 실수를 넣은 파일 3개가 있습니다.

  • 같은 종목이 두 번 들어간 줄
  • 단가 파일에 없는 종목
  • 수량이 마이너스(−)인 줄
  • 통화를 "KRWW"로 잘못 쓴 줄
  • 날짜를 하루 틀리게 쓴 줄
  • 단가가 빈칸인 줄, 단가 단위를 100배 틀린 줄

3단계와 똑같이 올려서 실행해 보세요. 지난번 파일과 이름 모양이 달라서 "형식 변경" 안내가 먼저 나오면, 이유를 적고 변경 확인 후 실행을 누르면 됩니다.

CRITICAL(아주 심각) 오류는 승인으로 넘길 수 없습니다"키 중복" 같은 심각한 오류는 승인자가 와도 통과시킬 수 없습니다. 원본 엑셀을 고쳐서 다시 실행해야 합니다. 덜 심각한(HIGH) 오류는 승인자가 이유를 적고 "예외 승인"할 수 있고, 원래 오류 기록은 지워지지 않고 남습니다.

그 밖의 연습 폴더: unit_error(금액을 천원 단위로 잘못 씀), format_change(열 이름이 바뀐 파일), journal(전표 파일 검사), new_workflow_etf(처음 보는 종류의 파일), pdf(PDF로 된 단가표).

앱으로 설치하기

FinClose는 설치형 웹앱입니다. 플레이스토어나 앱스토어에서 받는 앱이 아니라, 브라우저에서 "설치" 버튼을 누르면 바탕화면에 아이콘이 생기고 따로 창이 열리는 방식입니다. 유튜브나 트위터를 PC에 앱으로 설치하는 것과 같은 기술입니다.

PC에 설치 (가장 쉬움)

  1. 2단계처럼 프로그램을 켜고 크롬이나 엣지로 http://127.0.0.1:8000에 들어갑니다.
  2. 주소창 오른쪽 끝의 설치 아이콘(모니터에 화살표 모양)을 누르거나, 화면 위쪽의 앱으로 설치 버튼을 누릅니다.
  3. 설치를 누르면 바탕화면과 시작 메뉴에 FinClose 아이콘이 생깁니다.
앱 아이콘만 눌러서는 안 켜집니다앱은 "화면"이고, 2단계의 검은 창이 "엔진"입니다. 앱을 쓰기 전에 항상 run.bat으로 엔진을 먼저 켜 두세요.

휴대폰에서 쓰기

휴대폰 화면 크기에 맞춰 메뉴가 아래로 내려가도록 만들어 두었습니다.

다만 휴대폰에서 쓰려면 회사 전산팀의 도움이 필요합니다. 지금은 프로그램이 내 PC 안에서만 열리도록 막혀 있기 때문입니다(보안 때문). 전산팀이 사내망 서버에 올리고 https 주소를 붙여 주면, 휴대폰 브라우저에서 그 주소로 들어가 메뉴의 홈 화면에 추가를 누르면 됩니다.

앱에 회계 자료가 저장되나요?아니요. 앱은 화면 모양만 기억합니다. 숫자와 파일은 PC 안의 finclose/data 폴더에만 있습니다.

자주 묻는 질문

회사 자료가 인터넷으로 나가나요?

나가지 않습니다. 모든 계산은 내 PC 안에서만 합니다. 인공지능 서비스나 외부 서버로 보내는 기능이 아예 없습니다.

실제 우리 회사 채권 파일을 넣어도 되나요?

넣을 수는 있지만 결과를 그대로 쓰면 안 됩니다. 지금 계산식(보유수량 × 단가 ÷ 10,000)과 분개 계정은 연습용 예시입니다. 단가 단위, 경과이자 포함 여부, 계정과목을 회사 기준으로 정해 승인자가 등록해야 정식으로 쓸 수 있습니다.

열 이름이 매달 조금씩 다르면요?

프로그램이 비슷한 이름은 알아서 짝을 지어 줍니다. 대신 지난번과 달라진 점이 있으면 멈추고 "이거 맞아요?" 하고 물어봅니다. 확인하고 이유를 적으면 진행됩니다.

실수로 같은 결산을 두 번 돌리면요?

같은 파일, 같은 기준일이면 "이미 실행한 적 있다"고 막습니다. 다시 돌리려면 이유를 적어야 합니다. 같은 달 결산을 두 번 확정하는 것도 막습니다.

오류 기록을 지울 수 있나요?

지울 수 없습니다. 모든 기록(누가, 언제, 무엇을)은 감사 로그에 남고, 몰래 고치면 감사 로그 → 무결성 검증에서 들통납니다.

"Python을 찾을 수 없습니다" 오류가 나요

1단계의 "Add python.exe to PATH" 체크를 빼먹은 경우가 대부분입니다. 파이썬 설치 파일을 다시 실행해 Modify에서 체크하고, 검은 창을 새로 열어 다시 시도하세요.

브라우저에 "사이트에 연결할 수 없음"이 떠요

검은 창(엔진)이 꺼져 있는 것입니다. 2단계의 run.bat을 다시 실행하세요.

새로운 종류의 결산 업무도 넣을 수 있나요?

두 자료를 맞대어 보는 업무(대사)는 파일 두 개를 올리면 프로그램이 "이런 업무 같다"고 초안을 만들어 줍니다. 저장하고 승인자가 활성화하면 다음 달부터 자동으로 알아봅니다. 계산이 복잡한 업무는 개발 작업이 조금 필요합니다.

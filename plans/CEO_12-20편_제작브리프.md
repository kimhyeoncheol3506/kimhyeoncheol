## 한 편을 맡은 에이전트가 만들 것 (녹음·렌더·업로드는 하지 않음)
1. **자료조사** `research/ceo_epNN_<이름>.md` — 형식은 `research/ceo_ep11_orion.md` 그대로. 표기: (DART) 공시 원문 / (보도) 언론으로만 확인 / (계산) / 미확인. 공시는 DART(dart.fss.or.kr), 시세는 네이버 증권(기준일 명시). 나무위키는 실마리로만. 쿠팡처럼 미국 상장사는 SEC 공시(10-K)와 NYSE 시세.
2. **대본** `<폴더>/script.txt` — 형식·말투·길이(약 100문장, 8~10분)는 `projects/ceo_orion_v2/script.txt` 그대로.
   - v2 규칙(`plans/CEO시리즈_v2_규칙.md`) 2~3절: 첫 문장 = 역설을 사실처럼, CEO마다 한 판(판돈→위기→결정→결과), 2~3분마다 질문→답, 성적표 도장(숫자로만, 학점·별점 금지), 마지막 반전 한 줄, 마지막 구독 멘트는 오리온 마지막 줄과 같은 문구.
   - 챕터 줄은 `# 1장 · 판돈` 형식(오리온과 같은 장 이름 흐름).
   - **사실 규칙**: 화면 숫자 = 대사 숫자 = 출처 숫자. 보도로만 확인된 건 대사에 "~라고 보도됐습니다". 진행 중 수사·재판·소송은 단정 금지(혐의·판결 상태를 날짜와 함께 사실만, 없으면 뺀다). 사생활·인신공격·후계 의견 금지. 실존 인물은 이름표 퍼펫만(얼굴 흉내 금지).
   - 숫자 읽기: 연도는 `say_as.json` 에 "1998년": "천구백구십팔 년" 식으로 넣는다(오리온 say_as.json 참고). 큰 금액(예 "3조 893억")은 받아쓰기 오인식이 잦으니 문장당 숫자는 2개 이하로.
3. **스토리보드** `<폴더>/make_story.py` → 실행해서 `story.json` — `projects/ceo_orion_v2/make_story.py` 를 본보기로(같은 헬퍼, cast 정의, 샷 종류). 샷 종류·인자는 `.claude/skills/reachmora-2d-longform/references/story-format.md`. 3~5초마다 새 동작, 같은 샷 종류 두 번 연속 금지, CEO 사업 결정 2~3개는 액션 샷(도장 쾅·스위치·테이블 탕 등). 로고·사진 금지.
   - 확인: `cd .claude/skills/reachmora-2d-longform && python3 tools/ko_timing.py <P> --estimate && nice python3 -m engine plan <P>` → **WARNING 0** 이 될 때까지 고친다. stills·render 는 하지 않는다(메모리·디스크 부족). 끝나면 추정 `timing.json` 은 지워도 된다(녹음 뒤 다시 만듦).
4. **업로드 글** `<폴더>/upload_meta.json` — 키·형식은 `projects/ceo_orion_v2/upload_meta.json` 그대로(title, asof, description, chapters: [], sources: [[출처, 날짜, 제목, url]…], tags). 제목은 바이럴 공식(역설·숫자). sources 마지막에 썸네일 로고 출처 한 줄.
5. **공식 CI**: 회사 공식 사이트(홈페이지 머리글·CI 소개·뉴스룸·IR)에서 로고 파일을 받는다. **위키미디어는 쓰지 않는다**(이 IP 차단). SVG 우선, 없으면 가장 큰 PNG. 다시 그리거나 색을 바꾸지 않는다. 저장: `neural-studio/assets/ci/<이름>_ci.svg`(있으면) + `<이름>_ci.png`(SVG면 `python3 /tmp/claude-0/hft/svg2png.py in.svg out.png 300`). 회사 색(brand)은 로고 파일에서 읽은 공식 색만. 흰색 로고만 있으면 `ci.bg` 에 공식 색. 받은 URL·날짜·색을 조사 파일 맨 끝 "썸네일 CI" 절에 적는다.
6. **B안 썸네일** `neural-studio/projects/thumb_viral/epNN_big.json` → `cd neural-studio && python3 tools/thumb_viral/make.py projects/thumb_viral/epNN_big.json projects/<폴더>/thumb_big.png`. 설정 본보기 `projects/thumb_viral/ep9_big.json`(A 공포)·`ep10_big.json`(C 비교)·`ep11_big.json`(D 숫자)·`ep2_big.json`(B 반전). 유형은 이야기에 맞게 A~D 중 고르고, 9~20편끼리 너무 겹치지 않게. 배경은 `assets/thumb_bg/` 의 A_crash / B_rebound / D_screens 중(새 유료 생성 금지). 숫자는 영상 속 출처 숫자만. 썸네일 png를 열어 보고 글자 잘림·겹침이 없는지 확인한다. **썸네일이 없으면 그 편은 미완성.**
7. 끝나면 `<폴더>/PREP_DONE` 빈 파일을 만든다(녹음 대기열이 이걸 보고 시작함). 커밋·푸시는 하지 않는다(메인 세션이 한다).

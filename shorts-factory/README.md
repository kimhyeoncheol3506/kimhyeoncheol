# 쇼핑 쇼츠 자동 제작기 (shorts-factory)

제품명·타겟·혜택 3개만 넣으면 **후킹 15개 → 15초 교정 대본 → 편집 타임라인 → mp4**까지 자동으로 만들고,
매번 **시청 이탈 방지 체크리스트**로 스스로 점검합니다. 편집을 몰라도 됩니다.

---

## 1. 채널 런칭 기획

### 콘셉트
| 항목 | 내용 |
|---|---|
| 포맷 | 15초 제품 소개형 쇼츠 (유튜브 쇼츠 · 인스타 릴스 · 틱톡 동시 업로드) |
| 첫 타겟 | 20대 여성 — 뷰티·자취·데스크테리어 소형가전/잡화 (2~4만원대) |
| 약속 | "3초 안에 사야 할 이유, 15초 안에 살 곳까지" |
| 수익 구조 | 쿠팡 파트너스 / 네이버 쇼핑 커넥트 링크 → 이후 자체 스마트스토어 |

### 영상 1편의 공식 (이 시스템이 자동으로 지키는 것)
```
0~3초    후킹 (BGM 없음, 단어 하나씩 타이핑 + "탁")
3~7초    제품 소개 + 특징1         ← 3초부터 BGM 페이드인
7~11초   특징2 + 사용 장면 (줌 인)
11~13초  가격 공개(숫자 줌 1.2배 + "팡") + 혜택 배지
13~15초  구매 유도 + 하단 고정 "지금 구매하기" 버튼, 마지막 1초 로고
컷 평균 1초 내외 · 자막 한 줄 15자 이내 · 키워드만 노란색
```

### 30일 런칭 로드맵
| 기간 | 할 일 | 목표 |
|---|---|---|
| 1주차 | 제품 5개 선정 → 제품당 후킹 다른 버전 2개씩 = 10편 업로드 | 어떤 후킹 유형이 먹히는지 데이터 확보 |
| 2주차 | 하루 2편. 조회수 하위 50% 영상은 `feedback "후킹이 약해"`로 재생성해 재업로드 | 3초 유지율 70% 이상 |
| 3주차 | 반응 좋은 유형(예: 가격충격형)을 rules.yaml `type_weights` 에 고정 | 평균 조회수 1,000+ |
| 4주차 | 반응 좋은 제품군으로 카테고리 집중, 고정 댓글에 구매 링크 | 링크 클릭률 2%+ |

### 매일 보는 지표 (KPI)
- **3초 유지율** — 후킹 성능. 낮으면 `feedback "후킹이 약해"`
- **평균 시청 지속률** — 70% 미만이면 대본이 늘어짐 (rules.yaml `script.syllables_per_sec` 상향)
- **링크 클릭률 / 구매 전환** — CTA 문구(`editing.cta.button_text`)를 바꿔 A/B 테스트

### 꼭 지킬 것 (법·플랫폼)
- 제휴 링크 영상에는 **"광고/제휴 링크 포함" 표기** (공정위 추천·보증 심사지침). 고정 댓글 + 설명란에 쿠팡 파트너스 고지문.
- 할인율(`--orig-price`)은 **실제 정가 근거가 있을 때만**. 허위 할인은 표시광고법 위반.
- 효과음·BGM은 **상업 이용 가능한 무료 음원**만 (rules.yaml `free_libraries` 목록).

## 2. 설치 (처음 한 번)
1. **Python 3.9+** 설치 — https://www.python.org/downloads/ (설치 시 *Add to PATH* 체크)
2. **ffmpeg** 설치 — Windows: `winget install ffmpeg` / Mac: `brew install ffmpeg`
3. 이 폴더에서: `pip install -r requirements.txt`

## 3. 사용법

### 가장 쉬운 방법 — 질문에 답하기
```
python shorts.py
```
제품명/타겟/혜택/가격을 묻고, 후킹 15개를 보여준 뒤 번호를 고르게 합니다 (Enter = 최고점 자동 선택).

### 한 줄로 만들기
```
python shorts.py run --product "무선 미니 고데기" --target "20대 여성" --benefits 가격,편리함,디자인 \
                     --price 19900 --orig-price 39000 --brand "GLOW LAB"
```
| 옵션 | 설명 |
|---|---|
| `--media 폴더` | 촬영한 사진/영상. 파일명을 `hook_1.mp4`, `intro_1.jpg`, `feature_2.mp4`, `price_1.jpg`, `cta_1.mp4` 처럼 지으면 해당 구간에 들어감. 없으면 색 배경 + **"컷3 · 제품 정면 전체샷"** 같은 촬영 가이드가 표시됨 |
| `--voice 파일` | 내 목소리 내레이션(wav/mp3). 있으면 **실제 말 사이 공백 0.2초 이상**에서 자동 컷 |
| `--hook 3` | 후킹 3위 문장 사용 (기본 `auto` = 1위) |
| `--raw-script 녹취.txt` | `intro: 어 이 이거 진짜 진짜 좋아요...` 형식 녹취를 **교정**해서 대본으로 사용 |
| `--no-render` | mp4 없이 대본/타임라인/ffmpeg 커맨드만 |

### 결과물 (output/날짜_제품명/)
| 파일 | 내용 |
|---|---|
| `a_hooks.md` | **(a)** 후킹 15개 + 점수 순위 + 근거 + 타이핑 타임라인 |
| `b_script.md` | **(b)** 15초 교정 대본 (타임코드 + 컷별 촬영 가이드) |
| `c_timeline.md` / `timeline.json` / `timeline.toml` | **(c)** 컷·자막·줌·효과음·BGM 위치 명세 |
| `render.sh` + `filter_complex.txt` + `subs.ass` | **(d)** 자동 생성된 ffmpeg 렌더링 커맨드 (그대로 다시 실행 가능) |
| `final.mp4` | 완성 영상 (1080×1920, 30fps, 15초) |
| `checklist.md` | 시청 이탈 방지 자체 점검 결과 |

## 4. 피드백 루프
```
python shorts.py feedback "조회수가 안 나왔어, 후킹이 약해"
```
→ rules.yaml 의 **HOOKS 블록만** 강화(강도 +1, strong 템플릿·부스터 활성화, 파워워드 가점↑, 지난번 유형 가중치↓,
최대 글자 −1, 타이핑 리듬 빠르게) → 지난번 입력으로 **전체 다시 생성**. 바뀐 내역은 `hooks.history` 에 기록됩니다.
강도는 최대 3까지 올라갑니다. 되돌리려면 `hooks.intensity` 를 1로 고치면 됩니다.

### 매 실행 후 자동 점검 (checklist.md)
- 첫 3초 자막 노출 (첫 자막 0.5초 이내 등장 + 0~3초 계속 노출)
- 컷 길이 평균 1.5초 이하
- 효과음 타이밍 오차 0.1초 이내 — **렌더된 효과음 트랙에서 실측**
- 그 외: 후킹 15자, 자막 15자/줄, 줌 1.1~1.2배, 0~3초 BGM 무음(실측), CTA 13~15초, 마지막 1초 아웃트로, 최종 길이 15초

## 5. 규칙 바꾸기 (rules.yaml)
편집할 때마다 rules.yaml 을 새로 읽으므로 **고치고 저장하면 다음 영상부터 바로 반영**됩니다.
- 자막 색: `editing.subtitle.highlight_color` · 크기: `font_size`
- 효과음/BGM 교체: `assets/sfx/ding.wav` 등 **같은 이름으로 파일을 덮어쓰기** (처음엔 자동 합성된 임시 음원)
- 로고: `assets/logo/logo.png` 를 넣으면 아웃트로에 자동 표시 (없으면 브랜드명 텍스트)
- 폰트: `assets/fonts/` 에 한글 .ttf 를 넣으면 자동 사용 (Pretendard·G마켓산스 등 무료 폰트 추천)
- 새 혜택 단어: `benefit_lexicon` 에 추가 (예: `성능`, `휴대성` 이미 있음)
- 후킹 문장 틀: `hooks.templates` / `hooks.strong_templates`

## 6. 폴더 구조
```
shorts-factory/
├── shorts.py            # 실행 명령 (run / feedback / clean / 대화형)
├── rules.yaml           # 편집 규칙집 — 매 실행마다 읽음
├── requirements.txt
├── engine/
│   ├── hooks.py         # [1단계] 후킹 엔진 · 점수 · 타이핑 타임라인
│   ├── script.py        # [2단계] 15초 대본 · 교정기
│   ├── timeline.py      # [3단계] 규칙 → 타임라인 명세 (JSON/TOML)
│   ├── render.py        # [4단계] ASS 자막 · ffmpeg 커맨드 생성 · 렌더링
│   ├── checklist.py     # [5단계] 이탈 방지 체크리스트
│   ├── pipeline.py      # 실행 순서 + 완료 알림
│   ├── rules.py         # rules.yaml 읽기 / 후킹 섹션 강화
│   └── ff.py            # 폰트 탐색 · 임시 음원 합성 · 오디오 실측
├── assets/{sfx,bgm,logo,fonts}/
└── output/              # 실행 결과
```

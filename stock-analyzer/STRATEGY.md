# 지지 눌림목 전략 (차트의 맥 x 워뇨띠) v2

구현: `strategy.py` · UI: `app.py` 의 "🎯 지지 눌림목 전략" 탭 · AI 프롬프트: 종목 분석 시 자동 첨부(§6-1)

## 1. 기본 철학 (7원칙)
| # | 원칙 |
|---|---|
| 1 | 캔들과 거래량을 먼저 보고, 보조지표는 거의 무시한다 |
| 2 | 거래량이 없는 움직임이나 돌파는 믿지 않는다 |
| 3 | 이평선은 기본값(5/20/60/120)으로 두고, 지지 확인에만 쓴다 |
| 4 | 돌파 추격보다 지지 구간(눌림목)에서 진입한다 |
| 5 | 참여자가 많은 대형 종목만 매매하고, 횡보장에서는 쉰다 |
| 6 | 진입 전에 시나리오를 세우고, 지지가 깨지면 바로 손절한다 |
| 7 | 소액으로 반복하면서 나에게 익숙한 패턴을 찾는다 |

## 2. 종목 선정과 필터
| 단계 | 항목 | 원안 | v2 (백테스트 적용) |
|---|---|---|---|
| 유니버스 | 대상 | 코스피 시총 1~500위, 코스닥 1~300위 | 같음 (기간 시작일 기준 시총) |
| | 제외 | 우선주, 스팩 | 우선주, 스팩, 상한가 종목 |
| 유동성 | 20일 평균 거래대금 | - | **300억 이상** |
| | 당일 거래대금 | - | **200억 이상** |
| 시장 필터 | 지수 상태 | 지수 < 60일선이고 60일선 하락 중이면 전체 쉼 | 끔 (켜면 7~9월 매매 0회) |
| 횡보 필터 | ① 20일선 평평 | 10일간 변화 ±1% 이내 | 같음 |
| | ② 이평선 꼬임 | 20일 내 5·20일선 2회 이상 교차 | 같음 |
| | ③ 박스권 | 20일 고저폭 8% 미만 | 같음 |

| | 쉬는 기준 | 4개 중 **2개 이상** | 4개 중 **3개 이상** |

## 3. 진입 조건 (시나리오)
| 단계 | 항목 | 원안 | v2 |
|---|---|---|---|
| 셋업 | 정배열 | 20 > 60 > 120일선 | **20 > 60일선** |
| | 추세 | 20일선 상승(5일 전보다 위), 종가 > 60일선 | 같음 |
| 눌림목 | 조정폭 | 최근 20일 고점 대비 **-4~-15%** | **-3~-20%** |
| | 조정 거래량 | 조정 기간 평균 < 고점 직전 10일 평균 | 같음 |
| | 지지 위치 | 저가가 20일선 ±2%, 강한 추세면 5일선 ±1% | 같음 |
| 트리거 | 캔들 | 양봉, 종가가 20일선 위 | 같음 |
| | 거래량 | 전일보다 많고 20일 평균의 80% 이상 | 같음 |
| 금지 | 고점 대량 장대음봉 | 최근 20일 내 (거래량 3배 이상, 하루 -4% 이하) 있으면 패스 | 같음 |
| 손익비 | 최소 기준 | (목표가 - 진입가) ÷ (진입가 - 손절가) **1.5 이상** | 같음 |

## 4. 매매 실행 (시각과 가격)
| 동작 | 시각 | 가격/방법 | 조건 |
|---|---|---|---|
| 신호 점검 | 매일 15:15 | 현재가 기준 조건 확인 | 위 2~3단계 전부 통과 |
| **매수** | **15:20~15:30 종가 단일가** | 종가 + 1호가 가정 | 신호 종목, 거래대금 큰 순 |
| 1차 익절 (절반) | 다음 날 08:30 주문 접수, **09:00 시가** 또는 **장중 지정가** | 직전 20일 고점 | 목표가 도달 |
| 본전 스톱 (나머지) | **09:00 시가** 또는 **장중 스톱** | 매수가 | 1차 익절 후 매수가로 되돌아오면 |
| 2차 익절 (나머지) | **15:30 종가 단일가** | 종가 - 1호가 | 종가가 5일선 아래로 내려간 날 |

## 5. 손절 규칙
| 종류 | 시각 | 조건 |
|---|---|---|
| 최대 손실 | 09:00 시가(갭 하락) 또는 장중 스톱 | 매수가 대비 **-7%** |
| 지지 붕괴 | 15:30 종가 | 종가가 **눌림목 최저가 아래** |
| 거래량 이탈 | 15:30 종가 | 거래량 평균 1.5배 이상으로 **20일선 이탈** |
| 긴급 청산 | 15:30 종가 | 보유 중 **고점 대량 장대음봉** 발생 |
| 시간 손절 | 15:30 종가 | **10거래일** 안에 +3%도 못 감 |

## 6. 자금 관리 (추천안)
| 항목 | 규칙 |
|---|---|
| 계좌 | 30억 |
| 1회 손실 한도 | 계좌의 **0.5% (1,500만 원)** |
| 매수금액 | 1,500만 원 ÷ 손절폭(%) (예: 손절폭 3%면 5억, 5%면 3억) |
| 최소/최대 | **최소 3억**, **최대 6억** (계좌의 20%). 계산값이 3억 미만이면 건너뜀 |
| 유동성 상한 | 20일 평균 거래대금의 **2% 이하** |
| 동시 보유 | 합계 30억 이내, 같은 업종은 2종목까지 |
| 신호가중 | 보류. 100건 이상 쌓이고 A등급 우위가 기간별로 일관될 때만 최대 1.5배 |
| 비용 반영 | 왕복 0.3% + 체결마다 불리한 1호가 (지정가 익절은 제외) |

## 8. 알려진 약점과 다음 수정 후보
| 약점 | 근거 | 수정 후보 | 툴 반영 |

## 툴 구현 시 가정 (일봉 한계)
- 신호는 일봉 종가 기준으로 판정(15:15 현재가와 다를 수 있음). 매수가 = 종가 + 1호가(KRX 호가단위 표 적용).
- 같은 날 익절가와 손절가가 모두 닿으면 손절 우선(보수적). 1차 익절은 시가가 목표가 이상이면 시가, 아니면 목표가에 체결.
- 우선주·스팩 제외와 기간 시작일 기준 시총 순위는 유니버스를 직접 입력하는 방식이라 사용자가 걸러야 함.
- 업종 2종목 제한은 `backtest(sectors={종목: 업종})`를 넘길 때만 적용.

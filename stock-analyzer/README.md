# AI 주식 분석기

종목(티커·종목코드·한글명)을 입력하면 차트 + 적정주가 + 근거 + 매수/매도 의견을 제시합니다.
KOSPI(.KS) · KOSDAQ(.KQ) · 넥스트레이드(.NXT, 시세 없으면 KRX로 대체) · 다우존스/나스닥/S&P 지수 및 종목 지원.

## 실행
```bash
cd stock-analyzer
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...     # 없으면 규칙 기반 요약만 표시
streamlit run app.py
# CLI: python stock_analyzer.py 005930
```

## 이미지 프롬프트 6종 → 반영 위치
| 분석 | 구현 |
|---|---|
| 기업 분석 | 사업개요·섹터 수집 → 프롬프트 §1 |
| 차트 분석 | 20/60/120/200일선, RSI, MACD, 스토캐스틱, 볼린저, ATR, 거래량, 지지/저항 → §5 |
| 실적 발표 분석 | 분기 손익, 실적 발표일 EPS 추정/실제 → §2 |
| 재무제표 분석 | 손익·재무상태·현금흐름 3~4개년, 마진/ROE/부채비율 → §3 |
| 밸류에이션 | PER/PBR/PSR/EV·EBITDA + 규칙 기반 적정가 + 애널리스트 목표가 → §4 |
| 교차 검증 | 적정가 vs 지지/저항/추세 → §6 |
| 매크로 분석 | KOSPI·KOSDAQ·다우·나스닥·S&P·VIX·미 10년물·환율·유가·금 → §7, 별도 탭 |
| 포트폴리오 분석 | 종목별 비중/수익률/변동성/상관계수 → §8, 별도 탭 |

시스템 프롬프트는 `prompts.py`. 데이터에 없는 수치는 "데이터 없음"으로 표기하도록 강제합니다(환각 방지).

## 주의
- 데이터는 야후 파이낸스(비공식)이며 지연/누락될 수 있습니다. 한국 종목은 EPS·PBR 등이 비는 경우가 있습니다.
- 투자 권유가 아닌 참고용입니다.

## 지지 눌림목 전략 (차트의 맥 x 워뇨띠 v2)
- `strategy.py`: 신호 판정(유동성·횡보 4종·셋업·눌림목·트리거·금지·손익비) / 자금관리 / 매매 시뮬레이션 / 계좌 단위 백테스트
- 앱의 "🎯 지지 눌림목 전략" 탭: 오늘 신호 스캔(체크리스트 O/X + 매수금액), 백테스트(청산 사유별 통계), 버전(v2 300억·150억·원안+시장필터)·손절 방식·여유폭 선택
- 종목 분석 시 전략 판정 결과가 AI 프롬프트에 자동 첨부됩니다.
- 전체 규칙표와 일봉 기반 가정은 [STRATEGY.md](STRATEGY.md)

## 퀀트 17전략 (`quant.py`)
모멘텀 · 평균회귀 · 통계적 차익거래 · 페어 · 추세 · 시장조성 · 이벤트 · 팩터 · 캐리 · 변동성차익 · 옵션 · 횡단면 · 단기반전 · 돌파 · 국면전환 · ML · 집행.
- 앱 "🧮 퀀트 17전략" 탭: 종목 17전략 판정표 + 백테스트(롱/현금, 비용 0.3%), 유니버스(횡단면 순위·통계차익·페어 탐색), 도구(캐리 계산기·집행 분할 계획)
- 종목 분석 시 17전략 판정이 AI 프롬프트(§6-2)에 자동 첨부됩니다.
- 시장조성·집행·옵션은 호가창/증권사 API가 필요해 **분석·계획만** 제공하며 주문을 내지 않습니다. 옵션·IV는 미국 종목만 가능합니다.
- ML(16)은 학습에 쓰지 않은 최근 30% 구간에서 기준선을 이겨야만 신호로 반영합니다.

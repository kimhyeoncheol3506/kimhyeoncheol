# 스킬 변경 이력 (yeonae-shorts-studio)

## v1.1.0 — 2026-10-11 (1차 리뷰 반영)
- 리뷰: "숏폼·롱폼 마음에 듦 / 목소리가 사람처럼 잘 나와야 함 / 소재는 PC 크롬 조회 또는 휴대폰 스샷 / 노란딱지 위험은 먼저 알릴 것"
- 목소리: 방송 톤 후처리 체인(무음 압축·EQ·컴프레서) + 최종 loudnorm -14 LUFS(유튜브 표준), BGM 더 낮춤(쇼츠 0.42, 롱폼 0.32)
- 쇼츠 말 속도 1.12 → 1.05배 (빠른 배속이 기계음처럼 들리는 문제)
- `tools/card_from_screenshot.py`: 휴대폰 스샷에서 사연 카드·줄 좌표 자동 추출, 가림 처리
- `tools/safety.py`: 노란딱지 사전 점검(안전/주의/위험) + 승인 플래그, make.py에 연결

## v1.0.0 — 2026-10-11 (첫 샘플)
- 쇼츠 포맷 "사연 낭독 + 판정소" 렌더러 (`studio/short.py`): 상단 고정 후크, 스샷 카드 형광펜+줌, 펀치줌 전환, 판정 도장, 진행바, 댓글 CTA
- 롱폼 포맷 "지도 한 장 + 콩 캐릭터 꽁트" 렌더러 (`studio/long.py`): 카메라 비행, 손글씨 타자 등장, 마커 동그라미, 말풍선, 음성 기반 입 싱크, 슬라이드 전환
- 효과음/BGM 전부 코드로 합성 (`studio/audio.py`) → 저작권 클레임 없음. 목소리 나올 때 BGM 자동 감쇠(사이드체인)
- 목소리: Voicebox(PC) 클라이언트 + Qwen3-TTS 직접 구동(클라우드) 두 경로, 폭주 감지 자동 재시도, Whisper 받아쓰기 QA
- 참고 영상 분석 한계: 유튜브가 클라우드 서버 다운로드를 차단 → 3개 영상의 썸네일/제목/채널로 스타일 추정
  - 혼잡스(@honjobs): 흰 화이트보드 지도 + 주황 마커 동그라미 + 검은 박스 타이틀(주황 강조) + 흑백 인물
  - 인생 녹음 중(@tikitakabooboo): 파스텔 단색 배경 + 흰 콩 캐릭터 + 굵은 손글씨 상단 타이틀 + 낙서 소품
- 제작 중 발견·반영한 것
  - Qwen3-TTS가 가끔 끝없이 생성(폭주)하거나 첫 문장을 빼먹음 → 예상 길이 0.6~1.6배 밖이면 시드 바꿔 자동 재시도, Whisper QA로 누락/더듬음 검출 후 재생성 (s02, L02, L08)
  - QA 비교 시 숫자↔한글 읽기 정규화(25만 ↔ 이십오만)로 오탐 제거
  - 쇼츠 원본 낭독이 40.9초 → 말 속도 1.12배(음높이 유지 atempo) + 간격 0.18초로 37초
  - 쇼츠 카드: 확대 1.2배 + 강조 줄 가로 보정, 후크/자막과 겹치지 않게 카드 고정
  - 롱폼 2분 48초 → 실전 시뮬레이션 꽁트 2개 추가(질문 하나 → 두 번째 약속 / 칼답 강요 → 끝)
  - 손글씨 폰트: Gaegu(자간 넓음) → Jua(제목·말풍선) + PoorStory(지도 본문). 폰트에 없는 글리프(→ — … ·) 자동 대체
  - 지도 중앙 타이틀 박스는 전체 보기에서만 표시 (구역 줌인 시 모서리에 잘려 보이던 문제)

레퍼런스: 바로쓰는 심리학 「단 3일 만에 뇌를 리셋하고 무서울정도로 인생을 바꾸는 혼잣말의 뇌과학 비밀」 (12분 03초, 조회수 약 46만, 2026-07-01). 링크는 https://youtu.be/-oYkAO58LSE 입니다.

## 0. 분석 방법과 한계

- **영상 파일은 받지 못했다.** YouTube가 다운로드를 403으로 막았고, 우회하지 않았다.
- **분석에 쓴 자료:** 공개 자막(단어별 시각이 있는 자동 자막), 챕터, 설명란, 공개 미리보기(스토리보드) 프레임 146장이다. 프레임은 약 4.95초마다 1장, 160×90 크기다.
- **실측한 것:** 말 속도, 쉼 길이, 그림이 바뀌는 간격, 자막 위치·크기·색, 화면 구성, 인트로·아웃트로 구성, 설명란 구성.
- **추정만 한 것:** 정확한 컷 시점(5초 해상도 안), 효과음·배경음 타이밍(오디오 없음), 확대 속도. 표에 **(추정)**으로 표시했다.

## 2. 수치 규칙

| 항목 | 레퍼런스 실측 | 우리 이전 값 | 규칙 |
|---|---|---|---|
| 말 속도 | 음절 4,234개 / 723초 = **초당 5.86음절** (쉼 포함) | 여의도남자 1.08배, 초당 약 7~8음절 | **배속 1.0**으로 낮추고 장면 사이 쉼을 늘린다 |
| 쉼 | 0.6초 넘는 쉼 484번, 평균 0.93초 | 장면 사이 0.30초 | 장면 사이 **0.45초** (`scene_pause`) |
| 그림 유지 | 타일 89%가 다음 타일과 다름 → **평균 약 5.6초**에 한 번 교체. 같은 그림이 10초 넘게 이어진 곳은 드묾(130구간 중 14) | 장면당 평균 6~7초, 10초 넘는 장면 회당 4~8곳 | 목표 5~6초, **10초를 넘으면 장면을 나눈다** |
| 자막 위치 | 하단 중앙, 아래 여백 약 6% | 하단 중앙 | 유지, 아래 여백 48 → **64px** |
| 자막 모양 | 검은 반투명 상자 + 흰 굵은 고딕, **한 줄** | 동일 | 유지 |
| 자막 크기 | 글자 높이 ≈ 화면 높이의 7% (1080p 기준 약 70~76px) | 54px | **70px** |
| 자막 길이 | 한 화면 10~16자 | 최대 30자 | 최대 **20자** |
| 강조 자막 | 화면 위 큰 글자 대신 **그림 속 말풍선·라벨**로 핵심어를 보여 줌 | 상단 헤드라인 + 강조색 | 스틱맨 장면에서는 말풍선·라벨을 쓰고, 정보 패널은 지금처럼 헤드라인을 쓴다 |
| 상단 고정 요소 | 왼쪽 위에 작은 영상 제목 한 줄, 오른쪽 위에 둥근 채널 로고 | 오른쪽 위 텍스트 워터마크 | **왼쪽 위 제목 + 오른쪽 위 둥근 배지**(개미 얼굴) |
| 화면 확대 **(추정)** | 정지 그림마다 느린 확대·이동(같은 그림 2~3타일에서 구도가 조금씩 다름) | HF 장면 전체에 4% 느린 확대 | 유지 |
| 자료 화면 | 전체의 약 10~15%를 실사 사진·영상(자동차, 숲, 뉴런, 물레방아)으로 채움 | 없음 | 저작권이 확인된 실사만, 회당 3~6컷 (선택 규칙, §4) |
| 전후 비교 | 해결책 파트에서 좌우 분할 비교를 반복 | dual·compare 패널 | 해결책·행동 파트에서는 **좌우 분할 비교를 우선** 쓴다 |

## 3. 인트로·아웃트로 규칙

1. **훅(첫 40~50초):** 공감 질문으로 시작한다. 장면마다 장소를 바꿔 같은 캐릭터를 여러 상황에 놓는다. 앞서 만든 A4 스틱맨 규칙과 같다.
2. **구독 범퍼:** 첫 챕터가 끝나기 약 5초 전에 오른쪽 아래(자막 위)로 5초짜리 구독 팝업이 뜬다. 구성은 배지, 채널명, 구독·알림 버튼이다. 커서가 '구독'을 누르면 회색 '구독중'으로 바뀌고 클릭음이 난다. 레퍼런스는 전체 화면 15초였지만, 우리는 내레이션을 끊지 않도록 **팝업형**으로 줄였다.
3. **아웃트로:** 마지막 6초에 화면 아래 가운데로 구독·좋아요·알림 버튼 3개가 차례로 눌린다(클릭음 3번). 엔딩 장면은 손 흔드는 개미, 노트북, 계좌 점검 장면을 쓴다.
4. **설명란:**
   - 첫 줄에 해시태그 3개를 넣는다.
   - 본문 다음에 타임라인(챕터)과 면책 문구를 넣는다.
   - "AI 음성·코드 그래픽을 활용해 제작된 콘텐츠입니다" 한 줄을 넣는다. 레퍼런스도 "AI 활용으로 제작된 콘텐츠입니다"라고 밝힌다.

## 4. 선택 규칙 (재료가 있을 때만)

- **실사 자료 화면:** 상업 이용이 가능한 무료 실사(Pexels·Pixabay 등)나 현철님이 준 클립만 쓴다. `clip` 장면으로 넣고 회당 3~6컷, 한 컷 4~6초. 출처는 설명란에 적는다. 이 환경에는 스톡 영상 API 키가 없어서 자동으로는 넣지 않는다.

- 링크: https://youtu.be/Faz_TaCJsd4 (2026-10-19 업로드, 28:37, 구독자 3.76만, 분석 시점 조회 약 1.5만 — 업로드 당일)
- 분석 자료: 장면 미리보기 174장(약 10초 간격) + 자동 자막 전문(약 14,300자) + 설명란
- 목적: 우리 채널에서 같은 '급'의 영상을 만들려면 무엇이 필요한지 (대본·그림·캐릭터는 복제하지 않음)

## 1. 한 줄 요약
"뉴스 한 줄(세계 최초 인도)을 70년 역사 다큐로 키운 영상". 손그림 같은 수채화 일러스트 + 어두운 정보 카드 + 단계별 도식 + 다큐 내레이션.

## 4. 말하기 기법 (우리가 바로 가져올 수 있는 것)
1. **첫 장면을 '현장'으로**: 숫자보다 사람이 있는 장면 묘사 → 마지막에 같은 장면으로 돌아와 닫기
2. **질문 2개로 시청 이유 만들기** + "이거 하나만 보면 ~를 알게 된다" 약속
3. **모든 숫자를 월급 단위로 환산**: "300만 원 들던 일이 8만 원" (우리 채널 이름과 딱 맞는 기법)
4. **어려운 구조는 생활 비유 하나로 끝까지**: 장독·평상 비유를 여러 번 재사용
5. **한계와 면책을 본문에서 정직하게**: "과장 없이 짚어야 할 것" → 신뢰
6. 출처를 설명란에 "○○ — △△ 확인" 형식으로 항목별 정리, 확인 못 한 숫자는 넣지 않았다고 명시
7. 말투: 존댓말 다큐체(~습니다/~거든요/~죠 섞기), 1분에 약 500자 (우리와 비슷)

## 5. 우리가 만들려면 — 필요한 것과 방법
| 필요한 것 | 방법 | 난이도·비용 |
|---|---|---|
| 같은 화풍 일러스트 40~70장 | 이미지 생성 도구로 '화풍 고정 프롬프트' + 장면 설명. 연결된 도구: Pollo·OpenArt(이미지/영상 생성, 크레딧 차감), Canva(지난번 6장에서 한도 초과) | **가장 큰 벽**. 크레딧 비용 + 화풍 일관성 관리 |
| 그림 천천히 움직이기(줌·이동) | 엔진에 Ken Burns 효과 추가 (ffmpeg) | 엔진 작업 반나절 |
| 남색 유리 정보 카드 | 엔진에 `card` 장면 타입 추가 (배경 그림 흐리게 + 반투명 카드) | 반나절 |
| 챕터 번호 타이틀 카드 | `chapter` 있는 장면에 자동 삽입 | 짧음 |
| 단계별 도식 | 주제마다 새로 설계 (예: 대출 구조, 금리 전달 경로) | 영상마다 추가 작업 |
| 실사·드론 영상 | AI 영상 생성(Pollo 등) 또는 생략 | 선택 사항 |
| 28분 분량 | 대본 약 14,000자 = 지금 영상의 약 2.6배 → 녹음 약 300장면, 백그라운드 2시간 제한 때문에 2~3번 나눠 실행 | 토큰·시간 2.5~3배 |

## 6. 권장 진행안
- **1단계 (엔진, 그림 도구 없이 가능)**: 정보 카드 스타일·챕터 타이틀·Ken Burns·'현장 묘사 → 질문 2개 → 월급 환산 → 생활 비유 → 한계 정직하게 → 첫 장면 회수' 대본 틀을 스킬에 추가
- **2단계 (시험)**: 그림 도구 하나로 같은 화풍 5장을 뽑아 샘플 2~3장면 비교 (크레딧 비용 확인 후)
- **3단계**: 15분 안팎 한 편으로 시험 → 반응 보고 28분급으로 확장
- 주제: 이 채널은 '산업 뉴스 + 진짜 이유' 구조. 우리 채널로 옮기면 "뉴스 한 줄 → 월급쟁이 돈과 연결" (예: K-조선 수주 → 조선주·내 연금 ETF 비중)

※ 레퍼런스의 대본·비유·그림·로고는 쓰지 않고, 구조 원리만 사용한다.

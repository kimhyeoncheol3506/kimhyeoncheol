# 스마트대디 영상 편집 스킬에서 배운 것 (2026-10-22)

- 자료: Drive `smartdaddy-video-edit.zip` (112KB, 스킬 문서·규칙·스크립트). 문서와 코드는 **읽기만 했고 실행하지 않았다**
- 성격: 사람이 **녹화한 영상**을 CapCut 초안으로 바꾸는 스킬. 우리는 **코드로 영상을 만드는** 형식이라 컷 편집·CapCut 조립·받아쓰기 컷 계획 부분은 해당이 없다

## 우리 엔진에 적용한 것 (v1.13.0)
| 배운 것 | 원래 규칙 | 우리 적용 |
|---|---|---|
| 효과음 | 챕터 전환=snap, 결과 공개=ding, −20dB, 1분에 1~2개(많아도 5개) | 롱폼 챕터 첫 장면 자동 snap, scene `sfx`로 ding·click 지정, 분당 3개 넘으면 경고 |
| 장 전환 쉼 | 문장 사이 0.16초, 장이 바뀔 때 0.45초 | 장이 바뀌기 전 0.45초(일반 0.30초) |
| 한 칸씩 켜기 | 여러 항목은 말하는 순서대로 하나씩, 안 나온 칸은 흐리게 | 체크리스트 한 칸씩 체크(`reveal`, `at`) |
| 같은 화면 10초 넘기지 않기 | 2~3초마다 화면 상태 변경 | 10.5초 넘는 장면 경고 |
| 최종본 점검 | 검은 화면·긴 무음·음량·피크 | `tools/verify_video.py` (우리 형식에 맞게 새로 작성) |
| 규칙은 숫자로, 피드백은 저장 | "내 규칙"에 날짜·이유와 함께 누적 | SKILL.md에 `내 규칙` 섹션 신설, 이번 주 반복된 문제 4개를 숫자 규칙으로 저장 |

## 점검 결과
- 최근 3편(대공황·급반등·하락장 비교) 모두 FAIL·WARN 0: 검은 화면 0, 긴 무음 0, 음량 −14.0 LUFS, 피크 −2.2~−2.5 dBFS

## 가져오지 않은 것과 이유
- 자막 시작 +0.15초: 우리는 파형으로 찾은 시작보다 0.06초 먼저가 이미 맞게 나옴 (평균 오차 0.02초)
- 숫자 굴러가기(count-up)·반전 스티커 강조: 효과는 좋아 보이지만 엔진 작업이 크고, 헤드라인 빨강 강조는 현철님이 고른 형식이라 유지
- CapCut 프로젝트로 내보내기: 지금 형식(완성 mp4)과 맞지 않음. 필요하면 추후 제안

## 참고: 이 스킬이 잘하는 것
- 규칙마다 "왜"(실제 피드백 인용)를 붙여서 비슷한 상황에도 적용하게 함
- 사람이 마지막 10%를 손볼 수 있게 클립을 쪼개 두는 구조 (우리는 이미 완성본이라 해당 없음)

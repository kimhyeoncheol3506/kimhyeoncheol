# 벤치마킹 3편 정밀 분석 → 제작 규칙

분석일 2026-10-11. 공개 정보(제목·설명·자동 자막·스토리보드 프레임·썸네일)만 사용했고, 영상 파일은 내려받지 않았다.
**대본·캐릭터·로고는 복제하지 않는다.** 아래 '구조·속도·화면 문법'만 우리 영상에 적용한다.

## ① 경제학똑똑 — 롱폼 설명형의 교과서

**화면 문법**
- 한 문장 = 한 그림. 30초당 그림 약 9장, 즉 **3초마다 장면 전환**
- 같은 캐릭터 하나(정장 마스코트)가 끝까지 등장하고, 표정과 소품으로 감정을 전달 (갸웃·식은땀·밧줄 당기기·쿠션)
- 숫자는 단순 막대그래프 한 장(분배율 12% vs 14%)으로만 보여줌
- 하단 검은 반투명 박스에 흰 자막 1줄, 오른쪽 위에 작은 채널 로고
- 파스텔 단색 배경에 바닥선 하나로 공간을 만듦 (배경이 단순해야 캐릭터와 자막이 읽힘)

**대본 구조** (15분)
1. **0~15초 양자택일 훅**: "월 100만 원이 들어오는 투자 vs 자산이 크게 불어나는 투자, 어느 쪽?" → "나는 현금흐름을 사는가, 수익률을 사는가?"
2. **역설 수치**: 분배율 12%인데 SEC 수익률은 음수? → "바로 여기서 가장 중요한 **함정**이 시작됩니다"
3. **"아주 단순하게 풀어 보겠습니다"** → 사과 비유(옵션 = 사과를 살 권리)
4. **돈의 출처 4가지**로 쪼개기 (배당·자본이득·프리미엄·이자)
5. **시나리오 3개** (상승장·횡보장·급락장) — 장면마다 마스코트가 언덕을 오르고 미끄러짐
6. **오해 깨기**: "방패가 아니라 쿠션입니다"
7. **새 해법 등장**: "그렇다면 상승분을 덜 포기하면서 받을 수는 없을까?" → 커버드콜 2.0
8. **숫자 예시**: 1억 투자 → 1,200만 원 받았지만 원금이 8,800만 원이 됐다면?
9. **체크리스트 6개** → 큰 금액 예시(5억) → 세금·절세계좌
10. **세 가지만 기억하세요** → **첫 질문으로 되돌아오는 마무리** → 마지막 질문 던지기

**썸네일**: 가운데 마스코트(손 모으고 음흉한 미소) + 좌우 달력 아이콘 '15일'·'월말' + 둘을 잇는 금색 화살표·동전 + 성조기·캔들 차트·야경 배경 + 하단 2줄 문구(노랑 "배당만 받을줄 알았는데" / 빨강 "성장까지 잡는다?").

## ② 머니치트키 — 쇼츠 73초의 정석

**화면 문법 (9:16)**
- 검은 배경. **상단에 제목 2줄 고정** (노랑 1줄 + 흰색 1줄). 영상 내내 바뀌지 않아 스크롤 중에도 주제가 보임
- 가운데 1:1 정사각형 그림 영역. 단순한 캐릭터(밈 개구리 → 대머리 캐릭터)
- 그림 아래쪽에 **굵은 흰 자막 2줄 + 검은 외곽선**, 4~6어절씩 빠르게 바뀜
- 맨 아래 게시 날짜와 SNS 핸들

**대본 공식** (73초, 반말)
1. **0~3초 훅**: 이상한 숫자 + 질문 — "한 달 월세가 500만 원인데도 집이 없어서 난리, 이게 무슨 얘기일까?"
2. **재정의**: "이건 단순히 집값 문제가 아니야. ~라는 강력한 신호거든"
3. **개념에 이름 붙이기**: "락인 효과라는 **황금 수갑**" (기억에 남는 은유)
4. **숫자 2개 대비**: 3%대 저금리 → 7% 고금리, "이자가 두 배"
5. **"진짜 소름 돋는 건"** — 2차 반전 (집주인이 개인 → 거대 자본, 이익률 27%)
6. **우리 이야기로 가져오기**: "우리나라도 결국…"
7. **양자택일 마무리**: "평생 월세 내는 세입자로 남을지, 그 시스템의 주인이 될지"
8. CTA: "다음에도 알찬 내용 받고 싶으면 팔로우해"

## ③ 인생 녹음 중 — 210만 조회의 이유 (경제 아님, 형식만 차용)

- 실제 부부의 대화 녹음 + **아주 단순한 선 그림 애니메이션** (둘이 식탁에 앉아 있는 한 장면이 오래 지속)
- 상황 설명은 괄호 자막: "(시험관 시도 실패 소식)"
- 감정 곡선: 나쁜 소식 → 대화 속 농담·웃음 → "그래도 다시 웃기로 했습니다" (위로)
- 화려한 그래픽 없이 **목소리와 관계**가 영상을 끌고 감 → 시청 지속 시간이 긺
- 썸네일: 단색 배경 + 껴안은 두 캐릭터 + 큰 손글씨 한 줄 "임신은 어려워"

**우리 채널 적용**: 여의도남자·여의도여자 **부부/동료 대화형** 경제 영상. 예) "전세 만기 두 달 남았는데 어떡해?" → 대화로 문제를 꺼내고, 남자가 데이터로 설명하고, 여자가 시청자 입장에서 되묻는다. 감정(걱정 → 안도)이 있는 경제 이야기.

## 우리 영상 제작 규칙 (make_video.py가 이 규칙으로 동작)

### 쇼츠 (45~60초, speed 1.1)
| 구간 | 내용 | 예시 |
|---|---|---|
| 0~3초 | 이상한 숫자 또는 모순 + 질문 | "금리 내렸다는데, 내 이자는 왜 그대로일까?" |
| 3~10초 | "~가 아니야. 진짜 이유는 ~야" 재정의 | |
| 10~35초 | 개념 이름 붙이기 → 숫자 2개 대비 → 반전("진짜 소름인 건") | |
| 35~50초 | 내 생활에 적용 (예시 계산은 '예시' 표기) | |
| 마지막 5초 | 양자택일 질문 또는 체크리스트 3개 + 팔로우 | |
- 상단 고정 제목 2줄: 1줄 노랑(상황), 2줄 흰색(의문)
- 반말, 장면당 1~2문장, 자막 18자 이내 조각
- 대화가 필요하면 여의도여자가 시청자 질문을 대신함 (전체의 20~30%)

### 롱폼 (8~15분, speed 1.0)
1. 양자택일 훅 (15초) → 2. 역설 수치·"함정" (45초) → 3. "단순하게 풀어 보겠습니다" + 비유 → 4. 구성요소 쪼개기 → 5. 시나리오 3개 → 6. 오해 깨기 → 7. 숫자 예시 (작은 금액 → 큰 금액) → 8. 체크리스트 → 9. 세금·제도 → 10. 세 가지 요약 + 첫 질문 회수 + 마지막 질문
- 존댓말, 한 문장 = 한 장면 (평균 3~4초), 하단 자막 1줄
- 마스코트 표정 7종(neutral·happy·worried·shock·smug·think·angry)으로 감정 표현

### 썸네일 (공통)
- 가운데 마스코트(충격·음흉 표정) + 좌우 아이콘 2개(숫자·날짜·화살표) + 금색 연결 화살표
- 하단 2줄: 노랑(상황) / 빨강(반전 질문, 끝에 '?')
- 제목을 그대로 반복하지 않고 **궁금증만** 남김. 영상에서 답하지 않는 약속은 쓰지 않음

### 신뢰 규칙
- 모든 수치는 출처와 기준일을 설명란에 표기. 확인 못 한 숫자는 쓰지 않음
- 예시 계산은 화면에 '예시'라고 표기
- "무조건·확정·보장" 표현 금지, 투자 권유 금지 문구를 설명란에 포함

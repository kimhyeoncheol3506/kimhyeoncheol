# 신용점수 올리는 법 2026｜NICE·KCB 점수 체계와 진짜 영향 주는 것, 오해 7가지

신용점수를 올리는 가장 빠른 방법은 세 가지입니다. 연체를 만들지 않고, 현금서비스·리볼빙·카드론을 끊고, 카드 한도의 50% 아래로 쓰는 것. 여기에 통신비·건강보험료 납부 실적을 직접 제출하면 몇 점이라도 바로 오를 수 있습니다.

조회했다고 떨어지지 않습니다. 카드를 여러 장 갖고 있어도 상관없습니다. 하나씩 보겠습니다.

## NICE와 KCB, 뭘 보고 점수를 매기나

두 회사 모두 0~1,000점입니다. 등급제는 2021년 1월 1일부터 없어졌습니다.

평가 비중은 회사마다 다릅니다(2026년 5월 연합뉴스 팩트체크 기준).

| 평가 요소 | NICE | KCB |
|---|---|---|
| 상환 이력(연체 등) | 28.4% | 21% |
| 부채 수준 | 24.5% | 24% |
| 신용거래 기간 | 12.3% | 9% |
| 신용거래 형태 | 27.5% | 38% |
| 비금융·마이데이터 | 7.3% | 8% |

NICE는 연체에, KCB는 거래 형태에 더 민감합니다. 같은 사람이라도 두 점수가 다르게 나오는 이유입니다.

## 내 점수, 어느 구간인가

금융위원회가 점수제로 바꾸면서 제시한 기준선입니다.

| 기준 | NICE | KCB | 의미 |
|---|---|---|---|
| 신용카드 발급 | 680점 이상 | 576점 이상 | 상위 93% |
| 중금리대출 우대 | 859점 이하 | 820점 이하 | 하위 50% |
| 서민금융상품 지원 | 744점 이하 | 700점 이하 | 하위 20% |
| 구속성 영업행위 기준 | 724점 이하 | 655점 이하 | 하위 10% |

이 숫자는 2021년 전환 당시 값입니다. 기준점은 매년 4월 1일 전 국민 점수 분포로 다시 산정됩니다. 지금 기준선은 이보다 높을 수 있습니다.

## 점수 깎는 것: 이것만 피하면 됩니다

- **연체 10만 원 이상, 5영업일 이상.** 이때부터 평가에 들어갑니다. 갚아도 단기연체 기록은 해제 후 3년간 활용됩니다.
- **장기연체.** 한국신용정보원에 등록되면 해제 후 5년.
- **현금서비스·리볼빙·카드론.** 셋 다 크게 깎입니다. 현금서비스가 특히 큽니다.
- **2금융권 대출.** 같은 금액도 저축은행·캐피탈에서 빌리면 더 깎입니다. 여러 곳에서 쪼개 빌리면 더 불리합니다.
- **한도 꽉 채운 카드·마이너스통장.** 한도의 40~50% 이하가 권장선입니다.

## 점수 올리는 것: 오늘 할 수 있는 체크리스트

- [ ] NICE지키미·올크레딧(또는 금융앱)에서 **비금융 납부실적 제출** — 통신비, 건강보험료, 국민연금, 공과금, 아파트관리비
- [ ] 제출 조건 확인 — 최근 3개월 안에, 6개월 이상 성실 납부한 자료가 있어야 반영
- [ ] 자동이체 걸기 — 연체 사고 차단
- [ ] 연체가 여러 건이면 **오래된 것부터** 상환
- [ ] 체크카드 꾸준히 쓰기 — NICE는 체크카드 실적도 평가에 넣습니다
- [ ] 카드 한도가 작다면 여러 카드로 나눠 써서 각 카드 사용률을 절반 아래로

비금융정보 제출로 오르는 폭은 전문가 설명 기준 최소 3점에서 최대 40점입니다. 단, 이미 같은 달에 반영했거나 변동이 없으면 그대로일 수 있습니다.

## 흔한 오해 7가지

**1. "신용점수 조회하면 떨어진다"** → 이건 오해입니다. 2011년 10월 제도 개선 이후 조회는 점수에 영향이 없습니다. 다만 짧은 기간 대출 심사 조회가 몰리면 금융사가 사기 방지 차원에서 참고할 수는 있습니다.

**2. "카드 많으면 불리하다"** → 오해입니다. 발급 개수, 재발급, 해지·탈회 모두 점수와 무관합니다.

**3. "카드 해지하면 점수 오른다"** → 오해입니다. 오히려 전체 한도가 줄어 사용률이 높아 보일 수 있습니다.

**4. "대출 한 번도 안 받으면 만점"** → 아닙니다. 빌리고 제때 갚은 기록이 쌓여야 점수에 도움이 됩니다.

**5. "연체 갚으면 바로 원상복구"** → 아닙니다. 서서히 회복됩니다. 단기연체도 해제 후 3년간 기록이 활용됩니다.

**6. "몇천 원 하루 밀려도 끝"** → 과장입니다. 10만 원 미만이거나 5영업일 미만인 연체는 평가에 반영되지 않습니다. 그래도 습관이 되면 위험합니다.

**7. "올해도 신용사면 있겠지"** → 기대하지 마세요. 2020년 1월~2025년 8월 발생한 5,000만 원 이하 연체를 2025년 말까지 다 갚은 사람의 연체이력을 지워준 조치(개인 257만2,000명, 평균 29점 상승)는 2025년 말로 끝났습니다. 2026년 11월 현재 새 신용사면 발표는 확인되지 않습니다. 오히려 혜택을 받은 사람 중 22.2%가 올해 상반기에 다시 연체했다는 국회 자료가 나왔습니다.

## 2026년에 달라진 것

- 금융위원회가 **신용평가체계 개편 TF**를 꾸려 대안신용평가 활성화를 논의 중입니다. 시행 일정은 아직 없습니다.
- 개인사업자용 **소상공인 특화 신용평가(SCB)**가 8월 31일부터 국민·기업·농협·부산·신한·우리·제주·하나은행 8곳에서 시범 운영 중입니다. 매출·업종·상권 정보를 대출 심사에 반영하는 제도로, 개인 신용점수와는 별개입니다.

정리하면 순서는 이렇습니다. 연체 0건 → 고비용 단기대출 정리 → 사용률 50% 아래 → 비금융정보 제출. 점수는 한 달 만에 크게 바뀌지 않지만, 깎이는 일만 막아도 방향은 위로 갑니다.

※ 이 글은 일반적인 정보 정리입니다. 개인별 점수 변화는 금융 이력에 따라 다르며, 대출·카드 이용 판단은 본인 책임입니다.

## 이미지 아이디어
1. "NICE와 KCB" 표 뒤 — 두 회사 평가 비중을 나란히 놓은 가로 막대 그래프 — 직접 만드는 그래프
2. "내 점수, 어느 구간인가" 뒤 — 점수 눈금 위에 680/744/859점(NICE) 기준선을 표시한 자 모양 그림 — 직접 만드는 도식
3. "오늘 할 수 있는 체크리스트" 뒤 — NICE지키미 '신용점수 올리기' 비금융정보 제출 메뉴 화면 — 직접 캡처(개인정보·점수 가리기)
4. "흔한 오해 7가지" 앞 — O/X 카드 7장 묶음(조회=X, 카드 개수=X 등) — 직접 만드는 카드
5. 마무리 앞 — "연체 0 → 단기대출 정리 → 사용률 50% → 비금융 제출" 4단계 화살표 — 직접 만드는 카드

## 검토 메모
- 2026년 4월 재산정된 최신 카드발급·서민금융 기준점(NICE/KCB)은 확인하지 못해 2021년 전환 당시 값으로 쓰고 단서를 달았습니다. 최신 값 확인되면 교체 권장.
- 평가 비중 표와 "비금융 제출 3~40점"은 연합뉴스 1곳만 확인했습니다. NICE·KCB 공식 페이지 비중과 대조 필요(NICE 페이지에 비중 링크 있음).
- 2026년 신규 신용사면은 검색상 없음. 발행 직전 금융위원회 보도자료 한 번 더 확인(연말 발표 가능성).
- 재연체율 22.2%는 국회 자료 인용 언론 보도 기준입니다.
- 리볼빙 감점 폭에 대한 공식 수치는 없습니다(정성적 서술만).

# 폰 요금 월 4만 원 넘게 내고 있으면 이거 안 하면 손해임 (2026년 11월 알뜰폰·통신비 감면 정리)

오늘(11월 21일) 기준 알뜰폰 평생요금제 목록을 보니까 KT망 5G 20GB짜리가 월 7,900원이야. 3주 사이에 새로 올라온 요금제만 288개고.

첫 월급 받고 통신사 매장에서 개통한 그 요금제, 아직 그대로 쓰고 있지? 그럼 이번 글 끝까지 봐 줘.

## 일단 계산부터 해 보자

통신3사에서 월 5만 5천 원짜리 요금제를 쓰고 선택약정 25%를 받는다고 쳐 볼게(예시로 잡은 금액이야).

| 구분 | 월 요금 | 1년 |
|---|---|---|
| 통신3사 5만 5천 원 + 선택약정 25% | 41,250원 | 495,000원 |
| 알뜰폰 KT망 5G 20GB 평생요금제 | 7,900원 | 94,800원 |
| 차이 | 33,350원 | 400,200원 |

1년에 40만 원이야. 한 달 데이터를 20GB 안쪽으로 쓰는 사람이면 체감 차이도 거의 없어. 알뜰폰도 결국 통신3사 망을 빌려 쓰는 거라서 통화 품질이 따로 노는 게 아니거든.

## 알뜰폰 고를 때 이것만 보면 됨

**1. '평생'인지 '몇 개월 할인'인지**

요금 비교 사이트 보면 0원, 4,000원짜리가 막 보여. 근데 대부분 6~7개월 뒤에 정상가로 올라가.

- 100GB+5Mbps 요금제: 할인 중 4,000원 → 이후 42,900원
- 5G 15GB+ 요금제: 할인 중 0원 → 이후 16,900원

할인 끝나는 달을 캘린더에 적어 두고, 그때 다른 요금제로 갈아타면 돼. 이게 귀찮으면 처음부터 평생요금제로 가는 게 속 편해.

**2. 데이터 다 쓰고 나서 속도(QoS)**

'+1Mbps', '+5Mbps' 이런 숫자가 데이터 소진 후 속도야. 1Mbps면 카톡이랑 지도 정도, 5Mbps면 영상도 그럭저럭 돼. 유튜브 자주 보면 이 숫자부터 확인해.

**3. 어느 망인지**

집이랑 회사에서 잘 터지던 통신사 망을 고르면 실패 확률이 확 줄어.

## 갈아타는 순서

1. 지금 통신사 약정 남았는지, 위약금 얼마인지 고객센터 앱에서 확인
2. 쓰는 폰이 자급제거나 약정 끝났으면 그대로 유심만 바꾸면 됨
3. 알뜰폰 사이트에서 번호이동 신청 → 유심 받거나 eSIM으로 셀프 개통
4. 개통되면 기존 통신사는 자동으로 해지돼

가족 결합 할인이나 인터넷 결합 묶여 있으면 그거 깨지는 금액도 같이 계산해 봐. 결합이 크면 본인만 빠지는 게 손해일 수도 있어.

## 통신3사 남을 거면 이건 챙기자

2026년 4월에 과기정통부가 통신3사 요금제 개편안을 발표했어. 핵심은 두 개야.

- **데이터 안심옵션**: 모든 LTE·5G 데이터 요금제에 추가 요금 없이 들어가서, 데이터 다 써도 메신저·지도 검색 정도는 계속 돼
- **2만 원대 5G 요금제** 출시, 요금제 수도 절반 이하로 정리

그러니까 통신3사에 남더라도 지금 요금제가 내 사용량보다 큰 건 아닌지 한번 보자. 데이터 끊길까 봐 무제한 쓰던 사람이면 한 단계 낮춰도 버틸 수 있어.

태블릿이나 워치를 따로 회선으로 쓰고 있다면 데이터 쉐어링도 봐. 폰 요금제 데이터를 나눠 쓰는 추가 유심이라, 별도 요금제 하나 더 내는 것보다 싸게 먹히는 경우가 많아. 다만 쉐어링 가능 여부랑 유심 요금은 요금제마다 달라서 내 요금제 상세 페이지에서 확인해야 해.

## 부모님 폰도 같이 보기

이건 내 거 말고 부모님이나 할머니 할아버지 폰 얘기야.

- **기초연금 받는 만 65세 이상**: 통신요금 50% 감면(상한 있음)
- **생계·의료급여 수급자**: 기본료 26,000원 감면 + 통화료 50%
- **주거·교육급여 수급자·차상위**: 기본료 11,000원 감면 + 통화료 35%
- **장애인**: 기본료·통화료 35%

중요한 건 자동으로 안 된다는 거. 통신사 고객센터나 대리점, 감면 안내센터(휴대폰 1523)에 본인 명의 회선으로 신청해야 해. 1인 1회선이고, 알뜰폰도 감면 전용 요금제로 받을 수 있어.

그리고 이번 개편으로 65세 이상은 음성·문자가 기본 무제한으로 제공되는 쪽으로 바뀌고 있어(통신사마다 적용 조건이 조금씩 달라). 부모님 요금제가 통화 시간 제한형이면 지금 조건이 어떻게 적용됐는지 확인해 드려.

## 정리하면

- 데이터 월 20GB 이하 → 알뜰폰 평생요금제부터 보기
- 할인형 요금제 → 끝나는 달 메모 필수
- 통신3사 유지 → 개편 요금제랑 내 사용량 비교
- 부모님 → 감면 신청했는지 전화 한 통

요금은 진짜 자주 바뀌어. 가입 전에 통신사 공식 가입 화면에서 최종 금액이랑 조건 꼭 다시 보고 넘어가자.

## 검토 메모
- 대상별 월 최대 감면액은 출처마다 다름(생계·의료 33,500원 vs 41,000원, 기초연금 11,000원 vs 12,000원 vs 22,000원). 본문엔 감면 방식만 쓰고 상한 금액은 생략. 과기정통부·복지로 원문 확인 후 추가 권장.
- 차상위계층 이동통신 감면: 연수구 페이지는 "항목 없음", 다른 자료·ZDNet은 대상 포함. 본문은 주거·교육급여와 같은 기준으로 썼으니 재확인 필요.
- 알뜰폰 요금은 매일 바뀜. 발행 직전 7,900원 요금제 유지 여부 재확인.
- 통신3사 '2만 원대 5G' 실제 출시 요금제명·가격은 확인 안 함(본문에 숫자 없음).
- 데이터 쉐어링은 통신사·요금제별 조건이 달라 본문에서 결합 할인 정도로만 언급.

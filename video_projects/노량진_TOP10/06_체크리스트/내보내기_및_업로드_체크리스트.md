# 내보내기 설정 & 업로드 전 체크리스트

## 1. 캡컷 내보내기 설정
| 항목 | 값 |
|---|---|
| 해상도 | 1080p (원본 스톡이 4K면 4K/2160p 권장. 유튜브가 더 높은 화질로 처리함) |
| 화면비 | 16:9 (프로젝트 생성 때부터 16:9로 설정) |
| 프레임 | 30fps |
| 코덱 | H.264 |
| 비트레이트 | "권장" 또는 "높음" (1080p 기준 약 10~16Mbps) |
| 형식 | MP4 |
| 오디오 | AAC 48kHz, 마스터 볼륨 피크 -1dB, 내레이션 평균 -14 LUFS 안팎 |

## 2. 러닝타임 맞추기 (19~21분 목표)
- [ ] 대본 본문은 4,500자입니다. 애덤 TTS 기본 속도로 읽으면 13~15분 안팎이 나옵니다.
- [ ] 애덤 속도를 0.9x로 설정했나요?
- [ ] 맛집마다 먹거리 묘사 앞뒤로 ASMR·B롤 여백을 2~4초씩 넣었나요? (맛집당 약 15~20초)
- [ ] 순위 전환 카드(3초)와 아웃트로 엔드스크린(20초)을 넣었나요?
- [ ] 최종 길이가 19:00~21:00 안에 들어오나요? 남으면 B롤 여백을 줄이고, 모자라면 묘사 구간 슬로모션을 늘리세요.
- [ ] 길이를 조정했다면 SRT 타이밍을 다시 맞추세요. 가장 쉬운 방법: 캡컷 [텍스트 → 자동 캡션]으로 다시 생성한 뒤 `02_자막/자막_srt.srt`의 문구(숫자 표기)로 덮어쓰기.

## 3. 스타일 체크 (클린 미니멀)
- [ ] 모든 섹션 앞에 챕터 카드가 있고, 상단 라벨과 순위 배지가 섹션 끝까지 깔려 있나요?
- [ ] 기본 자막이 한 줄 + 반투명 검정 박스로 통일되어 있나요? (SRT를 불러온 뒤 스타일 일괄 적용)
- [ ] 강조 자막은 세그먼트당 1개 이하, 초록 자막은 꿀팁 문장에만 썼나요?
- [ ] 흔들기, 플래시, 반짝이, 스티커 같은 효과가 남아 있지 않나요?
- [ ] 엔드카드의 "채널명"을 실제 채널명으로 바꿨나요?

## 4. 업로드 전 체크리스트

### 사실 검증
- [ ] 리뷰 수(484 / 892 / 1,768 / 2,219 / 3,218 / 1,142)가 기획안 표와 같은가요?
- [ ] 업로드 직전에 네이버 지도 등에서 현재 리뷰 수를 다시 확인했나요? 크게 달라졌으면 자막에 "(제작 시점 기준)"을 추가하세요.
- [ ] 진주식당 "35년·2대째", 손선장 "1℃·일평균 800마리", 전라상회 "5만 원 이상 광어초밥 서비스"가 여전히 유효한가요?
- [ ] 각 가게가 아직 영업 중인가요? (폐업·이전 여부)
- [ ] 노량진수산시장 연혁(1927년 서울역 인근 시작 → 1971년 노량진 이전)을 수협 노량진수산 공식 자료로 한 번 더 확인했나요?
- [ ] 바가지나 가격 논란 같은 단정적 표현이 대본·자막·제목·썸네일 어디에도 없나요?
- [ ] 1~2위는 검색 노출 기준, 3~4위는 리뷰 수 기준이라는 언급이 4위 구간(11:30 부근)에 들어가 있나요?
- [ ] 면책 문구가 아웃트로 내레이션·자막, 설명란, 고정댓글 세 곳에 모두 있나요?

### 저작권·초상권
- [ ] BGM 3곡이 모두 "상업적 이용 가능" 표시가 있는 곡인가요?
- [ ] 스톡 영상은 CapCut 라이브러리·Pexels·Pixabay 것만 썼나요? (출처 목록을 메모장에 남겨 두면 저작권 신고에 대응하기 쉽습니다)
- [ ] 화면에 다른 가게의 간판이나 상호, 알아볼 수 있는 일반인 얼굴이 크게 나오지 않나요?
- [ ] 썸네일 인물 사진의 사용 권한이 있나요?
- [ ] 협찬이나 광고가 있다면 유튜브 '유료 프로모션'을 체크하고 설명란에 표시했나요?

### 업로드 설정
- [ ] 제목: `05_메타데이터/제목_후보 3개.txt`에서 선택
- [ ] 설명란: 타임스탬프가 00:00으로 시작해야 챕터가 만들어집니다. 최종 편집본의 실제 시간에 맞게 고쳤나요?
- [ ] 자막: `자막_srt.srt` 업로드(언어: 한국어)
- [ ] 썸네일: 1280×720 업로드
- [ ] 재생목록: "맛집 TOP10 시리즈" 등에 추가
- [ ] 카테고리: 여행/이벤트 또는 인물/블로그
- [ ] 아동용 아님 체크
- [ ] 엔드스크린: 19:40부터 구독 버튼과 추천 영상 2개
- [ ] 공개 시간: 평일 저녁 6~8시 또는 금요일 저녁 (타깃이 2030 직장인)

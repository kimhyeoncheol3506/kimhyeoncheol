# 그래픽 사용법 (클린 미니멀 스타일)

모든 이미지는 1920×1080 PNG입니다. 캡컷에서 [미디어 → 가져오기]로 폴더째 불러오세요.
문구를 고치려면 `01_대본/대본데이터.json`의 `graphics` 항목을 수정한 뒤 아래 명령으로 다시 만드세요.
`python3 -I .claude/skills/ranking-video/scripts/make_graphics.py video_projects/노량진_TOP10/01_대본/대본데이터.json video_projects/노량진_TOP10`

| 폴더 | 쓰는 법 | 길이 |
|---|---|---|
| `01_챕터카드/` | 메인 트랙. 각 섹션의 맨 앞에 놓기(00 인트로 ~ 11 오늘의 요약) | 2초 (1위만 3초) |
| `02_상단라벨/` | **오버레이** 트랙. 챕터 카드 바로 뒤부터 그 섹션이 끝날 때까지 늘리기 | 섹션 전체 |
| `03_순위배지/` | **오버레이** 트랙(라벨 위). 오른쪽 아래 원형 배지. 라벨과 같은 길이 | 섹션 전체 |
| `04_정보카드/` | 메인 트랙. 가게 소개 구간(훅이 끝난 직후)에 끼우기. 4위는 2장(순위 기준 → 3,218개) | 3~4초 |
| `05_요약카드/` | 아웃트로 정리 멘트에 맞춰 `00`(빈 칸) → `01`(땅끝마을) → … → `10`(전체) 순서로 교체 | 장당 약 1초, `10`은 3초 |
| `06_엔드카드/` | 영상 맨 끝. **"채널명"을 실제 채널명으로 바꿔서** 다시 만드세요(`graphics.channel_name`) | 3초 |
| `07_썸네일틀/` | 썸네일. 1280×720. 틀 아래에 메인 사진을 깔기 | — |

- 정보 카드의 숫자와 문구는 기획안 표 데이터만 사용했습니다.
- 자막은 SRT를 불러온 뒤 캡컷에서 스타일을 일괄 적용하세요. 설정값은 `.claude/skills/ranking-video/references/스타일_가이드.md` 2장에 있습니다.

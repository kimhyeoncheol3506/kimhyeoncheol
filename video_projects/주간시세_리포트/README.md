# 노량진 주간 시세 리포트 — 이번 주 회차 만들기

매주 토요일 업로드. 이번 주(월~토) vs 지난주(월~토) 노량진수산 경락시세 비교. 여의도남자 1.12배속, 먹색+금색, 7~9분.

**데이터(2026-11-23~)**: 1순위는 공개 일별 수집본 `github.com/StarRate1214/smart-noryangjin` `data/daily/YYYY-MM-DD.csv`(매일 05·07시 갱신, 17~18시 최종). `준비`가 자동으로 가져오고(`noryangjin_prices.py import`), 이미 받은 날도 수집본 행 수가 바뀌면 다시 받는다. kg 경매 행은 사이트 직접 수집과 같음을 확인(11/2~11/14). 사이트 직접 수집은 교차 확인용으로만 `NORYANGJIN_SITE=1`. 출처 표기: **노량진수산(주) 어종별 경락시세(일별 수집본)**.

**엔딩·설명란(#5~)**: 구독 멘트부터 끝까지 17.5초 이상 엔딩화면 자리(빈 화면), 썸네일 1280×720, 설명란 마지막 줄 재생목록 링크.

```bash
# 1) 준비: 데이터·새 회차 폴더·비교표 후보·고정 썸네일
bash video_projects/주간시세_리포트/이번주_회차.sh 준비 2026-11-23 [2026-11-27]   # 끝날짜 생략 시 토요일
# 2) 새 폴더의 01_대본/build_data.py (TOP·UP·문장·weekly)와 build_short.py 문장만 이번 주 숫자로 수정
# 3) 만들기: 숫자 대조 → 음성 → 발음 검수 → 렌더 → 검수 → 쇼츠 → 제목·설명란·고정댓글·회차.json
bash video_projects/주간시세_리포트/이번주_회차.sh 만들기 video_projects/주간시세_리포트/05_20261121
```

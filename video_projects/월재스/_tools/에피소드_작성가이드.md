# 월재스 롱폼 1편 작성 가이드 (서브에이전트용)

채널: **월급쟁이 재테크 스킬(월재스)** — 경제 사건·개념을 사실 검증된 숫자로 쉽게 설명하고, 마지막에 월급쟁이의 돈 관리 교훈으로 끝내는 10~11분 롱폼.
오늘 날짜: **2026-11-26**. "최신"은 이 날짜 기준이다.

## 반드시 지킬 것
1. **수치는 실제로 연 출처만.** 웹 검색·페이지를 직접 열어 확인한 숫자만 쓴다. 확인 못 한 것은 쓰지 않거나 "추정"·범위로 말한다. 지어내지 않는다.
2. 다른 채널(경제사냥꾼 등)의 대본·제목·썸네일 문구를 베끼지 않는다. 주제만 같고 내용·구성·표현은 새로 쓴다.
3. **종목 추천 금지**("○○ 사라/담아라", "수혜주 5개"). 개념·구조·역사·숫자 설명과 월급쟁이 관점의 위험 관리까지만. 투자 권유가 아님을 설명란에 적는다.
4. 실존 인물 사진·얼굴 합성 썸네일 금지(그래픽·숫자·국기만). 근거 없는 '파산·붕괴·폭락 확정' 단정 금지. 예측은 "~라는 전망이 있다(출처)"로.
5. "매주·매일·주기적으로·정기적으로·다음 주에 또" 같은 **연재 주기 문구 금지**.
6. 말투: 친근한 존댓말 설명체("~거든요", "~죠", "~예요"). 너굴경제 말투('~구리') 금지. 문장은 짧게(한 줄 = 한 문장, 40~70자).
7. git 커밋은 하지 않는다(메인이 한다).

## 만들 파일 (에피소드 폴더 `video_projects/월재스/<NN_이름>/`)
1. `research/facts.md` — 확인 날짜, 한 줄 요약, 사실 표(# / 사실 / 수치 / 날짜·기준 / **실제로 연 URL** / 메모), 사건 연표, '쓰면 안 되는 주장'(퍼졌지만 틀리거나 미확인), 확인 못 한 항목, `## 출처 목록`(제목 — URL).
2. `script/01_본편.txt` — 아래 형식의 대본. **음성 글자 수 4,300~4,900자**(공백 포함, 지시줄·주석 제외. 숫자는 한글로 읽혀 더 길어짐) → 10~11.5분.
3. `research/clips.json` — 큰 숫자 애니메이션 클립 2개 설정(아래).
4. `research/thumbs.json` — 썸네일 후보 2개 설정(아래).
5. 릴리스 문구 4개: `../../release/<NN_이름>/` 에
   - `제목_후보.txt` (추천 순 3개 + 검토 메모: 과장·단정 피한 이유)
   - `설명란_템플릿.txt` (소개 3~4문장 → `⏱ 목차` 다음 줄에 `{CHAPTERS}` 그대로 → `📚 주요 출처 (수치 확인일 2026-11-26)` 6~10개 → ⚠️ 교육용·투자 권유 아님·수치 기준일 → `🎙 내레이션: AI 합성 음성 / 화면의 그래픽은 직접 제작했습니다.` → 해시태그 5~6개)
   - `고정댓글.txt` (📌 영상 속 숫자 정리 4~5줄 + 출처는 설명란 + 💬 질문 1개)
   - `출처.md` (facts.md의 출처 목록 전체, 맨 위에 확인일)

## 대본 형식 (예시: `video_projects/월재스/01_아이슬란드/script/01_본편.txt` 를 꼭 열어 보고 그대로 따라 할 것)
- 한 줄 = 내레이션 한 문장. `#`로 시작하면 주석(근거 표 번호 적기). `!`로 시작하면 강조 문장.
- 숫자 읽기가 애매하면 `화면 문장 || 읽을 문장` (예: `S&P A+ || 에스앤피 에이 플러스`). 영문 약어는 대부분 읽기 줄을 단다.
- 장면 지시(다음 문장부터 적용):
  - `@part 1` (맨 위 한 번)
  - `@section 1. 소제목` — 챕터(목차 시각이 됨). 오프닝은 `@section 오프닝`, 본론 5~6개, 마지막은 `@section 6. … 교훈`류.
  - `@hook ../assets/hook.png | 헤드라인1 | 헤드라인2` — 오프닝 첫 장면(헤드라인 각 16자 이내).
  - `@broll ../assets/broll1.png` / `@broll ../assets/broll2.png` — 챕터 첫머리 분위기 컷(번갈아).
  - `@s {json}` — 인포그래픽 슬라이드. 키: `title`, `subtitle`, `source`("자료: …"), `theme`("cream" 밝은 배경, 없으면 어두운 배경), 그리고 아래 중 하나:
    - `cards`: `[{"label","value","unit","color","caption"}]` 2~4개(`color`: red/blue/yellow/purple) 또는 개념 카드 `[{"text":"줄1\n줄2"},…,{"text":"…","fill":"yellow"}]` + `"card_height":220`
    - `bars`: `[{"label","value"(숫자),"text"(표시),"color":"red_num|blue_num","arrow":true,"strong":true,"at":"L1"}]`
    - `bignum`: `{"value","unit","caption","color"}`
    - `bullets`: `["…","…"]` (+ `"underline":true` 결론용)
    - 선택: `"highlights":[{"target":"card:0|bullet:1","at":"L2"}]`, `"banner":{"text":"… →","accent":"강조","at":"L2"}`
    - `"at":"L2"` = 그 장면의 3번째 문장이 시작될 때 등장.
  - 숫자 클립: `@s {"title":"","subtitle":"","source":"","image":"clips/c1.mp4","image_box":[0,0,1920,1080],"section":""}` (c1·c2 두 번, 오프닝 1개 + 본론 1개 권장)
  - `@toc 그래서 오늘 영상은요 | 항목1 ; 항목2 ; … ; 항목6` (오프닝)
  - `@sub 월급쟁이 재테크, 같이 해요` (오프닝 구독 요청 직전) / 끝에 `@sub 다음 재테크 이야기도 같이 봐요`
  - `@mascot 짧은 반응(10자 이내)` 1~2번 / 맨 끝 `@outro` 다음 줄 `월급쟁이 재테크 스킬, 월재스였습니다. 다음 영상에서 만나요.`
- 장면은 25~32개, 한 장면에 문장 2~6개. 슬라이드 `"at"`의 L번호는 그 장면 문장 수보다 작게.
- JSON은 한 줄, 큰따옴표, 유효해야 함(`python3 -c "import json;json.loads(...)"`로 확인 권장).
- 구성: 훅(단정적 사실 + 숫자 2~3개, 30초 안) → `@toc` → 구독 요청 → 개념 설명 → 숫자·역사 → 반전/오해 바로잡기 → 2026년 지금 상황 → 월급쟁이 교훈 3가지(한국 제도·숫자 연결) → 마무리.

## clips.json 형식
```json
[{"file":"c1.mp4","kicker":"2026년 11월, 원·달러","label":"짧은 라벨(20자 이내)","from":0,"to":1475,"unit":"원","decimals":0,"color":"#f2262b","caption":"자료: … (60자 이내)","tags":["태그1","태그2"],"seconds":8},
 {"file":"c2.mp4", …}]
```
`color`: 오르면/위험 `#f2262b`, 내리면 `#3d97e5`. 음수는 `to`에 음수로. 소수면 `decimals`.

## thumbs.json 형식 (1280x720, 배경은 국기 또는 차트)
```json
[{"flag":"kr","big":"줄1<br>줄2","big_size":120,"sub":"노란 띠 부제(14자 이내)","num":"큰 숫자(선택)","kicker":"왼쪽 위 작은 글(선택)"},
 {"flag":"chart","big":"…","big_size":120,"color":"#4FA3FF","sub":"…","bubble":"말풍선(선택, 14자 이내)","kicker":"…"}]
```
`flag`: `kr` `us` `jp` `is` `chart_red`(하락·위기) `chart_blue`(상승·차분). `big` 한 줄 8자 이내 × 2줄. 단정·과장 금지(질문형 OK).

# 네이버 재테크 블로그 자동 글쓰기

블로그: https://blog.naver.com/no4angel (채널 "월급쟁이 재테크 스킬" 톤)
초안 폴더: C:\Users\Admin\Desktop\네이버블로그_초안\YYYY-MM-DD_키워드.md
문체 학습 파일: 같은 폴더의 `문체_학습노트.md` (매번 읽고, 사용자가 고친 점을 추가)

## 순서 (매 단계 ask_user_question, 보기 정확히 10개)
1. **오늘 시장 조사**: WebSearch로 당일 코스피/코스닥 마감, 환율, 금리, 주요 정책·세금 일정. 숫자는 기사 2곳 이상 교차 확인.
2. **1단계 주제 10개**: 오늘 이슈 + 시즌(연말정산, 배당, ISA 등)을 섞어 제시.
3. **2단계 제목 10개**: 검색 키워드를 앞쪽, 32자 이내.
4. **3단계 말투/구성 10개**: 동료 대화형, 경험담, 해설, Q&A, 체크리스트, 계산 예시, 통계, 실수 고백, 짧은 요약, 혼합.
5. **선택이 끝나면 더 묻지 않고 끝까지 자동 진행** (사용자 요청 2026-11-02):
   a. 주제 자료 조사: 공식 출처(한국거래소, 금감원, 국세청, 한국은행, 기재부, 금융사 공지) + 언론 기사 2곳 이상 교차 확인.
   b. 경험담 2곳 직접 작성(아래 규칙). `[내 경험]` 빈칸을 남기지 않는다.
   c. 그림 2~3장 직접 마련(아래 "그림 고르는 법"). `[사진]` 빈칸을 남기지 않는다.
   d. 초안 파일과 그림을 바탕화면 초안 폴더에 저장 → 네이버에 제목·본문·그림·태그 10개 입력 → 임시저장.
   e. 검증: 표시자(@@IMG, [사진, [내 경험) 0개, 이미지 개수, 태그, 임시저장 시각 확인 후 스크린샷으로 보고.
6. 발행은 하지 않는다. 사용자가 읽고 직접 발행.

## 그림 고르는 법 (주제에 맞게, 저작권 안전한 것만)
- 지수/종목/환율/금리: 네이버페이 증권(stock.naver.com) 차트·시세·수급 화면 캡처. 환율은 시장지표 탭, 금리는 한국은행 기준금리 화면.
- 세금·제도(연말정산, ISA, 연금저축, 환급금): 국세청·금감원·정부 보도자료의 표/안내 화면 캡처(출처 표기).
- 계산 예시: 본문 숫자로 간단한 표/막대 그림을 HTML로 만들어 `python -m http.server`로 띄운 뒤 스크린샷(또는 Image Generation 스킬로 설명 일러스트).
- 다른 사람 블로그·뉴스 사진은 가져오지 않는다(저작권). 캐처 화면에서 사용자 프로필·개인정보는 잘라낸다.
- 첫 그림은 대표 이미지가 되므로 주제를 가장 잘 보여주는 것을 넣는다.

## 문체 규칙 (AI 티 줄이기)
- 짧은 문장, 한 문단 1~3줄, 실제 날짜와 숫자로 시작.
- 금지: "결론적으로", "다양한", "중요합니다" 반복, "~에 대해 알아보겠습니다", 과한 이모지, 같은 어미 3번 연속.
- 구어체 연결어 허용: "솔직히", "보시죠?", "여기가 핵심이에요".
- 경험담은 사용자 요청(2026-11-02)대로 Aside가 직접 채운다. 단 "있을 법한" 수준으로: 그날 실제 지수 등락률로 계산한 직장인 계좌 시나리오(예: 1,000만 원 지수 ETF면 -35만 원)와 가벼운 감정 표현만. 지어낸 개인 수익률·매매 내역·종목 보유 주장은 쓰지 않는다. 계산은 반드시 검산.
- 문체_학습노트.md의 사용자 수정 사례를 우선 반영.

## 독자 수익 도움 원칙
- 매 글에 바로 따라 할 수 있는 행동 2~3개(계산 예시 포함)를 넣는다: 절세, 수수료/이자 절약, 분할매수 규칙, 현금 비중 등.
- 특정 종목 매수 권유, 수익 보장 표현 금지. 끝에 유의 문구 필수:

- 출처(기관/언론, 날짜)를 파일 끝에 남긴다.

## 네이버 입력 방법 (검증됨 2026-11-02)
- 이동: https://blog.naver.com/GoBlogWrite.naver (로그인 안 돼 있으면 탭을 띄우고 사용자가 직접 로그인. 비밀번호 받지 않기)
- 도움말 패널이 뜨면 "닫기".
- 제목: frameLocator('#mainFrame') `.se-documentTitle .se-text-paragraph` 클릭 → keyboard.insertText.
- 본문: keyboard 입력은 중간이 누락됨. PowerShell `Set-Clipboard`로 본문 복사 → 본문 `.se-component.se-text .se-text-paragraph` 클릭 → Ctrl+V. 글자 수로 검증.
- 상단 "저장" 버튼 = 임시저장. "임시저장된 글 보기" 숫자 증가로 확인. **발행은 사용자가 직접.**
- 사진: 본문에 `@@IMG1@@` 같은 표시 줄을 넣어 붙여넣고 → 표시 줄 클릭, End, 표시 글자 수만큼 Backspace → 사진 버튼(`button.se-image-toolbar-button, button[data-name="image"]`) 클릭 + filechooser.setFiles. setFiles 파일은 세션 tmp 폴더에 있어야 함.
- 차트 캡처: https://stock.naver.com/domestic/index/KOSPI/price, 뷰포트 1800x950, "1개월" 클릭, 전체 스크린샷 후 PowerShell System.Drawing으로 자르기(locator/clip 스크린샷은 레이아웃이 흔들려 부정확). 오른쪽 상단 프로필 사진은 잘라낸다.
- 태그: "발행" 버튼으로 설정 창을 열고 `태그 입력` 칸에 입력+Enter → "발행 설정 닫기" → 상단 "저장". 설정 창 안의 "발행" 버튼은 누르지 않는다.

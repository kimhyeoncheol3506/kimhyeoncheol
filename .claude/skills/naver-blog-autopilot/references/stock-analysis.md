# 주식분석: 급등주 분석 블로그

블로그 입력, 문체, 경험담, 유의 문구, 임시저장 방법은 `naver-finance-blog` 스킬(C:\Users\Admin\.aside\u\0\skills\naver-finance-blog\SKILL.md)을 그대로 따른다. 실행 전에 그 파일을 읽는다.
초안 폴더: C:\Users\Admin\Desktop\네이버블로그_초안\YYYY-MM-DD_종목명_급등분석.md (+ 그림 png)

## 1. 급등주 5개 엄선 (묻기 전 자동)
- 상승률 상위: openTab `https://stock.naver.com/market/stock/kr/stocklist/upper` → 3초 대기 → `table tbody tr` innerText로 읽기
  (열: 순위, 종목명, 현재가, 전일비, 등락률, 거래량, 거래대금(백만), 고가, 저가, 시가총액). 시장 탭(코스피/코스닥)을 각각 확인한다.
  장중이면 "현재 기준", 장 마감 후(15:30 이후)면 마감 기준이라고 밝힌다.
- 제외: 우선주(이름 끝 우, 우B, 2우B), 스팩, ETF/ETN, 거래대금 100억 원 미만, 관리종목·거래정지·투자경고 종목, 시총 300억 원 미만.
- 우선순위: 급등 이유가 공시나 기사로 확인되는 종목 > 거래대금 큰 종목 > 코스피·코스닥 섞기(가능하면 각 2개 이상).
- 후보마다 WebSearch로 급등 이유를 한 줄 확인한 뒤 ask_user_question 1개, 보기 정확히 5개:
  label "N. 종목명", description "시장 | +등락률 | 거래대금 | 급등 이유 한 줄".

## 2. 고른 종목 분석 (더 묻지 않고 끝까지)
### a. 급등 이유 (소스 찾기)
- 종목코드: `https://ac.stock.naver.com/ac?q=<종목명>&target=stock` (JSON items[0].code, typeName).
- 공시: DART 전자공시 `https://dart.fss.or.kr` 회사명 검색(최근 1주 공시: 단일판매·공급계약, 유상증자, 무상증자, 최대주주 변경, 실적, 임상 등). 필요하면 KIND도 확인.
- 뉴스: WebSearch로 당일 기사 2곳 이상 교차 확인. 테마성 급등이면 테마와 연관 근거를 분리해서 쓴다.
- 확인 안 되는 "카더라"는 쓰지 않는다. 이유가 불분명하면 "공시·뉴스로 확인된 재료 없음"이라고 쓴다.

### b. 추세추종 기술적 분석 (직접 계산)
- 일봉 데이터: `https://fchart.stock.naver.com/sise.nhn?symbol=<코드>&timeframe=day&count=250&requestType=0`
  `<item data="날짜|시가|고가|저가|종가|거래량">` 파싱 → REPL에서 계산.
- 아래 6개 체크를 모두 계산하고 표로 정리한다(통과 O / 미통과 X, 실제 수치 함께).
  1. **이동평균 정배열**: 종가 > 5일 > 20일 > 60일선, 20일선 기울기 상승(5일 전 대비).
  2. **신고가 돌파(돈치안)**: 종가가 직전 20일 최고가 돌파, 55일 최고가 돌파 여부도 표기.
  3. **거래량 확인**: 당일 거래량 / 20일 평균 거래량 배수 (3배 이상이면 O).
  4. **MACD(12,26,9)**: MACD > 시그널, 0선 위면 O.
  5. **ADX(14)**: 25 이상이면 추세 강함 O, 40 이상이면 과열 가능성 함께 언급.
  6. **이격도**: 종가/20일선. 120% 이상이면 "단기 과열" 경고(추세는 맞지만 추격 위험).
- 판정(이 기준으로 Aside가 정함):
  - 1~5 중 4개 이상 O → "추세 진행형 돌파"
  - 2·3 O, 1 X → "바닥권 첫 돌파(추세 초입 후보)"
  - 2 X, 3만 O → "재료성 단발 급등 가능성"
  - 6이 과열이면 판정 뒤에 "단기 과열" 덧붙임
- 관리 기준(매수 추천 아님, 추세추종 관점의 기준선으로만 표기):
  - 추세 이탈 기준: 20일선 종가 이탈, 또는 고점 대비 ATR(14)×2 하락(샹들리에 방식)
  - 눌림 확인 구간: 돌파한 직전 20일 고가 부근 지지 여부
- 상한가(+29.9% 이상)면 다음 날 갭·변동성 위험을 반드시 언급.

### c. 그림 (2~3장, 직접 캡처/제작)
- 종목 일봉 차트: `https://stock.naver.com/domestic/stock/<코드>/price`, 뷰포트 1800x950, 3개월 또는 6개월 → 전체 스크린샷 후 PowerShell System.Drawing으로 차트만 자르기(프로필 영역 제외).
- 공시가 재료면 DART 공시 화면의 핵심 표 부분 캡처(출처 표기).
- 기술적 체크리스트 표: 6개 체크 결과로 간단한 HTML 표를 만들어 tmp에 저장 → `python -m http.server`로 띄워 openTab → 스크린샷 → 이미지로 삽입.
- 뉴스 사진, 다른 블로그 이미지는 쓰지 않는다.

## 3. 글 구성 (1,800~2,500자, naver-finance-blog 문체)
- 제목: "종목명 +등락률% 급등, 이유와 차트로 본 추세" 식. 종목명을 맨 앞에, 32자 이내.
- 순서: 오늘 무슨 일(가격·거래대금) → 급등 이유(공시/뉴스, 출처) → 차트 그림 → 추세추종 체크 6개 표와 판정 → 경험담(있을 법한 직장인 시나리오, 실제 수치로 계산) → 이런 종목을 볼 때 내 원칙 2~3개(추격매수 금지, 분할, 이탈 기준) → 정리 → 유의 문구.
- 독자 도움: 다음에 급등주를 볼 때 바로 쓸 수 있는 체크 방법을 남긴다. 특정 매수/매도 권유, 목표가, 수익 보장 표현 금지.
- 태그 10개: 종목명, 종목명주가, 급등주, 상한가(해당 시), 재료 키워드, 기술적분석, 추세추종, 코스피/코스닥, 주식공부, 월급쟁이재테크.
- 끝에 출처 목록(공시명·날짜, 기사명·매체·날짜).

## 실전 메모 (2026-11-02 한진칼 실행에서 확인)
- 상승률 목록과 fchart/api 일봉은 KRX+NXT 통합 가격이다. 저녁에 보면 애프터마켓 종가가 들어가 있으므로 글에 정규장 종가(기사 확인)와 NXT 종가를 구분해 쓴다. 종목 페이지 '기준가'가 KRX 전일 종가.
- 일봉 대체 API: `https://api.stock.naver.com/chart/domestic/item/<코드>/day?startDateTime=YYYYMMDD0000&endDateTime=YYYYMMDD2359` (JSON).
- DART: `https://dart.fss.or.kr/dsab007/main.do?option=corp&textCrpNm=<회사명>` → "1개월" + "검색" → 표에서 `/dsaf001/main.do?rcpNo=...` 링크 → 본문은 url에 `viewer`가 들어간 프레임, 목차는 `#listTree a` 클릭.
- 체크리스트 표: openTab('about:blank') 후 `page.evaluate(h=>{document.open();document.write(h);document.close()})` 로 렌더 → `locator('#card').screenshot()` (setContent 없음).
- 새 글쓰기에서는 mainFrame이 2개 잡힐 수 있음: evaluate는 url에 `PostWriteForm` 있는 프레임을 쓰고, 조작은 frameLocator('#mainFrame').

## 4. 입력·검증
- naver-finance-blog의 "네이버 입력 방법"대로 제목 → 본문(클립보드 붙여넣기, `@@IMG1@@` 표시자) → 그림 → 태그 → 임시저장.
- 검증: 표시자 0개, 이미지 개수, 태그 10개, 자동저장 시각 확인 → 스크린샷으로 보고. 발행은 사용자가 직접.

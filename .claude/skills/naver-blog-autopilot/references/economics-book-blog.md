# 경제학 책 소개 블로그

트리거: 사용자가 **"경제학 책"**이라고 입력하면 처음부터 자동 실행.
스타일·입력 방법은 `seoul-realestate-blog` 스킬(C:\Users\Admin\.aside\u\0\skills\seoul-realestate-blog\SKILL.md) 3~5절을 그대로 따른다(인사말, 밑줄 인용구, 번호 소제목, 형광 강조, 한 줄 결론, HTML 클립보드 붙여넣기, 소제목 드래그+Ctrl+B, 인용구 삽입, 사진 표시자, 태그, 임시저장). 네이버 공통 방법은 `naver-finance-blog`. 실행 전 두 파일을 읽는다.
초안 폴더: C:\Users\Admin\Desktop\네이버블로그_초안\YYYY-MM-DD_책제목_책소개.md (+ 그림 png)
다룬 책 기록: 같은 폴더 `경제학책_기록.md` (없으면 생성). 날짜, 책 제목, 저자 한 줄씩 추가.

## 1. 최근 추천 경제학 도서 20권 모으기 (묻기 전 자동)
여러 곳을 섞어서 고른다. 한 서점 순위만 쓰지 않는다.
- 서점 베스트셀러: 예스24 경제경영 `https://www.yes24.com/product/category/bestseller?categoryNumber=001001025&pageNumber=1&pageSize=24` (fetch 후 `class="gd_name"` 파싱, 확인됨), 교보문고·알라딘 경제 분야는 openTab으로 읽기.
- 언론·기관 추천: WebSearch로 "이달의 경제 추천도서", "경제학 신간", "매경·한경 북 리뷰", "노벨경제학상 수상자 책 번역", "삼성·한은·KDI 추천도서" 등 최근 3개월.
- 거르기: **경제학 책 위주**(경제사, 거시·미시, 행동경제학, 화폐·금융 원리, 경제 사상, 국제경제, 불평등·성장). 순수 매매기법·종목추천·자기계발형 재테크 책은 최대 3권까지만. 이미 기록에 있는 책은 뺀다.
- 책마다 확인: 제목, 저자(번역서면 역자), 출판사, 출간 연월, 한 줄 소개, 추천 출처.

## 2. 고르기
- 먼저 채팅에 20권 표(번호, 제목, 저자, 출간, 한 줄 소개, 추천 출처)를 보여준다.
- 이어서 ask_user_question으로 고르게 한다. 보기는 20개(1~20, label "N. 제목", description "저자 | 한 줄 소개"). 도구가 20개를 받지 않으면 1~10, 11~20 두 질문으로 나눈다.
- 고르면 더 묻지 않고 끝까지 진행.

## 3. 자료 찾기 (책 내용은 공개 정보로만)
- 출판사 책 소개, 서점 상세페이지(책소개·목차·저자 소개), 언론 서평 2곳 이상, 저자 인터뷰·강연 기사.
- 책에 나오는 경제 개념·데이터는 원 출처(통계청·한은·IMF 등)로 다시 확인해서 쓴다.

## 4. 저작권 원칙 (반드시)
- 본문 문장을 길게 옮기지 않는다. 직접 인용은 글 전체에 최대 2곳, 각 1~2문장 이내, 따옴표와 "(책 OO쪽 / 책에서)" 표기.
- 줄거리·내용은 **내 말로 다시 정리한 요약**만. 장별 상세 요약을 이어 붙이지 않고, 목차는 장 제목 나열 정도만.
- 표지·본문 이미지, 출판사 홍보 이미지, 다른 블로그 사진은 쓰지 않는다. 그림은 직접 만든 카드·표·도식만.
- 결론·반전·핵심 사례 전부를 다 공개하지 않는다("책에서 직접 확인해 보시길" 식으로 남김).

## 5. 글 구성 (부동산글쓰기와 같은 흐름, 약 2,600~2,900자, 그림 6~8장)
- 맨 위 밑줄 인용구: 제목 반복.
- 인사: "안녕하십니까." / "매일 돈이 되는 재테크 소식 전해드리는 **월급쟁이 재테크 스킬**입니다."
- 도입: "오늘은 경제학 책 한 권 소개해볼까 합니다." → 왜 지금 이 책인지(최근 경제 뉴스와 연결) → 내 입장 한마디.
- 밑줄 인용구: "책 한 줄 요약 (핵심: ...)"
- **1. 책 기본 정보** (그림: 책 정보 카드 — 제목, 저자, 출판사, 출간, 분량, 분야, 추천 출처)
- **2. 핵심 내용** ①②③ (그림: 핵심 개념 3가지 카드 / 개념 도식)
- **3. 줄거리 맛보기** (저작권 안전 요약, 그림: 책의 흐름 타임라인 — 장 제목 수준)
- **4. 경제학적으로 유익한 포인트** ①②③: 개념 → 지금 한국 경제 뉴스·통계와 연결 → 직장인이 바로 써먹을 생각법·행동 (그림: "지금 우리 경제에 대입하면" 표)
- **5. 이런 분께 추천 / 아쉬운 점** (그림: 추천 대상 체크리스트)
- "한 줄 결론:" + 형광 강조
- 마무리 밑줄 인용구 두 줄 → 내 생각 → 다음 책 예고 + 댓글 유도 → "※ 책 내용 요약은 공개 자료와 필자 해석에 기반하며, 투자 권유가 아닙니다."
- 경험담: "출퇴근길에 읽으며 ~" 같은 있을 법한 독서 상황은 가능. 지어낸 수익·매매 내역은 금지.
- 제목: "책제목 줄거리·핵심 정리, 지금 읽어야 하는 이유?! 경제학 책 추천" 식.
- 태그 10개: 책제목, 저자, 경제학책, 경제학책추천, 경제책추천, 책리뷰, 서평, 핵심 개념 키워드 2개, 월급쟁이재테크.
- 끝에 출처(출판사 소개, 서평 기사·날짜, 통계 출처).

## 6. 입력·검증
- seoul-realestate-blog 5절 방식 그대로. 표시자 0개, 그림 수, 인용구 수, 소제목 굵게, 태그 10개, 자동저장 시각 확인 → 스크린샷 보고. 발행은 사용자가 직접.

# 서울 부동산 구별 블로그

네이버 입력·임시저장·사진·태그 방법은 `naver-finance-blog` 스킬(C:\Users\Admin\.aside\u\0\skills\naver-finance-blog\SKILL.md)을 따른다. 실행 전 읽는다.
초안 폴더: C:\Users\Admin\Desktop\네이버블로그_초안\YYYY-MM-DD_OO구_부동산.md (+ 그림 png)
다룬 구 기록: 같은 폴더 `부동산_구_기록.md` (없으면 만든다). 날짜, 구, 다룬 단지를 한 줄씩 추가.

트리거: 사용자가 **"부동산글쓰기"**라고 입력하면 아래를 처음부터 자동 실행한다.

## 0. 최신 트렌드 조사 (구를 묻기 전에 먼저, 최근 7일 중심)
네 갈래를 모두 본다. 하나만 보고 주제를 정하지 않는다.
1. **네이버 뉴스(최신순)**: `fetch('https://search.naver.com/search.naver?where=news&query=<검색어>&sort=1')` 또는 openTab 후 제목·언론사·시간 읽기. 검색어 예: 서울 아파트, 재건축, 재개발, 신고가, 분양, 전세, 토지거래허가.
2. **구글 뉴스 RSS**: `fetch('https://news.google.com/rss/search?q=<검색어> when:7d&hl=ko&gl=KR&ceid=KR:ko')` → `<title>`, `<pubDate>` 파싱(확인됨).
3. **정부·서울시 정책**: 국토교통부 보도자료(https://www.molit.go.kr/USR/NEWS/m_71/lst.jsp — fetch는 막힘, openTab으로 읽기), 정책브리핑 korea.kr, 서울시 보도자료·도시계획위원회 결과, 금융위(대출 규제)·기재부(세제) 발표. WebSearch로 "국토부 주택 공급 대책", "토지거래허가구역 지정", "대출 규제 스트레스 DSR", "보유세 세제개편" 등 보완.
4. **시장 통계**: 한국부동산원 주간 동향(목요일 발표), KB 월간, 아실 매물, 국토부 실거래.
- 정리: 이번 주 핵심 트렌드 3~5개(예: 강남3구 하락 확대, 강북 중저가 강세, 신규 정책, 대형 수주전)와 그 트렌드가 가장 잘 드러나는 구를 뽑는다. 정부 정책이 있으면 글에 반드시 한 섹션("정책 업데이트")으로 넣는다.

## 1. 구 고르기 (ask_user_question, 보기 정확히 10개)
- 0단계 트렌드가 가장 뜨거운 구 위주로 10개. 최근 기록(부동산_구_기록.md)에 있는 구는 큰 새 소식이 없으면 뺀다.
- 각 보기 description: "이번 주 화제 + 어느 출처(뉴스/정책/통계)" 한 줄. 질문 문구에 이번 주 핵심 트렌드를 짧게 보여준다.
- 고르면 더 묻지 않고 끝까지 진행.

## 2. 자료 찾기 (네이버 뉴스 최신순 + 구글 뉴스 RSS + WebSearch + 정부·구청 공고, 최근 1~2개월, 기사 2곳 이상 교차 확인)
- 고른 구 이름 + "재건축/재개발/신고가/시공사/통합심의/분양"으로 네이버 최신순·구글 RSS를 각각 검색해 일주일 안 새 소식을 먼저 찾는다. 최신 소식을 글 앞쪽에 둔다.
- 정부·서울시 정책 중 그 구에 영향 있는 것(토지거래허가, 재건축 규제, 공급 대책, 대출·세제)을 연결해서 설명한다.
- 시장 지표: 한국부동산원 주간 아파트가격 동향(최신 주, 서울 + 해당 구), KB 월간 동향, 아실 매물 수, 국토부 실거래(머스타드데이터·아파트리더 등 집계 사이트) 해당 구 월 거래 건수·평균가.
- 핫한 단지 3~5곳: 재건축(정비계획·공람·통합심의·관리처분·이주), 재개발(촉진구역·시공사 선정), 신고가 거래, 분양. 단지마다 세대수·층수·시공사·단계·다음 일정·최근 실거래.
- 출처는 언론사·날짜로 메모. 공식 공고(구청 공고 번호, 서울시 정보몽땅)는 있으면 우선.

## 3. 참고 글 스타일 (https://blog.naver.com/kinhazk2/224462307862 분석, 2026-11-02)
- 길이: 본문 약 2,600~2,900자, 컴포넌트 25~30개, 그림 7~13장.
- 맨 위: 제목과 같은 문구를 **인용구(밑줄형, quotation_underline)**로 한 번 더.
- 인사: "안녕하십니까." / "매일 돈이 되는 재테크 소식 전해드리는 **월급쟁이 재테크 스킬**입니다."(블로그명은 굵게+노란 형광).
- 도입: "오늘은/이번 주는 ~ 이야기를 해볼까 합니다." → 시장 분위기 → 내 입장 한마디("저는 ~론자는 아니고요") → 왜 이 글을 쓰는지.
- 문단: 한두 문장마다 빈 줄. 존댓말 "~입니다/~는데요/~거든요".
- 본문 섹션: 인용구(밑줄형)로 "2026년 N월 OO구 요약 (핵심: ...)" → 굵은 번호 소제목 "1. 지표 현황", "2. ...", 하위는 "① ② ③".
- 각 소제목 아래 그림 1장 → 숫자 위주 설명 3~5줄. 핵심 문장은 굵게+노란 형광, 경고성 포인트는 빨간 굵은 글씨(#ba0000).
- "한 줄 결론:" 다음 줄들에 형광 강조.
- 마무리: 인용구(밑줄형) 두 줄 메시지 → 내 생각 문단 → 다음 주 예고 + 댓글 유도 → "※ 정보 제공 목적, 투자 권유 아님, 일정·수치는 보도 기준이며 변경될 수 있음".
- 제목: "서울 OO구 ~ 지금 어디까지 왔나?! 단지A·단지B·단지C 총정리" 식, 물음표·느낌표 섞기.

## 4. 그림 (직접 제작, 뉴스 사진·다른 블로그 이미지 사용 금지)
- about:blank 탭에 HTML을 document.write로 렌더 → `scrollIntoView` 후 `locator('#id').screenshot()`.
- 기본 7장: ① 서울 구별 주간 변동 막대그래프 ② OO구 지표 카드(월 거래 건수·평균가·평당가·주간 변동 흐름) ③~⑥ 단지별 표/카드(기존 vs 변경, 구역별 단계, 최근 실거래) ⑦ 다가오는 일정 타임라인. 각 그림 하단에 "자료: 언론사(날짜) · 직접 정리".

## 5. 네이버 입력 (2026-11-02 검증)
- 본문은 HTML로 만들어 Windows PowerShell 5.1 `-STA`에서 CF_HTML(UTF-8 바이트 오프셋 헤더)을 직접 만들어 `Windows.Forms.DataObject`에 'HTML Format'(MemoryStream)+UnicodeText로 넣고 `Clipboard.SetDataObject` → 에디터에서 Ctrl+V. (`Set-Clipboard -AsHtml`은 한글이 깨짐)
- 붙여넣기 후 `<span>` 안의 `<b>`/형광/색은 유지되지만, 문단 전체를 감싼 `<b>`는 사라진다 → 소제목은 마우스 드래그 선택(scrollIntoView 후 sleep 400ms) + Ctrl+B로 굵게. 이미 `<b>`가 있으면 건너뛰기.
- 인용구: 표시 줄(@@Q1@@) 클릭 → End → 표시 글자 수만큼 Backspace → 툴바 `button.se-document-toolbar-select-option-button[data-name="quotation"]` → `button[data-value="quotation_underline"]` → insertText(줄바꿈은 Shift+Enter).
- 사진은 @@IMGn@@ 표시 자리에 naver-finance-blog 방식으로 삽입. 태그 10개 입력 후 임시저장, 표시자 0개·그림 수·인용구 수·태그 확인 후 스크린샷 보고. 발행은 사용자가 직접.

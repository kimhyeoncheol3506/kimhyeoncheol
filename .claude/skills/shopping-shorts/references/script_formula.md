# 구매 전환형 쇼핑 쇼츠 대본 공식 (25~35초)

| 순서 | 길이 | 역할 | 예 (무선 미니 고데기) |
|---|---|---|---|
| 1. 훅 | 2~3초 | 타깃이 겪는 장면을 질문으로. 제품 이름 먼저 말하지 않기 | "앞머리 무너진 채로 출근하세요?" |
| 2. 해결 제시 | 3~4초 | "이거 하나면" 으로 제품 등장 | "이제 파우치에 이거 하나만 넣고 다니세요." |
| 3~5. 특징 3개 | 장면당 3~5초 | 스펙을 **생활 장면의 이득**으로 바꿔 말하기 (무선 → 회사 화장실에서도) | "선 없는 무선이라 회사 화장실에서도 바로 써요." |
| 6. 증거 | 3~5초 | 페이지에 있는 숫자만: 상품평 수, "한 달 N명 구매", 별점 | "한 달 동안 이백 명 넘게 샀고, 상품평도 오백 개가 넘어요." |
| 7. 가격·혜택 | 3~5초 | 가격 배지 + 내일 도착/무료배송. 할인율은 정가가 페이지에 있을 때만 | "지금 이만 삼천팔백 원, 내일 바로 도착해요." |
| 8. 행동 | 2~3초 | 고정 댓글/설명란 링크로 | "최저가 링크는 고정 댓글에 있어요." |

## 잘 팔리는 쪽
- 문장은 짧게, 한 장면 한 메시지. 말 속도는 빠르게(초당 6~7음절).
- "여러분" 보다 "~하세요?" 처럼 바로 말 걸기.
- 자막은 말과 똑같이 쓰지 말고 핵심만 (말: "선 없는 무선 미니 고데기라 회사 화장실에서도 바로 써요" → 자막: "선 없는 *무선* / 어디서든 바로").
- 실제 사용 장면(사용자가 찍은 손·사용 영상)이 한 컷이라도 있으면 전환율이 크게 오름. 사진만 있을 땐 색상·디테일 컷을 번갈아.
- 같은 상품으로 훅만 다른 2개 버전을 만들어 반응 비교(문제형 / 가격충격형).

## 하지 말 것
- 과장 광고: "무조건", "최저가 보장", 의학적 효능, 확인 안 된 사용 시간.
- 허위 할인: 정가 근거 없는 할인율.
- 경쟁 상품 비하, 실존 인물·연예인 이름이나 얼굴.
- 남의 리뷰 사진·영상을 그대로 쓰기.

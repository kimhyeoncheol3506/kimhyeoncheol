# ComfyUI 연동 (ranking-video v2.12.0, 사용자 지시 2026-11-04 "스킬적용")

**무엇**: Comfy-Org/ComfyUI — 노드(그래프) 방식의 이미지·영상 생성 앱(GPL-3.0, 로컬 실행). 큰 기술 회사 서버가 아니라 내 PC에서 돌린다.
**왜 클라우드에서 직접 안 돌리나**: 클라우드 세션은 GPU가 없고(CPU 4개) 디스크 여유가 몇 GB뿐이라, 모델 하나(SDXL 약 7GB)도 올리기 어렵고 한 장에 수십 분이 걸린다. → Pavo·Digen과 같은 방식: **클로드가 워크플로(프롬프트)를 만들고, 사용자가 PC의 ComfyUI에서 실행 → 결과물을 영상 폴더에 넣는다.**

## 언제 쓰나
- 썸네일 배경(시장 분위기·회 한 상 등 — 실제 사진이 없거나 자유 이용 사진이 부족할 때)
- 챕터 타이틀 카드 배경, 분위기용 B롤 정지 이미지
- 쓰지 않는 곳: **사실을 증명하는 장면**(실제 시세, 실존 점포·인물·간판), 특정 가게처럼 보이게 만드는 이미지

## 순서
1. 대본이 끝나면 `09_소재/comfy_프롬프트.json`을 만든다: `[{"name": "썸네일_배경", "prompt": "영어 프롬프트"}, …]` — 글자·간판·로고·사람 얼굴이 나오지 않게 쓴다(기본 negative가 이것들을 막는다).
2. `python3 -I scripts/make_comfy_workflow.py 09_소재/comfy_프롬프트.json 09_소재/comfy_workflow [--ckpt 사용자모델.safetensors]`
3. 사용자: PC에서 ComfyUI(데스크톱 앱 또는 `python main.py`)를 켜고 JSON을 창에 끌어다 놓기 → Queue. 결과 PNG를 `09_소재/ai_img/`로 보낸다.
   - 사용자 PC가 Remote Control로 이 세션에 연결돼 있으면 `--submit http://127.0.0.1:8188`로 클로드가 바로 보낼 수 있다.
4. 썸네일은 `make_thumbnail_title.py --photo 09_소재/ai_img/썸네일_배경_00001_.png …`, B롤은 `09_소재/video/`·사진 칸에 넣는다.

## 지킬 것
- 설명란에 'AI로 만든 이미지 포함'을 적는다(`make_description.py`의 AI 고지와 같은 원칙). 실제처럼 보이는 합성물은 유튜브 업로드 때 '변경·합성 콘텐츠'로 표시.
- 모델 라이선스는 사용자가 확인: 상업 이용이 비교적 자유로운 예 — FLUX.1 [schnell](Apache-2.0), SDXL base(CreativeML Open RAIL++-M, 사용 제한 조항 있음). 다른 사람이 만든 LoRA·체크포인트는 각자 약관 확인.
- 실존 인물 얼굴, 다른 채널 썸네일 모방, 특정 가게 간판·상호 재현은 만들지 않는다.

## 이 카드에서 바로 가져온 개선 (v2.10.0)
- `scripts/check_script.py`: 음성 만들기 전 대본 점검('그' 시작·카드 위치 문구 오타·어미 반복·군더더기·숫자 밀도·내 관점·숫자 출처).
- `verify_video.py`에 멈춘 화면(정지 프레임) 점검 추가.
- `scripts/ledger.py` + `video_projects/발행_원장.jsonl`(제작 완료 6건, 업로드 1건 시드).
- `.agents/skills/ranking-video` 연결로 Codex와 스킬 공유.

## 하지 않는 것
- 카드에 나온 서비스 중 클로드가 로그인·결제·계정 작업이 필요한 것(Aside, AutoKliq, Suno, PVC)은 대신 쓰지 않는다. 필요하면 사용자가 만든 결과물을 받아서 쓴다.
- 이 카드는 다른 제작자의 환경이다. 거기 적힌 경로·규칙 개수(146개)·설치 스킬 수는 우리와 무관하다.

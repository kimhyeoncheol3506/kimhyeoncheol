## 03_B롤_샷리스트/B롤_샷리스트.md
- 머리말: 검색할 곳(캡컷 라이브러리, Pexels, Pixabay). 영어 검색어 우선. **간판·상호가 보이는 화면 금지**
- 공통 편집 규칙 표: 훅은 클로즈업과 줌인 / 소개는 전경과 숫자 카운트업 / 묘사는 슬로모션 0.5x와 ASMR / 꿀팁은 하단 라벨 바 / 맺음은 다음 순위 티저
- 섹션마다(인트로, N개 순위, 아웃트로):
  - `## N위 이름 (mm:ss~mm:ss)`
  - 무료 스톡 검색어 5개(실제 촬영 없이 커버할 수 있는 일반 검색어)
  - 숫자나 특징을 살리는 그래픽 1개(카운트업, 막대그래프, 아이콘 등)
  - **전환 지점**: 기본은 웜 슬라이드. 3위→2위는 암전과 기준 전환 자막, 2위→1위는 암전 1초와 쿠궁 2회, 1위→아웃트로는 페이드 화이트
- 썸네일용 정지 이미지 검색어

## 04_음악_효과음/음악_효과음_가이드.md
- BGM 3곡 표: 쓰는 구간 / 캡컷 검색어 / 고르는 기준(BPM·악기·보컬 유무) / 볼륨(dB)
  - BGM1: 업비트 한국 힙합. 인트로, 1위 공개, 아웃트로
  - BGM2: 어반 재즈·로파이. 하위 순위 구간
  - BGM3: 시티팝·재지 힙합. 상위 순위 구간
- 대안: YouTube 오디오 보관함. 자동 덕킹 켜기
- 효과음 5종 표: 물방울, 칼 소리, 갈매기, 코인, 쿠궁 → 캡컷 검색어 / 대본 사용 위치 / 볼륨

## 05_메타데이터/
### 제목_후보 3개.txt
- 60자 이내. ① 인트로 반전 훅과 같은 질문형(추천) ② 검색 키워드를 앞에 둔 유형 ③ 사용자 원제
- 근거 없는 수치에는 경고를 붙인다

### 설명란.txt
1. 훅 1줄과 요약 2~3줄
2. 📌 순위 기준
3. ⏱ 타임스탬프. 반드시 `00:00`부터 시작(챕터 생성 조건)
4. 💬 댓글 유도, 🔔 구독
5. ⚠️ 면책: 사용자 지정 문구 그대로 + 방문 전 확인 + 협찬 여부 + 스톡 영상 안내
6. 해시태그 10개

### 썸네일_가이드.txt
- 1280×720. 문구 후보 2개(7~10자, 2줄 이하, 핵심 단어 노란색)
- 구도를 ASCII 그림으로: 메인 피사체 60% + 인물 표정 40% + TOP N 배지 + 화살표. 오른쪽 아래 15%는 비움
- 주의: 본편에 없는 메뉴를 특정 가게와 연결 금지, 초상권, 매장 사진 허락

## 06_체크리스트/내보내기_및_업로드_체크리스트.md
1. 내보내기 표: 1080p(4K 원본이면 4K) / 16:9 / 30fps / H.264 / MP4 / AAC 48kHz / -14 LUFS
2. 러닝타임 맞추기: TTS 0.9x, 여백, 전환 카드, 엔드스크린. 길이를 바꾸면 SRT 다시 맞추기
3. 업로드 전 체크
   - 사실 검증: 표 숫자 대조, 현재 리뷰 수 재확인, 영업 여부, 표 밖 정보 확인, 민감한 표현, 순위 기준 언급, 면책 3곳
   - 저작권: BGM 상업적 이용 표시, 스톡 출처 기록, 간판·얼굴, 썸네일 인물, 유료 프로모션
   - 업로드 설정: 제목, 설명란(실제 시간으로 수정), SRT, 썸네일, 재생목록, 카테고리, 아동용 아님, 엔드스크린, 공개 시간
4. 고정댓글 템플릿: 순위 목록 + pick 댓글 유도 + 면책 문구

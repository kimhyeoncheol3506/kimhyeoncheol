## 2. 캡컷 설정값 (1080p 기준)
- **기본 자막**: 프리셋 없이 [텍스트] → 글꼴 Pretendard Bold(없으면 캡컷 "노토 산스 KR Bold"), 크기 7~8, 흰색 / [배경] 검정, 불투명도 60%, 모서리 둥글게 / 위치 Y = -780 부근(하단 중앙)
- **강조 자막**: Pretendard ExtraBold, 크기 13~15, 흰색, [윤곽선] 검정 두께 30~40, 화면 하단 1/3 / 등장 애니메이션은 "팝" 0.2초 하나만
- **초록 자막**: 기본 자막과 같고 글자색만 `#19C37D`. 꿀팁 문장에만 사용
- **챕터 카드**: 2초, 앞뒤 전환은 "디졸브" 0.3초 또는 그냥 컷. 줌·흔들기 효과 금지
- **상단 라벨·순위 배지**: 오버레이 트랙에 PNG를 놓고 섹션 길이만큼 늘리기. 애니메이션 없음
- **정보 카드**: 3~4초. 등장은 "페이드 인" 0.2초
- **B롤**: 컷 길이 3~5초(참고 영상의 화면 교체 간격이 약 4~5초). 슬로모션은 묘사 구간에서만 0.7x
- **색 보정**: 필터 없음 또는 "자연" 계열 20% 이하. 채도는 음식 컷만 +10
- **전환**: 섹션 사이는 챕터 카드로 구분하므로 별도 전환 효과 없음. 웜 슬라이드, 플래시, 흔들기 등은 쓰지 않음

## 3. 소리 (추정 기반 권장)
- 참고 영상은 진행자 목소리가 중심이고, 자막에서 확인되는 음악 표시는 끝부분 "[음악]" 하나뿐이다.
- 깔끔한 인상을 위해 **BGM은 1곡을 낮게(-22dB) 깔고, 효과음은 세그먼트당 1~2개**(칼 소리 또는 물방울)로 줄인다. 쿠궁은 인트로 첫 컷과 1위 공개에만 쓴다.

## 4. 대본·구성에 미치는 영향
- 자막이 한 줄이므로 대본 문장은 **20자 안팎**을 유지한다(빌더가 쉼표·마침표에서 자동으로 나눔).
- "오늘의 요약"은 순위를 1위부터 한 번 더 부르는 구성이 요약 카드 애니메이션과 잘 맞는다.

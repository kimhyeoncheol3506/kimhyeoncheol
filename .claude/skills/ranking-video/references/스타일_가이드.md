> 사용자가 원하는 "아주 깔끔한" 스타일의 참고 영상: https://youtu.be/1V27x7n4g78
> 아직 분석하지 못했습니다(클라우드 환경에서 YouTube 접근이 차단됨). 분석하면 이 파일을 다시 쓰고 v1.1.0으로 올립니다.
> 분석 전까지 아래 기본값은 "깔끔함" 쪽으로 보수적으로 잡았습니다. 참고 영상과 다를 수 있습니다.

## 분석할 때 기록할 항목 (v1.1.0 작업용 체크리스트)
- [ ] 자막: 폰트, 크기, 위치(하단/중앙), 색, 외곽선·그림자·박스 유무, 한 줄 글자 수
- [ ] 순위 표시: 숫자 카드 디자인, 화면에 머무는 시간, 등장 애니메이션
- [ ] 컷 속도: 평균 컷 길이(초), 훅 구간과 설명 구간의 차이
- [ ] 전환: 종류(컷/디졸브/슬라이드), 사용 빈도
- [ ] 색감: 필터와 LUT, 채도, 밝기
- [ ] 정보 그래픽: 숫자 강조 방식, 아이콘, 지도
- [ ] 소리: BGM 장르와 볼륨, 효과음 사용량, 내레이션 속도
- [ ] 인트로·아웃트로 길이와 구성
- [ ] 썸네일 레이아웃과 문구 스타일

## 기본 스타일 (임시)
| 항목 | 기본값 |
|---|---|
| 자막 | 하단 중앙, 흰색 굵은 고딕, 얇은 검은 외곽선(2px), 한 줄 22자 이내, 2줄까지 |
| 강조 자막 | 숫자와 핵심어만 노란색(#FFD400). 한 화면에 강조 1개 |

| 컷 길이 | 훅·묘사 1.5~2.5초, 소개 3~4초 |

| 색감 | 채도 +10 이하, 선명도 +10 이하 |
| 효과음 | 기본 5종만, 세그먼트당 2~3회 이내 |
| 화면 정보 | 숫자 카운트업, 간단한 막대그래프. 장식 스티커는 쓰지 않음 |

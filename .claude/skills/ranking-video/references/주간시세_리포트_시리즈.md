# 고정 시리즈: "이번 주 노량진 뭐가 싸? 주간 시세 리포트" (ranking-video v2.4.0)

매주 1회, 약 9분짜리 롱폼. **틀은 고정, 숫자·품목·사진만 매주 바뀐다.** 사용자가 "이번 주 시세 리포트 만들어" 또는 정기 실행(Routine)으로 부르면 이 문서대로 끝까지 만든다.

## 1. 일정과 회차
- 집계 기간: **월요일~일요일 7일**(일요일 경매가 없으면 토요일까지). 비교 대상은 바로 앞 7일.
- 제작: 일요일 아침에 시작(경락 데이터는 당일 밤에 올라오므로 일요일 오전엔 토요일까지가 확정). 업로드 권장: 일요일 저녁 또는 월요일 아침.
- 회차 번호: `video_projects/주간시세_리포트/회차.json`의 마지막 번호 + 1. 폴더는 `video_projects/주간시세_리포트/<회차:02d>_<끝날짜YYYYMMDD>/`.

## 2. 데이터 (사실의 근거 — 지어내지 않는다)
1. `scripts/noryangjin_prices.py fetch video_projects/주간시세_리포트/data <지난주 월> <이번 주 일>` (하루 약 1.5분, 이미 받은 날은 건너뜀)
2. `scripts/noryangjin_prices.py week video_projects/주간시세_리포트/data <이번 주 끝날짜>` → `주간비교_YYYYMMDD.csv/.md`
3. 고르는 기준:
   - **싸진 품목 TOP5**: 변동률이 가장 많이 내린 순. 단, 이번 주 수량이 충분하고(기본 20 이상, 대표 품목은 50 이상 권장) 2일 이상 거래된 것. 같은 품목이 규격만 달리 여러 줄이면 수량이 가장 큰 줄 하나만 쓴다.
   - 일반 소비자가 노량진에서 실제로 사는 품목을 우선(회·조개·게·새우·제철 생선). 잡어·가공용(H/G, 냉동 덩어리 등)은 뺀다.
   - **주의! 오른 품목 3개**: 같은 기준으로 가장 많이 오른 것.
   - **한눈에 카드**(`graphics.movers`): 내린 5 + 오른 3을 막대로.
4. 대본에 쓰는 숫자는 모두 이 표에서 나온 것만. **경락가 = 도매 경매 낙찰가**라서 소매가(가게 판매가)와 다르다는 말을 인트로와 아웃트로에 매번 넣는다. "가게에서 이 가격에 산다"고 말하지 않는다. 변동 방향과 비율("지난주보다 ○○% 내렸다")을 중심으로 말한다.
5. 품목 설명(제철·먹는 법·고르는 법)은 네이버 블로그 최근 3개월(`naver_blog_research.py`)과 기사로 확인한 것만. 원인(입하량, 날씨 등)은 출처가 있을 때만 말하고, 없으면 "경매 물량에 따라 달라질 수 있다" 정도로 둔다.

## 3. 영상 구성 (고정, 약 9분 · 대본 3,600~3,900자 · 여의도남자 1.12배)
| 순서 | 섹션 | 내용 | 길이 |
|---|---|---|---|
| 0 | 인트로 | 훅: "이번 주 노량진, ○○가 지난주보다 ○○% 내렸습니다" → 기간·출처(노량진수산 경락시세, 도매가) → 오늘 볼 것(싸진 TOP5, 오른 것 주의, 장바구니) → "오위부터" | 30초 |
| 1 | chapter "한눈에" | 비교 품목 수, 내린 품목 수 vs 오른 품목 수, 막대 카드, 이번 주 특징 1~2개 | 50초 |
| 2~6 | 싸진 품목 5위→1위 | 품목 소개(제철·맛) + 정보 카드(`trend: "down"`, big "▼ ○○%", caption "지난주 ○○원 → 이번 주 ○○원 (kg당 경락 평균)") + 고르는 법/먹는 법 꿀팁 + 다음 예고 | 각 55초 |
| 7 | chapter "주의! 오른 품목" | 3개를 빠르게, 정보 카드(`trend: "up"`) 1장, 대신 살 만한 것 | 60초 |
| 8 | chapter "이번 주 장바구니" | 싸진 품목 + 제철로 짠 추천 조합 2가지(예: 둘이서 회 한 상 / 가족 찜 한 상). 가격은 말하지 않거나 경락가 기준임을 밝힘 | 50초 |
| 9 | 아웃트로 | 요약 카드(5위까지) → 다음 주 예고 → "도매가라 가게 값은 다를 수 있다" → 구독 | 40초 |

- 상단 라벨·순위 배지·타이틀 카드·자막 크기·BGM은 기존 롱폼과 같다.
- `graphics.recap_regex`: `^(일위|사위)` (예: "일위 ○○, 이위 ○○, 삼위 ○○." / "사위 ○○, 오위 ○○.")

## 4. 썸네일 (시리즈 고정 틀 = E. 주간 시세 리포트형, `thumbnail_weekly`)
- 시리즈는 **같은 틀을 매주 유지**해야 구독자가 알아본다(일반 영상의 "매번 다른 컨셉" 규칙의 예외). 매주 바뀌는 것: 사진, 품목명, 변동률, 회차, 기간.
- 구성: 왼쪽 위 초록 회차 배지("주간 시세 #1") · 오른쪽 위 흰 기간 칩("10/12~10/18") · 아주 큰 흰 품목명 · 그 아래 아주 큰 파랑 "▼○○%"(오른 품목을 내세울 땐 빨강 ▲) · 하단 남색 띠 노란 글씨 "이번 주 노량진 뭐가 싸?"
- 1위 품목 사진을 쓴다(없으면 시장 사진).

## 5. 설명란·제목
- 제목 틀: `이번 주 노량진 뭐가 싸? ○○ ○○%↓ | 주간 시세 리포트 #N (MM/DD~MM/DD)`
- 설명란: 바로가기 시간 + "자료: 노량진수산주식회사 오늘의 경락시세(도매 경매가, 수량 가중 평균). 가게 판매가는 다를 수 있습니다." + 해시태그 3개 고정 `#노량진수산시장 #수산물시세 #주간시세`
- 고정댓글: 이번 주 TOP5 + 지난주 대비 표 링크 대신 표 요약 3줄 + 사진 출처.

## 6. 결과물과 기록
- 회차 폴더 안: 기존 롱폼과 같은 폴더 구조(01_대본 … 08_완성영상) + `주간비교_YYYYMMDD.md`(그 주의 근거 표 사본).
- `회차.json`에 `{회차, 기간, 1위 품목, 변동률, 영상 길이}`를 덧붙인다.
- 완성되면 720p 전달본·썸네일·설명란을 사용자에게 보내고, 작업 브랜치에 커밋·푸시한다.

## 7. 새 세션에서 한 회 만들기 (정기 실행 순서, 약 3시간)
작업 브랜치: `video/noryangjin-top10` (스킬과 이전 회차가 여기에 있다). 먼저 `git fetch origin video/noryangjin-top10 && git checkout video/noryangjin-top10`.
1. **준비(10~15분)**: `bash .claude/skills/ranking-video/voice/setup_cloud.sh` (여의도남자는 Base 모델만 필요). 폰트는 make_graphics가 자동으로 받는다.
2. **데이터(약 25분)**: 이번 주 월요일=M, 일요일=E, 지난주 월요일=M0 →
   `python3 -I .claude/skills/ranking-video/scripts/noryangjin_prices.py fetch video_projects/주간시세_리포트/data M0 E`
   `python3 -I .claude/skills/ranking-video/scripts/noryangjin_prices.py items video_projects/주간시세_리포트/data E`
3. **고르기**: `주간품목비교_E.md`에서 2장 기준으로 싸진 TOP5·오른 3을 고른다. 범위(최저~최고)가 100원~수만 원처럼 비정상적으로 넓고 수량이 적은 줄, 잡어·가공품은 뺀다. 숭어류처럼 이름이 헷갈리는 품목은 출처로 확인되지 않으면 쓰지 않는다.
4. **조사**: 고른 품목 중 이전 회차·다른 프로젝트 `조사표.md`에 없는 것만 `naver_blog_research.py`로 최근 3개월 블로그를 확인한다.
5. **대본**: 직전 회차 `01_대본/대본데이터.json`을 복사해 숫자·품목·문장만 바꾼다(섹션 구조, recap_regex, info_cards 형식, movers_items, thumbnail_weekly 유지). 회차 번호·기간·badge·dates를 바꾼다. 숫자는 한글로 쓰고 `display_map`을 맞춘다(긴 표현부터 치환됨). '그'로 여는 문장 금지. 3,500~3,900자.
6. **사진**: 이전 프로젝트들의 검수된 사진(`video_projects/*/09_소재/img/meta.json`)을 먼저 재사용하고, 없는 품목만 `fetch_images.py`로 받아 검수한다(얼굴·글자·워터마크 제외). 모든 사진 `own_only`.
7. **그래픽**: `make_graphics.py <json> <회차폴더> --img <회차폴더>/09_소재/img` → 타이틀 카드·막대 카드·시세 카드·`썸네일_주간시세.png`를 열어 확인.
8. **음성(약 90분)**: `make_voice_yeouido.py <json> <tts> --voice 여의도남자 --speed 1.12` → `check_tts.py`로 검수 → 0.85 미만 중 진짜 오류만 문장을 고쳐 `--only`로 다시 만든다(2시간 실행 한도가 있으면 나눠서 이어 만든다. 이미 만든 문장은 건너뛴다).
9. **렌더링(약 20분)**: `render_video.py … --jobs 4` → `blackdetect`로 엔드카드 외 검은 화면이 없는지, 영상·소리 길이가 같은지 확인.
10. **메타데이터**: `make_credits.py` → `make_description.py` → 설명란의 'AI 음성'을 'AI 음성(여의도남자)'로, 제목 후보 3개(5장 틀), `회차.json` 갱신.
11. **전달**: 720p 전달본·썸네일·설명란을 사용자에게 보내고 커밋·푸시. 실패하거나 데이터가 이상하면(경매 결과가 거의 없음 등) 만들지 말고 이유를 알린다.

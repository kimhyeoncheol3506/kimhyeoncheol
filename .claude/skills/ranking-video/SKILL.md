# ranking-video v2.6.0 — 주제 한 줄로 랭킹 영상 한 세트

> 버전 규칙과 변경 이력: `CHANGELOG.md`. 고칠 때마다 frontmatter의 `version`·`updated`, 이 제목 줄, CHANGELOG를 함께 올린다.
> 완성 예시(기준 품질): `video_projects/노량진_TOP10/` + `examples/노량진_TOP10.json` — 이 수준이 최소 기준이다.

너는 유튜브 PD, 작가, 편집자, 썸네일 디자이너를 겸한다. 사용자는 **주제와 간단한 줄거리만** 준다. 나머지는 이 문서대로 끝까지 만든다.

## 고정 시리즈: 주간 시세 리포트 (v2.4.0)
"이번 주 시세 리포트", "주간 시세", "이번 주 노량진 뭐가 싸?" 요청이나 정기 실행이면 **`references/주간시세_리포트_시리즈.md`를 먼저 읽고 그대로 따른다**(데이터 수집 → 품목 고르기 → 고정 구성 → 시리즈 고정 썸네일 → 회차 기록). 데이터는 `scripts/noryangjin_prices.py`(노량진수산 오늘의 경락시세)에서만 가져오고, 도매가임을 매번 밝힌다. 회차 폴더: `video_projects/주간시세_리포트/<회차>_<끝날짜>/`.

## 0. 입력과 기본값
| 항목 | 사용자가 주면 | 안 주면 (기본값) |
|---|---|---|
| 주제 | 필수 | — |
| 줄거리·구성 | 그대로 따름 | TOP10 카운트다운(10위 → 1위). 정보형 주제(감별법, 비교, 수율 등)는 **챕터 섹션 2~3개 + TOP5~6 카운트다운**으로 짠다(섹션에 `"chapter": "PART 1"`, `card_name`을 주면 순위 없이 사진 타이틀 카드가 나온다) |
| 순위 데이터 표 | 그대로 사용(사실을 바꾸지 않음) | **직접 조사**(1단계). 출처 없는 숫자는 쓰지 않음 |
| 길이 | 맞춤 | 약 9분(대본 3,600~3,900자, 여의도남자 1.12배 기준 3,885자 = 9분 8초). 사용자 기준: 지난 롱폼과 같은 길이·자막 크기·더빙 |
| 목소리 | 맞춤 | **여의도남자**(클라우드에서 Qwen3-TTS로 직접 생성, 초당 약 6음절에 맞춰 속도 조절). 여자 목소리 요청 시 여의도여자 |
| 면책 문구 | 토씨 하나 바꾸지 않고 삽입 | 데이터 성격에 맞춰 1문장 작성 |
| 채널명 | 엔드카드·배지에 사용 | "채널명"으로 두고 보고 때 요청 |

사용자가 "묻지 말고 진행"을 원하는 스타일이므로 **질문 없이 끝까지 진행**하고, 가정한 부분은 마지막 보고에 모아 밝힌다. 단, 순위 데이터를 조사할 수 없으면 지어내지 말고 멈춰서 알린다.

## 1. 단계별 실행 (각 단계가 끝나면 1줄 보고)
작업 폴더: `video_projects/<주제>_TOP<N>/` · 스크립트: `.claude/skills/ranking-video/scripts/` · 임시 파일: 스크래치패드

1. **자료 조사**(데이터 표가 없을 때) — **네이버 블로그 우선, 최근 3개월, 잘 쓴 블로거 위주**:
   - `naver_blog_research.py <폴더>/01_대본 "검색어1" "검색어2" … --months 3 --max 30`을 실행한다. 네이버 블로그를 최근 3개월로 걸러(`nso=so:r,p:3m`) 글마다 점수를 매긴다. 점수 기준은 본문 길이, 사진 수, 소제목·번호 구성, 최신성, 광고·협찬 표시 없음이고, 주제 관련도를 곱한다. 결과는 `블로그조사.tsv`와 `블로그_발췌/`에 남는다.
   - **점수는 참고용이다.** 상위 글을 직접 읽고, 주제와 맞고 직접 가서 겪은 내용이 구체적인 글(사진과 가격·위치·메뉴 같은 세부 정보가 있는 글)만 고른다. 광고·협찬·체험단 표시가 있는 글은 사실 확인용으로만 쓰고 평가나 순위 근거로 쓰지 않는다.
   - 숫자(리뷰 수, 시세, 선정 이력, 연도)는 **블로그 2곳 이상 또는 공식·언론 출처 1곳**으로 교차 확인한다. 확인이 안 되면 대본에서 빼거나 "~로 알려져 있습니다"로 처리한다.
   - 블로그 문장을 그대로 옮기지 않는다. 사실만 가져와 새로 쓴다(표절 금지). 참고한 글의 URL은 `01_대본/조사표.md`에 남긴다.
   - 순위 기준(검색 노출, 리뷰 수, 이달의 수산물 선정 등)을 정하고, 기준이 섞이면 대본에서 1회 밝힌다. 민감한 내용(가격 논란 등)은 단정하지 않는다. 공식 자료(해양수산부, 지자체, 언론)는 WebSearch로 보완한다.
2. **대본 JSON**: `01_대본/대본데이터.json`을 `examples/노량진_TOP10.json` 형식으로 쓴다(4·5장 규칙). 섹션마다 `rank`·`label`·`card_title`·`tagline`·`title_image`를 넣고, `graphics`(info_cards, summary, thumbnail_bold), `upload`(hook, summary, hashtags 3개, disclaimer), `voice`, `display_map`도 채운다.
3. **대본 빌드**: `build_script.py <json> <폴더>` → 전체대본, 캡컷 분할(100자 이내), SRT.
4. **이미지**: 섹션별 영어 검색어 5~7개를 `검색어.json`({섹션명: [...]})으로 만들어 `fetch_images.py <img폴더> 검색어.json`을 실행한다. Openverse에서 CC0·CC BY·퍼블릭도메인만 받는다(약 20분, 백그라운드). 받은 뒤 contact sheet로 **한 장씩 직접 검수**한다.
   - 빼야 할 사진: 사람 얼굴이 크게 나온 사진, 간판·상호·가격표·상품 포장, 워터마크·글자, 주제와 무관한 사진(수중 사진, 흑백, 다른 음식, 그림·도감)
   - 쓸 만한 사진이 3장 미만인 섹션은 검색어를 바꿔 다시 받는다(예: 낙지 → `octopus sashimi`, `sannakji`).
   - **모든 사진에 `own_only`를 붙인다.** 순위마다 그 품목 사진만 나오게 하고, 다른 순위 사진을 빌려오지 않는다(사진이 모자라면 같은 사진을 다른 방향의 팬으로 반복).
   - 섹션 첫 장면은 `first`, 순위마다 가장 좋은 사진 1장은 `title_image`로 지정한다.
5. **그래픽**: `make_graphics.py <json> <폴더> --img <이미지폴더>` → 챕터 카드, 상단 라벨, 순위 배지, 정보 카드, 요약 카드, 엔드카드, **순위 타이틀 카드**, **임팩트 썸네일**. 결과 PNG를 직접 열어 글자 넘침을 확인한다.
6. **음성·소리** — 기본은 **여의도남자**(사용자 고정 목소리). PC 없이 클라우드에서 바로 만든다:
   - 준비(새 세션에서 1회, 10~15분): `bash .claude/skills/ranking-video/voice/setup_cloud.sh` → `~/.cache/shorts-tts/venv`(torch CPU + qwen-tts) + 모델(`Qwen/Qwen3-TTS-12Hz-1.7B-Base`, 여자 목소리는 `-CustomVoice`도 필요)
   - 생성: `~/.cache/shorts-tts/venv/bin/python .claude/skills/ranking-video/voice/make_voice_yeouido.py <json> <tts폴더> [--voice 여의도남자|여의도여자] [--speed 1.1]` → `00_00.wav` 형식. 여의도남자는 `voice/assets/여의도남자_기준음성.wav`를 복제해서 PC Voicebox와 같은 목소리가 난다(연애 쇼츠 스튜디오와 같은 방식).
   - 문장마다 예상 길이를 벗어나면(폭주·누락) 시드를 바꿔 다시 만든다. 대본은 `voice/pronounce.py`로 읽는 글로 바꿔 넣는다(숫자·약어 교정, `voice/lexicon.json`에 대체어 누적).
   - **사용자가 지적한 발음은 영구 규칙이다.** 지적을 받으면 그 영상만 고치지 말고 `voice/lexicon.json`(낱말) 또는 `voice/pronounce.py`(규칙)에 넣어, 이후 모든 영상에서 같은 발음으로 읽게 한다. 자막은 표준 맞춤법 그대로 두고 TTS 입력만 바꾼다. 지금까지 누적된 것:
     - `열 가지` → [열까지]
     - ㄹ받침 뒤 `-게(요)` → [께(요)]: 드릴게요→드릴께요, 이어 갈게요→이어 갈께요, 볼게요→볼께요 (`l_gettsu()`)
     - `그 이야기는`, `그럼`처럼 '그'가 짧게 문장을 여는 말은 여의도남자가 [그그]·[흐름]으로 더듬는 일이 있다 → 대본에서 '자세한 이야기는', '자,'처럼 다른 말로 시작한다
     - `사잇살`·`꼬릿살`(사이시옷 낱말) → [사이쌀]·[꼬리쌀]로 소리 나는 대로 넣는다(lexicon)
     - `깻잎` → [깬닙] (lexicon). 숫자 '이만 오백'처럼 '이만+짧은 수'는 [이천오백]으로 들리기 쉬우니 '이만 원대'처럼 말하고 정확한 값은 카드에 둔다
   - **여의도여자**: `--voice 여의도여자 --speed 1.2`(기본 속도에서 초당 약 4.5~5음절이라 1.2배). CustomVoice 모델이 따로 필요하다(약 4GB). 두 목소리 모델을 동시에 돌리면 메모리(약 7GB씩)가 모자라니 하나씩 돌린다
   - 속도: 생성 후 초당 음절을 재서 6음절 안팎이 되도록 `--speed`(atempo)를 정한다.
   - 대안: 사용자 PC가 연결된 세션이면 `yeouido-voice` 스킬(Voicebox), 둘 다 안 되면 Edge TTS 현수(`make_tts.py`).
   - 효과음과 BGM은 `make_audio_assets.py`로 만든다.
   - **발음 검수(필수)**: `check_tts.py <json> <tts폴더>`(faster-whisper)로 음성을 다시 받아 적어 대본과 비교한다. 유사도 0.85 미만인 문장은 직접 읽고 고친다(외래어·숫자·약어를 풀어 쓰거나, 쉼표와 띄어쓰기 조정). 고친 문장만 다시 만들고 다시 검수한다.
   - **대본 말투**: 한국인 내레이터가 실제로 말하듯 쓴다. "~입니다"만 이어지지 않게 "~죠/~거든요/~예요/~고요"를 섞고, 속담이나 생활 표현으로 훅을 건다. 숫자와 월은 TTS가 틀리기 쉬우니 한글로 쓴다(10월 → 시월, 6월 → 유월, 2019년 → 이천십구년).
7. **샘플 렌더링**: `render_video.py … --until 175`로 앞 3분을 만들어 사용자에게 먼저 보낸다(약 2분 소요). 사용자가 처음부터 "전부 만들어"라고 했으면 이 단계를 건너뛴다.
8. **전체 렌더링**: `render_video.py <json> <폴더> --tts … --img … --sfx … --work <임시> --jobs 4`. 1080p 원본과 **30MB 이하 720p 전달본**이 자동으로 생긴다. 끝나면 프레임 타일(`fps=1/8, tile`)로 전체를 훑어 사진과 장면이 어긋난 곳을 고치고, 영상·오디오 길이가 같은지 확인한다.
9. **메타데이터**: `make_credits.py <이미지폴더> <폴더>` → `make_description.py <json> <폴더>` → `설명란_업로드용.txt`(순위별 바로가기 시간 + 해시태그 3개), `고정댓글.txt`(순위 목록 + 이미지 출처). 제목 후보 3개는 `05_메타데이터/제목_후보 3개.txt`에 쓴다.
10. **전달과 저장**: 720p 전달본, 썸네일, 설명란은 SendUserFile로 보낸다(30MB 초과는 보낼 수 없음). MP4는 git에서 제외되어 있다. 나머지는 커밋해서 작업 브랜치에 푸시한다(main 직접 푸시 금지).

## 3. 영상 구성 (v1.3 피드백이 반영된 기본값)
- **인트로(약 30초)**: 반전 훅(데이터에서 가장 의외인 사실, 0~3초 큰 강조 자막과 쿠궁) → 목적 약속("어디 갈지, 뭘 시킬지, 여기서 끝납니다") → 하이라이트 예고 3개 → 오픈 루프("꿀팁은 끝에 있으니 놓치지 마세요") → "십위부터 바로 갑니다". **장소의 역사나 일반 설명은 넣지 않는다**(지루하다는 피드백).

## 4. 화면·소리 스타일 (클린 미니멀 + v1.3)
- **색**: 흰색, 검정, 초록 #19C37D. 흔들기, 플래시, 웜 슬라이드, 스티커는 쓰지 않는다.

- **말 속도**: 문장 사이 0.25초. 느리면 답답하다는 피드백이 있었다.
- **BGM**: 밝고 통통 튀는 업비트(합성곡, 116BPM). 내레이션 아래 -25dB, 카드가 나올 때만 살짝 올린다. 목소리를 묻지 않게 한다.
- **효과음**: 5종(칼 소리, 물방울, 쿠궁, 코인, 갈매기). 세그먼트당 2개 이하, 전체 15회 이내.
- **화면 품질(v2.1)**: 순위 타이틀 카드는 천천히 확대된다(켄 번스, 약 10%). 자막의 숫자·월·순위는 노란색으로 강조된다. 제철·기간 정보가 있는 품목은 정보 카드에 **12칸 달력**을 넣는다(`months`, `peak`). 정보 카드는 `at`으로 해당 문장에 맞춰 띄운다.
- **썸네일 — 매번 다른 컨셉, 글씨는 아주 크게**: 같은 채널 안에서 썸네일이 획일화되지 않게, 직전 영상과 다른 컨셉을 고른다. 고른 컨셉은 `05_메타데이터/썸네일_가이드.txt`에 기록한다. 제목은 최소 150px 이상 ExtraBold로 쓰고 화면 폭에 맞춰 자동으로 줄어들게 한다.
  - A. **임팩트 칩형**(`thumbnail_bold`, 노량진 맛집 TOP10에 사용): 사진 전면 + 빨간 윗줄 + 기울어진 흰/노랑 큰 제목 + 하단 흰 칩 3개 + 배지
  - B. **VS 대결형**(`thumbnail_versus`, 제철 해산물 TOP10에 사용): 왼쪽 흑백(모두가 예상한 답) vs 오른쪽 컬러(진짜 답) + 아주 큰 2줄 제목 + 빨간 원형 스탬프 + 하단 초록 띠
  - C. **큰 숫자형**(`thumbnail_number`, 대방어 부위 TOP6에 사용): 숫자 하나(예: 8kg)를 화면 절반 크기 노랑으로 + 흰 칩 보조 문구 + 빨간 윗줄 질문 + 아주 큰 흰 제목
  - D. **체크리스트형**(`thumbnail_checklist`, 노량진 킹크랩 TOP6에 사용): 왼쪽 어둡게 + 큰 2줄 제목(흰/노랑) + 초록 체크 3줄 + 빨간 원형 스탬프
  - **썸네일 글자 규칙(사용자 지시)**: 썸네일에 '노량진'을 쓸 때는 항상 **'노량진수산시장'**으로 쓴다.
  - F. **손글씨·스티커 팝형**(`thumbnail_weekly_pop`, 주간 시세 시리즈 현재 틀): 시장 사진 + 날짜 메모지 + 파란 간판 + 붓글씨 2색 제목 + 손글씨 스티커 3장 + 물방울·물고기 낙서
  - E. **주간 시세 리포트형**(`thumbnail_weekly`, 시리즈 전용·고정 틀)(이전 틀): 회차 배지 + 기간 칩 + 아주 큰 품목명 + 큰 ▼/▲ 변동률(파랑/빨강) + 하단 시리즈 제목 띠. 시리즈는 틀을 바꾸지 않는다
  - G. **경고 테이프형**(`thumbnail_alert`, 노량진 바가지 실전편에 사용): 사진 위 노랑·검정 경고 테이프 + 빨간 윗줄 + 아주 큰 2줄 제목 + 수법 칩 5개 + 원형 스탬프 → `07_썸네일틀/썸네일_경고.png`

- **썸네일(임팩트형)**: 사진 전면 + 빨간 윗줄(훅 질문) + 기울어진 큰 흰 제목 + 노란 둘째 줄 + 하단 흰 칩 3개(아이콘 + 두 줄, 둘째 줄 빨강) + 오른쪽 위 남색 배지. 사용자 참고 썸네일보다 외곽선과 채도를 **한 단계 낮춘다**.

## 5. 대본 작성 규칙 (어기면 안 됨)
- 방송용 존댓말, 문장은 15~25자 안팎.
- TTS 대본의 숫자는 한글로 쓴다("3,218개" → "삼천이백십팔 개", "1위" → "일위"). 자막용 아라비아 숫자는 `display_map`에 추가한다.
- 데이터 표나 조사표에 없는 숫자, 연혁, 가격, 메뉴는 만들지 않는다.
- 사용자가 지정한 필수 멘트는 그대로 넣는다(아웃트로 + 설명란 + 고정댓글).
- 제목과 썸네일에 근거 없는 수치를 쓰지 않고, 본편에 없는 메뉴를 특정 가게와 연결하지 않는다.

## 6. 지켜야 할 원칙
- **목소리**: 다른 채널 영상의 목소리는 AI 음성이라도 추출하거나 복제하지 않는다(서비스 약관, 성우 권리, 사칭 위험). 사용자가 같은 서비스에서 직접 만든 음성 파일을 주면 그 파일을 쓴다. 실존 인물의 목소리를 복제하는 것도 하지 않는다.
- **사진**: CC0, CC BY, 퍼블릭도메인만 쓴다. CC BY는 고정댓글에 저작자를 표시한다. 영상과 설명란에 "실제 매장 사진 아님"을 밝힌다.
- **참고 영상**: YouTube 자막과 스토리보드는 yt-dlp(`--js-runtimes node`, `player_client=web_embedded`)로 받을 수 있다. 오디오와 영상은 봇 차단이나 403으로 막히는 경우가 많다. 막히면 그대로 알리고, 추측해서 만들지 않는다.

## 7. 알려진 함정
- 네이버 검색은 파이썬 urllib 요청을 403으로 막는 일이 잦다 → `naver_blog_research.py`는 curl로 받는다(v2.3.0).
- `display_map`은 긴 표현부터 한 번에 바꾼다(v2.3.0). 순서대로 바꾸면 '이만 원'→'2만 원'→'21만 원'처럼 겹쳐 깨진다. 그래도 '십만 원'처럼 짧은 표현이 긴 표현 안에 들어가는지 미리 자막을 뽑아 확인한다.
- 아웃트로 요약 카드는 `graphics.recap_regex`(예: `^(일위|사위) `)로 정리 문장을 찾는다. TOP6이면 '일위…삼위' + '사위…육위' 두 문장으로 쓴다.
- 순위가 아닌 '첫째…다섯째' 구성(수법·방법 N가지)은 `graphics.recap_regex`(예: `^(첫째|넷째)`)와 `graphics.recap_item_regex`(예: `(첫째|둘째|셋째|넷째|다섯째)`)로 요약 카드를 잡고, `graphics.summary_title`로 요약 카드 제목을 바꾼다(v2.6.0).
- 정보 카드 `kind: "checklist"`는 체크 줄 목록 카드다. 인트로 '이 영상을 끝까지 보면'(시청 효용)과 아웃트로 체크리스트에 쓴다(v2.6.0).
- 완성 후 길이가 모자라 문장을 끼워 넣을 때: 예전 JSON과 새 JSON의 문장 **텍스트**로 기존 wav를 새 id에 옮기고, 없는 문장만 `--only`로 만든다. 번호만 보고 옮기면 뒤 문장이 전부 밀린다(v2.6.0).
- '전문가 인터뷰'를 요청받아도 직접 인터뷰가 없으면 지어내지 않는다. 공개 영상·기사의 발언을 출처와 함께 요약하고 `조사표.md`에 적는다(v2.6.0).
- Openverse 검색어 묶음은 섹션 이름이 아니라 **주제 묶음**(통째, 회, 뱃살, 시장…)으로 받고, 검수할 때 섹션에 배정한다. 저울·주차·돈 같은 생활 사진은 따로 묶음을 만들어 받는다.
- Edge TTS mp3는 앞뒤 무음이 약 1.7초다. 렌더러가 잘라낸다.
- 장면 조각은 프레임 수(`-frames:v`)를 고정해야 소리와 어긋나지 않는다. 렌더러가 0.2초 넘게 어긋나면 멈춘다.
- 큰 배열을 np.convolve로 이동평균하면 멈춘다. 누적합 방식을 쓴다.
- Wikimedia와 Flickr의 직접 다운로드는 429로 막힌다. Openverse 썸네일 프록시(`/v1/images/{id}/thumb/?full_size=true`)를 쓴다.
- 렌더링을 기다릴 때 `pgrep -f render_video.py`를 쓰면 기다리는 명령 자신이 걸린다. 로그 파일의 "완성" 문구로 확인한다.
- `rm`에 셸 변수를 쓸 때는 `"${VAR:?}"` 형태로 쓴다.
- 파일 전송 한도는 30MB, Google Drive 커넥터는 base64 업로드라 대용량 영상은 올릴 수 없다. 그래서 720p 전달본을 만든다.

- Edge TTS는 하루에 많이 요청하면(수백 문장) 이 환경 IP가 403으로 막힐 수 있다. 버전을 바꿔도 풀리지 않는다. 문장 TTS는 한 번에 만들고, 실패하면 빈 mp3가 생기니 크기(2KB 미만)로 확인해 다시 만든다. 막히면 목소리 우선순위 ②를 쓰거나 사용자에게 알린다.
- faster-whisper는 `av` 버전 충돌로 파일 열기가 실패할 수 있다. ffmpeg로 16kHz float 배열을 만들어 넘긴다(check_tts.py가 이렇게 함). 대본을 `initial_prompt`로 주면 오류가 가려지니 주지 않는다.
- 셸 heredoc 안에 파이썬 삼중따옴표 코드를 넣으면 이스케이프가 깨진다. 긴 패치는 파일로 써서 실행한다.

## 8. 마지막 보고 형식

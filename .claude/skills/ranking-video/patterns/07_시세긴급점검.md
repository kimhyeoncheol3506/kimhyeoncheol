# 패턴 7 — 시세 긴급점검 폭락·폭등

- **제목 공식**: 「○○ 3주 새 ○○%↓, 지금 사도 될까」 / 「○○ 폭등, 언제까지 갈까」
- **학습 표본**: 해산물 이야기꾼 백대표 시세 긴급점검(5.6만)·뉴스 배추 폭락(200만)
- **길이**: 6~8분 · 쇼츠는 같은 패턴의 '숫자 충격 1개' 30~40초 — 퍼센트 숫자 1개 + 이유 한 줄

## 대본 구조
1. 폭락/폭등 숫자(0~10초)
2. 이유 3가지(물량·날씨·수입) — 공공자료·보도
3. 언제까지 갈까(과거 같은 시기 비교, 선 그래프)
4. 살 타이밍 + 도매가·과거 데이터 고지 + 엔딩

## 화면 톤 (themes.json "7")
증권 차트 톤(검정 격자, 오름 빨강·내림 파랑), 위쪽 LIVE 시세 점검 표시, 자막은 화면 아래 전체 폭 띠(뉴스 티커), 전환은 짧은 컷(0.2초)

| 항목 | 값 |
|---|---|
| 배경 | `grid` · 바탕 #0E1117 / #161B22 / #05070A |
| 강조색 | #FFD60A · 보조 #FF3B30 · 글자 #E6EDF3 · 내림 #1E88E5 · 오름 #FF3B30 |
| 제목 글꼴 | Pretendard ExtraBold |
| 장식 | `ticker` |
| 전환 | `cut` · 0.2초 |
| 자막 | 위치 `bottom` · 모양 `strip` · 글자 #fff · 숫자 강조 #FFD60A (크기 87px 유지) |

## 썸네일 틀 (theme.thumb_html)
차트 선 + 큰 화살표·퍼센트. thumb 키: top·big(품목)·pct·dir(up/down)·tag — `build_data.py`의 `CFG["thumb"]`에 이 키를 넣으면 `make_thumb.py`가 A안을 이 틀로 만든다(B안·세로는 패턴 색으로).

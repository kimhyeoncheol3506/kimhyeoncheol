# 패턴 4 — 고발·사례 재구성

- **제목 공식**: 「○○ 샀는데 집에선 ○○? 이렇게 당합니다」 / 「○kg 샀는데 ○kg? 수법별 손해액」
- **학습 표본**: 인어교주해적단 킹크랩 바가지(598만)·생선선생 미스터S 소래포구 빨대게 사건(285만)·뉴스 횟집 바가지(100~200만)
- **길이**: 8~10분 · 쇼츠는 같은 패턴의 '숫자 충격 1개' 30~40초 — 수법 1개 + 손해액 숫자 1개(보도 근거)

## 대본 구조
1. 훅: 보도된 사례 한 줄(가게 지목 없음, '재구성' 표시) + 손해액 숫자
2. 수법별 재구성 3~4개 — 각 수법을 경락가로 환산한 손해액
3. 확인 체크리스트(저울·물 빼기·영수증·원산지)
4. 도매가 고지 + 엔딩

## 화면 톤 (themes.json "4")
어두운 남색 + 경고 빨강, 모서리 괄호와 '● 사례 재구성' 표시, 화면 주사선, 자막은 왼쪽 아래 빨간 막대(재연 자막), 전환은 셔터(0.4초)

| 항목 | 값 |
|---|---|
| 배경 | `scan` · 바탕 #0B1530 / #14244D / #060C1C |
| 강조색 | #FF3B3B · 보조 #FF8A8A · 글자 #E8EEF8 · 내림 #4FC3F7 · 오름 #FF3B3B |
| 제목 글꼴 | Pretendard ExtraBold |
| 장식 | `recon` |
| 전환 | `shutter` · 0.4초 |
| 자막 | 위치 `lowerleft` · 모양 `bar` · 글자 #fff · 숫자 강조 #FF6B6B (크기 87px 유지) |

## 썸네일 틀 (theme.thumb_html)
어두운 사진 + 큰 숫자 대비(3kg → ?kg) + 빨간 '재구성' 도장. thumb 키: top·from·to·sub·tag — `build_data.py`의 `CFG["thumb"]`에 이 키를 넣으면 `make_thumb.py`가 A안을 이 틀로 만든다(B안·세로는 패턴 색으로).

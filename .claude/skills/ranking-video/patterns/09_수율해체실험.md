# 패턴 9 — 수율·해체 실험

- **제목 공식**: 「○○ 1kg 사면 먹는 건 몇 g?」 / 「○○ 수율 실험, 100g당 진짜 값」
- **학습 표본**: 활어티비 수율(31만)·광어수율 편
- **길이**: 6~9분 · 쇼츠는 같은 패턴의 '숫자 충격 1개' 30~40초 — 저울 숫자 대비 1개

## 대본 구조
1. 무게 훅(0~20초): 1kg → 먹는 g
2. 부위별 분해 애니메이션(yieldfx)
3. 100g당 원가(경락가 ÷ 수율)
4. 인원별 계산 + 수율 범위 고지 + 엔딩

## 화면 톤 (themes.json "9")
흰 실험실 모눈 배경, 위쪽 눈금자 + LAB 표시, 청록·보라, 자막은 흰 상자 + 청록 밑줄, 위→아래 스캔선 전환(0.35초)

| 항목 | 값 |
|---|---|
| 배경 | `labgrid` · 바탕 #FAFCFC / #FFFFFF / #E9F2F2 |
| 강조색 | #00A3A3 · 보조 #6C63FF · 글자 #102A43 · 내림 #00A3A3 · 오름 #E8590C |
| 제목 글꼴 | Pretendard ExtraBold |

| 자막 | 위치 `bottom` · 모양 `underline` · 글자 #102A43 · 숫자 강조 #00A3A3 (크기 87px 유지) |

## 썸네일 틀 (theme.thumb_html)
저울 LCD 두 개(1,000g → ○g). thumb 키: big·from·to·sub·tag — `build_data.py`의 `CFG["thumb"]`에 이 키를 넣으면 `make_thumb.py`가 A안을 이 틀로 만든다(B안·세로는 패턴 색으로).

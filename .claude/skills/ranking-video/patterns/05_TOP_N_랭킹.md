# 패턴 5 — TOP N 랭킹

- **제목 공식**: 「지금 가장 싸진 ○○ TOP5」 / 「가성비 ○○ TOP3」
- **학습 표본**: 회사랑RawFishEater「무한리필 횟집 TOP3」·주간 시세 리포트 시리즈
- **길이**: 7~9분 · 쇼츠는 같은 패턴의 '숫자 충격 1개' 30~40초 — 1위 품목 + 변동률 숫자 1개

## 대본 구조
1. 기준 공개(0~20초): 1위 미리보기 + 기준(물량·값 폭)
2. 5→1위 카운트다운 — 순위 카드(경락가 변화)
3. 총정리 표 + 도매가 고지 + 엔딩

## 화면 톤 (themes.json "5")
짙은 남색 + 금색 순위 배지, 위에서 퍼지는 빛줄기, 오른쪽 위 RANKING 리본, 자막은 둥근 알약 상자, 카드가 튀어나오는 빠른 줌 전환(0.3초)

| 항목 | 값 |
|---|---|
| 배경 | `rays` · 바탕 #101828 / #1D2A44 / #0A101C |
| 강조색 | #FFB800 · 보조 #FF6B00 · 글자 #FFFFFF · 내림 #32D583 · 오름 #F97066 |
| 제목 글꼴 | Black Han Sans |
| 장식 | `badge` |
| 전환 | `zoom` · 0.3초 |
| 자막 | 위치 `bottom` · 모양 `pill` · 글자 #fff · 숫자 강조 #FFB800 (크기 87px 유지) |

## 썸네일 틀 (theme.thumb_html)
금색 원형 '1위' 배지 + 1위 품목 크게 + 변동률. thumb 키: rank·top·big·sub·tag — `build_data.py`의 `CFG["thumb"]`에 이 키를 넣으면 `make_thumb.py`가 A안을 이 틀로 만든다(B안·세로는 패턴 색으로).

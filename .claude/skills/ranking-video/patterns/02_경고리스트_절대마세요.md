# 패턴 2 — 경고 리스트 「절대 ~마세요」

- **제목 공식**: 「회 좋아하면 절대 사지 마세요, ○가지」 / 「생선회 전문가가 절대 먹지 않는 ○가지」
- **학습 표본**: 입질의추억TV「생선회 전문가가 절대 먹지 않는 7가지」·「11~12월엔 무조건 이런 방어회만」(259만)
- **길이**: 9~11분 · 쇼츠는 같은 패턴의 '숫자 충격 1개' 30~40초 — '절대 ○○ 마세요' 1개 + 근거 숫자 1개

## 대본 구조
1. 훅: 결론 숫자(○가지) + 가장 센 1개 미리보기
2. 7→1위 카운트다운 — 항목마다 근거(경락가 값 폭·물량·공공자료·보도)
3. 대신 이걸 사라(대안 카드)
4. 체크리스트 + 도매가 고지 + 엔딩

## 화면 톤 (themes.json "2")
검정 + 형광 노랑, 위·왼쪽 노랑/검정 경고 줄무늬, WARNING 표시, 자막은 노란 상자에 검정 글씨, 전환은 줄무늬가 빠르게 쓸고 감(0.25초)

| 항목 | 값 |
|---|---|
| 배경 | `flat` · 바탕 #090909 / #141414 / #000000 |
| 강조색 | #FFE600 · 보조 #FF2D2D · 글자 #FFFFFF · 내림 #FFE600 · 오름 #FF2D2D |
| 제목 글꼴 | Black Han Sans |
| 장식 | `hazard` |
| 전환 | `stripes` · 0.25초 |
| 자막 | 위치 `bottom` · 모양 `box` · 글자 #000 · 숫자 강조 #D10000 (크기 87px 유지) |

## 썸네일 틀 (theme.thumb_html)
왼쪽 사진 위 큰 빨간 X + 오른쪽 노란 숫자. thumb 키: top·big(○가지)·sub(절대 사지 마세요)·tag — `build_data.py`의 `CFG["thumb"]`에 이 키를 넣으면 `make_thumb.py`가 A안을 이 틀로 만든다(B안·세로는 패턴 색으로).

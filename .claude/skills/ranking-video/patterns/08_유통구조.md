# 패턴 8 — 유통 구조 「산지는 남는 게 없다」

- **제목 공식**: 「산지 ○원인데 마트는 ○원, 차이는 어디로?」 / 「마트에선 비싼데 밭에선 남는 게 없다」
- **학습 표본**: 밥상의이유「마트에선 비싼데 밭에선 남는 게 없다 TOP5」
- **길이**: 10~14분 · 쇼츠는 같은 패턴의 '숫자 충격 1개' 30~40초 — 두 숫자(산지 vs 소매) 1개 비교

## 대본 구조
1. 훅: 산지가와 소매가 두 숫자
2. 산지가 → 경락가(가락/노량진) → 소매가 단계별 분해(흐름도)
3. 단계마다 붙는 비용(공공자료: aT·KAMIS·통계)
4. 소비자 팁 + 도매가 고지 + 엔딩

## 화면 톤 (themes.json "8")
밝은 회청색 인포그래픽, 위쪽 '산지 → 경매 → 소매' 흐름 표시, 파랑·청록, 자막은 남색 둥근 상자, 화살표가 지나가는 전환(0.6초)

| 항목 | 값 |
|---|---|
| 배경 | `flat` · 바탕 #EEF3F8 / #F8FBFE / #DCE6F0 |
| 강조색 | #0057B8 · 보조 #00A99D · 글자 #0F2540 · 내림 #00A99D · 오름 #D64545 |
| 제목 글꼴 | Pretendard ExtraBold |
| 장식 | `flow` |
| 전환 | `arrow` · 0.6초 |
| 자막 | 위치 `bottom` · 모양 `box` · 글자 #fff · 숫자 강조 #6FE3D8 (크기 87px 유지) |

## 썸네일 틀 (theme.thumb_html)
가격 3단 계단 상자 + 화살표. thumb 키: big·steps[[단계,값]×3]·tag — `build_data.py`의 `CFG["thumb"]`에 이 키를 넣으면 `make_thumb.py`가 A안을 이 틀로 만든다(B안·세로는 패턴 색으로).

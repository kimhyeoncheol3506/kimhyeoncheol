# 패턴 1 — 가격 검증 「○○의 진실」

- **제목 공식**: 「○○ kg ○천원의 진실, 과연 먹을만할까?」 / 「○○ 9천원짜리의 진실」
- **학습 표본**: 입질의추억TV「9천원짜리 킹크랩」(125만)·「은갈치 한박스 만원의 진실」
- **길이**: 8~10분 · 쇼츠는 같은 패턴의 '숫자 충격 1개' 30~40초 — 'kg ○원, 진짜 싼 걸까?' 숫자 1개 → 답 한 줄

## 대본 구조
1. 훅(0~20초): 싼 가격 한 줄 + 결론 숫자(예: 경락가로 계산하면 kg ○원)
2. 경락가로 원가 계산(calc·table): 같은 품목 활/선·크기별 경락가
3. 왜 싼가 3가지(크기·선어·산지) — 카드 3장
4. 사도 되는 경우 / 거를 경우(summary 좌우)
5. 요약 + 도매가 고지 + 엔딩 17.5초

## 화면 톤 (themes.json "1")
밝은 흰 배경, 빨간 가격표(PRICE CHECK 리본), 제목은 블랙한산스, 전환은 빨간 판이 밀고 지나감(0.45초)

| 항목 | 값 |
|---|---|
| 배경 | `flat` · 바탕 #F7F5F0 / #FFFFFF / #ECE8DF |
| 강조색 | #E02424 · 보조 #B91C1C · 글자 #1B1B1B · 내림 #1D4ED8 · 오름 #E02424 |
| 제목 글꼴 | Black Han Sans |
| 장식 | `pricetag` |
| 전환 | `push` · 0.45초 |
| 자막 | 위치 `bottom` · 모양 `box` · 글자 #fff · 숫자 강조 #FFD640 (크기 87px 유지) |

## 썸네일 틀 (theme.thumb_html)
흰 배경 + 오른쪽 사진 + 빨간 가격표(big) + 큰 물음표. thumb 키: top·big(가격)·sub(먹을 만할까?)·tag — `build_data.py`의 `CFG["thumb"]`에 이 키를 넣으면 `make_thumb.py`가 A안을 이 틀로 만든다(B안·세로는 패턴 색으로).

# 패턴 6 — 가성비 앵커 「○원에 이게 가능?」

- **제목 공식**: 「1인 1만원으로 회 몇 g? 시장별로 계산」 / 「인당 ○원에 이게 가능해요??」
- **학습 표본**: 회사랑RawFishEater「인당 16000원에 이게 가능해요??」·대방어 맛집(37만)
- **길이**: 7~9분 · 쇼츠는 같은 패턴의 '숫자 충격 1개' 30~40초 — 예산 1개 → g 숫자 1개

## 대본 구조
1. 예산 고정(0~20초): 1만 원 → 결론 g 숫자
2. 시장·품목별로 얼마나 사지는지(영수증 카드: 예산 ÷ kg당 경락가)
3. 최적 조합(장바구니) + 수율 고지
4. 도매가 고지 + 엔딩

## 화면 톤 (themes.json "6")
크림색 점무늬 배경, 영수증 지그재그·점선 테두리, 초록(남는 돈)·주황 강조, 자막은 흰 둥근 상자, 영수증이 올라오는 전환(0.5초)

| 항목 | 값 |
|---|---|
| 배경 | `dots` · 바탕 #FFF6E0 / #FFFBF0 / #F5E6C4 |
| 강조색 | #00A86B · 보조 #FF7A00 · 글자 #222222 · 내림 #00A86B · 오름 #E5484D |
| 제목 글꼴 | Pretendard ExtraBold |
| 장식 | `receipt` |
| 전환 | `slideup` · 0.5초 |
| 자막 | 위치 `bottom` · 모양 `box` · 글자 #1A1A1A · 숫자 강조 #00A86B (크기 87px 유지) |

## 썸네일 틀 (theme.thumb_html)
영수증 카드(예산 금액 크게) + 원형 접시 사진. thumb 키: top·budget·big·tag — `build_data.py`의 `CFG["thumb"]`에 이 키를 넣으면 `make_thumb.py`가 A안을 이 틀로 만든다(B안·세로는 패턴 색으로).

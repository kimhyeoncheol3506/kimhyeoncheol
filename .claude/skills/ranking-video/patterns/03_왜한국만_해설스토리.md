# 패턴 3 — 「왜 한국만 ~할까」 해설 스토리

- **제목 공식**: 「왜 한국만 겨울에 ○○을 줄 서서 먹을까」 / 「왜 한국 사람만 ○○에 열광할까」
- **학습 표본**: 밥상의이유(얼굴 없는 해설 채널)「왜 한국만 겨울마다 대방어를 줄 서서 먹을까」(14만)
- **길이**: 14~18분 · 쇼츠는 같은 패턴의 '숫자 충격 1개' 30~40초 — 질문 1개 + 숫자 1개(예: 방어 경락가 10년 새 4배)

## 대본 구조
1. 질문(0~20초): 질문 + 오늘의 결론 숫자(예: 10년 새 4배)
2. 역사·문화(챕터 PART 1): 언제부터, 왜 그 계절인가 — 공공자료·보도 인용
3. 유통·가격 데이터(PART 2): 경락가 추이(flow 선 그래프), 물량·수입
4. 오늘의 결론(PART 3) + 내 생각 한 줄 + 도매가 고지 + 엔딩

## 화면 톤 (themes.json "3")
따뜻한 베이지 종이 질감, 명조 제목, 가장자리 어둡게(비네트), 모든 장면 천천히 줌(5%), 자막은 상자 없이 진한 갈색, 전환은 느린 디졸브(1.1초)

| 항목 | 값 |
|---|---|
| 배경 | `paper` · 바탕 #EFE4D2 / #F7EFE2 / #D9C7AB |
| 강조색 | #A0522D · 보조 #7A3E1F · 글자 #3B2F25 · 내림 #4E7D6B · 오름 #B5482E |
| 제목 글꼴 | 나눔명조 ExtraBold |
| 장식 | `vignette` |
| 전환 | `dissolve` · 1.1초 · 장면 천천히 줌 5% |
| 자막 | 위치 `bottom` · 모양 `plain` · 글자 #2A2019 · 숫자 강조 #A0522D (크기 87px 유지) |

## 썸네일 틀 (theme.thumb_html)
베이지 배경 + 원형 세피아 사진 + 명조 질문 한 줄. thumb 키: top·big(질문)·sub(결론 숫자) — `build_data.py`의 `CFG["thumb"]`에 이 키를 넣으면 `make_thumb.py`가 A안을 이 틀로 만든다(B안·세로는 패턴 색으로).

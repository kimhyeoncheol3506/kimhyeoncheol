# 영상 패턴 10가지 (CHECK ISSUE POINT, 2026-11-28 사용자 지시 · '가장 큰 핵심')

모든 영상이 먹색+금색 한 템플릿이라 채널이 한 패턴으로 보이는 문제를 없앤다. 인기 유튜버(입질의추억TV·밥상의이유·회사랑·인어교주해적단·생선선생 미스터S·백대표·활어티비·뉴스) 영상 분석으로 정한 10가지.

## 규칙
1. **새 영상마다 10개 중 랜덤 1개, 직전 2편과 같은 패턴은 제외** — `python3 pick_pattern.py <프로젝트>` (기록: `history.json`). `시장3x3_시리즈/공통/새편.sh`가 폴더를 만들 때 자동으로 뽑는다(`PATTERN_ONLY=1,3`으로 후보 제한).
2. 뽑힌 패턴은 `<프로젝트>/00_data/pattern.json` · `pattern.txt`에 남고, `롱폼_만들기.sh`가 `upload_ready/<편>/pattern.txt`(번호·이름)로 복사한다. 다시 렌더해도 패턴은 바뀌지 않는다.
3. 화면 톤(색·배경·장식·자막 위치/모양·전환 속도·제목 글꼴)과 썸네일 틀은 패턴마다 다르다 — `engine/`(build_hf·build_shorts·make_thumb)가 `theme.py`로 읽는다. pattern.json이 없는 옛 편은 0번(기존 먹색+금색) 그대로.
4. 이미 완성된 업로드 대기분은 다시 만들지 않는다. 새 롱폼은 **하루 1편**(대기 롱폼 17편, 2026-11-28 기준).
5. 공통: 첫 20초 안에 결론 숫자, 30초 이내 장면 전환, 도매가·과거 데이터 고지, CC 사진+출처, 특정 가게 지목 금지, 엔딩 15~20초 비우기(17.5초), 자막 87px·숫자 강조, 쇼츠는 같은 패턴의 '숫자 충격 1개' 30~40초.

## 파일
- `themes.json` — 패턴별 팔레트·배경·장식·전환·자막 설정(0번 = 기존)
- `theme.py` — 생성기용 함수: `load`, `bg_css`, `deco_html`, `wipe_html/wipe_js`, `cap_css`, `card_css`, `layer`, `thumb_html`, `remap`(대본에 적힌 옛 금색 코드 → 패턴 색)
- `engine/` — 패턴 대응 롱폼·쇼츠·썸네일 생성기(3대시장_광어비교 생성기 기반). 새 편은 여기서 복사
- `pick_pattern.py`, `history.json` — 랜덤 뽑기와 기록
- `make_samples.py` → `samples/NN_장면.png·제목.png·전환.png·썸네일.png·샘플5초.mp4` (샘플 숫자는 실제 조사값만)

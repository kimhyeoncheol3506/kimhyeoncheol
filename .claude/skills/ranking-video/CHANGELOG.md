# ranking-video 변경 이력

## 버전 규칙 (Semantic Versioning)
| 올리는 자리 | 언제 | 예 |
|---|---|---|
| **MAJOR** (x.0.0) | 폴더 구조, 입력 JSON 형식, 산출물 파일명이 바뀌어 예전 프로젝트와 호환되지 않을 때 | 2.0.0 |
| **MINOR** (1.x.0) | 새 기능·규칙·스타일을 추가할 때(기존 결과물은 그대로 유효) | 스타일 반영, 쇼츠 버전 추가 |
| **PATCH** (1.0.x) | 오타, 문구 다듬기, 버그 수정 | 자막 줄바꿈 수정 |

버전을 올릴 때 할 일:
1. `SKILL.md` frontmatter의 `version`, `updated`와 제목 줄의 버전을 수정
2. 이 파일의 버전 규칙 아래에 새 항목 추가(추가/변경/수정)
3. `scripts/*.py`가 바뀌었으면 docstring의 버전도 수정
4. 커밋 메시지를 `ranking-video vX.Y.Z: <요약>` 형식으로 쓴다. 버전 기록은 이 커밋 메시지로 찾는다.
   - 버전별 커밋 목록: `git log --oneline --grep "ranking-video v" -- .claude/skills/ranking-video`
   - 예전 버전 보기: `git show <커밋>:.claude/skills/ranking-video/SKILL.md`
   - 예전 버전으로 되돌리기: `git checkout <커밋> -- .claude/skills/ranking-video`
   - git 태그(`ranking-video/vX.Y.Z`)도 쓸 수 있지만, 현재 클라우드 환경은 태그 푸시가 막혀 있어 커밋 메시지 방식을 기본으로 쓴다.

## v1.3.1 — 2026-10-11 · 현수 목소리, 임팩트 썸네일
### 변경
- 기본 TTS 목소리: 인준 → **현수**(밝은 남성). `make_tts.py`의 세 번째 인자나 JSON `"voice"`로 바꿀 수 있다
- 경매장 사진 중 얼굴이 크게 나온 1장 제외
### 추가
- `thumbnail_bold()`: 사용자 참고 썸네일(시장 사진 + 큰 제목 + 하단 칩 3개)을 한 단계 차분하게 만든 임팩트 썸네일
### 원칙
- 다른 채널의 AI 목소리는 추출하거나 복제하지 않는다(서비스 약관과 성우 권리). 같은 서비스에서 사용자가 직접 만든 음성을 받아 쓴다

## v1.3.0 — 2026-10-11 · 피드백 반영: 빠른 말, 타이틀 카드, 큰 글씨, 경쾌한 BGM
### 변경
- TTS 속도: -12% → **+22%** (참고 영상 https://youtu.be/_DTI05Ww8gQ 자막 타이밍 실측 초당 6.0음절). 문장 사이 0.45 → 0.25초, 꿀팁 앞 여백 3 → 2초
- 상단 점포명 라벨: 44 → **88px**, 오른쪽으로 기울임, 그림자 추가
- 자막: 58 → **87px**(1.5배), 강조 96 → 124px
- BGM: 로파이 → **밝은 업비트**(116BPM, 플럭 + 바운스 베이스 + 클랩), 내레이션 아래 -25dB
- 인트로: 노량진수산시장 연혁과 "왜 성지인가" 4문장 삭제
### 추가
- 순위 **타이틀 카드**(`07_그래픽/08_타이틀카드`): 대표 사진 전면 + 순위 + 큰 점포명 + 한 줄 특징
- `render_video.py --until`(샘플 렌더링), `--bgm`, 섹션 `card_at`
### 한계
- 참고 영상 오디오는 YouTube 봇 차단으로 받지 못해 속도만 맞췄다. 목소리는 인준(남성)을 유지했다.

## v1.2.0 — 2026-10-11 · 완성 MP4 자동 렌더링
### 추가
- `scripts/make_tts.py`: 문장별 TTS(Edge TTS 인준, 느리게▲/빠르게▼ 속도 반영)
- `scripts/make_audio_assets.py`: 효과음 5종과 로파이 BGM 루프를 numpy로 합성
- `scripts/fetch_images.py`: Openverse CC 이미지 수집과 출처 메타데이터
- `scripts/render_video.py`: 타임라인 계산, 오디오 믹스(BGM 덕킹, 효과음), 사진 팬과 오버레이, ASS 자막 굽기 → 1080p30 H.264 MP4
- `scripts/make_credits.py`: 실제로 쓰인 이미지의 저작자 표시 목록
- 출력 폴더 `08_완성영상/` (하위 호환)
### 교훈
- Edge TTS mp3는 앞뒤 무음이 약 1.7초 → 그대로 이으면 5분이 늘어나므로 잘라낸다
- 큰 배열에 np.convolve 이동평균을 쓰면 렌더러가 멈춘다 → 누적합 방식으로 처리
- Wikimedia와 Flickr의 직접 다운로드는 이 환경에서 429 → Openverse 썸네일 프록시 사용

## v1.1.0 — 2026-10-11 · 클린 미니멀 스타일
참고 영상(https://youtu.be/1V27x7n4g78, 신영선의 AI탐구)을 분석해 기본 스타일로 반영했다. 분석 자료는 장면 썸네일 189컷, 자막, 챕터 정보이고 영상 원본과 오디오는 받지 못했다(403).
### 추가
- `scripts/make_graphics.py`: 챕터 카드, 상단 라벨, 원형 순위 배지, 정보 카드, 요약 카드(칸 채우기), 엔드카드, 썸네일 틀 PNG 생성(Pretendard 글꼴 자동 다운로드)
- 출력 폴더 `07_그래픽/` (기존 01~06은 그대로라 하위 호환)
- 입력 JSON 선택 항목: 섹션 `rank`·`label`·`card_title`·`card_sub`, 최상위 `graphics`, `subtitle_max`
### 변경

- 효과음 사용 규칙: 세그먼트당 최대 2개, 전체 15회 이내. 웜 슬라이드, 흔들기, 플래시 금지

- `examples/노량진_TOP10.json`에 그래픽 데이터를 추가하고 효과음 메모를 줄임
### 수정

# ranking-video 변경 이력

## 버전 규칙 (Semantic Versioning)
| 올리는 자리 | 언제 | 예 |
|---|---|---|
| **MAJOR** (x.0.0) | 폴더 구조, 입력 JSON 형식, 산출물 파일명이 바뀌어 예전 프로젝트와 호환되지 않을 때 | 2.0.0 |
| **MINOR** (1.x.0) | 새 기능·규칙·스타일을 추가할 때(기존 결과물은 그대로 유효) | 참고 영상 스타일 반영, 쇼츠 버전 추가 |
| **PATCH** (1.0.x) | 오타, 문구 다듬기, 버그 수정 | 자막 줄바꿈 수정 |

버전을 올릴 때 할 일:
1. `SKILL.md` frontmatter의 `version`, `updated`와 제목 줄의 버전을 수정
2. 이 파일 맨 위에 새 항목 추가(추가/변경/수정)
3. `scripts/build_script.py`가 바뀌었으면 docstring의 버전도 수정
4. 커밋한 뒤 git 태그 `ranking-video/vX.Y.Z` 생성
   - 예전 버전 보기: `git show ranking-video/v1.0.0:.claude/skills/ranking-video/SKILL.md`
   - 예전 버전으로 되돌리기: `git checkout ranking-video/v1.0.0 -- .claude/skills/ranking-video`

## v1.0.0 — 2026-10-10
최초 버전. "노량진수산시장 맛집 TOP10" 제작 과정을 스킬로 정리.
### 추가
- `SKILL.md`: 입력 항목·기본값, 폴더 구조, 실행 순서, 타임라인, 인트로 공식(반전 훅 → 목적 약속 → 몽타주 → 오픈 루프), 세그먼트 템플릿, 작성 규칙
- `scripts/build_script.py`: JSON 대본 데이터로 전체대본, 캡컷 분할(100자 이내·타임스탬프·연출 분리), SRT(숫자 표기 변환·2줄 분할)를 생성
- `examples/노량진_TOP10.json`: 실제 제작에 쓴 대본 데이터(완성 예시)
- `references/산출물_템플릿.md`: B롤, 음악·효과음, 메타데이터, 체크리스트 틀
- `references/스타일_가이드.md`: 기본 편집 스타일(v1.1.0에서 참고 영상 기준으로 갱신 예정)
### 첫 제작에서 얻은 교훈(규칙에 반영)
- 대본 4,500자는 TTS 기본 속도로 약 13~15분 → 0.9x와 B롤 여백으로 20분을 맞춰야 함
- 캡컷 곡명은 지어내지 말고 검색어와 기준으로 지정
- 근거 없는 수치를 제목에 쓰면 허위 표시 위험 → 경고를 붙임

# ranking-video 변경 이력

## 버전 규칙 (Semantic Versioning)
| 올리는 자리 | 언제 | 예 |
|---|---|---|
| **MAJOR** (x.0.0) | 폴더 구조, 입력 JSON 형식, 산출물 파일명이 바뀌어 예전 프로젝트와 호환되지 않을 때 | 2.0.0 |
| **MINOR** (1.x.0) | 새 기능·규칙·스타일을 추가할 때(기존 결과물은 그대로 유효) | 스타일 반영, 쇼츠 버전 추가 |
| **PATCH** (1.0.x) | 오타, 문구 다듬기, 버그 수정 | 자막 줄바꿈 수정 |

버전을 올릴 때 할 일:
1. `SKILL.md` frontmatter의 `version`, `updated`와 제목 줄의 버전을 수정
2. 이 파일의 버전 규칙 아래에 새 항목 추가(추가/변경/수정)
3. `scripts/*.py`가 바뀌었으면 docstring의 버전도 수정
4. 커밋 메시지를 `ranking-video vX.Y.Z: <요약>` 형식으로 쓴다. 버전 기록은 이 커밋 메시지로 찾는다.
   - 버전별 커밋 목록: `git log --oneline --grep "ranking-video v" -- .claude/skills/ranking-video`
   - 예전 버전 보기: `git show <커밋>:.claude/skills/ranking-video/SKILL.md`
   - 예전 버전으로 되돌리기: `git checkout <커밋> -- .claude/skills/ranking-video`
   - git 태그(`ranking-video/vX.Y.Z`)도 쓸 수 있지만, 현재 클라우드 환경은 태그 푸시가 막혀 있어 커밋 메시지 방식을 기본으로 쓴다.

# 쓰레드 댓글방 (대댓글 제안)

사용자에게 묻지 말고 끝까지 진행. Threads에는 직접 답글을 달지 않는다(사용자가 텔레그램에서 복사→붙여넣기로 직접 단다).

## 1. 댓글 수집 (Aside 브라우저, 로그인된 threads.com)
1. `openTab('https://www.threads.com/activity/replies')`, 4초 대기. 로그인 팝업이 보이면 텔레그램 댓글방에 "쓰레드 로그인이 풀렸어요" 한 줄 보내고 종료.
2. `page.mouse.wheel(0,4000)` 8번(1.5초 간격) 스크롤.
3. `page.evaluate`로 `[aria-label="칼럼 본문"] div[data-pressable-container="true"]` 마다: 작성자(`a[href^="/@"]`), `time[datetime]`, innerText(줄: 작성자 | 시간 | 시간 | 내 글 첫줄 | 댓글…), 내가 이미 답글 달았는지(`svg[aria-label="답글을 달았습니다"]` 있으면 답함), 댓글 링크(`a[href*="/post/"]`).
4. 조건: datetime 이 지금부터 48시간 이내 + 아직 내가 답글 안 단 것 + `sent.json`(이 폴더)에 없는 링크.
5. 제외: 광고/추천코드/가입 유도(예: "코드:", "토큰 10억개", VPN 홍보), 다른 사람끼리 주고받는 멘션·장난(@다른사람 ~, "긁혔다"), 욕설로 나를 공격하는 댓글, 의미 없는 이모지만.

## 2. 대댓글 문구 (10가지 형식, 랜덤 로테이션)
댓글 취지에 공감하는 말. 형식 10개를 섞어 쓰되 같은 형식을 연달아 2번 이상 쓰지 말고, 같은 배치 안에서 한 형식은 최대 3번. 문구는 매번 단어·어미를 바꿔서 쓴다(템플릿 복붙 금지).
| # | 형식 | 예시(복붙 금지, 느낌만) |
|-|-|-|
| F1 | 감탄 맞장구 | 와 해고엔딩.. 이건 진짜 현실적인 얘기네요 |
| F2 | 내 경험 살짝 | 저도 AI 상담 쓰다 속 터진 적 있어서 완전 공감이요 |
| F3 | 댓글 핵심 되받기 | 제설에 산불감시에 선거사무까지.. 딱 만능이죠 |
| F4 | 웃음 리액션 | ㅋㅋ 저 일 다 시키려면 200으론 택도 없겠어요 |
| F5 | 가볍게 되묻기 | 그쵸 연차 쌓이면 결국 비용 따져보게 되겠죠? |
| F6 | 초단답 | ㄹㅇ 단가가 답이네요 / 그쵸ㅎㅎ / 인정이요 |
| F7 | 고마움·응원 | 현직분이 말해주시니 더 와닿네요 고생 많으세요ㅠ |
| F8 | 걱정 공감 | 그러게요 시골도 그 정도면 주거비가 젤 걱정이네요ㅠ |
| F9 | 키워드 강조 | 책임지는 거 이게 핵심이네요 진짜 |
| F10 | 한마디 덧붙임 | 맞아요 GPU 값 생각하면 아직은 사람이 더 싸긴 하죠 |
규칙: 1문장, 5~45자. 존댓말 반말 섞인 편한 말투(~네요, ~죠, ~이요, ㅋㅋ/ㅠ 가끔). 이모지·해시태그·링크 금지. "좋은 의견 감사합니다", "공감합니다!" 같은 AI 티 나는 정형 문구 금지. 댓글 내용(숫자, 단어)을 하나는 꼭 받아서 쓴다. 정치 편들기, 투자 권유 금지. 경험(F2)은 누구나 겪을 법한 일만.

## 3. 텔레그램 댓글방으로 보내기
- 봇 토큰: `C:\Users\Admin\AsideTools\threads-bot\.env` 의 TELEGRAM_BOT_TOKEN (출력 금지). 그룹 chat_id: `-5452466519` ("쓰레드 댓글방").
- 새 댓글이 0개면 아무것도 보내지 않는다.
- 있으면 먼저 한 줄: `💬 새 댓글 N개 대댓글 제안`. 그다음 댓글마다 sendMessage(parse_mode HTML, HTML 이스케이프):
  `💬 <b>@작성자</b> · 내 글 첫줄\n댓글 원문(120자 이내)\n\n↪ 대댓글 문구` + inline 버튼 한 줄에 두 개: `[{text:'📋 답글 복사', copy_text:{text:대댓글문구}}, {text:'💬 댓글 열기', url:'https://www.threads.com'+댓글링크}]`.
- 참고: Threads는 답글을 미리 채운 링크를 지원하지 않음(intent/post의 reply_to 파라미터는 무시되고 새 글, url=은 인용 글이 됨). 그래서 복사 버튼 + 열기 버튼 방식. Threads API 토큰이 생기면 reply_to_id로 버튼 한 번에 진짜 답글 발행 가능.
- 보낸 링크를 `sent.json`(배열, 최근 500개 유지)에 추가. 탭 닫기.

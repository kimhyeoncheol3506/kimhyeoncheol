# 너굴경제 스타일 편집 규칙집

근거는 편집분석집.md(롱폼 3편 측정)입니다. 각 규칙의 수치는 `scripts/rules.json`에 그대로 들어 있고, 편집기 `scripts/neogul_edit.py`가 자동으로 적용합니다. 좌표와 크기는 1920x1080 기준입니다.

## 0. 영상 뼈대 (반드시 이 순서)

| 순서 | 장면 type | 길이 | 규칙 |
|---|---|---|---|
| 1 | `hook` | 5~6초 | R-H1 |
| 2 | `slide` x 2~4 | 각 6~18초 | 오프닝 숫자로 충격 주기 (섹션 라벨 "오프닝") |
| 3 | `slide` (목차, 크림) | 6~10초 | "그래서 오늘 영상은요" 멘트, 카드 3~6장, 마지막 카드 노란색 |
| 4 | `subscribe` | 4~6초 | R-C1 "그전에 형님들 구독과 좋아요" |
| 5 | 챕터 반복: `broll` → `slide` x N (+`mascot`, `pip`) | 챕터당 1.5~3분 | R-X1, R-X2 |
| 6 | 결론 `slide`(크림) → `mascot` → `subscribe` | 30~45초 | |
| 7 | `outro` | 4~6초 | R-C2 "그럼 ㅃ"에서 바로 끝 |

## 1. 컷과 리듬

- **R-P1** 큰 장면 전환은 분당 2~3회(장면 길이 중앙값 15~20초). 오프닝 1분은 분당 4~5회로 더 빠르게.
- **R-P2** 슬라이드가 15초를 넘으면 그 안에서 3~5초마다 강조 요소(박스, 화살표, 밑줄)를 하나씩 켠다. 화면이 8초 넘게 아무 변화 없이 있으면 안 된다.
- **R-P3** 장면은 문장 시작에 맞춰 바꾼다(`start_line` = 자막 줄 번호).

## 2. 내레이션과 소리

- **R-A1** 0.4초 넘는 쉼은 0.25초로 줄인다(`tighten`). 무음 바닥은 -38dB 기준.
- **R-A2** 본문에 배경음악을 넣지 않는다. 넣더라도 훅과 아웃트로에만, 볼륨 0.06 이하(`bgm_mode` 기본값).
- **R-A3** 최종 음량 -16 LUFS, 피크 -1.5 dBTP.
- **R-S1** 효과음은 자동으로 이렇게 들어간다: 훅 0초 `impact`, B-roll 진입 `whoosh`, 빨간 박스/화살표 `pop`, 마스코트 글씨 `pop`, 구독 버튼 `click`, 큰 숫자 `ding`. 효과음은 목소리보다 작게(0.25~0.55 배).
- **R-S2** 원하는 효과음 파일이 있으면 project.json의 `sfx_files`로 바꿔 끼운다.

## 3. 자막

- **R-T1** Pretendard Medium 50px, 흰 글자, 검은 불투명 박스(여백 9px), 가운데 아래, 아래 여백 72px.
- **R-T2** 한 줄만, 최대 30자. 넘으면 문장 끝(. ? !) 또는 쉼표/연결어미에서 자동으로 나누고 시간도 글자 수에 비례해 나눈다.
- **R-T3** 강조 자막: `**문장**` 또는 `!문장` → 노란 글자 + 검은 박스. `"인용"` 또는 `[Q]문장` → 검은 글자 + 노란 박스. 영상당 5~10회만 쓴다.

## 4. 슬라이드 레이아웃

- **R-L1** 공통 틀: 왼쪽 위 섹션 라벨(회색 26px), 오른쪽 위 출처 "자료: …"(회색 24px), 제목 ExtraBold 68px, 부제 회색 34px, 그 아래 얇은 구분선, 본문 영역 y 352~880.
- **R-L2** 배경: 다크 #181614가 기본(70~75%), 정리·구조·목차는 크림 #F4F0E8(`theme: "cream"`).
- **R-L3** 뉴스 기사형 제목은 흰 박스 + 검은 글자(`title_style: "news"`, 두 줄은 `\n`).
- **R-L4** 슬라이드 오른쪽 아래에 마스코트 반응 스티커를 붙일 수 있다(`sticker`).
- **R-L5** 본문 레이아웃 5종:
  - `cards`: 숫자 카드 1~4장 + 카드 사이 → 화살표 + 아래 배너(`banner.accent`는 노란 굵은 글씨)
  - `bars`: 가로 막대 비교, 핵심 막대에 빨간 화살표(`arrow: true`)
  - `bignum`: 가운데 큰 빨간 숫자 + 빨간 모서리 괄호 + 캡션
  - `bullets`: 노란 막대가 붙은 항목 목록(`build_step`초 간격으로 하나씩)
  - `image`: 외부 차트/기사 캡처, 직접 만든 그래프 PNG
- **R-L6** 숫자 색: 상승·경고 = 빨강 `red`, 하락 = 파랑 `blue`(한국식), 결론·핵심 = 노랑 `yellow`, 보조 = 보라 `purple`/청록 `teal`.

## 5. 강조

- **R-E1** 빨간 테두리 박스(#FD000A, 두께 9px)를 말하는 순간에 켠다(`highlights: [{target:"card:1", at:1.5}]`, target은 `card:N`, `bar:N`, `bullet:N`, `bignum`, `image`. 좌표로 직접 지정하려면 `{rect:[x,y,w,h], at:2}`).
- **R-E2** 빨간 화살표로 차트의 한 점을 가리킨다(`pointers: [{x, y, angle, at}]`, angle은 화살표가 향하는 방향, 0 = 오른쪽, 90 = 위).
- **R-E3** 제목 빨간 밑줄(`underline: true`)은 0.3초에 켜진다. 챕터 첫 슬라이드나 핵심 주장에만.

## 6. 전환

- **R-X1** 기본은 하드컷. 슬라이드끼리는 효과 없이 바로 바꾼다.
- **R-X2** 챕터 시작: 앞 장면 0.3초 블랙 페이드 → B-roll(0.25초 블랙 뒤 135%→100% 줌 0.4초, 이후 106%까지 느린 푸시, `whoosh`) → 다음 슬라이드 첫 0.6초 분홍 플래시(#F6BFD3). 앞 장면 type이 `broll`이면 자동으로 적용된다.
- **R-X3** `transition`으로 덮어쓸 수 있다: `cut`, `flash`, `fade`. `fade_out: true`는 장면 끝 블랙 페이드.

## 7. 확대·축소

- **R-Z1** 훅: 장면 전체에 100%→107% 느린 줌인.
- **R-Z2** 슬라이드: 줌 없음.
- **R-Z3** 마스코트 컷인: 글씨가 뜨는 `at` 순간 100%→112% 펀치 줌(0.12초).
- **R-Z4** 인셋 자료(`pip`): 검은 배경, 72% 크기, 0.18초 페이드인.

## 8. 훅, 구독, 아웃트로

- **R-H1** 훅: 주제 인물/로고 사진이나 과장된 캐릭터 일러스트를 배경으로 깔고, 흰 박스 뉴스 헤드라인 1~2줄(ExtraBold 92px, 왼쪽 위). 첫 문장은 "여러분들 지금 ~ 난리 났죠?" 형식으로 시청자에게 바로 말을 건다.
- **R-C1** 구독 요청: 흰 배경, 마스코트 이미지, 위쪽에 "채널명 구독" 알약 버튼이 `click_at`초에 회색→분홍(#FF4F86)으로 눌린다(`click`). 캡션은 "도와주세요..제발" 같은 애원형 한 줄.
- **R-C2** 아웃트로: 구독 요청 뒤 엄지척 마스코트 한 컷, "저는 또 내일 맛있는 영상으로…" → "그럼 ㅃ"에서 하드컷으로 끝(엔드 페이드 없음).
- **R-M1** 마스코트 컷인은 영상당 2~4회, 펀치라인이나 질문 직후에 1.5~3초. 글씨는 초록 #7BE22E + 검은 외곽선 124px.

## 9. 대본 말투 (편집과 함께 쓰는 규칙)

- "형님들", "~죠?", "떡락/개박살/ㄷㄷ" 같은 구어체, 한 문장 15~30자, 분당 약 270자.
- 오프닝 숫자 2~3개 → "그래서 오늘 영상은요 ~ 아주 쉽고 재밌게 알아보도록 하죠" → 구독 요청 → "바로 가보죠" → "자, 일단 ~부터".

## 부록: project.json 형식

아래 `//` 주석은 설명용입니다. 실제 파일에는 넣지 마세요.

```json
{
  "voice": "voice.wav",          // 내레이션 (wav/mp3)
  "srt": "voice.srt",            // 내레이션 자막 (강조 표시 **, !, "" 사용 가능)
  "tighten": true,               // R-A1 무음 압축 (자막·장면 시각 자동 보정)
  "output": "output.mp4",
  "bgm": "bgm.mp3",              // 선택. 기본은 훅+아웃트로에만
  "sfx_files": {"whoosh": "my_whoosh.wav"},   // 선택
  "scenes": [
    {"type": "hook", "start": 0, "media": "assets/hook.png", "headline": ["헤드라인 1", "헤드라인 2"]},
    {"type": "slide", "start_line": 3, "section": "오프닝", "source": "자료: …", "title": "…", "subtitle": "…",
     "cards": [{"label": "…", "value": "15%", "unit": "돌파", "color": "red", "caption": "…", "at": 0}],
     "banner": {"text": "원인 →", "accent": "결과"},
     "highlights": [{"target": "card:1", "at": 1.5}], "pointers": [{"x": 1200, "y": 600, "angle": 135, "at": 2}],
     "sticker": "assets/mascot_peek.png", "theme": "dark", "underline": false},
    {"type": "slide", "start_line": 7, "title": "…", "bars": [{"label": "…", "value": 63, "text": "63억 달러", "color": "blue_num", "arrow": true}]},
    {"type": "slide", "start_line": 9, "title": "…", "bignum": {"value": "4.99", "unit": "%", "caption": "…"}},
    {"type": "slide", "start_line": 11, "title": "…", "image": "assets/chart.png"},
    {"type": "subscribe", "start_line": 12, "media": "assets/mascot_sub.png", "channel": "내채널", "caption": "도와주세요..제발"},
    {"type": "broll", "start_line": 13, "media": "assets/broll.mp4", "from": 3.0},
    {"type": "pip", "start_line": 20, "media": "assets/old_thumbnail.jpg"},
    {"type": "mascot", "start_line": 25, "media": "assets/mascot.png", "caption": "거품이냐 아니냐", "at": 0.3},
    {"type": "outro", "start_line": 40, "media": "assets/mascot_thumb.png"}
  ]
}
```

- 장면 시작은 `start`(초, 원본 음성 기준) 또는 `start_line`(srt 줄 번호, 1부터) 중 하나. 장면 끝은 다음 장면 시작이다.
- 장면 안의 `at`은 그 장면 시작부터 센 초.
- 모든 장면에 `"sfx": [{"name": "pop", "at": 1.2}]`로 효과음을 더 넣을 수 있다.

# 출근길 경제뉴스 3줄 (morning-news)

PC 전용(Voicebox, ffmpeg 필요). 폰에서는 `경제뉴스_폰연결.bat`으로 연 원격 세션에 사진을 첨부한다.

## 경로
- 스크립트: `%USERPROFILE%\.claude\skills\morning-news\scripts\` (make_news.py, upload.py)
- 파이썬: `C:\Users\Admin\Videos\morning-news\.venv\Scripts\python.exe`  (실행 전 PYTHONHOME/PYTHONPATH 비우기, PYTHONIOENCODING=utf-8)
- 작업폴더: `C:\Users\Admin\Videos\morning-news\YYYYMMDD\`
- 업로드 기록(중복 방지): `C:\Users\Admin\Videos\morning-news\uploaded.json`

## 절차
1. 첨부 파일 구성: 매일 **뉴스 기사 사진 29장 + GIF 1개**. **GIF(.gif, 움직이는 그림)는 무조건 제외**하고 영상·요약·개수 계산에 넣지 않는다. 확장자가 바뀌어 왔더라도 움직이는 그림/인사 카드/광고처럼 기사 지면이 아닌 이미지는 뺀다. 남은 기사 사진(보통 29장)만 쓴다. 이미지 1장 = 기사 1개가 기본. 같은 사건 기사는 하나로 합치고, 광고/부고/인사/사진만 있는 지면은 뺀다. 날짜는 오늘(KST).
2. 기사마다 **직접 다시 쓴** 요약을 만든다 (원문 문장 복사 금지, 저작권):
   - `title`: 25자 안팎, 핵심 숫자/고유명사 포함, 강조할 부분은 `**...**`
   - `say`: 쇼츠에서 읽을 낭독문 = 제목 + 핵심 한 줄, **30~40자**(쉼표로 이어 한 호흡). 29개 기준 기사당 약 5.5초. 스크립트가 남는 시간은 카드 노출로 채우고(목표 170초), 넘치면 여백 축소 후 말 속도를 최대 1.5배까지 올려 178초 안에 맞춘다.
   - `lines`: 정확히 3줄, 줄당 18자 이내 짧은 명사형/요약체 (화면에만 표시), 강조는 `**...**` 한 곳 정도
   - `cat`: 증시/환율/금리/채권/부동산/산업/기업/정책/글로벌/가상자산 중 하나
   - `source`: 이미지에서 확인되는 신문명(모르면 생략)
   - 순서: 중요도/화제성 높은 순. 맨 앞 기사가 썸네일·제목에 들어간다.
3. `news.json` 작성 (UTF-8):
```json
{"date":"2026-11-12",
 "items":[{"cat":"증시","source":"한국경제","title":"...","lines":["...","...","..."]}],
 "shorts":[0,2,5],
 "youtube":{"title":"11월 12일 출근길 경제뉴스 30개 | 첫 기사 핵심 한 줄 (100자 이내)"},
 "shorts_youtube":{"title":"..."}}
```
   롱폼도 원하면 `"long": true` 추가 (기본은 쇼츠만).
4. 렌더: `python make_news.py <작업폴더>` -> shorts.mp4, shorts_thumb.jpg, upload.json. 스크립트가 총 길이를 재서 178초를 넘으면 여백을 줄이고 말 속도를 최대 1.5배까지 자동으로 올린다. 그래도 넘으면 오류로 멈추니 say를 더 줄여 다시 실행. 음성 생성은 Voicebox CPU라 29개에 약 15~25분. 오래 걸리니 백그라운드로 돌리고 log를 확인한다. 중간에 끊겨도 다시 실행하면 만든 음성은 재사용된다.
5. long.mp4 길이, thumb.jpg를 확인한 뒤 업로드: `python upload.py <작업폴더>` (즉시 공개, 롱폼+쇼츠). 채널명이 '월급쟁이 재테크 스킬'이 아니면 자동 중단된다.
6. 결과 링크 2개를 사용자에게 짧게 보고.

## 규칙
- 신문 지면 이미지를 영상에 넣지 않는다. 우리 카드 디자인 + 직접 쓴 요약만.
- 말 속도 기본 1.2배 (환경변수 NEWS_SPEED로 변경).
- 같은 날짜는 두 번 올리지 않는다(uploaded.json). 재업로드가 필요하면 사용자 확인 후 해당 키를 지운다.
- 설명란에 '직접 요약, 투자 판단은 본인 책임' 고지가 자동으로 들어간다.

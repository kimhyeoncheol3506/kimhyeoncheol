# 와따마 스타일 개그 짤

편집기: `scripts/wadda_edit.py render <project.json>` (표준 라이브러리 + ffmpeg, 폰트 `scripts/fonts`: Black Han Sans, Pretendard).

## 규칙집 (와따마 쇼츠 3편 실측, 2026-11-05)

| 코드 | 규칙 |
|---|---|
| R-W1 구성 | 한 인물, 챕터 4~6개, 챕터당 12~30초, 총 80~170초. 챕터 사이는 하드컷 |
| R-W2 제목 | 챕터마다 "짧은 주제;" (세미콜론으로 끝남). 위쪽 y≈300, 검정 극굵은 글씨 + 흰 외곽선. 영상 제목은 "[특징 묘사] [이름]ㅋㅋ" |
| R-W3 화면 | 720x1280 흰 배경(#FFFEF9). 원본을 720x520 띠로 크게 크롭해 y=360에 배치. 원본에 박힌 자막·로고는 크롭으로 잘라낸다(챕터별 `x`,`y`,`zoom`) |
| R-W4 자막 | 클립 띠 안쪽 아래, 한 줄 14자 이내, 굵은 글씨 + 검정 외곽선. 주인공 노랑, 상대 초록, 소리치기/핵심 빨강, 제3자 흰색, `(상황 설명ㅋㅋ)` 흰색 작게. 단어 강조 `[red:단어]` |
| R-W5 강조 | 펀치라인에 큰 빨강 팝 텍스트(크게 튀어나왔다 줄어듦) + 화면 펀치 줌(1.2~1.3배) + 팝 효과음. 챕터당 1~2번 |
| R-W6 댓글 | 클립 아래에 흐린 아바타 + 흐린 닉네임 + 댓글 한 줄. 원본 영상의 실제 인기 댓글을 쓴다 |
| R-W7 컷 | 원본 컷을 살리고 말 사이 빈 구간만 잘라 분당 15~20컷 템포 유지. 음량 약 -12~-13 LUFS |

## 실행 순서

1. 인물의 웃긴 소스 영상을 `youtube.search`로 찾는다. 가능하면 본인 채널(예: 이수지 → 핫이슈지) 콘텐츠를 쓴다. 기존 와따마 짤과 겹치지 않는 주제를 고른다.
2. `youtube.getTranscript(id,{lang:'ko',includeTimestamp:true})`로 웃긴 구간 4~6개를 고른다.
3. 셸에서 yt-dlp로 그 구간만 받는다: `--download-sections "*MM:SS-MM:SS" --force-keyframes-at-cuts --ffmpeg-location <ffmpeg bin>`. TEMP/TMP는 쓰기 가능한 폴더로 지정한다. 단어 단위 타이밍이 필요하면 `--write-auto-subs --sub-langs ko --sub-format json3`로 받는다(tStartMs + tOffsetMs).
4. 프레임 시트로 원본 자막과 로고 위치를 확인하고, 챕터별 크롭을 정한다.
5. project.json을 쓴다. 형식은 아래 예시와 같고, 자막 시각은 챕터 `in` 기준 초다. 자동자막이 불확실한 대사는 원본에 박힌 자막을 보고 고치거나 빼고, 지어내지 않는다.
6. 렌더한 뒤 프레임 시트로 검수하고, mp4를 artifacts에 복사한다.

```json
{"output":"짤.mp4","chapters":[{"title":"제이미맘;","src":"src/jamie.mp4","in":9.4,"out":26.2,"x":0.5,"y":0.35,"zoom":1.45,
 "comments":[{"at":0,"text":"실제 인기 댓글"}],
 "subs":[{"t0":0.1,"t1":2.0,"text":"소피아는 그러면"},{"t0":12.6,"t1":14.6,"text":"[red:사이판]까지 갔을 거예요","color":"green"},{"t0":7.3,"t1":9.3,"text":"(논리 무엇ㅋㅋ)","style":"paren"}],
 "pops":[{"at":12.75,"text":"사이판?!","zoom":1.25}]}]}
```

## 사용자 고정 규칙 (2026-11-05 지시)

- 챕터 제목은 세미콜론을 **앞에** 붙인다: `;제이미맘` (`제이미맘;` 아님).
- 길이 약 2분30초 = 24초 챕터 6개.
- 저장 위치는 항상 `%USERPROFILE%\Downloads\어럏`, 파일명은 `이름 번호.mp4` (김원훈 1, 김원훈 2 ...). 이미 있는 번호는 건너뛰고 다음 번호를 쓴다.
- 영상을 하나 만들 때마다 같은 폴더의 `쇼츠 일기장.txt`에 항목을 덧붙인다: 일시, 제목, 파일, 주제, 영상내용(챕터별 `;제목 - 출처 채널(영상제목)`).
- 장면 고르기: 다른 게스트·MC가 크게 웃는 순간을 우선한다. 자동자막(json3)의 `[웃음]`/`[박수]` 마커가 몰린 24초 구간을 점수로 뽑는다.
- 다 끝나면 PC 알림(notification 도구)으로 알린다 ("푸시" = PC 알림).

## 대량 제작 파이프라인 (`scripts/batch`)

1. REPL에서 인물별 후보를 `youtube.search`로 찾는다(레전드, 빵터짐, 라디오스타, 아는형님, 토크). 제목에 이름이 있고 2~50분인 영상만 남긴다. `getTranscript`로 `[웃음]` 개수를 세어 상위 8~10개를 고른다. 실제 댓글(6~32자)을 얻어 `sources.json`({이름:[{id,title,channel,dur,comments}]})으로 저장한다.
   - REPL이 없는 환경(Claude Code 등)에서는 `python find_sources.py 이름1 이름2`로 같은 일(검색, 웃음 마커 집계, 댓글)을 해서 sources.json을 만든다.
2. `python select2.py`: 구간 선택, 텍스트 유사도로 같은 방송 재업로드 중복 제거, 자막 청크(13자, `>>` 화자 전환 시 노랑/초록 교대)를 만들어 `segments.json`에 저장한다.
3. `python -u dl.py`: yt-dlp 구간 다운로드(4개 동시, 1개당 약 30초). 셸은 yield로 돌린다.
4. 구간 대사를 보고 `titles.json`({이름:{videos:[5개 영상 제목], ch:{구간번호:[";제목","팝 문구"]}}})을 쓴다. 자막이 깨진 구간이나 중복 구간은 빼고 번호를 넣지 않는다.
5. `python batch.py ["이름 번호"]`: 점수순 라운드로빈으로 5편에 나눠 렌더하고, 어럏 폴더 저장과 일기장 갱신까지 한다. `run_all.ps1`은 다운로드가 끝날 때까지 기다렸다가 전부 렌더한다.
6. `python meta.py`: 영상마다 업로드용 `이름N.TXT`(예: `김원훈1.TXT`)를 어럏 폴더에 만든다. 내용은 [제목] `영상제목 #shorts`, [설명] 소개 2줄 + 챕터 타임라인 + 원본 출처(채널·제목·링크) + 권리 고지, [해시태그] 10개 안팎, [태그] 쉼표 구분이다. 새 인물이 나오면 meta.py의 INFO에 소개 문구와 태그를 추가한다.
7. 썸네일: `.venv\Scripts\python.exe scripts\batch\thumbs2.py ["이름 번호"]`. 영상을 0.4초마다 훑어 얼굴을 찾고(YuNet), 기준 얼굴(`scripts/refs/이름_*.jpg`)과 같은 사람(SFace 유사도 0.36 이상)인 프레임 중 얼굴이 가장 크고 선명한 프레임을 저장한다. 파일명은 영상과 같은 `이름 번호.jpg`이다(720x1280, 제목·자막·댓글이 들어간 영상 화면 그대로). 새 인물은 refs에 본인 얼굴이 크게 나온 사진 1~3장을 넣는다(예: 와따마 쇼츠 썸네일 `i.ytimg.com/vi/<id>/maxresdefault.jpg`). `--check`로 기준 얼굴 크롭을 확인하고, 다른 사람이면 지운다. 가장 큰 얼굴만 보면 서장훈·강호동 같은 다른 출연자가 뽑히므로 본인 확인을 꼭 한다.
   - venv 설치(처음 한 번): Aside 셸에서 `PIP_*`, `PYTHONHOME`, `PYTHONPATH`, `PYTHONNOUSERSITE`, `VIRTUAL_ENV`를 지운 뒤 uv python 3.11로 `python -m venv .venv`를 만들고 `pip install "opencv-python-headless<5" numpy`. OpenCV 5에는 CascadeClassifier가 없다. 모델 파일은 `scripts/models`(opencv_zoo의 yunet 2023mar, sface 2021dec)이다.
8. 완료하면 PC 알림을 보낸다. 한 편을 만들 때마다 산출물은 `이름 N.mp4`, `이름N.TXT`, `이름 N.jpg`, 일기장 항목이다.
- 한계: 자막은 유튜브 자동자막 그대로라 오타가 있다. 원본에 박힌 방송 자막이 가끔 같이 보인다.

## 주의

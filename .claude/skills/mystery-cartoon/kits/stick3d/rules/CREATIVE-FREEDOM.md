# CREATIVE FREEDOM (anti-template engine)
You are allowed and expected to invent: new rooms, props, poses, camera moves, transitions, visual metaphors. Templates are forbidden.
Per scene: (1) quote the exact words (2) write 3 genuinely different ideas, each with a camera path and a character action (3) pick the most unexpected one that still serves the words (4) check the ledger: neighbours must differ in layout, camera, transition, action, colour world (5) build (6) log.
Idea prompts: change the scale (tiny character vs huge object), change the viewpoint (through a keyhole, from the ceiling, from inside a drawer), make the metaphor literal (a falling chart = stairs the character tumbles down), use the environment as the joke (the room itself reacts), use time (speed ramps, day->night), use cause-and-effect chains (domino), use contrast cuts. Reuse helpers, never layouts.
Ceiling: director-level cinematography inside a CPU toon engine. Say honestly when something would need Blender.

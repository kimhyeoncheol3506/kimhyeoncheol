# 네이버 블로그 글 구조

| 항목 | 기준 |
|---|---|
| 제목 | "지역 + 업종 + 주제" 공식, 25자 안팎, 느낌표 0개에서 1개 |
| 첫 문단 | 3문장, 훅 패턴 하나로 시작, 지역이나 업종 키워드 1회, 누가 어떤 상황에서 읽는 글인지 밝히기 |
| 소제목 | 3개에서 5개, 각 소제목 아래 2문단에서 3문단 |
| 본문 길이 | 공백 포함 1,200자에서 1,800자(해시태그 줄 제외) |
| 사진 자리 | 소제목마다 1장, "[사진: 설명]" 형태로 자리만 표시, 사진 폴더를 받으면 그 자리에 사진 업로드 |
| 사진 설명 | 사진마다 20자 안쪽 한 줄, 사진에 실제로 보이는 것만 적기 |
| 마지막 문단 | 아래 마무리 패턴(이용 방법, 문의 방법, 찾아오는 길) 중 한 가지로 끝내기, 요약과 다음 글 예고 금지 |
| 해시태그 | 3개에서 5개, 본문 마지막 줄 |

## 제목 공식

공식은 "지역 + 업종 + 주제"입니다. 네이버 검색은 제목에 든 단어를 먼저 봅니다. 손님이 검색창에 칠 만한 말을 앞쪽에 둡니다.

| 요소 | 규칙 | 예 |
|---|---|---|
| 지역 | 구나 동 이름을 앞쪽에 | 마포구 서교동 |
| 업종 | 손님이 검색하는 말 그대로 | 베이커리 |
| 주제 | 글에서 답하는 것 하나 | 예약 방법 안내 |
| 길이 | 25자 안팎 | 마포구 서교동 베이커리 예약 방법 안내 |
| 부호 | 느낌표 0개에서 1개 | 느낌표는 쓰지 않아도 됩니다 |

위 예는 형식을 보이기 위한 것입니다. 실제 지역과 업종은 가게정보.md 값으로 채웁니다.

## 첫 문단 훅 패턴

첫 문장에서 읽는 사람이 "내 이야기다"라고 느끼게 합니다. 아래 네 가지 중 하나를 고릅니다. 과장이나 낚시성 문장은 쓰지 않습니다.

| 패턴 | 만드는 법 | 쓰면 안 되는 형태 |
|---|---|---|
| 상황 제시 | 손님이 처음 가게를 찾는 장면이나 고민하는 장면을 한 문장으로 | "충격적인 비밀 공개" 같은 낚시 |
| 질문 | 가게정보.md의 "손님이 자주 묻는 것"을 그대로 질문으로 | 답이 글에 없는 질문 |
| 손님 한마디 | 손님이 실제로 자주 하는 말을 짧게 인용. 가게정보.md에 적힌 말만 | 지어낸 후기, 지어낸 손님 |
| 바로 안내 | 이 글에서 알려 줄 것을 첫 문장에 밝히기 | "오늘 알아볼 내용은 ~입니다" |

첫 문단 3문장 구성은 이렇습니다.

1. 훅 문장
2. 이 글을 읽으면 알게 되는 것(키워드 1회 포함)
3. 가게 이름과 지역 한 줄

## 소제목 순서 예시

1. 어떤 분에게 맞는 안내인지
2. 이용 방법(시간, 결제, 예약)
3. 대표 상품이나 시설 소개
4. 자주 묻는 질문 두세 개

글의 주제에 맞게 순서를 바꿔도 됩니다. 소제목끼리 내용이 겹치지 않게 합니다.

## 마무리 패턴

마지막 문단은 아래 중 하나로 씁니다. 한 가지만 고릅니다.

| 패턴 | 예 |
|---|---|
| 이용 방법 한 가지 | "예약은 전날까지 받습니다." |
| 문의 방법 한 가지 | "궁금한 점은 방문하실 때 편하게 물어봐 주세요." |
| 찾아오는 길 한 줄 | 가게정보.md의 위치 설명 그대로 |

금지

- 요약 문단("정리하면", "지금까지 ~였습니다")
- 다음 글 예고("다음 글에서는")
- 구독이나 이웃 추가 요청

## 해시태그 규칙

| 항목 | 규칙 |
|---|---|
| 개수 | 3개에서 5개 |
| 위치 | 본문 마지막 줄에 한 줄로. 네이버 에디터의 태그 칸은 건드리지 않음 |
| 구성 | 지역 + 업종 1개, 주제 1개에서 2개, 가게 이름 1개 |
| 형식 | 공백 없이 "#마포구베이커리" 형태, 태그 사이는 한 칸 띄우기 |
| 금지 | 가게와 상관없는 인기 태그, 다른 가게 이름, 같은 뜻 반복 |

해시태그 줄은 본문 글자 수에 넣지 않습니다.

## 하지 않을 것

- 제목에 느낌표 두 개 이상
- "꿀팁", "대박", "강추" 같은 과장 표현
- 글 끝의 "지금까지 ~였습니다" 식 마무리
- 다른 가게 이름 언급
- 가게정보.md에 없는 가격, 시간, 혜택

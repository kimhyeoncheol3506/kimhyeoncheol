# 네이버 에디터 임시저장 순서

발행 버튼은 누르지 않습니다. 임시저장까지만 합니다.

## 준비

- 브라우저 세션에는 naver.com 쿠키만 넣습니다.
- 쿠키 값은 화면과 로그에 출력하지 않습니다.
- 작업이 끝나면 쿠키 파일을 지웁니다.
- 저장 전에 상단 "저장" 버튼 옆의 임시저장 글 수를 적어 둡니다. 6단계에서 비교합니다.

## 순서

| 단계 | 할 일 | 확인 |
|---|---|---|
| 1 | blog.naver.com 에 들어가 글쓰기 버튼을 누른다 | 에디터 화면이 열린다 |
| 2 | 이전 임시저장 글을 불러올지 묻는 창이 뜨면 "아니오"를 고른다 | 빈 에디터 |
| 3 | 제목 칸에 제목을 입력한다 | 제목이 보인다 |
| 4 | 본문 칸에 소제목과 본문을 순서대로 입력하고, 마지막 줄에 해시태그 줄을 쓴다 | 줄바꿈이 유지된다. 태그 칸은 비어 있다 |
| 5 | 사진 폴더를 받았으면 사진 자리마다 그 사진을 올리고, 받지 않았으면 "[사진: 설명]" 텍스트로 남긴다 | 폴더가 없으면 사진 업로드는 하지 않는다 |
| 6 | 상단의 "저장" 버튼을 누른다 | "저장" 버튼 옆 임시저장 글 수가 1 늘어난다 |
| 7 | 저장 목록을 열어 방금 글을 다시 연다 | 제목, 본문, 해시태그 줄이 그대로 있다 |

## 게이트 5 통과 기준

| 확인 | 기준 |
|---|---|
| 글 수 | "저장" 버튼 옆 임시저장 글 수가 저장 전보다 정확히 1 많다 |
| 내용 | 다시 연 글의 제목과 소제목 수가 쓴 글과 같다 |
| 해시태그 | 마지막 줄에 해시태그 3개에서 5개가 있다 |
| 상태 | 글이 발행 상태가 아니다 |

글 수가 2 늘었으면 중복 저장입니다. 방금 글이 아닌 중복본은 지우지 말고 보고에 적습니다.

## 하지 않을 것

- "발행" 버튼 클릭
- 공개 설정, 카테고리 변경
- 에디터 태그 칸 입력
- 다른 탭이나 다른 사이트 접속

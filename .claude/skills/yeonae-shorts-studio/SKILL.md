# 연애 듀토리얼 스튜디오 v1.1.0

코드: `shorts-studio/` · 변경 이력: `shorts-studio/CHANGELOG.md` (스킬을 고치면 버전 올리고 이력 남길 것)
목소리: 반드시 `yeouido-voice` 스킬 규격(여의도남자/여의도여자). 다른 TTS로 대체 금지.

## 0. 소재 선정 규칙 (트리거)
| 소스 | 조건 | 결과물 |
|---|---|---|
| X @bingbingblind (빙글빙글 블라인드) 최신순 | 조회수 **3,000 이상** & 아직 안 만든 글 | 쇼츠 25~35초 (블라인드 스샷 띄우고 낭독) |
| X @BBstyle0508 (Secret BB) 최신순 | 조회수 **5,000 이상** & 아직 안 만든 글 | 롱폼 3~5분 (주제만 차용, 원문 복제 금지) |
- 이미 만든 소재는 `shorts-studio/projects/*/script.json`의 `source`로 중복 확인.
- 실명·회사명·얼굴은 가린다(블라인드 회사 배지 → 회색 원 처리, 음성에서는 "대기업"으로).
- 원문이 미성년자·범죄 피해·특정 개인 저격이면 제작하지 않는다.

### 소재 들어오는 길 (현철님 결정, v1.1.0)
1. **휴대폰 스샷** (기본): 현철님이 스샷을 올리면 바로 제작.
   `python tools/card_from_screenshot.py <스샷> projects/short_NNN_키워드 --mask x0,y0,x1,y1`
   → source_card.png + card_regions.json(line1..N) + debug.png(줄 번호 확인용). 회사 배지·실명은 --mask로 가림.
2. **PC 크롬 주기 조회**: 데스크탑 Claude 앱(Claude in Chrome 연결된 세션)에서 두 계정 최신순 조회 →
   게시물 JSON 저장 → `python monitor/watch.py --posts posts.json` → queue.json 소재로 제작. (클라우드 세션은 X 접근 불가)

### 수위 게이트 (노란딱지 방지, 필수)
- `tools/safety.py`가 원문·후크·음성·자막을 검사(make.py가 자동 실행) → 안전/주의/위험.
- **주의·위험이면 제작 전에 현철님께 먼저 묻는다**: "수위가 ○○(이유) 정도인데 올려도 될까요? 순화 버전도 가능합니다."
- 원문 이미지 자체의 수위(사진, 초성 욕설 등)는 키워드 검사가 못 잡으므로 스샷을 직접 보고 판단해 safety.level을 올린다.
- 승인(`safety.approved: true`) 전에는 업로드 목록에 넣지 않는다.

## 1. 쇼츠 포맷: "사연 낭독 + 판정소"
1. **후크 0~1.5초**: 상단 고정 타이틀(Black Han Sans, 노랑 키워드) 팝인 + boom + 흰 플래시. 첫 대사는 2초 이내 질문형("회사 회의실에서, 이걸 했다고요?").
2. **본문**: 스샷 카드가 튀어오르고, 읽는 줄에 형광펜(곱하기 블렌드)이 그어지며 카드가 그 줄로 줌. 장면마다 펀치줌(1.05→1) + whoosh.
3. **판정소**: 여의도여자(판사 톤) — 빨간 "판 정 소" 배지 → 카드 어둡게 → 마지막 단어에 도장(stamp+boom+흔들림+플래시).
4. **CTA**: "여러분이 ○○였다면?" 댓글 유도 → 첫 장면 질문과 이어져 루프 시청 유도.
- 자막: Pretendard ExtraBold 84px, 흰 글씨+검정 외곽 10px, `*키워드*`는 노랑. 한 덩어리 ≤ 14자, 하단 UI(1600px 아래) 피함.
- 금지어: "바람/불륜/섹스" 등은 **자막에만**(필요 시 초성), 음성은 "이걸", "그거", "회의는 아니었습니다"처럼 돌려 말한다.
- 상단 노란 진행바(리텐션).

## 2. 롱폼 포맷: "이 지도 한 장이면 끝" (혼잡스 지도 + 인생녹음중 꽁트)
- 구조: 꽁트 후크(남·여 대화 2컷) → 타이틀 카드(검은 박스, 주황 키워드) → 지도 전체보기 → 4구역을 카메라가 날아다니며 손글씨로 채움 → 구역마다 여자 속마음 꽁트 1컷 → 전체 정리 → 다음 편 예고 꽁트.
- 지도: 3840x2160 캔버스, 구역당 1920x1080. 제목 Jua 140, 본문 PoorStory 92, 주황 마커 동그라미, 체크박스, 아이콘(돈·티켓·말풍선·시계·소주·폰·하트).
- 꽁트: 파스텔 배경 + 콩 캐릭터(남=머리 4가닥, 여=긴 머리), 실제 음성 크기로 입 싱크, 말풍선 자막.
- 20초 이상 같은 화면 금지 — 꽁트/지도를 번갈아.
- 남자=설명(내레이터), 여자=여자 입장 속마음/반박. 여자 대사엔 `instruct`로 감정 지시.

## 3. 제작 절차
```bash
cd shorts-studio
# (1) 새 프로젝트: projects/<short_NNN_키워드>/script.json 작성 (기존 프로젝트를 복사해 수정)
#     쇼츠는 source_card.png(스샷 카드만 크롭+회사 가림)와 card_regions(줄 좌표) 필요
# (2) 음성: PC 연결 시 Voicebox, 아니면 클라우드에서 Qwen3-TTS 직접
python make.py projects/<프로젝트> --voice voicebox            # 현철님 PC
python make.py projects/<프로젝트> --voice cloud --tts-python <venv>/bin/python --models <모델폴더>
# (3) 빠른 확인: 특정 시점 프레임 PNG
python make.py projects/<프로젝트> --frames 1.0,5.0,20.0
# 결과: output/<프로젝트>/video.mp4, thumbnail.jpg, upload.json
```
- 클라우드 TTS 준비: `pip install qwen-tts soundfile faster-whisper` + HF `Qwen/Qwen3-TTS-12Hz-1.7B-{Base,CustomVoice,VoiceDesign}`.
- 목소리 후처리(자동): 긴 무음 0.22초로 압축 → 저역 정리 → 가슴/발음 EQ → 방송 컴프레서, 최종 믹스 loudnorm -14 LUFS. 속도 조절은 1.05배 이하 권장(그 이상은 기계음 느낌).
- 여의도남자 기준음성: `assets/voices/여의도남자_기준음성.wav`. PC의 `~/.yeouido-voice/여의도남자_기준음성.wav`로 교체하면 PC와 100% 같은 목소리.

## 4. 품질 게이트 (통과 못 하면 업로드 금지)
- [ ] `voice/qa.py` 전 장면 일치율 ≥ 0.85 (Whisper 받아쓰기 vs 대본). BAD는 `--only sXX --seed N`으로 재생성.
- [ ] 음성 길이 폭주 없음 (qwen_local이 예상 길이 0.6~1.6배 밖이면 자동 재시도)
- [ ] 프레임 시트로 자막 잘림·겹침·글리프 누락(□) 확인
- [ ] 쇼츠 25~40초, 롱폼 3~5분
- [ ] 회사명/실명/얼굴 가림, 음성 금지어 없음
- [ ] upload.json 제목 ≤ 60자, 해시태그 3~5개
- [ ] 최종 mp4를 다시 받아써서(Whisper) 목소리가 실제로 들어갔는지 확인, 음량 -14 LUFS
- [ ] 수위 '주의' 이상이면 현철님 승인 받았는지

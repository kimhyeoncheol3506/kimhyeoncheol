# 연애 듀토리얼 스튜디오 v1.5.0

코드: `shorts-studio/` · 변경 이력: `shorts-studio/CHANGELOG.md` (고치면 버전 올리고 이력 남김)
목소리: 반드시 `yeouido-voice` 규격(여의도남자/여의도여자). 다른 TTS로 대체 금지.

## 0. 운영 원칙 — 묻지 말고 만든다 (현철님 지시)
- **스샷 업로드 또는 제작 명령이 오면 확인 질문 없이 즉시 제작** → 완료되면 알림(PushNotification) + 파일 전송(video.mp4, thumbnail.jpg) + `upload.txt` 내용을 메시지에 그대로 붙여 준다.
- 판단이 필요한 것(테마, 제목, 주제, 컨셉)은 이 스킬 규칙대로 스스로 정한다.
- **유일한 예외 = 수위.** `tools/safety.py`가 '주의/위험'이면 제작은 끝까지 하되, 알림 첫 줄에
  `⚠️ 수위 주의(이유) — 이대로 올려도 될까요? 순화 버전도 바로 만들 수 있습니다.` 를 붙이고 승인 전엔 업로드 목록에서 뺀다.
  스샷 자체의 수위(사진·초성 욕설·노출)는 키워드 검사가 못 잡으니 이미지를 직접 보고 판단한다.
- 하루 목표: **쇼츠 2개 + 롱폼 1개.** "오늘치 만들어" = `python tools/plan.py`로 다음 컨셉·주제 확인 후 3편 제작.

## 0-1. 명령 → 할 일 (확인 질문 없이 바로)
| 현철님 입력 | 만드는 것 |
|---|---|
| 스샷 + "쇼츠" | 컨셉 A 사연 판정소: 스샷 카드 추출(파일이 없으면 `tools/make_card.py`로 글을 옮겨 카드 재구성) → 대본 → 음성 → 렌더 |
| 스샷 + "롱폼" | 스샷 내용(사연·게시물)을 주제로 롱폼 '연애 공략 지도' 3~5분 대본을 새로 씀(원문 복제 X, 주제만) → 썸네일 박스 문구 2줄 → 렌더 |
| 스샷만 | 연애 사연/게시물이면 쇼츠, 긴 글·조언형이면 롱폼으로 판단 |
| "쇼츠" (스샷 없음) | 컨셉 B 카톡 판독소, 주제 은행 다음 주제 |
| "롱폼" (스샷 없음) | 주제 은행 다음 롱폼 주제 |
| "오늘치" | 쇼츠 2 + 롱폼 1 |
- 새 세션 첫 제작이면 먼저 `bash shorts-studio/setup_cloud.sh`를 백그라운드로 시작(10~15분, 음성 엔진·모델 준비)하고 그동안 대본·화면을 만든다.
- 완료 알림 = PushNotification + 영상·썸네일 파일 + upload.txt 내용.

## 0-1b. 개인정보 가림 (현철님 지시, 매번 자동 — 다시 묻지 않음)
- **스샷 속 개인 아이디·닉네임은 첫 글자만 남기고 나머지는 별표**: `Abcd12 → A*****`, `bingbing99 → b*********`. 화면·자막·음성·업로드 문구 어디에도 원래 아이디를 쓰지 않는다.
  - 재구성 카드: `card.json`에는 처음부터 가린 아이디(예: A*****)를 적는다(원래 아이디를 저장소에 남기지 않음). `"mask_ids"`는 붙여넣은 원문을 자동 치환할 때만 쓰고 저장 전에 지운다
  - 원본 스샷 사용: `tools/card_from_screenshot.py ... --relabel x0,y0,x1,y1,Abcd12` (그 자리를 지우고 A*****처럼 다시 씀)
- 회사명·회사 배지: 가림(회색 원), 음성은 "대기업/공기업" 등으로. 게시판·채널 이름(예: '썸·연애', '공무원')은 그대로 둬도 됨.
- 실명·얼굴·전화번호·사는 동네(구 단위 이하)는 무조건 가림.
- 스샷 해상도가 낮으면(가로 700px 미만) 원본 대신 글을 옮겨 `make_card.py`로 선명하게 다시 그린다.

## 0-1c. 파일 이름 (현철님 지시, 매번 자동)
- 영상·썸네일·업로드 문구 파일 이름 = **영상 제목 앞 두 글자** (공백·기호 제외). 예) "예비 시댁 '이혼 서류'…" → `예비.mp4`, `예비.jpg`, `예비.txt`
- 같은 앞 두 글자가 이미 있으면 `예비2`, `예비3`… / 순화본은 `예비(순화)` (`state/names.json`에 기록, `tools/naming.py`)
- `output/_업로드/` 한 폴더에도 전부 모아 둔다. 현철님께 보낼 때도 이 이름의 파일을 보낸다.

## 0-1d. 여러 스샷이 연달아 오면
- 들어온 순서대로 대기열로 처리(앞 작업 렌더 중에 다음 대본·음성을 병렬로). 각각 끝날 때마다 알림.
- '위험' 수위(노골적 성 묘사·성기 언급 등 커뮤니티 가이드 위반 가능)는 **제작하지 않고 보류** → 사유와 대안(순화 각색/건너뛰기)을 물어본다. '주의'는 만들고 알림 첫 줄에 확인 요청.

## 0-2. 발음 마지막 점검 (필수)
1. TTS 직전 `voice/pronounce.py`가 읽는 글만 자동 교정(자막은 그대로): 숫자→한국식 읽기(7시→일곱 시, 3개→세 개, 1시간 46분→한 시간 사십육 분, 25만 원→이십오만 원), 영문 약어→한글(MBTI→엠비티아이), 자모(ㅎㅎ→흐흐, ㅠㅠ 삭제), `voice/lexicon.json` 대체어.
2. 생성 후 `voice/qa.py`(Whisper) 받아쓰기로 확인. 같은 단어가 2번 이상 뭉개지면 **한국인이 실제로 쓰는 더 자연스러운 말로 바꿔** 다시 생성하고, 그 쌍을 `lexicon.json`에 추가(다음부터 자동).
3. 판정·도장 직전 마지막 단어는 명사로 끝내지 말고 서술어를 붙인다("로또." ✗ → "로또입니다." ✓) — TTS가 끝 단어를 흘림.
4. 대본을 쓸 때부터: 번역투·문어체(~하였습니다, ~에 있어서) 대신 말하는 구어체, 한 문장 25자 안팎, 어려운 한자어는 쉬운 말로.

## 1. 소재 들어오는 길
1. **휴대폰 스샷**(기본) → 컨셉 A. `python tools/card_from_screenshot.py <스샷> projects/short_NNN_키워드 --mask x0,y0,x1,y1`
   → source_card.png + card_regions.json(line1..N) + debug.png. 회사 배지·실명은 --mask로 가림, 음성은 "대기업".
2. **PC 크롬 주기 조회**(데스크탑 Claude 앱 + Claude in Chrome 세션에서만): @bingbingblind 조회수 ≥3,000 → A, @BBstyle0508 ≥5,000 → 롱폼 주제.
   게시물 JSON → `python monitor/watch.py --posts posts.json` → `monitor/queue.json`. (클라우드 세션은 X 접근 불가)
3. **주제 은행** `state/topics.json` — 스샷이 없을 때 B 쇼츠와 롱폼 주제를 여기서 꺼낸다(리서치 기반 핫키워드).
- 원문이 미성년자·범죄 피해·특정 개인 저격이면 제작하지 않는다.

## 2. 쇼츠 — 두 컨셉 홀짝 교대
`tools/plan.py`가 마지막 쇼츠 컨셉을 보고 다음 컨셉을 정한다. A용 스샷이 없으면 B로 대체.

| | A. 사연 판정소 (`concept: card`) | B. 카톡 판독소 (`concept: kakao`) |
|---|---|---|
| 소재 | 블라인드 스샷 | 주제 은행의 카톡 상황(읽씹·답장·호감 신호) |
| 화면 | 스샷 카드 + 읽는 줄 형광펜 줌 | 카톡 대화 재현: 말풍선 팝, 입력중 '...', 읽음 '1' 사라짐, 답장 시간 마커 |
| 목소리 | 남=낭독, 여=판정관 | 남=내 카톡+해설, 여=상대 카톡(무심한 톤)+판독관 |
| 끝 | 판 정 소 배지 → 도장(레전드/유죄 등) | 카톡 판독소 배지 → 그린라이트(초록)/레드라이트(빨강) 도장 |
| CTA | "당신이 목격자라면?" | "당신이 받은 최악의 답장은? 댓글로 판독해 드립니다" |

공통 연출: 0~0.35초 **표지 프레임**(초대형 3줄 문구 + 기울어진 주인공 + 배지) → 후크 → 본문 → 판정 → CTA(첫 질문과 이어져 반복 시청). 진행바, 장면마다 펀치줌+whoosh.

### 테마 (주제에 맞게 매번 바꿈) — `script.json "theme"`
| 테마 | 언제 | 배경 / 강조색 / 후크 폰트 |
|---|---|---|
| office | 직장·블라인드 | 네이비 그리드 / 노랑 / Black Han Sans |
| money | 돈·연봉·데이트 비용 | 검정→금색 사선 / 골드 / Gasoek One |
| cheat | 바람·환승·전애인 | 검붉은 비네트 / 핫핑크레드 / Black Han Sans |
| sweet | 설렘·호감·그린라이트 | 핑크 하트 / 진핑크(진한 글씨+흰 외곽) / Jua |
| cold | 읽씹·식은 마음·이별 | 차가운 남색 도트 / 시안 / Do Hyeon |
| night | 새벽 연락·스킨십 직전(수위 주의) | 보라 도트 / 네온핑크 / Black Han Sans |
시인성: 후크·자막은 흰 글씨+검정 외곽 10px(밝은 테마는 반대), 강조색은 키워드에만 1개.

### 쇼츠 문구 공식
- **후크(상단 고정 2줄)**: `[대상]가 [구체 행동]하면` + `[단정 결론]` — 예) "소개팅녀가 *이렇게* 답하면 / 이미 끝난 겁니다"
- **표지(cover 3줄)**: 6~8자씩, 둘째/셋째 줄에 강조색. 숫자·인용(“넵ㅎㅎ”)·금기어를 앞에.
- **첫 대사 2초 이내**, 질문 또는 단정. 총 25~40초.
- 금지어(바람/불륜/섹스 등)는 자막에만(필요 시 초성), 음성은 돌려 말하기.

## 3. 롱폼 — '연애 공략 지도' 고정 포맷 (채널 정체성, 주제가 바뀌어도 배경·폰트 유지)
- 구조: 꽁트 후크 2컷 → 타이틀 카드 → 지도 전체 → 4구역(구역마다 여자 속마음 꽁트, 실전 시뮬레이션 꽁트 1~2개) → 정리 → 다음 편 예고. 3~5분.
- 목소리: 여의도남자 `voice_speed_by: {"여의도남자": 1.08}` (AI 느낌 감소, 현철님 피드백), 여자는 1.0 + instruct 감정 지시.
- **썸네일 고정 포맷**(`thumbnail.lines`): 흰 지도 배경 + 왼쪽 검은 박스(작은 '연애 공략' 라벨 + 2줄 초대형, 둘째 줄 주황) + 오른쪽 놀란 콩 + 빨간 화살표 + X친 소품 아이콘. 한 줄 7자 이내.
- **썸네일 박스를 영상에도 붙인다**(현철님 지시): 맨 앞 0.6초(`cover_sec`) = 썸네일 그대로, 타이틀 카드 = 같은 검은 박스·같은 문구. `lead_in`은 cover_sec+0.15.
- **제목 공식**: `[구체 숫자/상황] + [결과/반전] + (괄호 호기심)` 예) "첫 데이트에 25만 원 쓰고 차인 남자의 실수 (여자 속마음 공개)". 45자 안팎.

## 4. 업로드 카피 (`output/<프로젝트>/upload.txt` — 복붙용, 자동 생성)
- 제목: 위 공식. 쇼츠 40자 안팎, 롱폼 45자 안팎(60자 초과 시 경고).
- 설명: 2줄 요약(핵심 갈등 + 댓글 유도) — 롱폼은 챕터 자동 삽입.
- 해시태그: **정확히 3개** (주제 1 + 상황 1 + 장르 1). 예) #읽씹 #소개팅 #연애심리
- 추천 예약 시간(KST, 첫 가설 → 2~3주 뒤 스튜디오 시청 시간대로 조정): 쇼츠 12:30·19:30, 롱폼 21:00.

## 5. 제작 명령
```bash
cd shorts-studio
python tools/plan.py                                   # 다음 컨셉·주제
python make.py projects/<프로젝트> --voice voicebox      # PC Voicebox
python make.py projects/<프로젝트> --voice cloud --tts-python <venv>/bin/python --models <모델폴더>
python make.py projects/<프로젝트> --frames 1,5,20       # 빠른 프레임 확인
# 결과: output/<프로젝트>/video.mp4, thumbnail.jpg, upload.txt, upload.json  (history 자동 기록)
```
- 클라우드 TTS: `pip install qwen-tts soundfile faster-whisper` + HF `Qwen/Qwen3-TTS-12Hz-1.7B-{Base,CustomVoice,VoiceDesign}`.
- 대본 작성 팁: 'ㅎㅎ·ㅋㅋ·ㅠㅠ'는 음성에서 빼거나 "흐흐"로. 문장 첫 단어가 "답장/대기업"처럼 받침+격음이면 TTS가 뭉갬 → 앞에 "이/그" 한 글자 붙이기.

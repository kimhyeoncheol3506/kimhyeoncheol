# Real-ESRGAN 화질 키우기

```bash
python .claude/skills/upscale-esrgan/scripts/upscale.py <입력> <출력> [--model x4plus|general] [--scale 2|4]
```
- 입력이 폴더면 안의 이미지를 모두, `--video`를 붙이면 영상을 프레임 단위로 키운다.
- 가중치(공식 xinntao/Real-ESRGAN 릴리스)는 처음 실행 때 `models/`에 자동으로 받는다(저장소에는 넣지 않음).
- 로더는 `spandrel`(가중치만 안전하게 읽음). 공식 `realesrgan` 파이썬 패키지는 최신 torchvision과 호환이 깨져 쓰지 않는다.

| 모델 | 용도 | 클라우드 CPU 속도(960×1485 → 4배) |
|---|---|---|
| `x4plus` (기본) | 옛 그림·사진·인쇄물. 질감을 가장 잘 살림 | 약 4분 15초 |
| `general` | 빠른 범용, 그래픽·스크린샷 | 약 23초 |

## 언제 쓰나
- 위키미디어에서 받은 그림이 **긴 변 1280px 미만**이면 B-roll·썸네일에 넣기 전에 키운다(`--scale 2`면 충분한 경우가 많다).
- 썸네일 배경 사진은 2배 이상 키운 뒤 1280×720로 자른다.
- 영상 업스케일(`--video`)은 CPU에서 너무 느리다(1080p 한 프레임 수십 초). **PC의 GPU**에서 `--device cuda`로 돌리거나, 공식 `realesrgan-ncnn-vulkan` 실행 파일을 쓴다.

## 주의
- 얼굴·글자는 없는 디테일을 지어낼 수 있다. 실존 인물 사진은 키운 뒤 원본과 나란히 보고 얼굴이 바뀌지 않았는지 확인한다.
- 화질을 키워도 저작권은 그대로다. 퍼블릭 도메인·직접 만든 이미지에만 쓴다.
- 결과는 원본 옆 비교 크롭(바이큐빅 vs ESRGAN)으로 확인한다(ffmpeg-edit).

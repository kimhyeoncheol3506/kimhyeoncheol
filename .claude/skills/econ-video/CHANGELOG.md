# econ-video 변경 기록

스킬(`SKILL.md`의 version)과 엔진(`video-studio/VERSION`)은 같은 번호를 쓴다.
- 앞자리(major): 작업 절차나 project.json 형식이 바뀌어 예전 프로젝트가 그대로 동작하지 않을 때
- 가운데(minor): 장면 타입·아이콘·레이아웃 등 기능 추가
- 끝자리(patch): 오류 수정·디자인 미세 조정

# econ-video 변경 기록

스킬(`SKILL.md`의 version)과 엔진(`video-studio/VERSION`)은 같은 번호를 쓴다.
- 앞자리(major): 작업 절차나 project.json 형식이 바뀌어 예전 프로젝트가 그대로 동작하지 않을 때
- 가운데(minor): 장면 타입·아이콘·레이아웃 등 기능 추가
- 끝자리(patch): 오류 수정·디자인 미세 조정

## v1.3.0 — 2026-10-12
- 리뷰: "저작권 문제 없게 캐릭터·썸네일 바꿔 줘 / 정장 말고 비즈니스 캐주얼, 썸네일 배경도 교체"
- 마스코트 전면 교체: '여의도 개미'(캐러멜 얼굴·더듬이) + 비즈니스 캐주얼(셔츠+가디건, 넥타이 없음)
- 썸네일: split 레이아웃(큰 숫자 패널) + office 배경, 오해 소지 손동작 제거(만세 포즈)
- 썸네일 money_rain(돈비) 옵션, 강조형 돈주머니 글씨
- 콘텐츠: 미국 동일 주제 벤치마킹 + 98년 실데이터 백테스트(`tools/sp500_backtest.py`)

## v1.1.0 — 2026-10-12
- 리뷰: "연애 듀토리얼 세션 결과에 여의도남자·여의도여자 보이스가 있으니 그거 쓰면 돼"
- 클라우드 목소리 엔진 추가: Qwen3-TTS 직접 구동(`voice/qwen_cloud.py`, `setup_cloud.sh`) — Voicebox와 같은 엔진, 연애 튜토리얼 스튜디오와 **같은 여의도남자 기준음성**(`assets/voices/`)
- `--voice auto|voicebox|cloud` (auto = PC Voicebox 우선, 없으면 클라우드) → PC 없이 모바일 스샷만으로 완성본 가능
- 발음 교정기(`voice/pronounce.py`, 연애 스튜디오에서 이식) + 경제 용어 확장: 소수(0.25→영 점 이오), %p, 개월, ETF·COFIX·DSR·ISA·IRP·S&P 등
- 말 속도: 쇼츠 1.1→1.05배, 롱폼 여의도남자 1.08배 (연애 스튜디오에서 받은 현철님 피드백 반영)
- 최종 음량 loudnorm -14 LUFS (유튜브 표준)

## v1.0.0 — 2026-10-11
- 최초 버전
- 절차: 스크린샷 → 롱폼/쇼츠 질문 → 주제 조사 → 방향 예시 3개 질문 → 제작 → 영상·제목·설명란·썸네일 1세트
- 벤치마킹 3편(경제학똑똑·머니치트키·인생 녹음 중) 분석을 제작 규칙으로 정리 (STYLE_GUIDE.md)
- 쇼츠 1080x1920 / 롱폼 1920x1080 레이아웃, 장면 타입 10종, 마스코트 표정 8종·포즈 4종, 아이콘 15종
- 목소리: Voicebox 여의도남자(기본)·여의도여자(대화). 다른 TTS 대체 없음, `--preview-silent`만 예외
- 출력: video.mp4, thumbnail.png(+쇼츠 커버), title/description/tags.txt, subtitles.srt, 업로드정보.md

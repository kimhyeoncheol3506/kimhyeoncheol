# 사운드·화면 속도 규칙 (2026-11-24 업그레이드)

출처: Avery·CrazyKaomei 의 오픈소스 스킬 **Stickman Video Director**(MIT, github.com/kaomei/stickman-video-director, X 글 2026-11-22 "Make Viral Stickman Videos for $0").
그쪽 엔진(Google Flow 생성 / 코드 렌더)은 쓰지 않고, 우리 toon2d 파이프라인에 맞는 원칙과 무료 음원만 가져왔다.

## 1. 그림이 3초 넘게 그대로면 안 된다 → `tools/pace_check.py`
- 카메라 이동·줌·자막 교체는 '그림 변화'가 아니다. 인물 연기(표정·자세·소품·이동)나 장면 전환만 센다.
- **첫 3초 안에 눈에 보이는 그림 변화 1번 이상**(예: 놀란 표정 → 분노, 칼을 드는 자세, 팻말 등장). 제목·카메라만 움직이는 훅은 실패.
- 같은 그림 상태 최대 3초. 넘으면 그 문장의 단어에 act 추가(표정 변화, 고개 돌리기 `dir`, 소품 `hold`, 걸어 들어오기 `x`).
- 예외: `calm: true` 장면(설명·여운)은 경고만. 그래도 4초는 넘기지 않는다.
- 지도 장면(`map_table*`)은 인물이 없어 늘 걸린다 → 지도는 한 문장(3초) 안으로 짧게 쓰거나, 지도를 들고 있는 선비 장면으로 바꾼다.
- 순서: `plan` → **`pace_check.py`** → 고치기 → `stills`.

## 2. 대사가 말하는 사건은 들려야 한다 → `tools/sfx_bgm.py`
- "칼끝을 돌려", "보이는 대로 베라", "성문", "말머리를 돌립니다", "판결은?"처럼 사건을 말하면 그 소리를 넣는다(칼바람+타격, 성문, 말발굽, 판결봉).
- 효과음은 꼭 필요한 곳만: 한 문장에 하나, 최소 2.6초 간격. 매 문장 '쾅'은 오히려 감정을 죽인다.
- **배경음(bed)은 장면마다 아주 작게 계속**: 위화도 밤 = 빗소리, 야외 = 바람/새, 실내 밤 = 등잔불(장작 소리). 지도 장면은 없음.
- **첫 프레임부터 소리**(내레이션·배경음). 무음 인트로, 긴 페이드인 금지.
- 음악은 분위기로 전환: night/day/interior = 긴장곡(T_), golden/sunset/dawn/dream = 여운곡(S_). 내레이션이 나오면 자동으로 내려가고(사이드체인 덕킹) 쉼에서 올라온다.
- 판결 장면의 판결봉(gavel) 2타, 반전 번호("첫째/둘째")의 종소리는 채널 시그니처로 쓴다.
- 자동 스팟팅 결과는 `sfx_plan.json` 에 저장된다. 이상하면(예: "돌아온 건 환관"에 함성) 그 줄을 지우거나 바꾸고 `--plan sfx_plan.json` 으로 다시 믹스.
- 결과: `final_sfx.mp4` + `audio_credits.txt`. **업로드 TXT 설명 끝에 audio_credits.txt 내용을 붙인다**(Kevin MacLeod 곡·말발굽은 CC BY, 표기 필수).

## 3. 풀 렌더 전에 20초 미리보기 → `tools/preview.py`
- 대본 + 앞 20초(540x960, 자막·음성 포함)를 먼저 사용자에게 보여주고 OK 받은 뒤 풀 렌더. 4코어 기준 20초 미리보기 ≈ 20초.
- 첫 3초 훅, 목소리 톤, 자막 위치, 사운드 크기를 여기서 잡는다. 풀 렌더 후 고치면 몇 분씩 다시 걸린다.
- 사용자가 "기다리지 말고 끝까지"라고 하면 미리보기를 만들어 보여 주기만 하고 바로 풀 렌더로 넘어간다.

## 4. 사실을 팻말로 다시 쓰지 않는다
- 그림이 이미 보여주는 것(장소·옷·행동)을 팻말로 또 쓰지 않는다. "6월 1일", "위화도" 같은 반복 팻말은 줄이고,
  팻말은 **사료 이름(태조실록·고려사), 결정적 숫자(수백 명), 직접 인용("베어라"), 판결 질문**에만.
- 같은 템플릿 팻말을 장면마다 반복하면 양산형으로 보인다.

| 파일 | 용도 |
|---|---|
| music/T_decisions, T_five-armies, T_temple-of-the-manes | 긴장(궁중 암투, 전쟁, 음모) |
| music/S_heartbreaking, S_teller-of-the-tales | 여운(최후, 판결, 클리프행어) |
| sfx/swish_sword_1·2, hit_heavy | 칼, 처형, "베라" |
| sfx/horse_gallop_ground·grass | 말발굽, 회군, 기병 |
| sfx/door_wood, gavel_wood, thud_soft, bell_heavy, metal_heavy | 성문, 판결봉, 왕명, 반전 종 |
| sfx/splash, bed_water_loop, bed_rain_loop | 강·여울·장마 |
| sfx/crowd_shouting, bed_outdoor_loop, bed_fire, step_grass·wood | 함성, 야외, 실내 밤, 발소리 |
- 새 음원은 사용자가 준 것 또는 라이선스가 확인된 무료 음원만. 임의로 내려받지 않는다.
- 국악풍 곡(해금·대금·북)은 라이브러리에 없다. 원하면 사용자가 라이선스 있는 음원을 `audio/music/T_*.mp3`·`S_*.mp3` 이름으로 넣으면 자동으로 쓰인다.

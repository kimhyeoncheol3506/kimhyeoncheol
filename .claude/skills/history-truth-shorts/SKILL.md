# 《역사, 그날의 진실》 한국사 카툰 쇼츠

부제: 우리가 몰랐던 권력과 배신, 전쟁과 인간의 이야기.
원칙: 인물의 일대기가 아니라 **그 인생에서 가장 극적인 하루, 선택 하나**를 보여준다. 시청자가 "다음 편도 봐야겠다"고 느끼게 만드는 것이 목표.
그림 엔진: `../mystery-cartoon/kits/toon2d` (C타입 2D 카툰, 한국사 팩 포함). 애니메이션 스타일은 사용자가 만족한 상태 → 바꾸지 말 것.

## 1. 5가지 감정 (모든 편에 최소 4개, 논쟁형은 5개 전부)
| 감정 | 시청자 속마음 | 대본에서 만드는 법 |
|---|---|---|
| 분노 | 도대체 누가 이런 짓을? | 가해자 **이름**, 피해 **숫자**, 구체적 **장면**. "제도", "권력" 같은 추상명사 금지 |
| 배신감 | 우리가 알던 사실이 틀렸다고? | 교과서/통념 vs 사료 차이. **근거가 확실한 것만**(사료명 명시). 억지 반전 금지 |
| 호기심 | 그래서 결국 어떻게 됐는데? | 결과를 먼저 던지고 과정을 숨김. 20~30초마다 재훅("그런데 기록에는 이상한 문장이 있다") |
| 통쾌함 | 약자가 권력자를 이겼다고? | 약자(병사·백성·하급자)의 반격 장면을 이야기체로. "어떻게 이겼나" 해설문 금지 |
| 논쟁 | 저 사람은 영웅인가, 악인인가? | **법정 구조**: 양쪽 근거를 대등하게(각 20~30초) 보여주고 마지막에 "당신의 판결은?" |
대본 작성 후 반드시 **감정 체크표**(문장 번호 → 감정)를 만들어 사용자에게 보여준다. 빠진 감정이 있으면 고쳐 쓴다.

### 1-1. 감정이 '느껴지게' 쓰는 법 (2026-11-21 사용자 피드백: 연대기식 대본은 감정이 전혀 안 느껴지고 다음 화가 기대 안 됨)
감정 이름을 붙이는 것만으로는 안 된다. 실패한 대본은 사실을 시간순으로 나열하고 감정표에만 '분노', '배신감'을 적었다. 다음 규칙을 지킨다.
1. **결말(가장 비극적인 장면)부터 연다.** 시간순 금지. 예: "1388년 겨울, 일흔세 살 노장군의 목이 베였습니다. 그를 무너뜨린 건 적이 아니었습니다." → 바로 "도대체 무슨 일이?"로 되감기.
2. **사람 대 사람 구도.** 제도·국가가 아니라 이름 있는 두 사람(최영 vs 이성계)의 관계(함께 싸운 선후배, 스승과 제자, 부자)로 만든다. 관계가 깊을수록 배신이 아프다.
3. **통념을 무기로.** 시청자가 이미 아는 이미지("황금 보기를 돌같이", "4불가론의 지혜로운 장군")를 먼저 꺼내고 그것을 뒤집는다. 배신감은 '모르는 사실'이 아니라 '알던 사실이 다른 얼굴을 가졌다'에서 나온다.
4. **명령·대사를 직접 인용.** "보이는 대로, 베라." "다른 말은, 듣지 마소서." "잘 가십시오, 잘 가십시오." 짧은 직접 인용이 분노와 통쾌함을 만든다(사료에 있는 말만).
5. **통쾌함은 '같은 사람'의 역전.** 베라던 왕 앞에 바로 그 병사들이 돌아온다. 약자가 당하던 장면을 앞에 깔고, 같은 인물·같은 단어로 되돌려준다(콜백).
6. **반전은 두 개, 번호를 붙여서.** "진짜 반전은 여기서부터입니다. 첫째… 둘째…" 하나는 사건의 허무(전쟁의 이유가 실제로는…), 하나는 기록의 출처(그 기록을 쓴 건 승자/그의 아들).
7. **판결은 두 인물 모두.** 한 사람만 재판하지 말고 양쪽을 각각 "A인가, B인가"로 묻는다.
8. **다음 화 클리프행어 필수(사용자 요구).** 이번 편 결말을 완성한 뒤 마지막 2~3문장으로 다음 회 사건의 결과만 던지고 원인은 숨긴다. 예: "사 년 뒤, 고려의 마지막 충신이 길 위에서 쓰러집니다. 그 죽음을 지시한 건, 이성계의 아들이었습니다." → 다음 회차 주제와 이어지게 회차 순서를 짠다.
9. 문장은 짧게(한 줄 25자 안팎), 3~4문장마다 질문이나 반전 신호("그런데", "그리고 아무도 예상 못 한").
11. **연수는 항상 한자어 + 숫자 '년'(사용자 규칙, 2026-11-22).** '열네 해', '두 해', '예순네 해'처럼 고유어 숫자 + '해' 금지 → '14년', '2년', '64년'으로 쓴다(내레이션은 십사 년, 이 년으로 읽힘). '그해', '이듬해'는 괜찮다.
10. 전설·전승은 감정 효과가 크면 써도 되지만 반드시 "~라는 전설이 있습니다/전해집니다"로 표시.
모범 예시: `examples/wihwado_truth_v2_script.txt` (이 규칙으로 다시 쓴 위화도 편).

### 1-2. '숨은 정체 → 마지막 공개' 포맷 (2026-11-22, 채널 사람이만든역사 48편 · 하루한줄 48편 분석)
- 사람이만든역사(최고 80만회, 평균 70~90초): 첫 문장 = "[기묘한 행동/물건]으로 [놀라운 결과]를 만든 [익명: 관리·노인·사내·외교관]가 있습니다." → 연도·장소 + 위기를 감각적으로(숫자·몸의 디테일) → 주인공은 역할로만 부름 → 기묘한 행동을 구체적으로 → 짧은 직접 인용 → 결과를 숫자로 → 별칭을 쌍아 올리다 마지막 줄 "…[이름]이었습니다." 제목도 이름을 숨기고 '기묘한 행동 + 결과 + 미친/충격 정체'.
- 편집: 2.5~3초마다 캷 전환, 문장이 말하는 대상을 그대로 보여줌, 자막 핵심어는 색(노랑=숫자·이름·핵심 명사, 빨강=분노·잔혹). 엔진: storyboard 최상위 "highlight": [...], "highlight_red": [...] (부분 문자열 일치). 내레이션은 빠르게(약 5음절/초, TARGET으로 1.2~1.3배).
- 하루한줄: 장소·물건을 주인공으로(고개, 문짝으로 만든 거문고, 샘, 성). 지금 남아 있는 흔적(구멍 세 개, 비석, 소나무)에서 시작해 그 흔적이 본 사건을 풀고, '지금 여기에 있다'로 끝낸다. 장소 편도 이름은 마지막에 공개(예: 32_삼전도비, 33_청령포 대본 = examples 참고).
- 썸네일: 인물/장소 이름만(다른 문구 금지). 위 흰 띠 + 검은 굵은 글씨, 아래 흑백 세피아 장면, 둥근 테두리 (tools/thumb_name.py).
- BGM: 장면 mood 따라 긴장곡/슬픈곡 전환 + 내레이션 덕킹 (tools/bgm_mix.py, 음원은 YouTube 오디오 보관함에서 받아 music/T_*.mp3, S_*.mp3).

## 2. 길이와 구성
- A형 50~70초(단일 사건·통념 뒤집기·통쾌함), B형 90~120초(분노·비극), C형 150~180초(논쟁 법정형). 사용자가 길이를 지정하면 그것을 따른다.
- C형(3분) 시간표(초):
  - 0~3 가장 충격적인 장면/숫자 (분노·호기심). 인물 소개로 시작 금지
  - 3~20 상황 설정: 누가 무엇을 잃게 되는가 (호기심)
  - 20~25 재훅 1: "그런데 기록에는…" (배신감)
  - 25~70 갈등 확대, 가해자와 피해자 구체화 (분노)
  - 70~75 재훅 2: 반전 예고 (호기심)
  - 75~130 약자의 반격 또는 선택의 대가 (통쾌함/비극)
  - 130~160 평가가 갈리는 지점, 양쪽 근거 (논쟁)
  - 160~180 결말 한 줄 + "당신이라면?" (논쟁/댓글)
- 3~5초마다 화면에 새 정보(새 장면·팻말·지도·숫자). 내레이션은 설명문이 아닌 이야기체. 이번 편 결말을 먼저 완성한 뒤, 마지막 2~3문장은 다음 회 클리프행어(1-1의 8번).
- 한국어 내레이션 속도: 여의도여자 ≈ 4.3음절/초(문장 사이 쉼 포함). 160초 ≈ 690~720음절.

## 3. 사실 검증 (게시 전 필수)
- 모든 사실 문장에 출처를 붙인 **팩트 시트**(문장 → 사료/근거 → 정설/설/전승 구분)를 대본과 함께 만든다. 사료 우선순위: 국사편찬위원회 한국사데이터베이스(삼국사기·고려사 등), 조선왕조실록(sillok.history.go.kr), 우리역사넷.
- 숫자는 사료마다 다르면 범위/"~여"로(예: 명량 적선 130여 척). 회고 증언은 "회고에 따르면".
- 입증 안 된 설(독살설 등)은 "~설"로만. "진짜 이유" 같은 단정 제목 금지.
- 법적 선(형법 308조 사자명예훼손, 대법원 2007도8411): 고인에 대한 **구체적 허위 사실**을 사실처럼 말하지 않는다. 범죄·사생활·비하를 지어내지 않는다. 각색/가상 장면은 화면과 설명에 표시. 1945년 이후 현대사·5·18은 자극적 반전 포맷 금지(증언·공식 기록 중심). 매국 행위처럼 법적으로 정리된 사안을 "영웅이냐" 논쟁으로 만들지 않는다.
- 공개 업로드는 사용자가 직접 명령/승인할 때만. 주기 표현(매주, 주기적으로 등) 문구 금지.

## 4. 제작 순서
1. 주제/길이 확정(사용자가 지정 안 했으면 후보를 객관식으로 제시).
2. 대본(script.txt, 한 줄=한 문장) + 감정 체크표 + 팩트 시트 → 사용자에게 요약 보고.
3. 음성: PC는 `tools/make_voice_pc.py`(Voicebox 여의도여자, `TARGET=초` 환경변수), 클라우드는 `tools/cloud_voice.py`(edge-tts). 둘 다 voice.wav + timings.json.
4. storyboard.json 작성(아래 5) → `python t2d.py words P --from timings.json --force` → end_pad = 목표길이 − 음성길이(가능하면 ≤2초, 남으면 대본에 결말 문장 추가가 낫다) → `plan` → `stills` 눈으로 검사 → `render P --workers N --budget 500`(DONE까지 반복) → `join` → `check`.
5. 1fps 콘택트 시트로 검은 화면·멈춤·얼굴 잘림 확인.
6. 썸네일: `tools/nocap.py P 초,초` 로 자막 없는 프레임 → `tools/thumb.py 원본 출력 "줄1|*강조줄|줄3" "그날의 진실"`.
7. 업로드 TXT: 제목(사건·갈등 중심, 인물 소개형 금지) / 설명(실제 역사 요약 + 참고 사료 + 각색 표시) / 해시태그 / 고정댓글(판결·추론 유도).

## 5. toon2d 한국사 팩 (스토리보드 작성 규칙)
엔진 문법은 `../mystery-cartoon/kits/toon2d/SKILL.md`, `docs/LIBRARY.md`. 예시: `examples/*_storyboard.json`(이전 '역사 IF' 버전 위화도·김춘추).
- 캐릭터(type): `jking`(익선관·곤룡포), `official`(청 단령·사모), `official_red`, `scholar`(갓·도포·붓), `general`(투구·두정갑·칼), `soldier`(전립·창), `peasant`(상투), `enemy`(진가사·창), `tang`(당 투구), `queen`, `youth`(댕기머리). 덮어쓰기: `torso`, `accent`, `hat`, `hair`, `beard`.
- 세트(set): 실내 `palace_hall`(어좌 540,1100 / 일월오봉도 540,780), `study_room`(서안 460,1310 / 등잔 690,1020), `map_table`(삼국시대 지도), `map_table_late`(고려·조선 지도), `gate_court`(궁궐 마당). 야외 `river_camp`(위화도 군영·압록강), `mountain_pass`(고갯길·목책), `sea_battle`(판옥선 갑판·거북선), `fortress_wall`(성벽·문루·봉수대 170,700), `village_road`(초가 마을).
- 지도 좌표(두 지도 공통): 요동 360,600 / 국내성 600,650 / 백두산 690,600 / 위화도·압록강 하구 450,735 / 평양 505,860 / 개경 520,990 / 강화 488,1015 / 한양 545,1040 / 탄현 590,1150 / 사비 525,1170 / 기벌포 488,1180 / 대야성 640,1240 / 경주 745,1245 / 부산 760,1340 / 한산도 700,1385 / 대마도 800,1450. 전체 [600,1060,900], 압록강 [460,740,500], 남해안 [700,1360,600]. map_table_late 는 반도에 '조선' 라벨이 있으므로 고려 시대에는 라벨이 크게 안 잡히게 프레이밍.
- 배치 요령(실측):
  - 사람 간격 x 240 / 540 / 840 (사모 날개·익선관이 넓어서 300 이하로 붙이면 겹침).
  - study_room 은 x ≤ 760, village_road 는 x 300~680 (앞쪽 흐린 기둥·감나무).
  - 투구·사모·당투구는 `:face` 대신 `"<id>"` 또는 [cx,cy,h] 로(깃털이 잘림). 창은 항상 수직이라 창병은 stand/hold/walk.
- 소품: `sign:텍스트`, `tag:텍스트`는 **8자 이하**(길면 화면 밖으로 잘림), 들고 있는 인물은 `"dir": 1`(왼쪽을 보면 글자가 좌우 반전됨). `newspaper:` 금지(영문 GAZETTE 가 찍힘).
- 빛 = 막 구조: 사실·설정 day/interior → 긴장 night → 핵심 반전 golden → (각색·가상 장면은 dream) → 결말 sunset/dawn. 장면 전환 10~16회.

# 네이버블로그 예약 자동업로드 (카테고리별 5편)

- 이미 예약된 글의 시간을 바꿀 때: `예약 발행 n건` 목록에서 글 클릭 → 에디터에 열림 → 발행 → 날짜/시·분 변경 → 발행(같은 글이 수정되며 중복 생성 안 됨). 코드: references/uploader.md의 retimeNaver.

## 3. 업로드 (검증된 방법, 2026-11-04)
`references/uploader.md`의 REPL 코드를 그대로 붙여 쓰고 글마다 `await naverSchedule(post)` 1회(약 70초, REPL 120초 제한 때문에 한 호출에 1편).
핵심 원리:
- 에디터는 `#mainFrame` 안 SmartEditor ONE. 로케이터는 `page.frameLocator('#mainFrame')`, 평가는 이름이 mainFrame인 최신 프레임(오래된 프레임이 수백 개 남으므로 뒤에서부터 찾기).
- 붙여넣기: 키 입력 대신 포커스된 `input_buffer*` iframe에 합성 `ClipboardEvent('paste')`(DataTransfer `text/html`)를 보낸다. 시스템 클립보드를 쓰지 않아 다른 에이전트와 충돌 없음. `<blockquote>`→인용구, `<table>`→표, `<hr>`→구분선, 색·형광·글자크기·가운데정렬 유지.
- 그림: 같은 방식으로 DataTransfer에 PNG File을 넣어 paste → 자동 업로드.
- 순서: 본문 첫 문단 클릭 1번 → [텍스트 덩어리 paste → 그림 paste]를 순서대로, 중간에 클릭하지 않는다(커서가 자동으로 끝에 있음). 마커를 먼저 넣고 지우는 방식은 다른 그림을 지우는 사고가 있어 쓰지 않는다.
- 검증 후에만 발행: 그림 수 = images 수, `@@IMG` 0개, 텍스트 덩어리 순서 확인. 실패하면 발행하지 않는다.
- 발행 창: 카테고리 버튼 → 카테고리명 button 클릭 / 태그는 특수문자 제거 후 insertText+Enter(특수문자 있으면 다음 태그와 붙어버림) / `label "예약"` → 날짜 textbox 클릭 → 날짜 button → 시·분 combobox selectOption(분은 10분 단위) → 창 안 마지막 "발행".
- 확인: 글쓰기 화면 `예약 발행 n건` 목록에 제목·시각이 보이면 성공. 잘못 올라간 글은 목록에서 hover → "삭제"(확인창 없이 바로 삭제됨, 주의).

# 쇼츠 업로딩 (하하크크하하)

## 최우선 규칙: 같은 영상 중복 업로드 절대 금지

- 올리기 전에 반드시 두 가지를 확인한다. 하나라도 걸리면 그 영상은 건너뛴다.
  1. `Downloads\어랏\업로딩 완료`에 같은 이름의 mp4가 있다.
  2. 업로드 기록부 `Downloads\어랏\uploaded.json`에 있거나, 채널(YouTube Studio 콘텐츠 목록, 또는 youtube.com/@zzggzz123/shorts)에 같은 제목이 이미 있다.
- 업로드가 끝나면(게시 완료 화면 확인) 즉시 uploaded.json에 {파일명, 제목, 영상 URL, 시각}을 추가한다. 그다음 파일 3종을 업로딩 완료로 옮긴다. 순서를 지켜서 중간에 끊겨도 다시 올리지 않게 한다.
- 업로드 중 오류가 나서 결과가 애매하면 바로 다시 올리지 말고 Studio 콘텐츠 목록을 먼저 확인한다(처리 중인 영상이 있을 수 있다).

## 문구 (TXT에서 '색칠한 부분'만)

- 제목: TXT의 [제목]에서 `#shorts`를 뺀 것.
- 설명: [설명]의 첫 두 줄(소개 + "OO 편: ...") + 빈 줄 + ※ 저작권 고지 2줄(…구독과 좋아요는 큰 힘이 됩니다ㅋㅋ) + 빈 줄 + [해시태그] 한 줄. ▶ 순서 타임라인과 ▶ 원본 출처는 넣지 않는다.
- TXT 파일명은 영상명에서 공백을 뺀 것이다(탁재훈 1.mp4 ↔ 탁재훈1.TXT, 썸네일 탁재훈 1.jpg).

## 동작 방법 (2026-11-07 검증)

- 계정: 브라우저 기본 채널이 꼬인다연애일 수 있다. YouTube 아바타 → 계정 전환 → "하하크크하하 @zzggzz123"을 고른다. Studio 주소는 studio.youtube.com/channel/UCF3Fzw2TUT9Y9EdyBgcShQg이다.
- 파일은 세션 tmp로 복사해서 고른다(다운로드 폴더를 직접 지정하면 업로드 창이 거부한다). #upload-icon → #select-files-button.
- 제목·설명은 입력한 뒤 두 칸의 innerText를 다시 읽어 원문과 같은지 확인한다. 설명이 제목 칸에 들어간 적이 있다. 썸네일 업로드 뒤에 한 번 더 확인한다.
- 썸네일은 세부정보의 "파일 업로드"(#select-button)로 이름 N.jpg를 올린다. 아동용은 VIDEO_MADE_FOR_KIDS_NOT_MFK를 고른다.
- 즉시 공개는 다음 ×3 → PUBLIC → #done-button이다. 성공 화면은 "게시된 동영상" 또는 "동영상 처리 중"(SD 처리 후 자동 공개)이다.
- 예약은 공개 상태 화면의 "예약" 카드를 펼친다(Click to expand). 날짜는 #datepicker-trigger("2026. 11. 8."), 시간은 #time-of-day-container input("오전 6:00")이고, 시간대는 현지 시간(GMT+9)이다. 성공 화면은 "동영상 예약됨" 또는 "동영상 처리 중 … 11월 8일 13:00에 공개"(오후는 24시간제)다. 확인이 안 되면 다시 올리지 말고, 콘텐츠 목록에서 그 제목의 영상 편집 화면 → 공개 상태에서 예약 시간을 확인한다.
- "지금부터 1시간 이후로 매 1시간"이면 get_time으로 현재 시각을 확인하고, +1시간을 다음 30분 단위로 올린 시각부터 1시간 간격으로 잡는다(예: 10:19 → 11:30, 12:30 …).
- 예약을 확인할 때 콘텐츠 목록은 예약 날짜 순이라 늦게 예약된 것이 위에 오고, 한 페이지는 30개다. 제목이 안 보이면 #navigate-after로 다음 페이지까지 찾고, 없다고 판단하기 전에 다시 올리지 않는다.
- 사용자가 "예약으로, 아침 6시부터 한 시간에 하나"라고 하면 06:00부터 1시간 간격으로 예약한다. uploaded.json에 schedule도 기록한다. 다음에 이어서 예약할 때는 기록의 마지막 schedule 다음 시간부터 시작한다.

## 순서와 설정

- 사용자가 지정한 인물부터 번호순으로 올리고, 나머지는 랜덤으로 올린다.
- 공개 상태는 즉시 공개(공개)로 한다. 아동용이 아님으로 두고, 나머지는 기본값을 쓴다.
- 하루 업로드 한도 메시지("일일 업로드 한도" 등)가 나오면 멈추고, 남은 영상 목록을 보고한다.
- 채널 확인: Studio 왼쪽 위 채널 이름이 하하크크하하인지 매번 확인한다. 다른 채널(꼬인다연애 등)이면 계정을 전환한다.
- 업로드가 끝나면 이름 N.mp4, 이름N.TXT, 이름 N.jpg를 `Downloads\어랏\업로딩 완료`로 옮긴다.
